Web API面试题

Web API 面试题，涵盖 Fetch 流式读取、AbortController、Web Components、文件预览、Clipboard API、WebRTC、WebAssembly 与 DOM 观察器。共 18 道题。

  • AbortController 能取消什么，不能取消什么？

    AbortController 通过 signal 向支持它的 API 传递取消信号，例如 fetch、部分流操作与事件监听清理。它不是能强制终止任意 JavaScript 函数的机制，普通 Promise 也不会因为外部创建了 co…

  • Custom Elements、Shadow DOM 和 template 分别负责什么？

    Custom Elements 定义可复用的自定义元素及生命周期；Shadow DOM 提供组件内部 DOM 和样式的封装边界；template 保存尚未直接渲染的片段，slot 用于内容分发。这些技术可以组合，也可以分别使用。

  • File、Blob 和 object URL 怎样用于文件预览？

    Blob 表示不可变的原始数据，File 在其基础上提供文件名等信息。页面通常通过用户选择或拖放获得文件，再用 FileReader、流或 object URL 等方式处理，不能任意读取用户磁盘上的所有文件。

  • 怎样正确消费 Fetch 返回的 ReadableStream？

    响应的 body 可以是 ReadableStream，通过 reader.read 逐块获取 value 和 done，或在支持的环境中使用异步迭代。取得 reader 会锁定流，因此不能同时让另一消费者随意读取同一响应体。

  • Permissions.query 是申请权限，还是查询权限？

    Permissions.query 查询当前上下文对某项能力的权限状态，常见结果是 granted、denied 或 prompt。它本身通常不是弹出授权框的统一申请入口，实际请求权限由相应功能 API 的流程决定。

  • 异步 Clipboard API 为什么会出现权限或用户激活错误？

    异步剪贴板 API 需要安全上下文，读取和写入还可能受到权限、用户激活和浏览器策略限制。不同浏览器的具体要求并不完全一致，不能用某个浏览器的一次成功推断所有环境。

  • AudioContext 与音频节点图怎样组织音频处理？

    Web Audio 使用音频节点图表达音源、处理与输出之间的连接。AudioContext 管理相关音频处理环境，音源可以经过增益、滤波等节点后连接到输出，不需要把全部处理写成 JavaScript 定时循环。

  • WebRTC 为什么需要信令、STUN 和 TURN？

    建立实时连接需要交换会话信息与候选连接信息，应用通常通过独立信令通道完成交换；WebRTC 并不规定必须使用某一种业务信令协议。ICE 组织连接候选和连通性检查。

  • WebAssembly 能替代 JavaScript 吗？适合哪些工作？

    WebAssembly 提供紧凑的模块格式与可执行模型，适合把某些编译型语言的计算逻辑带到 Web，常见场景包括编解码、图像处理和已有计算库复用。它与 JavaScript 协作，不是自动替代所有页面逻辑。

  • ResizeObserver 为什么可能出现循环通知错误？

    ResizeObserver 观察元素盒尺寸的变化，适合组件尺寸由容器而非单纯窗口大小决定的场景。观察目标的内容盒、边框盒等需要按 API 选项和支持情况明确区分。

  • MutationObserver 与 ResizeObserver 的观察对象有什么区别？

    MutationObserver 观察 DOM 结构、属性或文本等变化，ResizeObserver 关注元素尺寸变化。样式或窗口变化可能改变尺寸却不直接改变被观察的 DOM 属性，因此两者不能互相替代。

    理解摄像头、麦克风权限、设备约束、MediaStreamTrack 停止和安全上下文要求。

  • WebTransport 和 WebSocket 怎样选择？

    对比 WebTransport 的多路复用、可靠与不可靠传输和 WebSocket 的成熟性，理解协议与部署边界。

  • File System Access API 的权限和文件句柄怎样管理？

    理解用户选择文件、读写句柄、权限重新确认和浏览器兼容性，避免把本地文件当成普通 URL。

  • Web App Manifest 主要描述哪些 PWA 信息？

    了解 manifest 的名称、图标、启动方式和显示模式，区分安装元数据与离线能力。

    将 Canvas 绘制移到 Worker 时，理解 transferControlToOffscreen、消息同步和兼容性边界。

  • Web Serial API 适合怎样的硬件交互？

    通过用户选择串口设备并处理读写流，理解权限、波特率、断开和浏览器支持边界。
