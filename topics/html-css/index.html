HTML / CSS面试题

HTML 与 CSS 前端基础面试题，涵盖语义化、盒模型、BFC、Flexbox、Grid、层叠与定位、响应式布局和 CSS 动画，配合示例理解页面布局与样式。共 40 道题。

  • 标准盒模型和 border-box 有什么区别？

    content-box 中 width 只是内容区宽度，border-box 中 width 包含内边距和边框；外边距在两种模式下都不计入。

  • Flexbox 和 Grid 应该如何选择？

    Flex 沿一个方向按内容大小分配空间，适合工具栏、导航这类一行或一列的排列；Grid 先定义行列轨道再放置项目，适合需要跨行跨列对齐的布局。

  • 触发操作为什么应优先使用 button，而不是可点击的 div？

    原生 button 自带按钮角色、可聚焦、Enter 和空格激活、禁用状态和表单提交行为；用 div 模拟要自己补齐这些，很容易漏。跳转页面用带 href 的 a。

  • 为什么 z-index 设置很大，元素还是被遮挡？

    z-index 只在同一个层叠上下文内比较；元素所在的父级层叠上下文排得低，子元素的 z-index 再大也越不过外面的兄弟上下文。

  • HTML 语义化对阅读、搜索与无障碍有什么价值？

    语义化是用元素表达内容的角色，例如标题、导航、列表、按钮；浏览器、读屏软件和搜索引擎据此理解结构，代码也更易维护。语义元素不能代替正确的交互和内容。

  • 表单的 name、value、label 与提交行为如何协作？

    label 给控件提供名称并扩大点击区域，name 是提交时的字段名，value 是提交的值；没有 name、被 disabled 或未选中的控件不会提交，FormData 按同样规则收集。

  • 原生表单校验能解决什么，不能解决什么？

    required、type、pattern、min/max 等约束和 Constraint Validation API 能在提交前检查格式和范围；跨字段规则、异步检查要自己补，服务端校验永远不能省。

  • script 的 async、defer 和 module 有什么区别？

    普通 script 会暂停 HTML 解析去下载和执行；defer 并行下载，在解析完成后按顺序执行；async 并行下载，下载完立即执行、不保证顺序；type="module" 默认按 defer 方式执行，并启用模块语义。

  • srcset、sizes 和 picture 怎样减少图片浪费？

    srcset 列出同一张图的多种尺寸，sizes 告诉浏览器图片在页面上显示多宽，浏览器据此挑最小够用的文件；picture 用于换格式或在不同屏幕显示不同裁切。

  • head 中哪些信息会影响页面体验与收录？

    charset 和 viewport 影响显示，title 和 description 影响搜索结果展示，canonical 和 robots 影响收录，Open Graph 影响分享卡片；每个页面都要输出与自身内容对应的值。

  • dialog 和 Popover API 应该怎样使用？

    dialog 的 showModal() 打开模态对话框，背景变为惰性、Esc 可关闭、元素进入顶层；popover 属性用于非模态浮层，自带轻量关闭和顶层显示。先判断是否要阻断背景交互，再选择。

  • 层叠、优先级、继承和 !important 谁先决定样式？

    层叠按顺序比较来源与重要性、层叠层、优先级、作用域远近和源码顺序；继承只在元素没有任何声明时提供值，不携带父元素选择器的优先级。

  • BFC 解决哪些布局问题，什么时候用 flow-root？

    BFC 是块级格式化上下文。新建 BFC 可以包住内部浮动、避开外部浮动，并阻止父子外边距折叠；display: flow-root 是专门用来创建 BFC 的写法。

  • absolute、fixed 和 sticky 的定位参照是什么？

    absolute 相对最近的定位祖先；fixed 通常相对视口，但祖先有 transform、filter 等属性时会改为相对该祖先；sticky 在最近的滚动容器里吸附，且不会超出自己的父元素。

  • flex-basis、flex-grow、flex-shrink 如何分配空间？

    flex-basis 给出项目的初始尺寸；有剩余空间时按 flex-grow 比例分配，空间不足时按 flex-shrink 乘以 flex-basis 的比例收缩；min-width 等约束最后生效。

  • Grid 的 fr、minmax、auto-fit 和 auto-fill 如何使用？

    fr 按比例分配剩余空间，minmax 给轨道设上下限，repeat 配合 auto-fill 或 auto-fit 自动决定列数；两者区别在于空轨道是保留还是折叠。

  • px、rem、em、百分比和动态视口单位怎么选？

    px 是固定的 CSS 像素；rem 相对根元素字号，适合字号和间距；em 相对当前元素字号，适合随组件字号缩放的局部尺寸；百分比的参照由属性决定；svh、lvh、dvh 区分移动端浏览器工具栏伸缩时的视口高度。

  • 媒体查询和容器查询分别适合什么场景？

    媒体查询依据视口、设备能力和用户偏好，适合页面级布局；容器尺寸查询依据祖先容器的尺寸，让同一个组件在不同位置自行调整。

  • transition、animation 和 requestAnimationFrame 怎么选？

    transition 处理两个状态之间的过渡，animation 处理关键帧过程，requestAnimationFrame 用于由 JavaScript 按时间计算每一帧。性能取决于每帧触发的是布局、绘制还是合成。

  • CSS Modules、层叠层和自定义属性怎样帮助维护样式？

    CSS Modules 在构建时生成唯一类名避免命名冲突，@layer 显式规定覆盖顺序，自定义属性传递可被继承和覆盖的设计值；三者分别处理命名、优先级和主题。

  • font-display 怎样影响字体加载期间的文字显示？

    font-display 决定 Web 字体未就绪时文字是先隐藏还是先用回退字体显示，以及字体晚到时是否还要替换；配合预加载和回退字体度量调整可以减少闪烁和布局偏移。

  • 逻辑属性为什么比固定写 left、right 更适合国际化？

    逻辑属性按行内方向（inline）和块方向（block）描述边距、尺寸和定位，会随 direction 和 writing-mode 自动映射到实际方向，同一套样式可以用于从左到右、从右到左和竖排。

  • subgrid 如何让嵌套组件对齐父网格？

    普通嵌套 Grid 自己计算轨道，和父网格互不相关；子网格写 grid-template-rows 或 columns 为 subgrid 后，直接使用父网格中自己所跨的轨道，跨组件对齐由此变得简单。

  • 网页打印样式应该怎样单独设计？

    用 @media print 隐藏导航和交互控件、展开滚动区域、改用适合纸张的字号和颜色，用 @page 设置页边距，用 break-* 控制分页位置。

  • content-visibility: auto 与移除 DOM 有什么区别？

    content-visibility: auto 让浏览器跳过屏幕外内容的布局和绘制，但 DOM、状态和可访问内容都还在；它需要配合 contain-intrinsic-size 提供占位尺寸，不能替代虚拟列表。

  • :has() 怎样根据后代或相邻元素设置样式？

    :has() 检查当前元素之后的相对关系是否成立，匹配后选中的仍是当前元素；它让父元素和前面的兄弟元素第一次可以根据后面的内容改变样式。

  • CSS 滚动驱动动画适合什么场景？

    滚动驱动动画用 animation-timeline 把关键帧进度绑定到滚动位置（scroll()）或元素在视口中的可见进度（view()），适合阅读进度条和随滚动出现的效果；它目前不是 Baseline，需要渐进增强。

  • 容器样式查询怎样根据父级配置改变组件样式？

    @container style() 判断祖先容器上自定义属性的值，用来把主题、密度等配置传给内部组件；目前只能查询自定义属性。

  • HTML autocomplete 属性怎样帮助表单体验和隐私？

    autocomplete 用标准令牌告诉浏览器和密码管理器字段的用途，例如 email、new-password、one-time-code；它是提示而不是强制，填入的数据仍要校验。

  • inputmode 怎样改善移动端输入体验？

    inputmode 只决定虚拟键盘的类型，例如 numeric、decimal、tel、email；它不改变值的类型，也不限制输入字符，校验仍要靠 pattern 或代码。

  • Web 排版中的行高、行宽和断行怎样处理？

    正文行高用无单位数值，行宽控制在约 60–75 个字符或 30–40 个汉字，用 overflow-wrap 和 word-break 处理长单词与中日韩断行，可变字体用 font-weight 等高层属性控制轴。

  • CSS Masonry 和传统瀑布流方案应该怎样选择？

    原生瀑布流已改为 display: grid-lanes，仍是实验特性，要在普通 Grid 之上渐进增强；多栏布局和 JavaScript 定位各有顺序与性能上的取舍。

  • CSS Anchor Positioning 适合解决哪些浮层布局问题？

    锚点定位让绝对或固定定位元素直接依据另一个元素的位置和尺寸放置，并在空间不足时切换备选位置，替代大部分手写坐标计算。

  • CSS @scope 能解决哪些样式隔离问题？

    @scope 把选择器限定在某个根元素的子树内，并可以用下限排除内部区域；它不增加优先级，冲突时按作用域根的远近决定胜负。

  • CSS 多栏布局和 Grid 有什么区别？怎样避免内容被跨栏切开？

    多栏布局让一段连续内容依次流入多个栏，适合长文本；Grid 把独立项目放进行列格子。多栏中用 break-inside 防止卡片被切开，用 column-span 让标题横跨所有栏。

  • @starting-style 和离散属性过渡解决了什么问题？

    @starting-style 为首次渲染或从 display: none 出现的元素提供过渡起点；transition-behavior: allow-discrete 让 display、overlay 这类离散属性在过渡结束时才切换，从而实现进入和退出动画。

  • CSS @property 如何让自定义属性参与类型校验和动画？

    普通自定义属性只是一串 token，浏览器不知道它是颜色还是长度，因此不能插值；@property 注册类型、是否继承和初始值后，自定义属性可以平滑过渡，非法值会退回初始值。

  • field-sizing: content 会怎样改变表单控件尺寸？

    field-sizing: content 让 input、textarea、select 按内容自动调整尺寸，取代用 JavaScript 读 scrollHeight 的做法；要配合 min/max 约束防止布局失控。

  • text-wrap: balance 和 pretty 应该怎样使用？

    balance 让短文本各行长度接近，适合标题；pretty 用更慢的算法减少段落末行孤字，适合正文。两者在不支持的浏览器中退回普通换行，不影响内容。

  • interpolate-size 和 calc-size() 怎样实现 auto 高度动画？

    interpolate-size: allow-keywords 允许在长度与 auto、max-content 等固有尺寸之间过渡；它仍是实验特性，不支持的浏览器应直接切换状态。
