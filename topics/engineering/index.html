工程化面试题

前端工程化面试题，涵盖 Vite、webpack、Tree shaking、代码分割、npm 与 lockfile、Monorepo、Source Map、浏览器兼容和包管理。共 17 道题。

  • webpack 的 entry、output、loader 和 plugin 分别负责什么？

    entry 是依赖入口，output 决定产物，loader 做模块转换，plugin 通过生命周期钩子扩展构建。文中用一个完整配置讲 loader 顺序、publicPath、mode 和排错方法。

  • Vite 开发模式为什么启动快，生产环境为什么仍需要构建？

    开发时 Vite 靠原生 ESM 按需处理模块，加上依赖优化和 HMR，所以启动快；生产仍要打包，是为了减少请求、缩小体积、利用缓存。文中也区分了 Vite 8 和旧版本的工具链。

  • Tree shaking 如何工作？为什么有些代码无法移除？

    Tree shaking 删掉没被使用、也没有副作用的代码。文中从导出使用关系和模块副作用两类分析讲起，解释 ESM、sideEffects 和纯调用标注的作用，以及为什么要看真实构建结果验证。

  • 代码分割与懒加载适合哪些场景？

    代码分割把产物拆成多个文件，懒加载让一部分等到需要时才加载。文中用动态导入 import() 的例子讲模块缓存、取消边界和生命周期，以及预加载、错误恢复和旧版本资源问题。

  • 为什么需要提交 lockfile？npm ci 和 npm install 有何区别？

    package.json 写的是版本范围，lockfile 记录实际依赖树。文中讲 npm install 何时更新锁文件、npm ci 的一致性检查，以及工具版本、平台和安装脚本为什么要单独控制。

  • 为什么前端环境变量不能存放秘密？

    前端环境变量在构建时被写进发给用户的代码，谁都能看到。文中讲清构建环境与浏览器运行环境的区别、Vite 的变量前缀、字符串类型、文件优先级和 mode，以及运行时配置和服务端秘密的边界。

  • 编译目标、polyfill 和浏览器兼容性是什么关系？

    用可选链与 toSorted 说明 target 只管语法，polyfill 补运行时 API，类型声明、CSS 与安全上下文各管各的，支持范围要写成能验证的浏览器列表。

  • Source Map 如何帮助定位压缩后代码的错误？

    Source Map 把压缩后文件里的行列映射回源码位置。前提是映射、脚本和发布版本来自同一次构建；它只改善调试，不能保密源码，也不修复异常。

  • Monorepo 与 npm workspaces 能解决什么问题？

    Monorepo 把相关项目放进一个仓库，工作区负责本地包互相链接，任务编排工具负责构建顺序和缓存。文中用应用与组件包的例子讲依赖声明、构建顺序、发布验证和逐步采用的边界。

  • pnpm workspace 怎样管理多包前端仓库？

    pnpm 用工作区清单列出本地包，用 workspace 协议链接本地依赖。文中区分依赖与下游选择器，讲打包时版本转换、严格隔离和 CI 冻结安装的作用。

  • 前端构建产物应该怎样分析体积？

    产物分析要把文件大小、网络传输、解析执行和真实入口联系起来，找出不必要的提前加载、重复依赖和错误分块，再用同口径数据验证收益。

  • package.json 的 exports 和 imports 分别解决什么问题？

    exports 决定包对外公开哪些入口，imports 给包内部提供

  • 语义化版本号能否保证升级一定安全？

    SemVer 只是发布者的承诺，不是工具保证。文中区分版本号含义、包管理器的版本范围和锁文件，解释 0.x、预发布和构建元数据，以及为什么小版本更新也要验证。

  • Vite 插件的 resolveId、load 和 transform 分别做什么？

    resolveId 负责解析导入路径，load 负责提供源码，transform 负责改写源码。文中用一个虚拟版本模块讲内部 ID、返回值、开发和构建钩子、Source Map，以及插件为什么要按环境验证。

  • 前端功能开关和灰度发布应该怎样设计？

    功能开关把“代码已部署”和“功能已上线”分开。文中区分功能开关、权限和实验分流，讲前后端一致的灰度判断、缓存更新、紧急关闭和开关清理，并说明隐藏按钮不是安全控制。

  • ESLint Flat Config 和旧配置方式有什么区别？

    Flat Config 用一个配置对象数组，按 files 匹配、按顺序覆盖。文中用一个完整配置讲插件与预设导入、现代 extends 和全局忽略的行为，以及迁移时怎样检查最终生效配置。

  • Corepack 和 packageManager 字段怎样固定包管理器？

    packageManager 字段声明项目用的包管理器版本，Corepack 代理按声明下载并运行它。文中区分项目声明、Corepack 代理和实际执行的工具，讲 Node.js 分发边界、精确版本、首次下载和 CI 配置，以及它为什么不能代替锁文件。
