Node.js面试题

面向前端工程师的 Node.js 面试题，涵盖 Node 事件循环、Stream 流与背压，以及编写服务时的安全边界。共 12 道题。

  • Node.js 事件循环能完全照搬浏览器的执行顺序吗？

    不能。Node.js 有由 libuv 等机制支持的事件循环阶段，例如 timers、poll 和 check；浏览器还要协调页面渲染及自己的任务来源。两者都使用 JavaScript，但宿主调度机制并不相同。

  • 流和背压为什么能避免一次性读入大文件？

    流按块处理数据，让生产与消费逐步进行，减少一次性载入全部数据的需求。背压用于协调上下游速度：当写入方无法继续接收时，上游应暂停或等待，而不是无限堆积缓冲。

  • 前端工程师编写 Node 服务时需要守住哪些安全边界？

    服务端代码能够访问网络、文件系统和环境配置，权限边界比浏览器页面更广。输入校验、认证与授权、请求大小限制、超时和依赖安全都需要明确处理，不能把客户端已经验证当成可信依据。

  • Node.js Worker Threads 适合解决什么问题？

    区分 Worker Threads 与异步 I/O、子进程和集群，理解线程通信、数据传递和共享内存边界。

  • Node.js 的 package exports 会怎样影响模块解析？

    理解 package.json 的 exports、条件导出和子路径封装，避免浏览器构建与 Node 运行时解析结果不一致。

  • Node.js 的子进程、Worker 和集群应该怎样选择？

    从 CPU 任务、外部命令和服务扩展三个场景区分 Worker Threads、child_process 与 cluster，说明通信、隔离、资源限制和故障恢复不能混为一谈。

  • BFF 聚合接口怎样设计才能避免把前端耦合到后端细节？

    以题目详情页聚合多个后端服务为例，说明 BFF 的输入输出契约、并发、超时、错误降级、权限和版本兼容，避免把 BFF 做成无边界代理。

  • Node.js 服务如何实现优雅退出？

    从容器滚动发布和进程信号出发，解释 Node.js 优雅退出、连接排空、请求超时、重复信号和强制终止的实现边界。

  • Node.js 为什么要用 Worker Threads 任务池，而不是每次请求都创建 Worker？

    从 CPU 密集任务阻塞事件循环的问题出发，设计有上限的 Worker Threads 任务池，说明任务排队、错误、取消、传输成本和优雅关闭。

  • Node.js 的 diagnostics_channel 适合解决什么问题？

    解释 diagnostics_channel 如何为 Node.js 模块发布诊断事件，覆盖订阅时机、上下文关联、敏感数据、性能开销和与日志指标的边界。

  • AsyncLocalStorage 如何在 Node.js 请求链路中传递上下文？

    解释 AsyncLocalStorage 的上下文继承、并发隔离和边界，设计请求 ID 传递方案并分析定时器、回调、Worker 与错误处理中的常见问题。

  • 消息队列任务怎样设计取消、超时、确认和重试？

    从导出、转码和通知等后台任务出发，区分请求取消、任务取消、消息确认和业务回滚，说明 AbortSignal、租约、幂等键、重试和优雅排空如何协作。
