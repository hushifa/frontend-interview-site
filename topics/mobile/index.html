移动端与 PWA面试题

移动端与 PWA 面试题，涵盖渐进式 Web 应用、Service Worker 缓存更新，以及 React Native 与浏览器端 React 的差异。共 8 道题。

  • PWA 由哪些能力组成，是否所有浏览器体验都一致？

    PWA 使用 Web 技术提供接近应用的体验，常见能力包括可安装元信息、离线或弱网支持，以及与平台能力的渐进集成。Web App Manifest 描述名称、图标和启动方式等，Service Worker 可用于缓存与网络控制。

  • Service Worker 的安装、激活与缓存更新有哪些坑？

    Service Worker 有独立生命周期，注册后经历安装、等待和激活等过程，并不保证注册成功后立即控制当前页面。新版本等待旧页面释放控制是正常机制，不能把它误判为没有更新。

  • React Native 与浏览器里的 React 有哪些共同点和差异？

    React Native 复用 React 的组件与状态思路，但渲染目标是平台原生能力和组件，常见基础组件是 View、Text、Image 等，并不是把 div 和 CSS 原样搬进手机应用。

  • Pointer Events 为什么适合统一鼠标、触摸和触控笔交互？

    理解 pointerdown、pointermove、pointerup、pointerId 和 pointer capture，避免为不同输入设备维护重复逻辑。

  • 移动端虚拟键盘出现时怎样避免布局被遮挡？

    理解 Visual Viewport、虚拟键盘和安全区域之间的关系，设计输入框、底部操作栏和滚动容器的适配。

  • Web Share API 使用时要处理哪些降级？

    了解 navigator.share 的用户激活、权限和平台支持边界，为分享按钮设计复制链接等降级方案。

  • 移动端安全区域怎样避免内容被刘海和底部手势条遮挡？

    安全区域适配要把背景铺满和内容可用范围分开，用 CSS 环境变量保护固定控件、滚动末尾和横屏边缘，同时处理动态工具栏和键盘的独立影响。

  • Screen Orientation API 的锁定和解锁有什么限制？

    Screen Orientation API 能读取方向并在受支持的上下文中请求锁定，适合全屏游戏等沉浸式场景；普通页面应优先响应式布局，并处理权限、失败和退出清理。
