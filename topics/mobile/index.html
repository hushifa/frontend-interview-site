移动端与 PWA面试题

移动端与 PWA 面试题，涵盖渐进式 Web 应用、Service Worker 缓存更新，以及 React Native 与浏览器端 React 的差异。共 5 道题。

  • PWA 由哪些能力组成，是否所有浏览器体验都一致？

  • Service Worker 的安装、激活与缓存更新有哪些坑？

  • React Native 与浏览器里的 React 有哪些共同点和差异？

  • Pointer Events 为什么适合统一鼠标、触摸和触控笔交互？

    理解 pointerdown、pointermove、pointerup、pointerId 和 pointer capture，避免为不同输入设备维护重复逻辑。

  • 移动端虚拟键盘出现时怎样避免布局被遮挡？

    理解 Visual Viewport、虚拟键盘和安全区域之间的关系，设计输入框、底部操作栏和滚动容器的适配。
