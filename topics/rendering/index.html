SSR 与渲染面试题

前端渲染方案面试题，对比 CSR、SSR、SSG 与混合渲染，理解 Hydration 水合不匹配，以及 React Server Components 和服务端渲染的区别。共 7 道题。

  • CSR、SSR、SSG 和混合渲染如何选择？

    按页面 HTML 的生成时机比较客户端渲染、请求时渲染和构建时生成，结合内容时效、个性化、交互与部署条件选择组合，并说明缓存和搜索收录的边界。

  • Hydration mismatch 为什么发生，应该怎样修复？

    从客户端接管现有 HTML 的过程解释不一致，按初始数据、环境差异、HTML 结构和 DOM 修改定位原因，并用时间显示示例区分首次匹配与接管后的正常更新。

  • React Server Components 和 SSR 是同一件事吗？

    分别从组件执行与 HTML 生成理解 RSC 和 SSR，说明客户端边界、序列化数据、组合方式和构建时运行，并区分 Server Components 与 Server Functions。

  • React 流式 SSR 解决什么问题？

    用页面外壳和延迟区域解释流式输出，说明 Suspense、onShellReady、onAllReady、错误状态码与取消，并区分响应完成和客户端交互就绪。

  • SSR 和 SSG 中的缓存层应该怎样区分？

    区分浏览器与 CDN 的 HTTP 缓存、请求内去重、框架数据缓存和应用状态缓存，说明个性化数据、失效、权限与回滚不能靠一个 cache 开关解决。

  • 前端渲染方式怎样影响 SEO 和部署？

    从可抓取 HTML、状态码、规范链接和部署回退解释 CSR、SSR、SSG 对搜索与分享的影响，并说明预渲染不等于自动收录。

  • Next.js App Router 中的几层缓存怎样区分？

    区分请求数据缓存、Full Route Cache、客户端 Router Cache 和浏览器/CDN HTTP 缓存，说明动态函数、revalidate、失效和个性化数据的边界；具体行为需按 Next.js 版本核对。
