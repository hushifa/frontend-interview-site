架构设计面试题

前端架构设计面试题，讨论设计系统、组件规范、异步状态建模、渐进增强与优雅降级，关注项目长期维护。共 6 道题。

  • 设计系统为什么不能只有一套视觉样式？

  • 怎样避免加载、成功和失败状态互相矛盾？

  • 渐进增强和优雅降级怎样影响前端方案选择？

  • 前端大型项目怎样划分功能边界？

    从业务能力、依赖方向和状态归属设计模块边界，避免按文件类型分层导致代码互相穿透。

  • 设计 token 为什么比散落的颜色变量更适合大型前端项目？

    从语义、主题、组件和平台映射理解设计 token 的层级，避免把 token 变成另一套难以维护的常量表。

  • 微前端适合解决什么组织和部署问题？

    从团队边界、独立发布和运行时集成说明微前端的收益与成本，避免把拆分当成默认架构。
