JavaScript面试题

JavaScript 与 ES6+ 面试题，围绕闭包、作用域、原型链、this、事件循环、Promise、async/await、深浅拷贝和模块化，复习前端语言基础与异步编程。共 28 道题。

  • 什么是闭包？它有哪些实际应用？

    理解词法作用域，以及函数如何保留对外部变量的访问。

  • 事件循环中，任务和微任务按什么顺序执行？

    用一段代码区分同步执行、Promise 回调与 setTimeout。

  • 普通函数和箭头函数的 this 有什么区别？

    从调用方式与词法绑定解释 this，而不是只记规则。

  • Promise.all、allSettled、race 和 any 如何选择？

    根据成功条件和失败处理方式，选择合适的并发组合。

  • JavaScript 的值类型与相等比较应该怎样理解？

    JavaScript 的原始类型包括 undefined、null、boolean、number、bigint、string、symbol；对象包括普通对象、数组和函数等。变量保存值，对象值具有身份；两个内容相同但分别创建的对象并不相等。

  • 隐式类型转换有哪些容易踩坑的规则？

    判断条件首先把值转换为布尔值。空数组和空对象都是真值，空字符串、0、NaN、null、undefined 等是假值。字符串 "0" 也是真值，因此不能用是否为空代替数字是否合法。

  • var、let、const 和暂时性死区有什么关系？

    var 具有函数作用域，声明在执行前被建立并初始化为 undefined；赋值仍在代码执行到相应位置时发生。let 和 const 具有块级作用域，绑定在进入作用域时就存在，但初始化前不能访问，这段区域称为暂时性死区。

  • 原型链、class 和继承之间是什么关系？

    读取对象属性时，先查自身属性，找不到再沿内部原型链向上查找，直到 null。可以用 Object.getPrototypeOf 检查原型，用 Object.hasOwn 区分自身属性与继承属性。

  • 浅拷贝、深拷贝和 structuredClone 如何选择？

    展开语法和 Object.assign 通常只复制一层可枚举自身属性；嵌套对象仍共享引用。深拷贝则要根据业务决定如何处理循环引用、日期、Map、Set、原型以及函数等特殊值。

  • Map、Set、WeakMap 与普通对象各有什么用途？

    Map 是键值集合，键可以是任意值，并按插入顺序迭代；Set 保存不重复的值。普通对象更适合表达具有固定字段的记录，但其原型、属性键转换和整数键枚举规则不能简单等同于 Map。

  • 数组常用方法怎样选择，哪些会修改原数组？

    map 用于逐项转换，filter 用于筛选，find 返回首个匹配元素，some 和 every 表达存在性与全称判断。reduce 适合明确的累积过程，但复杂业务不必为了使用 reduce 牺牲可读性。

  • async/await 如何处理异常和并发？

    async 函数始终返回 Promise。await 暂停的是当前异步函数后续逻辑，不会阻塞整个线程；等待的 Promise 拒绝时，会在 await 位置抛出异常，可由 try/catch 处理。

  • 迭代器、可迭代对象和 Generator 有什么关系？

    迭代器通过 next() 返回包含 value 与 done 的对象。可迭代对象提供 Symbol.iterator 方法，其返回值是迭代器，因此可以用于 for...of、展开语法等。两种协议相关但不相同，普通对象默认不一定可迭代。

  • Proxy 与 Reflect 能实现什么，存在哪些限制？

    Proxy 可以拦截对象的读取、写入、属性枚举和函数调用等操作；Reflect 提供与这些内部操作对应的方法，适合在 trap 中保持默认行为，尤其是传递 receiver 时的访问器 this 语义。

  • 垃圾回收为什么无法自动解决所有内存泄漏？

    现代 JavaScript 引擎主要依据可达性判断对象是否仍可能被使用：从根对象可沿引用链到达的对象通常会保留。循环引用本身不意味着泄漏；不可达的循环结构仍可被回收。

  • 浮点精度、安全整数和 BigInt 有哪些边界？

    Number 使用 IEEE 754 双精度表示，许多十进制小数无法精确表示，所以 0.1 + 0.2 的结果可能不等于字面量 0.3。安全整数范围内的整数可以精确区分，超出范围可能发生相邻整数碰撞。

  • 正则表达式在前端使用时需要注意什么？

    正则适合匹配明确的文本模式，但不适合独自承担复杂语法解析。使用构造函数拼接外部文本时，应正确转义正则元字符，避免用户输入改变匹配语义。

  • 同步错误、Promise 拒绝和全局异常应该怎样处理？

    try/catch 只能捕获其执行范围内实际抛出的异常；在之后执行的计时器回调中抛错，不会被注册计时器时的 try 捕获。Promise 链需要 catch，async 函数应在调用边界处理返回的 Promise。

  • DataView 怎样读取指定字节序的二进制数据？

    多字节数值的字节排列有大端和小端之分。TypedArray 的多字节解释通常遵循平台字节序；DataView 可以在每次读写时显式指定字节序，更适合包含不同类型字段的二进制格式。

  • using 和 await using 解决什么资源清理问题？

    资源清理与内存回收不同：对象不再可达，并不保证文件句柄、订阅或其他资源及时释放。显式资源管理通过 using、await using 与可释放协议，表达资源离开作用域时应执行的清理。

  • Temporal 为什么把 Instant、PlainDate 和 ZonedDateTime 分开？

    这些类型表达不同业务语义。Instant 表示确定的时间线瞬间；PlainDate 表示不附带时区和具体时刻的日期；ZonedDateTime 则结合瞬间、时区与日历，让本地时间计算有明确上下文。

  • 可选链和空值合并为什么不能简单替换为 && 和 ||？

    空值合并只在左侧为 null 或 undefined 时使用右侧值；逻辑或则会把 0、false、空字符串等假值也视为需要回退。是否保留这些值取决于业务语义。

  • Object.keys、for...in 和 Reflect.ownKeys 会返回哪些属性？

    Object.keys 返回对象自身、可枚举的字符串属性键；for...in 还会遍历继承链上的可枚举字符串键；Reflect.ownKeys 包含自身的字符串键与 Symbol 键，不限于可枚举属性。

  • JavaScript 迭代器关闭和 return 方法有什么作用？

    了解 for...of、生成器和提前退出时的迭代器清理协议，避免自定义迭代器泄露资源。

  • 异步迭代器和 for await...of 适合处理什么数据？

    用异步迭代器顺序消费流式数据，理解 return、异常、背压和取消边界。
