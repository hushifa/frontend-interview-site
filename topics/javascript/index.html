JavaScript面试题

JavaScript 与 ES6+ 面试题，围绕闭包、作用域、原型链、this、事件循环、Promise、async/await、深浅拷贝和模块化，复习前端语言基础与异步编程。共 29 道题。

  • 什么是闭包？它有哪些实际应用？

    闭包是函数与其创建时词法环境的组合，外层函数返回后内层函数仍能读写这些绑定。常用于私有状态、工厂函数和回调；陈旧值与内存占用都源于旧环境仍被引用。

  • 事件循环中，任务和微任务按什么顺序执行？

    同步代码执行完、调用栈清空后，宿主会进入微任务检查点，把微任务队列清空（包括清空过程中新加入的），然后再取下一个任务，浏览器在合适时机渲染。Promise 回调是微任务，定时器回调是任务。

  • 普通函数和箭头函数的 this 有什么区别？

    普通函数的 this 由调用方式决定：方法调用、直接调用、call/apply/bind、new 各不相同。箭头函数没有自己的 this，沿用定义时外层作用域的 this，call 和 bind 也改不了它。

  • Promise.all、allSettled、race 和 any 如何选择？

    四个组合方法只定义"何时完成、结果是什么"。all 全部成功才成功、遇到首个拒绝即拒绝；allSettled 等全部敲定并返回状态；race 跟随首个敲定的结果；any 等首个成功，全部失败时以 AggregateError 拒绝。它们都不会启动、限流或取消任务。

  • JavaScript 的值类型与相等比较应该怎样理解？

    JavaScript 有 7 种原始类型和对象。原始值按值比较，对象按身份比较。===、Object.is 和 SameValueZero 都不做类型转换，区别只在 NaN 和正负零；== 会按规则转换类型。没有哪个运算符做深度比较。

  • 隐式类型转换有哪些容易踩坑的规则？

    不同运算触发不同转换：条件判断转布尔，减乘除转数字，+ 先把两侧转成原始值，有一侧是字符串就拼接，否则做数值加法。对象先经 Symbol.toPrimitive、valueOf、toString 转原始值。Number 和 parseInt 的解析规则也不同。

  • var、let、const 和暂时性死区有什么关系？

    var 是函数作用域，进入函数时就初始化为 undefined；let 和 const 是块作用域，在声明执行前处于暂时性死区，访问会抛 ReferenceError。const 只禁止重新赋值，不冻结对象。

  • 原型链、class 和继承之间是什么关系？

    每个对象通过内部 [[Prototype]] 链接到另一个对象，读属性时沿链查找直到 null。class 是建立在原型上的语法：方法放在 prototype 上共享，extends 同时连接实例原型和构造函数，并额外带来严格模式、必须 new 调用、私有字段等语义。

  • 属性描述符、Object.freeze 和只读有什么区别？

    属性描述符控制单个属性能否写入、枚举和重新配置。preventExtensions、seal、freeze 依次加强对整个对象的限制，但都只作用于一层。const 约束的是变量绑定，TypeScript readonly 只在编译期检查。

  • 浅拷贝、深拷贝和 structuredClone 如何选择？

    展开语法、Object.assign、slice 都是浅拷贝，嵌套对象仍共享。structuredClone 能深拷贝 Date、Map、Set、ArrayBuffer 和循环引用，但遇到函数、DOM 节点会抛错，并丢失原型、getter 和不可枚举属性。状态更新通常只复制被修改的路径。

  • Map、Set、WeakMap 与普通对象各有什么用途？

    普通对象适合结构固定的记录；Map 适合键动态、键可以是任意值、需要频繁增删和按插入顺序遍历的集合；Set 存唯一值，ES2025 起有并集、交集等方法；WeakMap 和 WeakSet 的键必须是对象（或未注册的 Symbol），不阻止键被回收，也不能遍历。

  • 数组常用方法怎样选择，哪些会修改原数组？

    按意图选方法：转换用 map，筛选用 filter，查找用 find/some，汇总用 reduce。sort、reverse、splice 等会修改原数组，ES2023 的 toSorted、toReversed、toSpliced、with 返回副本。返回新数组只是新容器，元素对象仍共享。

  • async/await 如何处理异常和并发？

    async 函数总是返回 Promise，内部 throw 会变成拒绝；await 让拒绝在当前位置抛出，可用 try/catch 捕获。try 中直接 return 一个 Promise 不会被本地 catch 拦截，需要 return await。异步任务是否并行取决于何时启动，而不是何时 await。

  • ES Modules 和 CommonJS 有哪些关键区别？

    ESM 用静态 import/export，先解析和链接整个依赖图再执行，导入的是只读的实时绑定，支持顶层 await。CommonJS 的 require 是运行时同步调用，返回 module.exports 当时的值。Node.js 22.12+ 与 20.19+ 默认允许 require 加载不含顶层 await 的 ESM。

  • 迭代器、可迭代对象和 Generator 有什么关系？

    可迭代对象实现 [Symbol.iterator]()，返回迭代器；迭代器的 next() 每次返回 { value, done }。for...of、展开、解构都按这个协议取值。Generator 函数用 yield 暂停执行，自动实现两个协议。ES2025 的 Iterator helpers 让迭代器可以直接链式调用 map、filter、take。

  • Proxy 与 Reflect 能实现什么，存在哪些限制？

    Proxy 用 get、set、has、deleteProperty 等陷阱拦截对象的基本操作；Reflect 提供每个陷阱对应的默认行为，转发时传入 receiver 才能让 getter 中的 this 指向代理。Proxy 必须遵守不变式，拦截不了私有字段，Map、Date 等依赖内部槽的对象直接经代理调用方法会抛错。

  • 垃圾回收为什么无法自动解决所有内存泄漏？

    垃圾回收只回收从根出发不可达的对象。前端常见泄漏是"业务上已经不用、但仍被引用"：未移除的监听器、未清除的定时器、无上限的缓存、长期订阅。循环引用本身不会泄漏。排查用堆快照比较对象数量和保留路径。

  • 浮点精度、安全整数和 BigInt 有哪些边界？

    Number 是 IEEE 754 双精度浮点数，0.1 + 0.2 不等于 0.3，超过 2^53 - 1 的整数无法精确区分。BigInt 精确表示任意大整数，但不能和 Number 混合运算，除法向零截断，JSON 不能直接序列化。金额通常用最小单位整数或十进制库处理。

  • 正则表达式在前端使用时需要注意什么？

    前端正则常见问题有四类：带 g 或 y 标志的正则在 test/exec 间共享 lastIndex；用户输入拼进正则前要转义（ES2025 的 RegExp.escape）；处理非 ASCII 文本要加 u 或 v 标志；嵌套量词可能导致灾难性回溯（ReDoS）。

  • 同步错误、Promise 拒绝和全局异常应该怎样处理？

    catch 只能捕获当前调用栈上抛出的错误，或在 try 内 await 的 Promise 拒绝。定时器和事件回调里的错误发生在之后的任务中，注册时的 try 捕获不到，需要在回调内部处理或转成拒绝。异步失败未被处理时由 window 的 error 和 unhandledrejection 兜底上报，但它们不负责业务恢复。

  • ArrayBuffer、TypedArray 和普通数组有什么区别？

    ArrayBuffer 是一段原始字节，本身不能读写；TypedArray 按固定数值类型（如 Uint8、Float32）查看缓冲区，长度固定、元素会被强制转换。subarray 共享缓冲区，slice 复制。普通数组可以存任意值并自由伸缩。

  • DataView 怎样读取指定字节序的二进制数据？

    DataView 在 ArrayBuffer 上按任意字节偏移读写不同数值类型，每次调用可指定字节序，默认大端。网络协议和文件格式常用大端，TypedArray 则按平台字节序（通常是小端）。解析前要校验长度，越界读取会抛 RangeError。

  • using 和 await using 解决什么资源清理问题？

    using 声明在离开块作用域时自动调用资源的 [Symbol.dispose]()，await using 调用并等待 [Symbol.asyncDispose]()，多个资源按声明逆序释放，替代手写 try/finally。释放与主逻辑都出错时，错误被包装成 SuppressedError。该特性在 TC39 列为 2027 版，MDN 标注为非 Baseline，部分浏览器尚不支持。

  • Temporal 为什么把 Instant、PlainDate 和 ZonedDateTime 分开？

    Date 只表示一个毫秒时间戳，却同时提供 UTC 和本地时间的读写方法，生日、预约和跨时区计算很容易混淆。Temporal 用不同类型区分语义：Instant 是时间线上的一点，PlainDate 是无时区的日历日期，ZonedDateTime 是带 IANA 时区的时刻，跨夏令时的日历运算按时区规则处理。

  • 可选链和空值合并为什么不能简单替换为 && 和 ||？

    ?? 只在左侧为 null 或 undefined 时取右侧，|| 遇到 0、''、false 也会取右侧。?. 只在左侧为 null 或 undefined 时短路并返回 undefined，&& 遇到任何假值都短路并返回该假值。两者都不会吞掉属性读取或函数调用中抛出的异常。

  • Object.keys、for...in 和 Reflect.ownKeys 会返回哪些属性？

    Object.keys 只返回自身、可枚举、字符串键；for...in 额外包含原型链上的可枚举字符串键；Object.getOwnPropertyNames 包含不可枚举的字符串键；Reflect.ownKeys 返回全部自身键，包括 Symbol 和不可枚举属性。普通对象的键顺序是整数索引升序，然后字符串和 Symbol 按创建顺序。

  • JavaScript 迭代器关闭和 return 方法有什么作用？

    迭代器的 return() 方法是"消费者不再读取"的通知。for...of 和解构在 break、return 或循环体抛错而提前退出时会调用它，生成器借此运行 finally 释放资源。迭代正常结束、next() 自身抛错或手动丢弃迭代器时不会调用。

  • 异步迭代器和 for await...of 适合处理什么数据？

    异步迭代器的 next() 返回 Promise，for await...of 逐项等待，适合分页接口、流式响应和逐块读取等"下一项稍后才到"的数据。消费是串行的；提前 break 会等待 return() 清理完成。背压取决于生产者是否按需产出。

  • Promise.withResolvers 适合解决什么问题？怎样避免 deferred 泄漏？

    Promise.withResolvers（ES2024）一次返回 promise、resolve 和 reject，适合把一次性事件或回调桥接成 Promise，替代在构造器外部保存 resolve 的写法。Promise 只能结算一次，不能当消息队列；它也不负责取消和清理，监听器和定时器要在结算时移除。
