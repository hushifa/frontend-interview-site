JavaScript面试题

JavaScript 与 ES6+ 面试题，围绕闭包、作用域、原型链、this、事件循环、Promise、async/await、深浅拷贝和模块化，复习前端语言基础与异步编程。共 45 道题。

  • 什么是闭包？它有哪些实际应用？

    闭包就是函数记住了它定义时能访问的变量，外层函数执行完以后，内层函数还能继续用这些变量。常用来做私有状态和工厂函数。

  • 事件循环中，任务和微任务按什么顺序执行？

    同步代码先跑完，再把微任务（比如 Promise 的 then）全部执行完，最后才轮到下一个任务（比如 setTimeout）。浏览器在任务之间找时机渲染页面。

  • 回调地狱是什么？Promise 链式调用怎样解决它？then 的返回值有哪些规则？

    几个异步操作要按顺序执行时，回调一层套一层，错误处理也要每层写一遍，这就是回调地狱。Promise 的 then 总是返回一个新的 Promise，回调返回的值、抛出的错误、返回的 Promise 决定这个新 Promise 的结果，所以多个步骤能写成一条平铺的链，错误统一交给末尾的 catch。

  • 宏任务和微任务分别有哪些？setTimeout、Promise、requestAnimationFrame 谁先执行？

    常说的宏任务就是 HTML 规范里的任务，比如整段脚本、setTimeout 回调、点击事件、postMessage；微任务有 Promise 回调、queueMicrotask、MutationObserver。同一段脚本里安排的 Promise 回调最先执行，setTimeout 和 requestAnimationFrame 的先后取决于下一次渲染什么时候到，requestAnimationFrame 回调既不是任务也不是微任务，而是渲染更新步骤的一部分。

  • 执行上下文、作用域链和变量环境是什么关系？

    每调用一次函数，引擎就创建一个执行上下文压进调用栈，里面记录这段代码用哪套环境记录查变量。环境记录通过外层引用连成作用域链，外层是函数定义的位置决定的。var 声明放在变量环境里，let、const 放在词法环境里。

  • 0.1 + 0.2 为什么不等于 0.3？怎么解决？

    Number 是 IEEE 754 双精度二进制浮点数，0.1 和 0.2 在二进制里是无限循环小数，只能存最接近的近似值，相加后误差显露出来。比较时用误差范围，金额换成整数单位计算，显示时再格式化，需要精确十进制时用十进制库。

  • 普通函数和箭头函数的 this 有什么区别？

    普通函数的 this 看它是怎么被调用的，谁调用它，this 一般就是谁。箭头函数没有自己的 this，用的是定义它的地方外层的 this，call 和 bind 也改不了。

  • 箭头函数和普通函数有哪些区别？

    箭头函数没有自己的 this、arguments 和 super，会沿用外层的；它不能用 new 调用，也没有 prototype 属性；函数体里不能用 yield。所以它适合写回调，不适合做对象方法、构造函数和需要动态 this 的场景。

  • ES6 及之后的版本有哪些常用新特性？

    ES2015 带来了 let/const、解构、展开、箭头函数、模板字符串、class、模块、Promise、Map/Set、Symbol 和迭代器，之后每年一版，常用的有 async/await、对象展开、可选链、空值合并、BigInt、Array.prototype.at、toSorted 等。回答时按版本说用途，再挑面试官会追问的点讲深。

  • for...in、for...of、forEach 和 map 有什么区别？forEach 能用 break 跳出吗？

    for...in 遍历对象的可枚举字符串键，会带上原型链上的键；for...of 按迭代器取值，能遍历数组、字符串、Map、Set；forEach 对每个元素调用回调，没有返回值；map 返回由回调结果组成的新数组。forEach 不能用 break，只有抛出异常才能中途停下，要提前结束就改用 for...of、some 或 find。

  • 怎样让 a == 1 && a == 2 && a == 3 成立？

    == 一边是对象、一边是数字时，会先把对象转成原始值，转换会调用对象的 Symbol.toPrimitive、valueOf 或 toString。让这些方法每次返回一个递增的数，三次比较就分别得到 1、2、3。全局变量改成 getter 也行，每次读取 a 都会执行函数，这时连 === 都能成立。Proxy 拦截 Symbol.toPrimitive 是同一个思路的变形。

  • 原型链、class 和继承之间是什么关系？

    每个对象都连着一个原型对象，自己身上找不到的属性，就沿着原型一路往上找。class 是在原型上搭起来的写法，方法放在原型上让所有实例共用，另外还多了必须 new 调用、私有字段等规则。

  • ES5 有哪些继承方式？为什么寄生组合继承最好？

    原型链继承会让所有实例共享父类的引用属性，构造函数继承拿不到父类原型上的方法。组合继承两者都解决了，但父类构造函数被调用两次。寄生组合继承用 Object.create(Parent.prototype) 连接原型链，只调用一次父构造函数，ES6 的 class extends 做的就是这件事。

  • Promise.all、allSettled、race 和 any 如何选择？

    四个方法都是把一组 Promise 合成一个，区别在于什么时候结束、结果是什么。all 要全部成功，allSettled 等全部结束，race 看谁先结束，any 看谁先成功；它们都不会帮你启动、限流或取消任务。

  • var、let、const 和暂时性死区有什么关系？

    var 的作用范围是整个函数，声明之前读到的是 undefined。let 和 const 只在代码块里有效，声明那一行执行之前访问会直接报错，这段时间叫暂时性死区。const 只是不能重新赋值，对象内容还能改。

  • JavaScript 的值类型与相等比较应该怎样理解？

    JavaScript 有 7 种原始类型，其他都是对象。原始值比较的是值，对象比较的是是不是同一个。===、Object.is 都不转换类型，区别只在 NaN 和正负零；== 会先转换类型再比。

  • 怎样准确判断一个值的类型？typeof、instanceof 和 Object.prototype.toString 各有什么局限？

    typeof 适合判断原始类型和函数，但 typeof null 是 "object"，数组也是 "object"。instanceof 检查原型链，判断不了原始值，跨 iframe 或 realm 会失效。Object.prototype.toString.call 能区分 Array、Date、Null 等内置类型，但会被 Symbol.toStringTag 改写。数组用 Array.isArray 最可靠。

  • 隐式类型转换有哪些容易踩坑的规则？

    不同运算会把值转成不同类型。条件判断转布尔，减乘除转数字，加号只要有一边是字符串就拼接。对象要先转成原始值再参与运算。

  • 浅拷贝、深拷贝和 structuredClone 如何选择？

    展开语法、Object.assign 只复制一层，里面的对象还是共用的。structuredClone 能完整深拷贝常见数据，但复制不了函数和 DOM 节点，也会丢掉类的原型。更新状态时通常只复制改动的那条路径。

  • Symbol 有什么用？常见的内置 Symbol 有哪些？

    每次调用 Symbol() 都得到一个独一无二的值，用作属性键不会和别人的键冲突，也不会出现在 Object.keys、for...in 和 JSON.stringify 里。Symbol.for 从全局注册表取共享的 Symbol。内置 Symbol 如 Symbol.iterator、Symbol.toPrimitive、Symbol.toStringTag、Symbol.hasInstance 让对象定制语言行为。

  • async/await 如何处理异常和并发？

    async 函数总是返回 Promise，异步代码里 throw 就等于返回一个失败的 Promise，用 await 加 try/catch 就能像同步代码一样捕获。几个任务是不是并行，要看它们什么时候开始，而不是什么时候 await。

  • async/await 的原理是什么？怎样用 Generator 实现自动执行？

    async 函数可以理解为 Generator 加一个自动执行器：遇到 await 就暂停，等 Promise 完成后带着结果恢复执行，失败就在暂停处抛出错误。手写时用 Generator 的 yield 代替 await，执行器反复调用 next，把每次 yield 出来的值包成 Promise，完成后再把结果传回去。

  • ES Modules 和 CommonJS 有哪些关键区别？

    ESM 的 import 在代码运行前就确定好依赖，导入的变量会跟着导出方实时变化。CommonJS 的 require 是运行到那一行才执行的函数，拿到的是当时的 module.exports。新版 Node.js 也允许 require 加载 ESM。

  • 严格模式改变了哪些行为？

    严格模式把一些静默失败改成抛错：给未声明变量赋值抛 ReferenceError，给只读属性赋值抛 TypeError。函数里的 this 不再被替换成全局对象或包装对象，arguments 不再和参数同步，禁用 with、八进制字面量和重复参数名，eval 不会往外层加变量。ES 模块和 class 内部自动是严格模式。

  • Map、Set、WeakMap 与普通对象各有什么用途？

    字段固定的记录用普通对象，键会动态增减、键不是字符串时用 Map，存不重复的值用 Set。WeakMap 的键必须是对象，不会阻止对象被回收，适合给对象挂额外数据。

  • 数组常用方法怎样选择，哪些会修改原数组？

    先想清楚要做什么，转换用 map，筛选用 filter，查找用 find 或 some，汇总用 reduce。sort、reverse、splice 这类方法会直接改原数组，想保留原数组就用 toSorted、toReversed 这些返回副本的版本。

  • 可选链和空值合并为什么不能简单替换为 && 和 ||？

    ?? 和 ?. 只把 null 和 undefined 当成"没有值"，而 || 和 && 会把 0、空字符串、false 也当成没有。所以合法值是 0 或 false 时，用 || 设默认值会出错。

  • 属性描述符、Object.freeze 和只读有什么区别？

    属性描述符管的是单个属性能不能改、能不能被遍历、能不能删。Object.freeze 把整个对象冻住，但只冻一层。const 只是不让变量重新赋值，TypeScript 的 readonly 只在编译时检查。

  • 浮点精度、安全整数和 BigInt 有哪些边界？

    JavaScript 的数字是二进制浮点数，0.1 + 0.2 不等于 0.3，超过 2^53 - 1 的整数也存不准。BigInt 能精确表示任意大的整数，但不能和普通数字混着算。金额一般换成"分"这样的整数来算。

  • 同步错误、Promise 拒绝和全局异常应该怎样处理？

    try/catch 只能接住当前正在执行的代码抛出的错误，以及在 try 里 await 的 Promise 失败。定时器和事件回调是后来才异步执行的，外面的 try 管不到。全局的 error 和 unhandledrejection 事件只负责兜底上报。

  • 迭代器、可迭代对象和 Generator 有什么关系？

    可迭代对象能交出一个迭代器，迭代器每调用一次 next() 就给出下一个值。for...of、展开、解构都靠这套约定取值。Generator 函数用 yield 一步一步产出值，自动满足这套约定。

  • Proxy 与 Reflect 能实现什么，存在哪些限制？

    Proxy 能拦截对一个对象的读、写、删除、遍历等操作，Reflect 用来在拦截后执行原本的默认行为。Vue 3 的响应式就靠它们。限制是必须遵守一些规则，而且拦截不到私有字段和 Map 这类对象的内部数据。

  • 垃圾回收为什么无法自动解决所有内存泄漏？

    垃圾回收只回收已经找不到的对象。前端的内存泄漏大多是"业务上不用了，但还有东西引用着"，比如没移除的监听器、没清除的定时器、只增不减的缓存。排查时用堆快照找谁还在引用它。

  • 正则表达式在前端使用时需要注意什么？

    前端写正则常踩四个坑。带 g 的正则反复 test 会记住上次的位置；用户输入拼进正则前要转义；处理 emoji 这类字符要加 u 标志；嵌套的量词可能让匹配卡死页面。

  • Object.keys、for...in 和 Reflect.ownKeys 会返回哪些属性？

    这几个方法的区别在于管不管继承来的属性、不可枚举的属性和 Symbol 键。Object.keys 只要自己的、可枚举的字符串键，for...in 会带上原型链上的，Reflect.ownKeys 拿到自己的全部键。

  • 异步迭代器和 for await...of 适合处理什么数据？

    数据一项一项陆续到达时，比如分页接口、流式响应，就用 for await...of 一项一项等着处理。它是串行的，提前 break 会等生产者清理完再继续。

  • JavaScript 迭代器关闭和 return 方法有什么作用？

    迭代器的 return() 是消费者在说"我不读了，你清理吧"。for...of 被 break、return 或抛错打断时会调用它，生成器借此执行 finally。正常读完、next() 自己抛错时不会调用。

  • ArrayBuffer、TypedArray 和普通数组有什么区别？

    ArrayBuffer 只是一段原始字节，自己不能读写；TypedArray 按固定的数字类型去读写这段字节，长度固定，写入的值会被强制转换。普通数组能放任何值，长度也能随意变。

  • DataView 怎样读取指定字节序的二进制数据？

    DataView 可以从一段二进制数据的任意位置读写数字，每次都能指定字节顺序，不指定就按大端。网络协议常用大端，所以解析协议时用它，并先检查长度够不够。

  • Promise.withResolvers 适合解决什么问题？怎样避免 deferred 泄漏？

    Promise.withResolvers 一次拿到 promise 和控制它的 resolve、reject，适合把"之后某个事件发生"包装成 Promise。它只能成功或失败一次，也不会帮你移除监听器和定时器，这些要自己清理。

  • Temporal 为什么把 Instant、PlainDate 和 ZonedDateTime 分开？

    Date 只存一个时间戳，却同时被当成本地时间和 UTC 时间用，生日、预约、跨时区计算很容易出错。Temporal 用不同类型表示不同意思：Instant 是一个确定的瞬间，PlainDate 只是日历上的一天，ZonedDateTime 是某个时区里的时刻。

  • using 和 await using 解决什么资源清理问题？

    用 using 声明的资源，离开代码块时会自动调用它的释放方法，不用再手写 try/finally。await using 用于需要异步释放的资源。这个特性还比较新，部分浏览器不支持。

  • WeakRef 和 FinalizationRegistry 是做什么的？

    WeakRef 持有对象的弱引用，不阻止对象被回收，deref() 可能返回 undefined。FinalizationRegistry 在注册的对象被回收后可能调用清理回调，但回调不保证执行，也不保证时机。MDN 建议尽量避免使用，典型用途是可丢失的缓存。

  • V8 是怎样执行 JavaScript 的？Ignition、TurboFan、隐藏类和去优化分别是什么？

    V8 先把源码解析成抽象语法树，没调用的函数只做预解析；Ignition 把语法树编译成字节码并解释执行，同时收集类型反馈；热点函数交给 Sparkplug、Maglev、TurboFan 这几层编译器生成机器码。对象按属性的名字和添加顺序共享隐藏类，内联缓存靠隐藏类加速属性访问；优化代码遇到不符合假设的对象就去优化，回到解释器继续执行。

  • 标签模板是什么？String.raw 有什么用？

    在模板字符串前面写一个函数名，就成了标签模板，这个函数会收到拆开的字符串片段数组和每个插值表达式的值，返回什么都可以。字符串数组带一个 raw 属性，保存没有处理转义的原始文本，String.raw 就是用它拼出原始字符串的内置标签，常用来写 Windows 路径和正则。
