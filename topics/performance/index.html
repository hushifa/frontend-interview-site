性能优化面试题

前端性能优化面试题，围绕长任务、懒加载、preload、虚拟列表、真实用户监测、Navigation Timing 和 Resource Timing 分析页面加载与交互。共 10 道题。

  • 什么是长任务，为什么会影响交互响应？

    浏览器主线程任务占用达到约 50 毫秒及以上时，可被 Long Tasks 相关 API 记录为长任务。执行期间，后续输入处理和渲染可能被推迟，用户会感到点击或输入没有及时反馈。

  • 懒加载为什么有时反而让首屏和首次交互变慢？

    懒加载把非关键资源推迟到需要时，能减少首屏下载与执行成本，但它也把部分等待转移到第一次使用。若首屏关键图片或用户马上要用的组件被延后，体验可能反而变差。

  • preload 怎样使用，为什么错误使用会浪费带宽？

    preload 提示浏览器提前获取当前页面即将使用的资源，但不会自动执行脚本或应用样式。正确的 as、类型与跨源设置帮助浏览器确定请求语义并复用后续请求。

  • 虚拟列表通过什么方式减少渲染成本？

    虚拟列表只渲染可视区及附近一小段内容，通过占位空间和偏移维持完整滚动范围。它减少同时存在的 DOM 和更新工作，但不会自动减少已经下载到内存的数据量。

  • 真实用户监测与实验室性能测试为什么要结合？

    实验室测试在可控制的设备、网络和步骤下运行，适合定位回归和比较改动。真实用户监测（RUM）从实际访问收集数据，能够反映不同设备、网络、地区和交互路径的体验分布。

    PerformanceNavigationTiming 记录一次文档导航的网络和生命周期时间点，例如 responseStart、domContentLoadedEventEnd、loadEventEnd。通过相应差值可以分析阶段耗时…

  • Resource Timing 为什么有些跨源字段是零？

    PerformanceResourceTiming 提供单个资源的请求阶段、传输大小等信息。为避免泄露跨源信息，部分细节需要资源响应通过 Timing-Allow-Origin 授权后才能暴露；它与允许跨源读取响应内容的 CORS 用…

  • Long Tasks API 怎样帮助定位主线程卡顿？

    使用 PerformanceObserver 观察超过 50 毫秒的任务，理解它能说明什么、不能直接说明什么，以及如何结合 INP 诊断。

  • 虚拟列表怎样减少长列表的渲染成本？

    解释只渲染可视窗口、估算高度、滚动偏移和动态高度测量，理解虚拟列表的正确性边界。

  • 前端内存泄漏应该怎样定位？

    通过增长曲线、堆快照、分离 DOM 和事件监听排查长期页面中的内存泄漏，避免把一次性占用当成泄漏。
