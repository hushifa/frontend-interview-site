性能优化面试题

前端性能优化面试题，围绕长任务、懒加载、preload、虚拟列表、真实用户监测、Navigation Timing 和 Resource Timing 分析页面加载与交互。共 16 道题。

  • 什么是长任务，为什么会影响交互响应？

    浏览器主线程任务占用达到约 50 毫秒及以上时，可被 Long Tasks 相关 API 记录为长任务。执行期间，后续输入处理和渲染可能被推迟，用户会感到点击或输入没有及时反馈。

  • 懒加载为什么有时反而让首屏和首次交互变慢？

    懒加载只是推迟下载或执行，减少了当前关键路径的工作，却可能把等待转移到用户第一次使用时。应按访问概率、首屏重要性和资源成本决定。

  • preload 怎样使用，为什么错误使用会浪费带宽？

    preload 提示浏览器提前获取当前页面即将使用的资源，但不会自动执行脚本或应用样式。正确的 as、类型与跨源设置帮助浏览器确定请求语义并复用后续请求。

  • 虚拟列表通过什么方式减少渲染成本？

    虚拟列表只渲染可视区及附近一小段内容，通过占位空间和偏移维持完整滚动范围。它减少同时存在的 DOM 和更新工作，但不会自动减少已经下载到内存的数据量。

  • 真实用户监测与实验室性能测试为什么要结合？

    实验室测试用于控制变量和定位原因，RUM 用于观察真实设备、网络和交互的体验分布；两者回答不同问题，不能相互替代。

  • Navigation Timing 的时间点能否代表页面已经可用？

    PerformanceNavigationTiming 记录一次文档导航的网络和生命周期时间点，例如 responseStart、domContentLoadedEventEnd、loadEventEnd。通过相应差值可以分析阶段耗时，但不能单独证明页面已经可用。

  • Resource Timing 为什么有些跨源字段是零？

    PerformanceResourceTiming 记录资源请求阶段和传输大小，但跨源细节受 Timing-Allow-Origin 保护。字段为零可能是缓存、连接复用、隐私限制或信息缺失，不能直接下结论。

  • Long Tasks API 怎样帮助定位主线程卡顿？

    Long Tasks API 能记录主线程连续占用超过 50ms 的时间段，为线上定位输入延迟提供线索；它不是函数调用栈，也不能单独代表 INP 或页面流畅度。

  • 虚拟列表怎样减少长列表的渲染成本？

    虚拟列表只挂载视口附近的内容，但要同时解决高度估算、滚动锚点、焦点保留和浏览器查找等正确性问题。

  • 前端内存泄漏应该怎样定位？

    通过增长曲线、堆快照、分离 DOM 和事件监听排查长期页面中的内存泄漏，避免把一次性占用当成泄漏。

  • 前端性能预算应该怎样制定和落地？

    性能预算把包体、资源、关键指标和业务完成时间转成可检查的上限，但预算必须绑定真实设备、网络和页面场景，并通过趋势与用户体验一起判断。

  • 一个线上页面变慢后应该怎样完成性能诊断闭环？

    用移动端题库列表 INP 和 LCP 同时变差的案例，说明从 RUM 定位人群、实验室复现、瀑布与主线程分析到分批发布验证的完整流程。

  • 如何用 Long Animation Frames API 定位卡顿来源？

    解释长动画帧与 Long Task 的区别，使用 PerformanceObserver 读取脚本、布局和渲染耗时，分析如何在真实用户环境中定位交互卡顿并设计降级方案。

  • INP 很高时，如何定位到底是哪一段交互变慢？

    从输入延迟、事件处理和呈现延迟三个阶段拆解 INP，结合 Event Timing、PerformanceObserver 和 DevTools 设计可复现、可验证的交互性能诊断流程。

  • 第三方脚本怎样接入，才能控制性能和安全风险？

    从统计、客服和营销脚本的加载出发，分析 async、defer、权限、主线程、隐私、故障隔离和回滚策略，建立第三方脚本治理流程。

  • Speculation Rules API 的预取和预渲染有什么区别？

    解释 speculationrules 中 prefetch 与 prerender 的工作边界，说明触发时机、隐藏页面副作用、缓存和隐私成本，以及如何安全地为导航加速。
