手写与算法面试题

JavaScript 手写题与算法练习，包含防抖、节流、LRU 缓存、Promise.all、异步并发池和树的前序遍历，附代码与边界说明。共 7 道题。

  • 怎样实现只在停止调用后执行的防抖函数？

    防抖将短时间内密集发生的调用合并。下面实现的是尾沿执行版本：距离最后一次调用经过 wait 后才执行，保留最后的参数与 this，并支持取消。它不包含首沿执行、最大等待时间或返回 Promise 等扩展语义。

  • 怎样实现首沿节流，和尾沿节流有什么区别？

    节流限制连续调用的执行频率。下面是首沿版本：第一次立即执行，然后在等待窗口内丢弃后续调用。它不会在窗口结束时补执行最后一次调用，因此不能直接替代需要尾沿结果的方案。

  • 如何利用 Map 实现固定容量的 LRU 缓存？

    LRU 在容量不足时淘汰最近最少使用的条目。Map 保留键的插入顺序，可以在命中或更新时先删除再插入，使最新使用的键位于末尾，最早的键作为淘汰候选。

  • 怎样实现保持输入顺序的 Promise.all 教学版本？

    核心是把每个结果写回输入索引，用计数判断是否全部完成。普通值与 thenable 通过 Promise.resolve 统一处理；某项拒绝时整体拒绝，但不会取消其他已启动操作。

  • 怎样实现有明确失败语义的异步并发池？

    限制并发需要接收尚未执行的任务函数，而不是已经开始的 Promise。下面的教学实现接收函数数组，最多同时等待 limit 个任务，结果按输入顺序排列。这里限制的是异步在途任务，不会让 JavaScript 计算自动多线程并行。

  • 怎样用显式栈实现树的前序遍历？

    前序遍历先访问当前节点，再按顺序遍历它的子树。递归写法直观，但很深的树可能超出调用栈；显式栈可以把待访问节点放到堆上维护。

  • 异步请求重试应该怎样设计？

    处理退避、最大次数、可重试错误、取消和幂等，避免无条件重试放大故障。
