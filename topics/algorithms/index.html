JavaScript 手写题与算法练习，包含防抖、节流、LRU 缓存、Promise.all、异步并发池和树的前序遍历，附代码与边界说明。共 14 道题。

  • 怎样实现只在停止调用后执行的防抖函数？

    用输入搜索的时间线解释尾沿防抖，逐步说明定时器重置、最后一次参数与 this、取消和返回值，并区分延后执行、请求取消与结果过期。

  • 怎样实现首沿节流，和尾沿节流有什么区别？

    通过连续调用的时间窗口解释首沿、尾沿与防抖的区别，给出带取消的首沿实现，并说明重入、异常、返回值以及频率限制不等于并发限制。

  • 如何利用 Map 实现固定容量的 LRU 缓存？

    LRU 在容量满时淘汰最久没有被访问的条目。利用 Map 的插入顺序，读取命中和更新时先删除再插入，把最近访问的键放到末尾，最前面的键作为淘汰对象。

  • 怎样实现保持输入顺序的 Promise.all 教学版本？

    从按位置保存结果和完成计数解释 Promise 聚合，覆盖普通值、thenable、空输入、迭代错误和拒绝语义，并说明它不负责启动、取消或限制任务并发。

  • 怎样实现有明确失败语义的异步并发池？

    并发池接收尚未启动的任务函数，由固定数量的执行循环领取任务。结果按输入位置保存；发现失败后拒绝并停止领取新任务，已经开始的任务仍可能继续。

  • 怎样用显式栈实现树的前序遍历？

  • 异步请求重试应该怎样设计？

    从失败分类与幂等性出发，给出带次数限制、随机退避和可取消等待的实现，并说明 Retry-After、整体超时、请求重建和重复副作用的处理。

  • 前端场景中的图遍历应该怎样建模？

    用模块依赖和页面路由图说明 BFS、DFS、访问集合和环检测的区别，给出可复用实现并分析复杂度、深度风险和异步遍历边界。

  • 文本编辑器为什么不能只用一个字符串保存全文？

    比较字符串、数组、Piece Table 和 Rope 在插入删除、撤销、内存和渲染上的取舍，说明编辑数据结构与 DOM 渲染、协同同步是不同层次的问题。

  • 如何用拓扑排序解析前端任务和模块依赖？

  • 如何合并时间区间？相邻区间算不算重叠？

  • 搜索建议什么时候适合用 Trie？前缀树怎样处理重复词和 Unicode？
