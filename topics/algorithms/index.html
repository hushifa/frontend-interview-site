手写与算法面试题

JavaScript 手写题与算法练习，包含防抖、节流、LRU 缓存、Promise.all、异步并发池和树的前序遍历，附代码与边界说明。共 43 道题。

  • 怎样实现只在停止调用后执行的防抖函数？

    防抖就是"等你停下来再执行"：最后一次调用之后等一段时间，这段时间里没有新调用才真正执行。每次调用都清掉旧定时器重新计时，执行时用最后一次的参数和 this，还要提供 cancel。防抖只能少发还没开始的请求，已经发出去的请求要用 AbortController 或请求序号处理。

  • 怎样实现首沿节流？它与尾沿节流、防抖有什么区别？

    节流是限制函数在每段时间里最多执行一次。首沿节流在一段时间开始时马上执行，这段时间里的其他调用都丢掉；尾沿节流在这段时间结束时，用最后一次调用的参数执行；防抖则要等调用停下来一段时间才执行。节流只管多久开始执行一次，不等异步操作做完。

  • 怎样实现数组去重和数组扁平化？

    去重最简单的是 [...new Set(arr)]，它按 SameValueZero 比较，能识别 NaN，但对象只按引用比较；对象数组要按某个字段去重时用 Map。扁平化可以直接用 flat(Infinity)，手写时用递归或显式栈，并注意 flat 会跳过稀疏数组的空位。

  • 怎样手写 call、apply 和 bind？用 new 调用 bind 返回的函数会怎样？

    call 和 apply 的手写思路是把函数临时挂到目标对象上调用一次再删掉，两者只是传参方式不同；bind 返回一个固定了 this 和前几个参数的新函数。用 new 调用 bind 出来的函数时，绑定的 this 不起作用，按原函数创建实例，预设的参数照样生效。

  • 怎样手写 new 和 instanceof？

    new 先创建一个原型指向 Fn.prototype 的空对象，再把它当作 this 调用构造函数，构造函数返回对象就用返回值，否则用新对象。instanceof 沿着左边对象的原型链往上找，看能不能遇到右边的 prototype。

  • 怎样用 Promise 实现红绿灯循环和 LazyMan 这类按顺序延时执行的题？

    这类题考的是把“等一段时间再做下一件事”串起来。先把 setTimeout 包成返回 Promise 的 sleep，再用 async/await 在循环里依次等待；LazyMan 这种链式调用，则先把每个方法要做的事放进任务队列，等同步代码跑完后再按顺序执行，sleepFirst 就是把任务插到队头。

  • 怎样实现保持输入顺序的 Promise.all 教学版本？

    Promise.all 接收一组输入，全部成功时按输入顺序返回结果数组，有一个失败就立刻失败。实现的关键是登记每一项时就记住它的下标，用计数器判断是不是全完成了，并用 Promise.resolve 统一处理普通值、Promise 和 thenable。

  • 怎样手写数组的 map、filter 和 reduce？

    三个方法都读取 length，按下标遍历，用 in 判断跳过稀疏数组的空位。map 和 filter 支持 thisArg 参数；reduce 没有 thisArg，不传初始值时用第一个存在的元素当起点，数组里一个元素都没有时抛 TypeError。

  • 怎样手写 Promise.race、Promise.allSettled 和 Promise.any？

    三者都返回一个新 Promise，遍历输入并用 Promise.resolve 包装每一项。race 跟随第一个敲定的结果；allSettled 等全部敲定后按输入顺序返回状态对象；any 取第一个成功的值，全部失败时用 AggregateError 拒绝。空数组时 race 永远 pending，allSettled 兑现为空数组，any 以 AggregateError 拒绝。

  • 怎样手写函数柯里化和 compose？

    柯里化把一个多参数函数改成可以分几次传参的函数，参数凑够原函数的个数才真正执行，常用来预先固定一部分参数。compose 把多个单参数函数串成一个，数据从右往左依次经过每个函数。

  • 怎样手写 Object.create、Object.assign 和 Array.from？

    Object.create 新建一个以指定对象为原型的空对象，可以用临时构造函数模拟；Object.assign 把源对象自己的可枚举属性（含 Symbol 键）用赋值的方式拷到目标上，是浅拷贝，会触发 getter 和 setter；Array.from 先看参数能不能迭代，能就逐个取值，否则按 length 当类数组处理，空位会变成 undefined。

  • 怎样实现 sleep、带超时的请求和可取消的 Promise？

    sleep 就是用 setTimeout 在指定时间后 resolve 的 Promise；超时可以用 Promise.race 让请求和一个定时拒绝的 Promise 比赛，但这只是不再等结果，请求本身没停；要真正停下工作，要用 AbortController 把 signal 传进去，fetch 和自己写的 sleep 都能响应它，AbortSignal.timeout 能直接生成到点自动取消的 signal。

  • 怎样手写 JSON.stringify 和 JSON.parse 的简化版？

    stringify 递归处理值：先调 toJSON，字符串加引号并转义，NaN 和 Infinity 变 null，对象里的 undefined、函数、Symbol 被跳过，数组里的变 null，BigInt 和循环引用抛 TypeError。parse 是一个从左到右读字符的递归下降解析器，按第一个字符决定读对象、数组、字符串、数字还是字面量，不合法就抛 SyntaxError。

  • 怎样实现函数只执行一次（once）和带缓存的 memoize？

    once 用闭包里的一个标记记住是否调用过，第一次执行并保存结果，之后直接返回这个结果；memoize 用 Map 按参数算出的键缓存结果，默认只拿第一个参数当键，多参数要传自定义的键函数。缓存 Promise 时失败结果也会被缓存，需要在拒绝时删掉。

  • 怎样手写 lodash 的 get 和 set？

    get 把 'a[0].b' 这样的路径拆成 ['a', '0', 'b']，一层层往下取，中途遇到 null 或 undefined 就返回默认值；只有结果是 undefined 时才用默认值，null 会原样返回。set 沿路径往下走，缺少的层级按下一段是不是数字下标补成数组或对象，并且要拒绝 __proto__ 这类键，防止原型污染。

  • 怎样手写大数相加？为什么 JS 的大整数会算错？

    JS 的 Number 是双精度浮点数，超过 Number.MAX_SAFE_INTEGER（2^53 - 1）的整数无法精确表示，所以接口里的长 ID、金额要用字符串传输。手写大数相加就是模拟竖式加法，从末位逐位相加并处理进位；现代环境也可以直接用 BigInt。

  • 怎样比较两个版本号的大小？

    按点号拆开，每一段转成数字从左往右比，第一段不相等就决定了结果；段数少的一方缺的部分当作 0，所以 1.0 和 1.0.0 相等。不能直接比字符串，因为字符串按字符比较，'1.10' 会比 '1.9' 小。带 -alpha 这类预发布标签时，要按 SemVer 的规则额外处理。

  • 驼峰和下划线命名怎样互转？怎样深度转换对象的 key？

    下划线转驼峰用正则匹配“下划线加一个字母”，在替换函数里把字母转成大写；驼峰转下划线匹配大写字母，替换成下划线加小写。深度转换对象 key 时递归处理：数组逐项转换，普通对象逐个转换 key 再递归处理值，Date 这类特殊对象和原始值原样返回。

  • 怎样用 setTimeout 实现 setInterval？两者有什么区别？

    在 setTimeout 的回调里先执行任务，再安排下一次 setTimeout，就能循环执行，用一个变量保存最新的定时器 ID 以便取消。区别主要在异步任务上：setInterval 只管按间隔触发回调，回调里发出的请求还没回来，下一次照样触发；链式 setTimeout 可以等请求完成后再安排下一次，还能根据结果调整间隔或停止。

  • 怎样封装一个带过期时间的 localStorage？

    localStorage 只能存字符串，而且数据没有过期时间。封装时把值和过期时间戳一起用 JSON.stringify 存进去，读取时先比较当前时间，过期了就删除并返回 null。JSON.parse 要用 try...catch 包住，防止被别的代码写入的非 JSON 数据弄崩；写入可能因为超出配额抛出 QuotaExceededError，也要捕获。

  • 怎样手写图片预加载和懒加载？

    预加载是提前创建 Image 对象并设置 src，浏览器下载后会放进缓存，真正显示时就不用再等；用 onload、onerror 把它包成 Promise，就能等一组图片都加载完再展示。懒加载反过来，先把真实地址放在 data-src 里，用 IntersectionObserver 监听图片进入视口后再把地址赋给 src，加载后取消监听。现在可以优先用 img 的 loading="lazy"，首屏图片不要懒加载。

  • 怎样用 XMLHttpRequest 手写一个返回 Promise 的 Ajax？

    创建 XMLHttpRequest，调用 open 设置方法和地址，open 之后、send 之前设置请求头，再用 send 发出。load 事件表示收到了响应，但 404、500 也会触发 load，所以要自己检查 status 在 200 到 299 之间才 resolve；error、timeout、abort 事件分别对应网络错误、超时和取消，都应该 reject。

  • 怎样手写数组乱序（洗牌）？为什么 sort(() => Math.random() - 0.5) 不对？

    正确做法是 Fisher-Yates 洗牌：从最后一个位置往前，每次在剩下没处理的元素里随机选一个和当前位置交换，每种排列出现的概率相同，时间 O(n)。用随机比较函数调 sort 违反了比较函数的一致性要求，结果分布不均匀，还依赖引擎的排序实现。

  • 怎样给数字加千分位分隔符？

    业务里直接用 Intl.NumberFormat 或 toLocaleString，它会按地区规则加分隔符、处理小数和货币。面试手写一般用正则 /\B(?=(\d{3})+(?!\d))/g 只处理整数部分，或者从右往左每三位切一段；要注意负号、小数部分不能被分隔，以及超出安全整数的数字要以字符串处理。

  • 怎样手写一个简单的模板字符串渲染函数？

    用正则 /\{\{\s*([\w.]+)\s*\}\}/g 找出模板里的 {{ name }} 这样的占位符，在 replace 的回调里按点号路径从数据对象取值替换。要处理取不到的值、防止原型链上的属性被读出，插到 HTML 里时还要转义，否则用户输入会变成 XSS。

  • 怎样手写深拷贝？和 structuredClone 有什么区别？

    深拷贝就是把对象里每一层都复制一份，改副本不影响原对象。手写时递归复制，用 WeakMap 记下复制过的对象来处理循环引用，Date、RegExp、Map、Set 单独处理，用 Reflect.ownKeys 才能拷到 Symbol 键。structuredClone 原生支持循环引用和大多数内置类型，但会丢掉 Symbol 键和原型，碰到函数会报 DataCloneError。

  • 怎样手写深比较 isEqual？

    先处理原始值和同一引用，再按类型逐层比较：Date 比时间戳，RegExp 比 source 和 flags，数组和普通对象比自有可枚举键的数量和每个键的值，用 WeakMap 记录正在比较的对象对来处理循环引用。NaN 通常当作相等，+0 和 -0 是否相等要按需求明确取舍。

  • 怎样实现一个简单的 Promise 调度器，限制并发并按优先级执行任务？

    调度器接收还没启动的任务函数和优先级，放进按优先级排好的等待队列；正在运行的任务少于上限时，就从队头取一个启动，任务结束再补下一个。add 返回的 Promise 跟随任务的结果，单个任务失败不影响队列继续跑。

  • 怎样手写一个支持 on、off、once 和 emit 的事件中心？

    用一个 Map 按事件名存监听器数组。emit 遍历之前先复制一份，这样执行过程中新加的监听器下一次才生效，刚被移除的这一轮仍会执行，和 Node.js 的 EventEmitter 一致。once 的监听器要在调用之前移除，回调里再 emit 同一事件才不会重复触发。

  • 怎样在 O(n) 时间内把扁平列表转成树，再把树转回列表？

    先遍历一遍，用 Map 按 id 把所有节点建好；再遍历一遍，按 parentId 从 Map 里找到父节点，挂到它的 children 上，找不到父节点的当作根。两遍各是 O(n)，而且不管输入顺序。树转回列表用一个栈做前序遍历，顺便记下每个节点的父 id。

  • 如何利用 Map 实现固定容量的 LRU 缓存？

    LRU 是缓存满了时，淘汰最久没用过的那一条。JavaScript 的 Map 按插入顺序遍历，每次用到一个键就先删再插，把它挪到最后，排在最前面的就是该淘汰的。经典写法是哈希表加双向链表，两种实现效果一样。

  • 怎样实现有明确失败语义的异步并发池？

    并发池就是"最多同时跑 limit 个任务，跑完一个再接下一个"。它接收还没启动的任务函数，同时开 limit 个循环去领任务，结果按原来的顺序存。有任务失败时整体失败，不再领新任务，已经开始的任务要靠 AbortSignal 自己停。

  • 异步请求重试应该怎样设计？

    只重试过一会儿可能自己好的失败，比如 429、502、503、504；次数要有上限，等待时间每次翻倍再加随机抖动，服务端给了 Retry-After 就照办，等待中途能取消。写操作重试前，服务端必须用幂等键保证重复提交不会做两次。

  • 怎样用显式栈实现树的前序遍历？

    前序遍历是先访问当前节点，再从左到右把每棵子树完整走一遍。用数组当栈代替递归，树很深时也不会把调用栈撑爆；因为栈是后进先出，子节点要倒着放进去。时间复杂度 O(n)，栈最多占多少看树的形状。

  • 如何合并时间区间？相邻区间算不算重叠？

    以视频已看过的片段为例，按左闭右开区间合并：先按起点排序，再一个个和结果里最后一个区间比较。首尾正好相接的区间要不要合并，看业务：统计看了多少时要合并，判断预约冲突时不算冲突。

  • 二分查找怎样定位时间轴边界？为什么重复值和空数组容易写错？

    以视频章节定位为例，用左闭右开区间写 lowerBound 和 upperBound：lowerBound 找第一个大于等于目标的位置，upperBound 找第一个大于目标的位置。两个组合起来，能找出当前在哪一章、统计重复值有几个，空数组和找不到的情况也自然处理好了。

  • 如何用拓扑排序解析前端任务和模块依赖？

    拓扑排序是把有依赖关系的任务排成一列，保证每个任务都排在它依赖的任务后面，常用在构建任务编排、插件加载、monorepo 包构建。Kahn 算法先数清每个节点还有几个依赖没完成，从没有依赖的开始一层层输出，最后还剩节点排不出来，就说明有循环依赖。

  • 前端任务怎样按优先级排队？二叉堆为什么不需要每次完整排序？

    以资源加载队列为例，用最小堆实现优先队列：插入时往上浮，取出时把最后一个元素挪到堆顶再往下沉，都是 O(log n)，比每次插入都整体排序省得多。同优先级要按提交顺序取，需要额外加一个序号。优先队列只管谁先谁后，不管并发数量和取消。

  • 搜索建议什么时候适合用 Trie？前缀树怎样处理重复词和 Unicode？

    以命令面板的前缀搜索为例，用 Map 节点实现 Trie：每个节点代表一个前缀，terminal 标记表示有个词在这里结束。查一个前缀要走几步只看前缀多长，跟总共有多少词无关。插入前要统一 Unicode 编码和大小写；要模糊匹配或按热度排序时，Trie 就不够用了。

  • 前端场景中的图遍历应该怎样建模？

    模块依赖、页面跳转、组件引用都可以看成有方向的图。DFS 用栈沿一条路走到底，适合找出所有能到达的节点、检查循环依赖；BFS 用队列一层层往外扩，能找到经过边数最少的路径。两种都要记录走过的节点，不然遇到环会无限循环。

  • 文本编辑器为什么不能只用一个字符串保存全文？

    字符串不能原地修改，在大文档中间插一个字，就要把整段内容复制一遍。Piece Table 保留原文和一个只往后追加的缓冲区，用一串片段描述当前文档，插入删除只改片段；Rope 把文本拆到一棵平衡树上，适合超大文本。存储结构只解决存的问题，渲染和多人协同是另外的事。
