数据结构与算法面试题

按分类查阅数据结构与算法面试题，包含参考答案与参考资料。共 19 道题。

  • 快速排序和归并排序怎样实现？时间复杂度和稳定性有什么区别？

    快速排序选一个基准，把数组分成比它小和比它大的两部分再递归，平均 O(n log n)，最坏 O(n²)，不稳定。归并排序把数组对半拆到只剩一个元素，再两两有序合并，始终 O(n log n)，稳定但要额外空间。JS 的 Array.prototype.sort 从 ES2019 起要求稳定。

  • 怎样反转链表、判断链表有环？

    反转链表用三个指针，一边遍历一边把每个节点的 next 指回前一个节点。判断有环用快慢指针，慢指针每次走一步、快指针走两步，有环就一定会相遇。两种做法都是 O(n) 时间、O(1) 额外空间。

  • 动态规划怎么入门？爬楼梯和最长递增子序列怎样做？

    动态规划把大问题拆成重叠的小问题，用数组记住小问题的答案，避免重复计算。写的时候先定义状态 dp[i] 表示什么，再找转移方程和初始值。爬楼梯 dp[i] = dp[i-1] + dp[i-2]；最长递增子序列 dp[i] 是以第 i 个数结尾的最长长度，O(n²)，用二分可以优化到 O(n log n)。

  • 回溯怎么写？全排列、子集和组合总和怎样做？

    回溯就是在一棵“选择树”上做深度优先搜索，每一步做一个选择、递归下去、回来时撤销这个选择。全排列用 used 数组避免重复使用元素；子集和组合用 start 下标保证只往后选，避免同一组合换个顺序再出现一次；组合总和允许重复选同一个数，所以递归时 start 传 i 而不是 i + 1。

  • 有效括号、最小栈这类栈题怎样做？

    栈是后进先出的结构，JS 里用数组的 push 和 pop 就能实现。有效括号：遇到左括号入栈，遇到右括号就和栈顶比对，最后栈必须为空。最小栈：再维护一个辅助栈，每次入栈时记下“到目前为止的最小值”，getMin 直接读辅助栈栈顶，所有操作 O(1)。

  • 最大子数组和、买卖股票的最佳时机怎样做？

    两题都是一次遍历、只记一两个变量。最大子数组和用 Kadane 算法：以当前元素结尾的最大和，要么接在前面后面，要么从自己重新开始，取较大值。买卖股票只能交易一次时，记住到目前为止的最低价，每天算一次“今天卖出”的利润取最大值。两者都是 O(n) 时间、O(1) 空间。

  • 双指针有哪些常见题型？

    双指针就是用两个下标在数组上配合移动，把两层循环降成一次遍历。常见的有两种：快慢指针同向走，比如移动零；左右指针从两头往中间走，比如盛水最多的容器、三数之和。三数之和先排序，固定一个数后用左右指针找另外两个，还要跳过重复值，整体 O(n²)。

  • 最长公共子序列和编辑距离怎样用动态规划求？

    两题都用二维 dp，dp[i][j] 表示第一个字符串前 i 个字符和第二个字符串前 j 个字符的答案。最长公共子序列：末尾字符相同时取左上角加 1，不同时取上方和左方的较大值。编辑距离：末尾相同时直接取左上角，不同时取插入、删除、替换三种操作里最小的再加 1。时间复杂度都是 O(mn)，空间可以压缩到一行。

  • 最长递增子序列怎样用贪心加二分做到 O(n log n)？Vue 3 的 diff 为什么用它？

    维护一个 tails 数组，tails[k] 是长度为 k+1 的递增子序列里最小的结尾。每来一个数，用二分找到第一个大于等于它的位置替换掉，比所有数都大就追加，tails 的长度就是答案。要还原出具体的子序列，需要额外记录每个数的前一个数的下标。Vue 3 在列表中间乱序的部分求最长递增子序列，子序列里的节点不用移动，只移动其他节点。

  • 岛屿数量怎样用 DFS 或 BFS 求？

    逐个扫描网格，碰到一块还没访问过的陆地，岛屿数加 1，再从它出发用 DFS 或 BFS 把上下左右相连的陆地全部标记掉，这样同一座岛只会被数一次。每个格子最多访问一次，时间 O(mn)。递归 DFS 在大网格上可能栈溢出，可以改成显式栈或用队列做 BFS。

  • 二分查找有哪些常见变体？怎样找边界、在旋转数组里查找？

    找目标第一次和最后一次出现的位置，用两次二分：一次找第一个大于等于目标的位置，一次找第一个大于目标的位置再减 1。旋转排序数组没有整体有序，但从中点切开，左右两半至少有一半是有序的，先判断哪一半有序，再看目标在不在这一半里，就能每次排除一半。

  • 两数之和怎样从 O(n²) 优化到 O(n)？哈希表在算法题里怎么用？

    暴力解法是两层循环检查每一对数，O(n²)。用 Map 记录已经看过的数和它的下标，每遇到一个数就查 target 减它的差值在不在 Map 里，一次遍历就够，时间 O(n)，空间 O(n)。这是用空间换时间的典型做法。

  • 回文字符串和最长回文子串怎样判断？

    判断回文用两个指针从两头往中间走，逐个比较，O(n)。忽略大小写和标点时，跳过非字母数字字符再比较。求最长回文子串用中心扩展：每个位置和每两个相邻位置之间都可能是回文中心，从中心向两边扩，共 2n-1 个中心，时间 O(n²)、空间 O(1)。

  • 滑动窗口怎样求无重复字符的最长子串？

    用左右两个指针围出一个窗口，右指针不断向右扩，遇到窗口里已有的字符，就把左指针移到这个字符上次出现位置的后一位。用 Map 记录每个字符最后出现的下标，每个字符最多进出窗口一次，整体 O(n)。

  • 二叉树怎样层序遍历、求最大深度？

    层序遍历用队列，每轮先记下当前队列长度，把这一层的节点依次取出，同时把它们的子节点放进队尾，一轮就是一层。最大深度可以递归求左右子树深度的较大值加 1，也可以数层序遍历一共走了几层。

  • 位运算在前端里有哪些用法？

    JS 的位运算会先把数字转成 32 位有符号整数再计算，结果也是 32 位整数。常见用法是权限位掩码：每个权限占一位，用 | 组合、& 检查、& ~ 移除。要小心 | 0 取整：超出 -2147483648 到 2147483647 的数会被截断成完全不同的值，取整应该用 Math.trunc。>>> 是无符号右移，结果总是非负数，常用来把负数看成 32 位无符号整数。

  • 并查集怎样实现？适合解决什么问题？

    并查集用一个 parent 数组把元素组织成若干棵树，每棵树代表一个集合，树根就是集合的代表。find 沿着 parent 找到根，union 把一棵树的根挂到另一棵的根下。加上路径压缩和按大小合并后，每次操作的均摊时间接近常数。适合动态判断“两个元素是否连通”，比如朋友圈数量、岛屿数量、检测无向图里的环。

  • 图的最短路径怎样求？BFS 和 Dijkstra 有什么区别？

    每条边一样长时，BFS 从起点一层层往外扩，第一次到达某个点时走的就是最短路径，O(V + E)。边有不同的非负权重时要用 Dijkstra：每次从还没确定的点里取出当前距离最小的一个，它的距离就确定了，再用它更新邻居。用最小堆取最小值时是 O((V + E) log V)。边权有负数时 Dijkstra 不再正确，要换 Bellman-Ford。

  • KMP 字符串匹配的思路是什么？

    暴力匹配在失配时把模式串只往后挪一位、从头再比，最坏 O(n × m)。KMP 先为模式串算出 next 数组：next[i] 是前 i + 1 个字符里，既是前缀又是后缀的最长长度。失配时主串指针不回退，模式串直接跳到 next 指出的位置继续比，整体 O(n + m)。JS 里日常查找直接用 indexOf 或 includes，KMP 主要考查对前缀函数的理解。
