AI 应用前端面试题

AI 前端开发面试题，涵盖大模型流式对话、SSE 与流解析、工具调用、RAG 引用、MCP、结构化输出、提示词注入和浏览器端推理。共 19 道题。

  • AI 对话前端为什么不能直接内置服务商 API 密钥？

    浏览器收到的 JavaScript、请求参数和构建时注入的变量，都可以被用户检查。把服务商长期密钥写进 VITE 环境变量、打包文件或混淆字符串，不能让它保密；私有源码仓库也不改变已发布网页的可读取性。

  • AI 流式响应为什么不能每收到一块就 JSON.parse？

    网络读取的 chunk 是字节分块，不保证对应一个字符、一条 SSE 事件或一个完整 JSON。一个消息可能跨多个块，一块也可能包含多个事件。需要按字符编码和协议边界增量解析，不能把 reader.read 的每个 value 直接当…

  • AI 聊天界面为什么不能只有 loading 一个状态？

    等待服务端开始响应、正在接收内容、生成完成和请求失败，对用户意味着不同的事情。AI SDK 当前 useChat 的 status 区分 submitted、streaming、ready 和 error，可据此控制等待提示、停止按钮和提交入口。

  • 点击“停止生成”后，服务端一定停止调用模型吗？

    不一定。前端停止显示、取消 HTTP 请求、服务端中止上游模型请求，是不同层次的动作。AI SDK 的 stop 会中止客户端请求；要让取消继续传到模型，还依赖服务端运行环境传播断连信号，并把信号传给模型调用。

  • 模型提出工具调用后，前端应该怎样展示和确认？

    工具调用表示模型提出带参数的操作请求，不代表操作已执行，更不代表获得用户权限。界面应区分参数接收中、参数就绪、等待确认、执行中、成功、失败和拒绝等状态，并用调用 ID 关联同一操作。

  • 提示词注入与普通 XSS 有什么区别？

    提示词注入试图让模型把不可信内容中的指令当成应执行的要求。输入不一定来自当前聊天用户，也可能藏在检索文档、网页、工具结果、代码注释或图片中，这类情况属于间接注入。

  • AI 生成的 Markdown 应该怎样安全地渲染？

    模型输出应按不可信内容处理。不要直接把生成文本作为 HTML 交给 dangerouslySetInnerHTML，也不要把生成的 JSX、MDX 或脚本直接编译执行。展示代码与执行代码是不同的权限边界。

  • RAG 应用中，前端除了展示答案还需要关注什么？

    RAG 是先取得与问题相关的外部信息，再把这些信息作为生成时的上下文。向量检索是一种实现方式，并非所有 RAG 都必须使用向量数据库，也不等于把全部资料重新训练进模型参数。

  • 哪些 AI 能力可以直接在浏览器中运行？

    浏览器可以下载合适的模型与运行时，在本地执行文本、图像或音频等推理任务。ONNX Runtime Web 提供 WebAssembly、WebGPU 等执行方式；Transformers.js 则提供模型与任务接口。是否可用取决于具体…

  • 浏览器端 AI 为什么用了 WebGPU 或 Worker 仍可能卡顿？

    总耗时包含模型下载、加载初始化、数据预处理、推理和结果后处理。首次运行与后续运行也可能不同。只看模型核心推理耗时，会漏掉下载、内存分配和 CPU/GPU 之间的数据复制成本。

  • 为什么不能用字符串长度准确计算 Token 和费用？

    Token 是模型分词器使用的单位，不等于字符数、字节数或单词数。不同模型及分词器可能对同一文本得到不同计数，不能把“一个中文字符等于一个 Token”写成通用规则。

  • MCP、模型工具调用和聊天界面是什么关系？

    MCP 定义 AI 应用与外部能力交换上下文的协议。宿主应用管理客户端，客户端连接服务器；服务器可暴露工具、资源和提示模板。它不规定模型怎样思考，也不自动替应用完成 Agent 编排。

  • AI 会话持久化为什么不能只保存最后一段回答？

    完整会话通常包含用户与助手消息、稳定 ID、有序消息片段、工具调用及结果，可能还包含来源和状态信息。只保存最终文字会丢失继续交互所需的结构，刷新后也难以准确恢复中断位置。

  • AI 前端应用为什么需要评测和可观测性？

    说明 AI 界面如何记录可比较的质量信号、延迟和失败原因，同时避免采集不必要的用户内容。

  • 多模态 AI 前端界面需要额外处理哪些状态？

    从文件、图片、音频和流式结果说明预览、上传、解析、生成和失败状态的界面设计边界。

  • AI 实时语音界面需要关注哪些前端状态？

    从麦克风权限、音频采集、连接状态、打断和播放队列设计实时语音 AI 交互，区分浏览器能力与服务端模型能力。

  • AI 结构化输出为什么仍需要 Schema 校验？

    区分模型声称返回 JSON 和应用真正得到可用数据，设计解析、校验、修复和错误展示流程。

  • Agent 前端界面怎样展示计划、工具调用和人工确认？

    建模 Agent 的消息、步骤、工具状态和审批状态，避免只显示一段不可解释的最终文本。

  • AI Prompt Caching 对前端请求设计有什么影响？

    理解提示词缓存的前缀、版本和失效边界，避免把缓存命中当成固定成本或隐私隔离保证。
