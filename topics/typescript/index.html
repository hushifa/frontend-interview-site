TypeScript面试题

TypeScript 面试题，涵盖泛型、类型收窄、联合类型、type 与 interface、映射类型、条件类型和 infer，帮助理解前端类型建模与编译配置。共 18 道题。

  • any、unknown 和 never 分别适合什么场景？

    分清绕过检查、未知输入和不可能出现的值。

  • type 和 interface 有哪些区别？

    比较对象建模、联合类型、扩展与声明合并。

  • 泛型解决了什么问题？如何约束泛型？

    在复用逻辑的同时，保留参数与返回值之间的类型关系。

  • 如何用可辨识联合避免不合理的状态组合？

    把加载、成功、失败建模为互斥状态，并检查分支是否完整。

  • TypeScript 怎样通过控制流缩小类型？

    TypeScript 会根据 typeof、instanceof、in、相等判断及可辨识字段分析控制流，从联合类型中排除不可能分支。可选链只处理 null 与 undefined，不会替你证明业务字段一定有效。

  • 映射类型与 Partial、Pick、Omit 如何用于接口建模？

    映射类型遍历一组属性键，生成具有新属性类型或修饰符的对象类型。Partial 把顶层属性变为可选，Required 移除可选，Readonly 添加只读；Pick 选择字段，Omit 排除字段。

  • 条件类型、infer 和分布式条件类型如何理解？

    条件类型用 T extends U ?

  • as const、类型注解和 satisfies 有什么不同？

    普通类型注解规定变量对外呈现的类型，可能把具体字面量拓宽。as const 会阻止表达式中的字面量拓宽，并使对象属性和数组结构在类型层面更只读；它不是运行时深冻结，也不会把表达式中已经引用的所有外部可变对象递归变成不可变对象。

  • 结构类型、可选属性和额外属性检查有哪些区别？

    TypeScript 主要按结构判断类型兼容，即对象具备所需成员时可赋给相应类型。对象字面量在直接赋值或传参时还有额外属性检查，帮助发现拼写错误；经过变量中转后检查方式可能不同。

  • strict、noUncheckedIndexedAccess 和 target 如何配置？

    strict 开启一组严格检查，是新项目常见起点，但并不包含所有有价值的检查。noUncheckedIndexedAccess 会让数组或索引签名访问结果包含 undefined，提醒调用者处理越界和缺失情况。

  • 为什么 TypeScript 不能替代接口数据校验？

    TypeScript 的类型通常在编译后被擦除，网络响应、localStorage 和第三方脚本返回值并不会因为写了接口声明就自动符合类型。response.json() 后直接断言，只是跳过了一层编译器疑问。

  • 函数重载、联合参数与泛型怎样选择？

    如果多个输入类型对应相同的处理方式和返回类型，联合参数往往最清楚；如果输入与输出存在可表达的类型关系，泛型更合适；当调用形式明确不同且返回值随形式变化时，可使用重载。

  • .d.ts 声明文件提供了什么，不能保证什么？

    声明文件描述 JavaScript 模块或全局对象对外暴露的类型，让 TypeScript 能进行检查和补全。它不提供对应的运行时代码，也不会把外部数据自动校验成声明的类型。

  • 项目引用与 tsc -b 如何管理多包类型构建？

    TypeScript 项目引用通过 tsconfig 中的 references 表达项目依赖，使大型代码库能按边界检查和构建。被引用项目需要启用 composite，并满足声明输出和文件范围等约束；消费者通常依赖其声明输出。

  • TypeScript 新装饰器与 experimentalDecorators 有何区别？

    TypeScript 5.0 引入了新装饰器语义的支持；旧 experimentalDecorators 则对应较早的实验方案。两者在调用参数、类型检查和输出上有区别，现有装饰器库不能默认直接切换。

  • import type 和 verbatimModuleSyntax 如何影响模块输出？

    import type 明确表达只在类型层面使用的依赖，整条纯类型导入会在输出中擦除。verbatimModuleSyntax 让导入导出的保留规则更直接：没有 type 修饰的内容按相应模块语法保留，类型部分被移除。

  • TypeScript 声明合并和模块扩展有哪些边界？

    区分接口合并、命名空间合并和 module augmentation，理解它们只影响类型系统而不自动改变运行时。
