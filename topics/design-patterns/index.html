设计模式面试题

按分类查阅设计模式面试题，包含参考答案与参考资料。共 8 道题。

  • 观察者模式和发布订阅模式有什么区别？前端哪里用到了它们？

    观察者模式里，被观察的对象自己保存观察者列表，状态变了直接逐个通知。发布订阅在中间多了一个事件中心，发布者和订阅者互不认识，只按事件名通信。Vue 的响应式依赖收集接近观察者模式，EventEmitter、DOM 事件和全局事件总线是发布订阅。

  • 单例模式在前端怎样实现？ES 模块天然是单例吗？

    单例模式保证一个类只有一个实例，并提供全局访问点，常见于全局弹窗、请求客户端、store。可以用闭包或静态属性缓存实例，惰性创建。ES 模块在同一个模块图里只执行一次，导出的对象天然被共享，但多个打包副本、微前端或测试隔离时可能出现多份。

  • 策略模式和代理模式分别解决什么问题？前端怎样使用？

    策略模式把一组可以互换的算法分别封装起来，用一张表按名字选择，替代一长串 if-else，常用于表单校验和价格计算。代理模式在访问对象前加一层，控制、增强或延迟这次访问，比如缓存代理、图片懒加载，以及 Vue 3 用 Proxy 实现的响应式。

  • 工厂模式和适配器模式在前端里怎样用？

    工厂模式把“创建哪种对象”的判断收进一个函数，调用方只传类型和参数，比如按类型创建不同的图表或表单控件。适配器模式把一种接口转换成调用方期望的接口，比如把新旧两套后端返回的数据整理成同一种格式，或者给第三方库包一层统一的调用方式。

  • 装饰器模式是什么？和高阶函数、高阶组件有什么关系？

    装饰器模式是在不修改原对象的前提下，用一个外层把它包起来，调用时先经过外层，从而叠加日志、校验、缓存等功能，接口保持不变。在 JavaScript 里最常见的写法是高阶函数，接收一个函数、返回增强后的函数；高阶组件是同样的思路用在 React 组件上。语言层面的 @ 装饰器语法还是 TC39 提案，要靠 TypeScript 或 Babel 编译。

  • SOLID 原则是什么？开闭原则在前端里怎样体现？

    SOLID 是五条面向对象设计原则：单一职责、开闭、里氏替换、接口隔离、依赖倒置。前端里最常用的是开闭原则，新增功能靠注册和组合，而不是修改已有代码，比如表单字段注册表、插件机制、组件插槽。文中用一个字段注册表演示，并讲什么时候不必套用。

  • 职责链模式是什么？中间件和请求拦截器是怎样用它的？

    职责链把多个处理者串成一条链，请求沿链传递，每个处理者决定自己处理、加工后交给下一个，或者直接中断。前端常见的是 Koa 中间件、Express 中间件和 axios 拦截器。文中写一个审批链和一个洋葱式中间件，并讲 axios 请求拦截器后加先执行的顺序。

  • 状态模式和命令模式分别解决什么问题？撤销重做怎样实现？

    状态模式让对象在不同状态下有不同行为，把“当前状态能做什么、做完去哪个状态”写成一张表，替代散落各处的 if 判断，常用于订单流程和异步请求状态。命令模式把一次操作封装成带 execute 和 undo 的对象，用撤销栈和重做栈实现编辑器的撤销重做。文中各写一个可运行示例，并对比保存快照的做法。
