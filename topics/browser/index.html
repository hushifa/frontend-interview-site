浏览器原理面试题

浏览器原理面试题，讲解页面渲染、DOM 事件与事件委托、重排与布局抖动、浏览器存储、Web Worker、同源策略和 bfcache。共 22 道题。

  • 浏览器从 HTML 到页面显示，经历哪些主要步骤？

    串起解析、样式计算、布局、绘制和合成。

  • 事件委托是什么？target 和 currentTarget 有何区别？

    利用事件传播，在父节点集中处理子元素的交互。

  • Cookie、localStorage 和 sessionStorage 如何选择？

    比较生命周期、请求携带行为与安全边界。

  • 什么是强制同步布局？如何避免布局抖动？

    识别 DOM 读写交错引发的重复布局工作。

  • addEventListener 的 capture、once、passive 和 signal 有什么作用？

    capture 决定是否在捕获阶段接收事件；once 表示监听器最多执行一次后移除；passive 声明监听器不会取消默认行为，在此监听器中调用 preventDefault 不会达到预期的取消效果。

  • IntersectionObserver 适合做什么，能否证明用户看到了内容？

    IntersectionObserver 异步报告目标元素与根区域的交叉情况，适合图片预加载、无限列表触发点和粗粒度可见性判断。root、rootMargin 与 threshold 分别控制参考区域、边界扩展和交叉比例阈值。

  • Web Worker 可以解决哪些主线程卡顿？

    Worker 在独立的执行上下文中运行脚本，适合解析大数据、计算、压缩等可与 DOM 分离的工作。普通 Worker 不能直接操作页面 DOM，需要通过消息把结果交回主线程。

  • IndexedDB 为什么比 localStorage 更适合大型离线数据？

    IndexedDB 提供异步的对象存储、索引和事务，能保存结构化数据，适合离线记录与较大缓存。localStorage 是同步键值存储，通常以字符串处理数据，大量读写可能影响主线程响应。

  • 页面进入后台后，计时器和动画还会按原速度运行吗？

    浏览器通常会对后台页面的计时器进行节流，并暂停或减少 requestAnimationFrame 回调，以节约资源。具体策略会受浏览器、设备和页面状态影响，不能依赖固定的后台执行频率。

  • 同源、同站点与跨域分别是什么意思？

    常见 HTTP 地址的源由协议、主机和端口组成。任一项不同就不再同源，路径不同不影响源。浏览器用同源策略限制脚本读取跨源数据和访问某些对象。

  • bfcache 与 HTTP 缓存有什么区别？

    bfcache 保存页面在内存中的快照，包括 DOM 和 JavaScript 堆等状态，用于快速恢复前进、后退导航。HTTP 缓存保存请求响应，重新加载页面时仍可能需要解析和执行，因此两者不是同一种缓存。

  • 为什么不断追加微任务会阻塞页面响应？

    在微任务检查点，浏览器会继续处理队列中新增的微任务，直到队列清空。递归调用 queueMicrotask 或不断衔接已兑现 Promise，可能让输入处理和渲染长期得不到机会。

  • crossOriginIsolated 为 true 需要哪些条件？

    跨源隔离用于收紧文档与其他来源的共享关系，为 SharedArrayBuffer 等能力提供环境条件。常见部署组合是 COOP： same-origin，以及 COEP： require-corp 或 credentialless，还…

  • 页面导航的关键阶段怎样用 Navigation Timing 分析？

    区分 DNS、连接、请求、响应、DOM 和加载事件时间点，避免把 loadEventEnd 当成页面可用时间。

  • Page Visibility API 适合处理哪些页面生命周期场景？

    使用 visibilitychange 感知页面进入后台，降低不必要的轮询和动画开销，同时理解它不能替代页面卸载通知。

  • BroadcastChannel 适合解决什么跨标签通信问题？

    使用 BroadcastChannel 在同源窗口、标签页和 Worker 之间广播消息，理解来源、生命周期和数据一致性边界。

  • Web Locks API 能怎样协调多个标签页？

    用 Web Locks 在同源页面之间协调独占资源，理解等待、超时、丢失页面和不可靠锁持有者的边界。

  • StorageManager 能告诉我们浏览器存储的哪些信息？

    了解 estimate、persist 和持久化存储请求的边界，区分配额估计与数据永久保存承诺。

  • SharedWorker 和 Dedicated Worker 有什么区别？

    理解共享 Worker 的连接端口和生命周期，选择合适的页面间后台任务通信方式。

  • Web Bluetooth API 的安全和兼容性边界是什么？

    理解用户选择设备、权限、GATT 服务和断开处理，避免把蓝牙设备访问当成普通网络请求。

  • scheduler.postTask 怎样安排浏览器任务优先级？

    了解 Scheduler API 的任务优先级、取消和实验性边界，避免把它当成任意长任务的自动优化器。

  • Navigation API 解决了传统 History API 的哪些问题？

    理解导航拦截、当前 entry 和跨文档导航事件，避免把实验性 Navigation API 当成所有浏览器的默认方案。
