图形与可视化面试题

前端图形与可视化面试题，对比 Canvas、SVG、WebGL 和 WebGPU，理解绘图方案、着色器与 GPU 处理的适用场景。共 10 道题。

  • Canvas 和 SVG 怎样选择？

    Canvas 主要通过脚本绘制像素结果，SVG 以矢量图形元素描述图像。SVG 元素可以参与 DOM、样式和事件体系；Canvas 绘制后的图形对象通常需要应用自行管理状态和命中检测。

  • WebGL 的着色器和 GPU 加速意味着什么？

    WebGL 通过图形 API 使用设备图形能力，在 canvas 中绘制二维或三维内容。应用准备几何数据、纹理和着色器，GPU 按图形流水线处理，JavaScript 负责组织命令与资源。

  • WebGPU 与 WebGL 的关注点有哪些不同？

    WebGPU 面向更现代的 GPU 使用模型，除了图形渲染，还提供通用计算管线等能力。它通过适配器、设备、资源、管线和命令提交等概念组织工作，并使用相应的着色器语言。

  • WebCodecs 适合哪些浏览器端音视频场景？

    WebCodecs 提供编码器、解码器和音视频帧的底层控制，适合剪辑、转码和帧分析；它不负责容器解析、播放时钟、网络传输或完整播放器。

  • Canvas 的 transform 怎样影响坐标和绘制？

    理解当前变换矩阵、translate、scale、rotate 和 save/restore，避免把页面坐标直接当成 Canvas 绘制坐标。

  • WebXR 应用需要处理哪些设备与会话边界？

    理解 XRSession、参考空间、帧循环和权限，区分沉浸式 VR/AR 与普通 WebGL 画布。

  • Canvas 图形命中测试应该怎样实现？

    用 Path2D、isPointInPath 和坐标转换判断点击图形，理解绘制像素和交互区域不是同一件事。

  • 前端图表如何同时满足无障碍和高性能？

    从 Canvas、SVG 和 HTML 图表的差异出发，设计可访问的数据替代、键盘操作、动态播报和颜色方案，并说明大数据量下的性能取舍。

  • WebGL 着色器如何工作？如何避免把 GPU 当成黑盒？

    从顶点着色器、片元着色器和坐标空间出发，解释 WebGL 数据如何进入 GPU，分析精度、纹理、批次和兼容性问题。

  • Three.js 页面退出后为什么还占内存？怎样管理模型和渲染器的生命周期？

    从产品预览反复打开的场景出发，区分场景移除、GPU 资源释放和 JavaScript 引用，给出独占资源的挂载与清理示例，并解释共享纹理和异步加载的边界。
