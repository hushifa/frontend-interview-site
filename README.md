# 前端知库

一个中文前端学习与查阅网站，提供面试题库和免费前端资源目录，方便日常学习、技术选型和面试复习。

**[在线访问](https://hushifa.github.io/frontend-interview-site/)**

## 功能

- 按知识分类浏览题目。
- 搜索题目标题、摘要、分类和标签，支持多个关键词。
- 按难度筛选，切换排序并分页浏览。
- 点击题目展开解析，阅读代码示例和参考资料。
- 通过题解底部的「反馈此题」提交 GitHub Issue，自动带上题目信息。
- 按用途、技术生态、资源类型和关键词筛选前端资源，查看使用说明和官方链接。
- 通过资源说明中的反馈入口提交 GitHub Issue，自动带上资源信息。
- 适配电脑和手机屏幕，无需注册登录。

提交反馈需要登录 GitHub，反馈内容公开可见。

## 内容范围

题库持续补充，涵盖 HTML / CSS、JavaScript、TypeScript、浏览器、Web API、网络、安全、无障碍、React、Vue、工程化、性能、测试、架构和手写算法等主题。

「AI 应用前端」分类包含流式对话、消息状态、工具调用、结构化输出、RAG、MCP、浏览器端推理和相关安全边界。

题解附参考资料，涉及版本或运行环境的内容会说明适用范围。内容用于学习与复习，不代表已经覆盖所有前端知识。

资源目录收录免费查阅资料、开源组件库和开发工具。混合提供免费与付费功能的项目只介绍许可明确的免费开源部分，不包含收费扩展、商业模板、托管服务或模型调用额度。
