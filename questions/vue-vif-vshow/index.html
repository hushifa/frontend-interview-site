v-if 和 v-show 应该怎样选择？

v-if 条件为假时真的把元素和组件删掉，里面的状态也没了；v-show 一直渲染，只是用 display 藏起来。很少切换用 v-if，频繁切换用 v-show。

参考答案

简答

v-if 是真正的条件渲染。条件为假时元素根本不存在，组件会被卸载，里面的状态和事件监听都被清掉。v-show 则总是渲染，只是用 display: none 把元素藏起来，组件实例和状态一直都在。

所以它们的成本正好相反。v-if 初始条件为假时什么都不渲染，开销小，但每次切换都要创建或销毁；v-show 一开始就要渲染，但切换只是改个样式。频繁切换的标签页、折叠面板用 v-show，权限控制、一开始不需要的大块内容用 v-if。

有一点容易忽略：v-show 藏起来的组件还在运行，计时器、请求、侦听器都不会停。隐藏时必须停掉这些东西，就用 v-if。

语法上，v-if 能配合 v-else、v-else-if，也能用在 <template> 上；v-show 两样都不行。

状态到底保不保留

用一个带输入框的组件试一下。它在挂载和卸载时各打印一句：

vue
<!-- Draft.vue -->
<script setup>
import { onMounted, onUnmounted, ref } from 'vue';

const text = ref('');
onMounted(() => console.log('挂载'));
onUnmounted(() => console.log('卸载'));
</script>

<template>
  <textarea v-model="text" />
</template>

父组件里放两份，一份用 v-if，一份用 v-show：

vue
<script setup>
import { ref } from 'vue';
import Draft from './Draft.vue';

const visible = ref(true);
</script>

<template>
  <button @click="visible = !visible">切换</button>
  <Draft v-if="visible" />
  <Draft v-show="visible" />
</template>

在两个输入框里都输入文字，再点两次切换。v-if 那份会打印“卸载”和“挂载”，文字被清空了；v-show 那份什么都没打印，文字还在。

原因是 v-if 隐藏时把组件整个销毁了，text 跟着没了，再显示时是一个全新的组件。v-show 只是改了根元素的 display，组件一直活着。

如果必须用 v-if，又想保留状态，可以把状态提升到父组件，或者用 <KeepAlive> 包住动态组件。

怎么选

场景选择
标签页、折叠面板来回切换v-show
权限控制、初始不需要的大块内容v-if
隐藏时必须停止计时器或断开连接v-if
隐藏时保留表单草稿v-show 或状态提升

v-if 和 v-for 写在一起会怎样

Vue 3 中，同一个元素上 v-if 的优先级比 v-for 高，所以 v-if 里读不到 v-for 的循环变量。想过滤列表，应该先用 computed 筛好再 v-for；想根据整体条件隐藏列表，就把 v-if 放到外层的 <template> 上。Vue 2 中两者优先级正好相反。

对屏幕阅读器有什么影响

display: none 和 v-if 都会让内容从无障碍树中移除，屏幕阅读器读不到。如果只想视觉上隐藏、但还要让辅助技术读到，应该用视觉隐藏的 CSS 类，而不是这两个指令。

常见追问

v-if 切换时 key 有什么用？

Vue 2 中，v-if 和 v-else 切换两个同类型元素时会复用同一个元素，比如两个输入框之间切换，输入的内容会留着，要加不同的 key 才能强制重建。Vue 3 的编译器会自动给各个分支生成不同的 key，所以不再需要手写。列表 key 的原理和 React 一样，见《列表中的 key 为什么不能随意使用数组下标？》。

在组件上用 v-show 会怎样？

display 会加在组件的根元素上。如果组件有多个根元素，Vue 会给出警告。
