v-if 和 v-show 应该怎样选择？

v-if 按条件创建或销毁元素与组件，条件为假时子组件被卸载、内部状态丢失；v-show 始终渲染，只切换 CSS display。初始不需要或很少切换用 v-if，频繁切换用 v-show。

参考答案

简答

  • v-if 是真正的条件渲染：条件为假时元素不存在，组件被卸载，内部状态和事件监听被清理。
  • v-show 总是渲染元素，只通过 display: none 隐藏，组件实例和状态一直保留。
  • v-if 初始条件为假时不渲染，初始成本低，切换成本高；v-show 正好相反。
  • v-show 隐藏的组件仍在运行：计时器、请求、侦听器都不会停止。
  • v-if 可以配合 v-else、v-else-if，也能用在 <template> 上；v-show 不支持 <template>，也不能配合 v-else。

对比状态是否保留

vue
<!-- Draft.vue -->
<script setup>
import { onMounted, onUnmounted, ref } from 'vue';

const text = ref('');
onMounted(() => console.log('挂载'));
onUnmounted(() => console.log('卸载'));
</script>

<template>
  <textarea v-model="text" />
</template>
vue
<script setup>
import { ref } from 'vue';
import Draft from './Draft.vue';

const visible = ref(true);
</script>

<template>
  <button @click="visible = !visible">切换</button>
  <Draft v-if="visible" />
  <Draft v-show="visible" />
</template>

在两个输入框都输入文字，再切换两次：

  • v-if 那份打印"卸载""挂载"，文字被清空。
  • v-show 那份没有打印，文字还在。

需要用 v-if 又想保留状态时，把状态提升到父组件，或者用 <KeepAlive> 包裹动态组件。

如何选择

场景选择
标签页、折叠面板来回切换v-show
权限控制、初始不需要的大块内容v-if
隐藏时必须停止计时器或断开连接v-if
隐藏时保留表单草稿v-show 或状态提升

v-if 与 v-for

Vue 3 中同一元素上 v-if 优先级高于 v-for，所以 v-if 里读不到 v-for 的循环变量。过滤列表应先用 computed 筛选，再 v-for；按整体条件隐藏列表，把 v-if 放在外层 <template> 上。Vue 2 中优先级相反。

无障碍

display: none 和 v-if 都会让内容从无障碍树中移除，屏幕阅读器读不到。只想视觉隐藏但保留给辅助技术，应使用视觉隐藏类而不是这两个指令。

常见追问

  • v-if 切换时 key 有什么作用？v-if / v-else 切换两个相同类型的元素时，Vue 会复用元素；加不同的 key 可以强制重建。列表 key 的原理和 React 相同，见《列表中的 key 为什么不能随意使用数组下标？》。
  • 组件上用 v-show 会怎样？display 加在组件根元素上；多根组件会给出警告。
