除了 this，箭头函数和普通函数还有哪些区别？

除了沿用外层 this，箭头函数也没有自己的 arguments、super 和 new.target；它不能用 new 调用，没有 prototype 属性，函数体里不能用 yield，参数和箭头之间不能换行。所以它适合写回调和短小的工具函数，不适合做构造函数和 Generator。

参考答案

简答

面试里问箭头函数，大家先想到 this，规则见《普通函数和箭头函数的 this 有什么区别？》。这里讲 this 以外的区别。

MDN 的说法是，箭头函数没有自己的 this、arguments 和 super 绑定，也没有 new.target，用到时都去外层找。所以箭头函数里读 arguments，拿到的是外层普通函数的参数；想要自己的参数，用剩余参数 (...args)。

它还不能当构造函数：用 new 调用会抛 TypeError，它也没有 prototype 属性。函数体里不能用 yield，所以也写不成 Generator。

因此箭头函数适合写回调和短小的工具函数，不适合写构造函数和 Generator。写法上它也更紧凑：单个参数可省括号，单个表达式可省花括号并直接返回。

先看几个区别

JavaScript
function Normal() {}
const Arrow = () => {};
console.log(typeof Normal.prototype); // object
console.log(Arrow.prototype); // undefined
try {
  new Arrow();
} catch (error) {
  console.log(error.name); // TypeError
}
function outer() {
  const arrow = () => arguments[0];
  return arrow('箭头自己的参数');
}
console.log(outer('外层参数')); // 外层参数
const timer = {
  seconds: 0,
  start() {
    [1, 2, 3].forEach(() => {
      this.seconds += 1;
    });
    return this.seconds;
  },
};
console.log(timer.start()); // 3

前两行说明箭头函数没有 prototype。new 一个函数时要拿它的 prototype 做新对象的原型，箭头函数既没有这个属性，也不允许被 new，所以直接抛 TypeError。

为什么 arrow('箭头自己的参数') 返回的是外层参数？因为箭头函数没有自己的 arguments，它里面的 arguments 指的是外层 outer 的。想拿箭头函数自己的参数，用剩余参数 (...args) => args[0]。

最后的 timer.start() 得到 3，这是箭头函数沿用外层 this 的效果，和 arguments 沿用外层是同一个道理：这些绑定箭头函数自己都没有，只能顺着代码位置往外找。

不能 new，也不能写成 Generator

构造函数要靠 prototype 给实例提供原型，还可能用 new.target 判断自己是不是被 new 调用的。箭头函数这两样都没有，所以它不能当构造函数，class 和普通 function 才能。

MDN 还写明，箭头函数体里不能使用 yield（除非出现在箭头函数内部嵌套的普通函数里），所以箭头函数不能用作 Generator。需要惰性产出数据时，用 function*。

类字段里写 handle = () => {} 时，MDN 提醒，类字段定义在实例上而不是原型上，每创建一个实例就会多一个新函数，子类也没法用 super.handle() 调用它。

写法上的区别

箭头函数只有一个简单参数（没有默认值、解构或剩余参数）时可以省略括号；函数体只有一个表达式时可以省略花括号，表达式的值就是返回值。要直接返回对象字面量，必须用括号包起来，写成 () => ({ id: 1 })，否则花括号会被当成函数体。

另外，参数和 => 之间不能换行，否则是语法错误；换行可以放在 => 之后。

常见追问

箭头函数用 call 传参还有效吗？

有效。传给 call、apply、bind 的 this 参数会被忽略，但后面的参数照常传入。

async 箭头函数可以吗？

可以，async () => {} 是合法的，里面能用 await，this 同样沿用外层。只是不存在“箭头 Generator”，因为箭头函数体里不能用 yield。
