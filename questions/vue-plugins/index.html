Vue 插件如何向应用提供可复用能力？

插件是一个带 install(app, options) 方法的对象或一个函数，用 app.use 装到应用上，可以注册全局组件和指令、提供服务。状态要在 install 里创建，这样多个应用和服务端渲染时互不干扰。

参考答案

简答

插件就是给整个 Vue 应用加能力的东西。它可以是一个带 install(app, options) 方法的对象，也可以直接是一个 (app, options) => {} 函数，通过 app.use() 安装。Vue Router、Pinia 都是插件。

在 install 里通常做这几件事：用 app.component 注册全局组件，用 app.directive 注册指令，用 app.provide 提供一个服务，或者往 app.config.globalProperties 上挂模板里能直接用的方法。

暴露服务时更推荐 provide，组件里再用 inject 或封装好的 useXxx() 拿到。这样类型推导更好，测试时也容易替换。

有两点要注意。同一个插件对同一个应用重复 app.use 只会装一次，不能靠再装一次来改配置。状态要在 install 里创建，不要放在模块级变量里，因为服务端渲染时每个请求都是新的应用实例，模块级状态会被所有用户共用。

写一个格式化插件

下面的插件提供金额和日期格式化，用工厂函数接收语言和币种：

JavaScript
// plugins/format.js
import { inject } from 'vue';

const FormatKey = Symbol('format');

export function createFormat({ locale = 'zh-CN', currency = 'CNY' } = {}) {
  return {
    install(app) {
      const money = new Intl.NumberFormat(locale, { style: 'currency', currency });
      const service = {
        money: (n) => money.format(n),
        date: (d) => new Intl.DateTimeFormat(locale).format(d),
      };
      app.provide(FormatKey, service);
      app.config.globalProperties.$money = service.money; // 可选：模板中直接用
    },
  };
}

export function useFormat() {
  const service = inject(FormatKey);
  if (!service) throw new Error('未安装 format 插件');
  return service;
}

安装和使用：

JavaScript
// main.js
import { createApp } from 'vue';
import App from './App.vue';
import { createFormat } from './plugins/format';

createApp(App).use(createFormat({ currency: 'USD' })).mount('#app');
vue
<script setup>
import { useFormat } from '@/plugins/format';
const { money } = useFormat();
</script>

<template>
  <span>{{ money(42) }}</span>
</template>

为什么不直接导出一个插件对象，而要用 createFormat() 包一层？因为每调用一次工厂函数，就得到一份独立的配置和服务。同一个页面上有两个应用，一个用人民币、一个用美元，也互不影响。service 是在 install 里创建的，跟着具体的应用实例走，也就不会出现服务端渲染时多个请求共用一份状态的问题。

useFormat 里找不到服务就直接报错，是为了让“忘了装插件”这种错误尽早暴露，而不是在某处悄悄得到 undefined。

插件加的全局监听怎么清理

插件如果给 window 加了 resize 之类的监听，应用卸载后监听还在。Vue 3.5 起可以用 app.onUnmount 在应用卸载时清理：

JavaScript
install(app) {
  const onResize = () => { /* ... */ };
  window.addEventListener('resize', onResize);
  app.onUnmount(() => window.removeEventListener('resize', onResize));
}

在 TypeScript 里声明 globalProperties

往 globalProperties 上挂了 $money，TypeScript 默认不知道它的类型，模板里会报错。要补一个类型声明：

TypeScript
declare module 'vue' {
  interface ComponentCustomProperties {
    $money: (n: number) => string;
  }
}

常见追问

Vue Router、Pinia、vue-i18n 都是插件吗？

是。它们都通过 app.use 安装，并用 provide 把实例暴露给组件。

和 Vue 2 的插件有什么区别？

Vue 2 的 Vue.use 修改的是全局构造函数，会影响页面上所有应用。Vue 3 的插件安装在具体的 app 实例上，各个应用互不干扰。
