Vue 插件如何向应用提供可复用能力？

插件是带 install(app, options) 方法的对象（或一个函数），通过 app.use 安装，用来注册全局组件和指令、用 app.provide 提供服务、或添加 globalProperties。插件状态应在 install 中按应用实例创建，以便 SSR 和多应用场景互不干扰。

参考答案

简答

  • 插件可以是 { install(app, options) {} } 对象，也可以直接是 (app, options) => {} 函数。
  • install 中常做的事：app.component 注册组件、app.directive 注册指令、app.provide 提供服务、app.config.globalProperties 添加模板可用的全局方法。
  • 推荐用 provide 暴露服务，组件通过 inject 或封装好的 useXxx() 获取，比 globalProperties 更利于类型推导和测试。
  • 同一个插件对同一个应用重复调用 app.use 只会安装一次，不能借此修改配置。
  • 状态在 install 中创建，不要放在模块级变量里；SSR 中每个请求都是新的应用实例，模块级状态会被所有用户共享。

示例：格式化服务

JavaScript
// plugins/format.js
import { inject } from 'vue';

const FormatKey = Symbol('format');

export function createFormat({ locale = 'zh-CN', currency = 'CNY' } = {}) {
  return {
    install(app) {
      const money = new Intl.NumberFormat(locale, { style: 'currency', currency });
      const service = {
        money: (n) => money.format(n),
        date: (d) => new Intl.DateTimeFormat(locale).format(d),
      };
      app.provide(FormatKey, service);
      app.config.globalProperties.$money = service.money; // 可选：模板中直接用
    },
  };
}

export function useFormat() {
  const service = inject(FormatKey);
  if (!service) throw new Error('未安装 format 插件');
  return service;
}
JavaScript
// main.js
import { createApp } from 'vue';
import App from './App.vue';
import { createFormat } from './plugins/format';

createApp(App).use(createFormat({ currency: 'USD' })).mount('#app');
vue
<script setup>
import { useFormat } from '@/plugins/format';
const { money } = useFormat();
</script>

<template>
  <span>{{ money(42) }}</span>
</template>

用 createFormat() 工厂函数返回插件，每次调用都得到独立的配置，适合同一页面有多个应用实例的情况。

清理资源

插件如果注册了全局监听（例如 window 的 resize），Vue 3.5 起可以用 app.onUnmount 在应用卸载时清理：

JavaScript
install(app) {
  const onResize = () => { /* ... */ };
  window.addEventListener('resize', onResize);
  app.onUnmount(() => window.removeEventListener('resize', onResize));
}

TypeScript 中声明 globalProperties

TypeScript
declare module 'vue' {
  interface ComponentCustomProperties {
    $money: (n: number) => string;
  }
}

常见追问

  • Vue Router、Pinia、vue-i18n 都是插件吗？是，它们都通过 app.use 安装，并用 provide 暴露实例。
  • 和 Vue 2 的区别？Vue 2 的 Vue.use 修改全局构造函数，影响页面上所有应用；Vue 3 的插件安装在具体的 app 实例上。
