Vue 插件如何向应用提供可复用能力？

Vue 插件通过 app.use 安装，可以是带 install 方法的对象，也可以直接是安装函数。它接收应用实例和选项，可注册组件、指令，提供依赖，或扩展应用级能力。

参考答案

Vue 插件通过 app.use 安装，可以是带 install 方法的对象，也可以直接是安装函数。它接收应用实例和选项，可注册组件、指令，提供依赖，或扩展应用级能力。

对于需要配置的共享服务，可以用 app.provide 配合组件注入，明确依赖入口；使用 globalProperties 时则要控制数量并补充类型，避免组件依赖大量隐式全局名称。

插件应明确初始化参数和资源生命周期，并考虑多个应用实例、测试隔离以及 SSR 请求间隔离。把可变用户状态放到模块级单例里并不会因为套了一层插件就安全。安装后是否支持动态配置、如何清理，也应写成可维护的接口约定。

组件层面的落地

Vue 题目可以沿着依赖收集、更新调度、组件渲染和副作用生命周期来理解。响应式引用记录的是读取关系，不代表所有嵌套对象都会以同样方式被追踪；具体行为还取决于使用的 API 和 Vue 版本。

落地时把派生状态、用户输入和副作用分开，避免用一个 watch 或可写变量反复同步同一事实。组件卸载、异步竞态、SSR 和第三方 DOM 操作都需要单独验证。
