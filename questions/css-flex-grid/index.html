Flexbox 和 Grid 应该如何选择？

Flex 是让东西沿一个方向按自身大小排开，适合导航栏、按钮组；Grid 是先画好行和列再往里放，适合要上下左右都对齐的布局。

参考答案

简答

Flex 是从内容出发的。项目先按自己的大小一个个排开，再分剩下的空间。换行以后，每一行各算各的。

Grid 是从布局出发的。先把行和列画好，这些行列叫轨道，再把项目放进格子里。所以不同行的同一列天然是对齐的。

所以要“最后一行的卡片和上面对齐”，用 Grid；要“按钮按文字宽度依次排开”，用 Flex。两者也经常嵌套使用，页面骨架用 Grid，卡片里一行图标加文字用 Flex。

它们都支持 gap，justify-*、align-* 这些对齐属性的用法也基本一样，换起来成本不高。

换行时差别最明显

CSS
.tags {
  display: flex;
  flex-wrap: wrap;
  gap: 8px;
}

.cards {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  gap: 16px;
}

标签有长有短，用 Flex 让每个标签按自己的文字宽度排，排不下就换行，正合适。

卡片要整整齐齐排成列，就该用 Grid。有人用 Flex 加 flex: 1 1 200px 来做卡片网格，前几行看着没问题，可最后一行如果只剩两张，这两张会被拉宽，跟上面的列对不齐。原因就是 Flex 每一行单独分配空间，它不知道上一行的列在哪里。

常见场景怎么选

导航栏、按钮组、表单里的一行，这种一个方向排列的，用 Flex。

页面的头部、侧栏、主区、底部，以及卡片网格、图库，需要行和列同时对齐，用 Grid。

图标加文字垂直居中，两种都可以。子组件要对齐父布局的列，用 Grid 加 subgrid。

居中怎么写

CSS
.center {
  display: grid;
  place-items: center;
}

用 Flex 写是 display: flex; justify-content: center; align-items: center;，效果一样，Grid 写法只是更短。

常见追问

Grid 的性能是不是比 Flex 差？

日常页面里，这点差别可以忽略。真正的性能问题通常来自布局抖动或者节点太多，而不是选了哪种布局。
