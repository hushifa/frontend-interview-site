Flexbox 和 Grid 应该如何选择？

Flex 沿一个方向按内容大小分配空间，适合工具栏、导航这类一行或一列的排列；Grid 先定义行列轨道再放置项目，适合需要跨行跨列对齐的布局。

参考答案

简答

  • Flex 从内容出发：项目先按自身大小排开，再分配剩余空间，换行后每行独立计算。
  • Grid 从布局出发：先定义轨道，项目放进格子，不同行的同一列天然对齐。
  • 需要“最后一行的卡片和上面对齐”时用 Grid；需要“按钮按文字宽度依次排开”时用 Flex。
  • 两者可以嵌套：页面骨架用 Grid，卡片内部的一行图标和文字用 Flex。
  • 两者都支持 gap，对齐属性（justify-*、align-*）用法基本一致。

换行时的差别

CSS
.tags {
  display: flex;
  flex-wrap: wrap;
  gap: 8px;
}

.cards {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  gap: 16px;
}

标签长短不一，用 Flex 让每个标签按内容宽度排列。卡片要整齐成列，用 Grid；如果用 Flex 加 flex: 1 1 200px，最后一行剩下的卡片会被拉宽，和上面的列对不齐。

典型选择

场景选择
导航栏、按钮组、表单一行Flex
页面头部、侧栏、主区、底部Grid
卡片网格、图库Grid
图标加文字垂直居中Flex 或 Grid 都可以
子组件要对齐父布局的列Grid 加 subgrid

居中

CSS
.center {
  display: grid;
  place-items: center;
}

Flex 写法是 display: flex; justify-content: center; align-items: center;，效果相同。

常见追问

  • Grid 性能比 Flex 差吗？日常页面里差别可以忽略。性能问题通常来自布局抖动或节点过多，而不是选了哪种布局。
