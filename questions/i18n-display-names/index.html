Intl.DisplayNames 怎样本地化语言、地区和货币名称？

Intl.DisplayNames 按 type 把语言、地区、文字、货币等代码转换成当前语言的名称。名称来自运行时的 CLDR 数据，只用于展示；存储和提交使用代码本身，并明确 fallback 行为。

参考答案

简答

  • 构造时指定显示语言和 type（language、region、script、currency、calendar、dateTimeField），of(code) 返回名称。
  • 名称来自浏览器或 Node.js 自带的 CLDR 数据，不同版本可能不同。界面显示名称，存储和接口传递代码。
  • 默认 fallback: 'code'：认不出的代码原样返回代码，格式正确的未知语言标签会返回类似 xx (UNKNOWN) 的结果；设成 'none' 时返回 undefined，由应用自己处理。
  • 代码格式不合法（例如地区写成 123x）会抛 RangeError。
  • 同样配置的实例要缓存复用；SSR 时服务端和客户端要用同一个 locale，避免水合不一致。

基本用法

JavaScript
const region = new Intl.DisplayNames('zh-CN', { type: 'region' });
const language = new Intl.DisplayNames('zh-CN', { type: 'language' });
const currency = new Intl.DisplayNames('zh-CN', { type: 'currency' });

region.of('TW'); // 台湾（Node 22 实测）
language.of('fr'); // 法语
language.of('zh-Hant'); // 繁体中文
currency.of('EUR'); // 欧元
new Intl.DisplayNames('en', { type: 'region' }).of('JP'); // Japan

地区名称受 CLDR 数据影响。产品对某些名称有特定要求时，用自己的覆盖表优先于 of() 的结果。

代码格式本身不合法时，of() 直接抛错，例如 new Intl.DisplayNames('en', { type: 'region' }).of('123x') 抛 RangeError。

创建实例要加载语言数据，同样的 locale 和 type 应缓存一个实例复用。SSR 时服务端和客户端必须用同一个 locale 创建，否则文字不同会造成水合不一致。

fallback

JavaScript
new Intl.DisplayNames('en', { type: 'region' }).of('XX'); // 'XX'
new Intl.DisplayNames('en', { type: 'region', fallback: 'none' }).of('XX'); // undefined
new Intl.DisplayNames('en', { type: 'language' }).of('xx-unknown'); // 'xx (UNKNOWN)'

xx-unknown 语法合法，运行时把它解析为"语言 xx 加变体 unknown"（new Intl.Locale('xx-unknown').region 是 undefined）并拼出名称，并不会走到返回代码那一步。需要判断"是否真的认识这个代码"时，用 fallback: 'none' 再检查 undefined。

语言名称的两种风格

JavaScript
new Intl.DisplayNames('en', { type: 'language' }).of('en-GB'); // British English
new Intl.DisplayNames('en', { type: 'language', languageDisplay: 'standard' }).of('en-GB');
// English (United Kingdom)

语言切换菜单里，通常每个选项用它自己的语言显示（"日本語""English"），这样不认识当前界面语言的用户也能找到自己的语言。

生成选项列表

JavaScript
function createLanguageOptions(codes, uiLocale) {
  const names = new Intl.DisplayNames(uiLocale, { type: 'language', fallback: 'none' });
  return codes
    .map((code) => ({ value: code, label: names.of(code) ?? code }))
    .sort((a, b) => a.label.localeCompare(b.label, uiLocale));
}

value 是代码，label 只用于显示。

常见追问

  • 能用显示名称反查代码吗？ 不能。名称不唯一，也会随数据版本变化，选项值要始终保留代码。
  • 阿拉伯语名称怎么显示？ new Intl.DisplayNames('ar', { type: 'language' }).of('en') 返回阿拉伯文，嵌入其他语言的页面时要设置 dir="auto" 或用 <bdi> 隔离方向。
