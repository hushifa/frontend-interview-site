CSS @property 如何让自定义属性参与类型校验和动画？

普通自定义属性只是一串 token，浏览器不知道它是颜色还是长度，因此不能插值；@property 注册类型、是否继承和初始值后，自定义属性可以平滑过渡，非法值会退回初始值。

参考答案

简答

  • 未注册的自定义属性在过渡时会直接跳到新值，因为浏览器不知道怎样在两串文本之间插值。
  • @property --x { syntax: '<color>'; inherits: false; initial-value: red; } 注册后，浏览器把它当成颜色计算和插值。
  • syntax 可以是 <length>、<percentage>、<number>、<angle>、<color> 等，也可以写 '*' 表示任意值。
  • 赋了不符合类型的值，声明在计算值阶段无效：inherits: false 时使用 initial-value，inherits: true 时继承父元素的值。
  • inherits: false 可以避免组件内部变量被外层同名变量影响，也减少继承带来的样式重算。

渐变动画

CSS
@property --angle {
  syntax: '<angle>';
  inherits: false;
  initial-value: 0deg;
}

.ring {
  background: conic-gradient(from var(--angle), steelblue, transparent);
  transition: --angle 600ms;
}

.ring:hover {
  --angle: 180deg;
}

渐变本身不能过渡，但渐变里用到的注册属性可以过渡，于是整个渐变平滑旋转。

JavaScript 注册

JavaScript
CSS.registerProperty({
  name: '--progress',
  syntax: '<percentage>',
  inherits: false,
  initialValue: '0%',
});

效果与 @property 相同，同一个名字只能注册一次，重复注册会抛错。

注意

  • 注册后赋了不符合 syntax 的值，例如给 <angle> 写 red，这条声明在计算值阶段无效：inherits: false 时退回 initial-value，inherits: true 时取父元素的值。
  • 除 syntax: '*' 外，initial-value 必须是计算上独立的值，例如 10px 可以，1em 不可以。
  • 注册对整个文档生效，组件库要使用带前缀的名字，避免和页面冲突。
  • @property 已被主流浏览器支持；不支持时属性按普通自定义属性工作，只是失去动画和类型检查。

常见追问

  • Shadow DOM 里写 @property 有效吗？注册是文档级的，写在影子树的样式表里不会生效，需要放在文档样式里或用 CSS.registerProperty。
