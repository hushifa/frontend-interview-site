useActionState 如何把异步 Action 的结果变成组件状态？

useActionState 接收一个 Action 函数和初始状态，返回当前状态、可以传给 form 的 dispatch 函数和 isPending。每次调用时 Action 收到上一次的返回值和本次参数，多次调用按顺序排队执行。

参考答案

简答

  • 签名：const [state, dispatch, isPending] = useActionState(action, initialState, permalink?)。
  • action(prevState, payload) 的返回值（可以是 Promise）成为新的 state。
  • 把 dispatch 传给 <form action={dispatch}> 时，payload 是 FormData；React 会在 Transition 中执行它，Action 完成且未抛错后会重置非受控表单字段，即使返回的是业务失败。
  • 多次触发的调用按顺序排队，后一次拿到的 prevState 是前一次的结果。
  • React 19 中它取代了 canary 时期的 useFormState；校验、权限、错误信息仍要在 Action 里自己实现。

表单示例

JSX
import { useActionState } from 'react';

async function subscribe(prevState, formData) {
  const email = String(formData.get('email') ?? '').trim();
  if (!email.includes('@')) {
    return { ok: false, message: '邮箱格式不正确', email };
  }
  const res = await fetch('/api/subscribe', {
    method: 'POST',
    body: JSON.stringify({ email }),
    headers: { 'Content-Type': 'application/json' },
  });
  if (!res.ok) return { ok: false, message: '订阅失败，请稍后重试', email };
  return { ok: true, message: '订阅成功', email: '' };
}

export default function SubscribeForm() {
  const [state, formAction, isPending] = useActionState(subscribe, {
    ok: false,
    message: '',
    email: '',
  });

  return (
    <form action={formAction}>
      <input name="email" type="email" defaultValue={state.email} aria-describedby="msg" />
      <button disabled={isPending}>{isPending ? '提交中…' : '订阅'}</button>
      <p id="msg" role="status">{state.message}</p>
    </form>
  );
}
  • 失败时把用户输入放进返回值，再用 defaultValue 回填，因为只要 Action 没有抛错，React 都会重置非受控字段。
  • 把可预期的错误作为返回值，而不是 throw。Action 中抛出的错误会交给最近的 Error Boundary，并且会取消队列中排在后面的调用。

在表单之外调用

dispatch 也可以手动调用，但必须放在 Transition 里，isPending 才会更新：

JSX
import { startTransition } from 'react';

function onClick() {
  startTransition(() => dispatch({ type: 'increment' }));
}

和 Server Functions 配合

在支持 RSC 的框架中，action 可以是 'use server' 标记的 Server Function。第三个参数 permalink 用于渐进增强：JavaScript 加载前提交表单时，浏览器跳转到这个 URL，由服务端处理后返回页面。

常见追问

  • 和 useFormStatus 的区别？useActionState 管理 Action 的结果，useFormStatus 只让表单内部的子组件读取父表单是否在提交，见《React useFormStatus 适合管理什么表单状态？》。
