dialog 和 Popover API 应该怎样使用？

dialog 的 showModal() 打开模态对话框，背景变为惰性、Esc 可关闭、元素进入顶层；popover 属性用于非模态浮层，自带轻量关闭和顶层显示。先判断是否要阻断背景交互，再选择。

参考答案

简答

  • dialog.showModal()：模态，页面其他部分不能操作，按 Esc 关闭，有 ::backdrop 遮罩。
  • dialog.show()：非模态对话框，不进入顶层，也没有遮罩。
  • popover：非模态浮层，点击外部或按 Esc 自动关闭（popover="auto"），用 popovertarget 不写 JavaScript 就能打开。
  • showModal() 打开的对话框和 popover 都进入顶层（top layer），不受父元素的 z-index 和 overflow 影响。
  • 关闭后焦点会回到打开它的元素，但对话框内部的初始焦点、名称仍需要正确设置。

模态对话框

HTML
<button id="open">删除</button>

<dialog id="confirm" aria-labelledby="confirm-title">
  <h2 id="confirm-title">删除这条记录？</h2>
  <form method="dialog">
    <button value="cancel">取消</button>
    <button value="ok">删除</button>
  </form>
</dialog>
JavaScript
const dialog = document.querySelector('#confirm');
document.querySelector('#open').addEventListener('click', () => dialog.showModal());
dialog.addEventListener('close', () => {
  if (dialog.returnValue === 'ok') deleteRecord();
});

method="dialog" 的表单提交时关闭对话框，被点击按钮的 value 存到 returnValue，不会发起网络请求。

点击遮罩关闭可以用 closedby="any" 属性，不支持时监听对话框的 click 事件，判断点击目标是否是 dialog 本身。

Popover

HTML
<button popovertarget="menu">更多</button>
<div id="menu" popover>
  <button>重命名</button>
  <button>复制</button>
</div>
  • popover="auto"：打开一个会关闭其他 auto popover，点击外部关闭。
  • popover="manual"：只能通过代码或按钮关闭，适合通知。
  • 位置用锚点定位，见《CSS Anchor Positioning 适合解决哪些浮层布局问题？》。

Popover 不是菜单组件，也不会自动加 role。做菜单时仍要实现方向键导航和对应的 ARIA 角色。

怎么选

场景选择
确认删除、填写表单，必须先处理showModal()
下拉菜单、提示气泡、选择器popover
页面角落的聊天窗口dialog.show() 或 popover="manual"
