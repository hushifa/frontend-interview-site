font-display 怎样影响字体加载期间的文字显示？

网页字体还没下载好时，font-display 决定文字是先藏起来，还是先用系统字体显示，以及字体晚到了还要不要换上。配合预加载和调整回退字体尺寸，可以减少闪烁和页面跳动。

参考答案

简答

网页用了自定义字体，字体文件还没下载完时，文字怎么显示？浏览器把这段时间分成三个阶段：阻塞期，文字先隐藏；交换期，先用回退字体显示，字体到了再换上；失败期，字体再到也不换了。font-display 就是调这几个阶段的长短。

block 是约 3 秒阻塞，交换期无限长；swap 几乎不阻塞，字体什么时候到都换；fallback 是约 100ms 阻塞加约 3 秒交换；optional 是约 100ms 阻塞，没有交换期，字体晚到这次就不用了。

正文一般用 swap 或 optional，别让用户长时间看不到字。图标字体常用 block，因为用回退字体显示会是一堆乱码。

要注意，换字体会让字宽和行高变化，页面会跳。可以用 size-adjust、ascent-override 把回退字体调到接近的尺寸。关键字体用 <link rel="preload" as="font" crossorigin> 提前请求，crossorigin 不能省。

一个完整的声明

CSS
@font-face {
  font-family: 'Brand';
  src: url('/fonts/brand.woff2') format('woff2');
  font-display: swap;
}

@font-face {
  font-family: 'Brand Fallback';
  src: local('Arial');
  size-adjust: 104%;
  ascent-override: 92%;
}

body {
  font-family: 'Brand', 'Brand Fallback', sans-serif;
}

第一段声明品牌字体，用 swap。第二段做了一个“调整过的 Arial”当回退字体。

为什么要专门调回退字体？因为 swap 下用户先看到的是回退字体，品牌字体到了再换。两种字体字宽不同，换的时候每行的字数和高度会变，下面的内容整体往下跳，这在性能指标里叫布局偏移（CLS）。把 Arial 放大 4%、调整上行高度后，它和品牌字体排出来的效果接近，换字体时几乎不跳。

具体的百分比要根据两种字体的实际尺寸来算。Next.js 的 next/font 和 Fontaine 这类工具可以自动生成。

四个值怎么选

品牌字体一定要出现，能接受换一次，用 swap。

首屏稳定最重要，字体只在有缓存时用，用 optional。第一次访问可能看到的是回退字体，下次有缓存了才是品牌字体。

fallback 介于两者之间。

图标字体，或者回退字体根本表达不了的内容，用 block。

还有哪些办法降低字体的成本

字体只提供 WOFF2 格式，按需拆子集。中文字体体积很大，可以用 unicode-range 分片，或者只给标题加载。

预加载只给首屏真正用到的一两个字体。预加载太多，会跟其他关键资源抢带宽。

有些场景要精确量文字尺寸，比如在 Canvas 上画字。这时用 document.fonts.ready 或者 FontFace.load()，等字体准备好再画。

常见追问

为什么预加载字体一定要写 crossorigin？

字体请求总是用 CORS 模式发出的，哪怕是同源字体。预加载不写 crossorigin，就是一个非 CORS 请求，跟后面真正用字体时的请求对不上，浏览器会再下载一次。
