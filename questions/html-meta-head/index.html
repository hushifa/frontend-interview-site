head 中哪些信息会影响页面体验与收录？

charset 和 viewport 影响显示，title 和 description 影响搜索结果展示，canonical 和 robots 影响收录，Open Graph 影响分享卡片；每个页面都要输出与自身内容对应的值。

参考答案

简答

  • <meta charset="utf-8"> 要放在 head 最前面，否则中文可能显示乱码。
  • <meta name="viewport" content="width=device-width, initial-scale=1"> 让移动端按设备宽度布局；不要写 user-scalable=no 或 maximum-scale=1，这会阻止用户放大。
  • <title> 是标签页名称和搜索结果标题，每页要不同；description 常被用作搜索摘要，但搜索引擎可能改写。
  • <link rel="canonical"> 指明同一内容的首选地址，带筛选参数、分页、追踪参数的地址应指向规范地址。
  • <meta name="robots" content="noindex"> 阻止收录，测试环境的 noindex 千万不能带到正式环境。

一个完整的 head

HTML
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>闭包是什么？ - 前端面试题</title>
  <meta name="description" content="闭包是函数和其创建时词法环境的组合……">
  <link rel="canonical" href="https://example.com/questions/js-closure">

  <meta property="og:title" content="闭包是什么？">
  <meta property="og:description" content="闭包是函数和其创建时词法环境的组合……">
  <meta property="og:image" content="https://example.com/og/js-closure.png">
  <meta property="og:url" content="https://example.com/questions/js-closure">

  <link rel="icon" href="/favicon.svg" type="image/svg+xml">
  <meta name="theme-color" content="#ffffff">
</head>

常见错误

  • 单页应用所有路由共用同一个 title 和 description，搜索结果全部一样。需要在路由切换时更新，或预渲染每个页面。
  • canonical 写成相对地址或统一指向首页，会让其他页面不被收录。
  • og:image 用相对路径，社交平台抓取不到图片，必须用绝对 URL。
  • 在 robots.txt 里禁止抓取某页，同时又想用 noindex 移除它：爬虫读不到页面，也就看不到 noindex。

其他

  • <html lang="zh-CN"> 写在 html 标签上，影响读屏发音、断词和翻译提示。
  • 资源提示（preconnect、preload）也放在 head 中，但它们影响的是加载性能，不影响收录。
  • 结构化数据用 <script type="application/ld+json">，可以帮助搜索引擎生成富摘要。

常见追问

  • keywords 还有用吗？主流搜索引擎早已不使用 <meta name="keywords"> 作为排名依据，可以不写。
