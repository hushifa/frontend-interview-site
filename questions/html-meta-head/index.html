head 中哪些信息会影响页面体验与收录？

title 提供页面标题，description 用于描述内容，字符编码应尽早声明。viewport 控制移动端布局视口，常见设置是 width=device-width, initial-scale=1；不应为了防布局问题禁用用户缩放。

参考答案

title 提供页面标题，description 用于描述内容，字符编码应尽早声明。viewport 控制移动端布局视口，常见设置是 width=device-width, initial-scale=1；不应为了防布局问题禁用用户缩放。

canonical 表达首选规范地址，robots 指令控制部分抓取和索引行为，社交分享元信息影响链接预览。它们各自解决不同问题，不能互相替代，更不能仅靠添加关键词元标签保证排名。

单页应用需要随路由同步标题等信息；需要稳定分享预览和索引时，应考虑静态生成或服务端输出关键元信息。错误的 canonical 或 noindex 配置可能让正确页面无法按预期收录。

复习提示

回答时先区分 HTML 语义、CSS 规则和浏览器默认行为，再说明结构、样式与交互之间的影响。涉及兼容性时给出目标浏览器范围，不把某个浏览器的现象当成规范结论。可先用一个最小示例验证“meta、viewport、SEO”，再补充空值、异常和兼容性边界。
