Vue 3 响应式依赖是怎样收集和触发的？

Vue 3 用 Proxy 拦截属性读取和修改。effect（组件渲染函数、computed、侦听器）执行时，读取到的属性被记录为依赖；属性被修改时，通知依赖它的 effect 重新执行。依赖每次执行都会重新收集，组件更新则放进队列批量处理。

参考答案

简答

  • reactive 返回 Proxy：get 时调用 track 记录"当前正在运行的 effect 依赖这个属性"，set 时调用 trigger 通知这些 effect。
  • effect 包括组件的渲染函数、computed 的 getter、watch 和 watchEffect。
  • 依赖按实际读取的属性记录，不是按对象整体；每次 effect 重新执行时都会重新收集，所以条件分支切换后不再读取的属性不会再触发它。
  • 只有在 effect 执行期间同步读取的属性才被追踪，await 之后或 setTimeout 回调里的读取不算。
  • 组件渲染 effect 被触发后不会立即重新渲染，而是放入队列，在同一轮微任务中批量更新，同一组件只渲染一次。

简化实现

JavaScript
let activeEffect = null;
const targetMap = new WeakMap(); // target -> key -> Set<effect>

function track(target, key) {
  if (!activeEffect) return;
  let deps = targetMap.get(target);
  if (!deps) targetMap.set(target, (deps = new Map()));
  let dep = deps.get(key);
  if (!dep) deps.set(key, (dep = new Set()));
  dep.add(activeEffect);
}

function trigger(target, key) {
  targetMap.get(target)?.get(key)?.forEach((effect) => effect());
}

function reactive(obj) {
  return new Proxy(obj, {
    get(target, key, receiver) {
      track(target, key);
      return Reflect.get(target, key, receiver);
    },
    set(target, key, value, receiver) {
      const result = Reflect.set(target, key, value, receiver);
      trigger(target, key);
      return result;
    },
  });
}

function effect(fn) {
  const run = () => {
    activeEffect = run;
    try { fn(); } finally { activeEffect = null; }
  };
  run();
}

const state = reactive({ count: 0 });
effect(() => console.log('count =', state.count)); // count = 0
state.count++; // count = 1

真实实现还处理了嵌套对象的懒代理、数组方法、Map/Set、清理旧依赖、避免 effect 触发自身等情况。

依赖随分支变化

JavaScript
const state = reactive({ showName: true, name: 'Lin', id: 1 });
watchEffect(() => {
  console.log(state.showName ? state.name : state.id);
});

state.showName = false; // 输出 1，此后依赖 showName 和 id
state.name = 'Chen'; // 不再触发

更新调度

JavaScript
state.count++;
state.count++;
state.count++;

组件只重新渲染一次。Vue 把组件更新任务放进队列，在微任务中统一执行，所以修改后立即读取 DOM 拿到的还是旧内容，需要 await nextTick()，见《修改状态后，为什么有时需要 await nextTick()？》。

和 Vue 2 的差别

Vue 2 在初始化时用 Object.defineProperty 遍历对象的每个属性，所以新增属性、删除属性和数组下标赋值检测不到，需要 Vue.set。Vue 3 的 Proxy 在访问时才拦截，嵌套对象也是访问到时才转换，这些限制都消失了。

常见追问

  • 为什么用 WeakMap 存依赖？原始对象不再被引用时，对应的依赖记录可以被垃圾回收。
  • 怎么调试依赖？computed 和 watch 的 onTrack、onTrigger 选项在开发环境中报告收集和触发的依赖。
