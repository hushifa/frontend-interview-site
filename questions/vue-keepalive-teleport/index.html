KeepAlive 与 Teleport 有哪些使用边界？

KeepAlive 缓存被切换掉的组件实例，切回时保留状态，并触发 activated 和 deactivated 钩子；Teleport 把一段模板渲染到组件之外的 DOM 位置，组件之间的逻辑关系不变。前者解决状态保留，后者解决 DOM 位置，两者都不会自动处理资源暂停或弹窗交互。

参考答案

简答

  • <KeepAlive> 包裹动态组件或路由视图，被切走的组件不会卸载，而是进入缓存；切回时触发 onActivated，切走时触发 onDeactivated。
  • 用 include、exclude（按组件 name 匹配）控制缓存哪些组件，用 max 限制数量，超出时淘汰最久未访问的实例。
  • 被缓存的组件仍在内存中，计时器、轮询、WebSocket 不会自动停止，要在 onDeactivated 中暂停、在 onActivated 中恢复。
  • <Teleport to="body"> 把内容渲染到指定 DOM 节点下，常用于弹窗、提示，避免被父元素的 overflow: hidden 或层叠上下文影响。
  • Teleport 只移动 DOM，props、事件、provide/inject 仍按组件树传递；目标节点必须在挂载时已存在，Vue 3.5 起可以用 defer 等待同一轮渲染中的目标。

KeepAlive

vue
<script setup>
import { shallowRef } from 'vue';
import ListPage from './ListPage.vue';
import DetailPage from './DetailPage.vue';

const current = shallowRef(ListPage);
</script>

<template>
  <button @click="current = ListPage">列表</button>
  <button @click="current = DetailPage">详情</button>
  <KeepAlive :max="5">
    <component :is="current" />
  </KeepAlive>
</template>
vue
<!-- ListPage.vue -->
<script setup>
import { onActivated, onDeactivated } from 'vue';

let timer;
function startPolling() {
  timer = setInterval(refresh, 10_000);
}

onActivated(startPolling); // 首次挂载时也会调用
onDeactivated(() => clearInterval(timer));
</script>

onActivated 在首次挂载和每次从缓存恢复时都会调用，onDeactivated 在进入缓存和最终卸载时都会调用，所以轮询只需写在这一对钩子里。

在 Vue Router 中，写法是：

vue
<RouterView v-slot="{ Component }">
  <KeepAlive include="ListPage">
    <component :is="Component" />
  </KeepAlive>
</RouterView>

include 匹配的是组件的 name；<script setup> 组件会根据文件名自动推断 name。

Teleport

vue
<script setup>
import { ref } from 'vue';
const open = ref(false);
</script>

<template>
  <button @click="open = true">打开</button>
  <Teleport to="body">
    <dialog v-if="open" open aria-labelledby="dlg-title" @close="open = false">
      <h2 id="dlg-title">确认删除？</h2>
      <button @click="open = false">取消</button>
    </dialog>
  </Teleport>
</template>

内容渲染在 body 下，但 open 仍由这个组件控制。真正的模态对话框还需要焦点移入、Esc 关闭、关闭后焦点返回触发按钮，使用原生 <dialog> 的 showModal() 能直接获得这些行为。

  • :disabled="true" 可以让内容留在原位，例如在移动端内联显示。
  • SSR 时 Teleport 的内容会单独输出，目标容器要在服务端模板中存在。

常见追问

  • KeepAlive 如何手动清除某个缓存？动态修改 include 列表，移除该组件的 name。
  • 两个 Teleport 指向同一个目标会怎样？按挂载顺序依次追加到目标节点中。
