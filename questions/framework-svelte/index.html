Svelte 的编译思路与 Runes 模型如何理解？

Svelte 在构建时把组件编译成直接更新 DOM 的 JavaScript，不使用虚拟 DOM，但仍有一个小型运行时。Svelte 5 用 Runes 显式声明响应式：$state 声明状态，$derived 声明派生值，$effect 声明副作用，$props 接收属性。

参考答案

简答

  • 编译器在构建时分析模板和状态依赖，生成"某个状态变了就更新这几个 DOM 节点"的代码，运行时不需要比较虚拟 DOM 树。
  • Svelte 5 的 Runes：$state 声明响应式状态，$derived 声明派生值，$effect 执行副作用，$props 接收组件属性。
  • $state 包装的普通对象和数组是深层响应式的，直接修改 obj.a = 1 或 list.push(x) 都会触发更新。
  • $derived 应是纯计算；$effect 只追踪同步读取的状态，返回的函数在重新执行前和组件销毁时调用。
  • Runes 是编译器识别的语法，只能在 .svelte 和 .svelte.js / .svelte.ts 文件中使用。

示例

svelte
<script>
  let { initial = 0 } = $props();
  let count = $state(initial);
  let doubled = $derived(count * 2);

  $effect(() => {
    document.title = `计数 ${count}`;
  });
</script>

<button onclick={() => count++}>点击 {count} 次</button>
<p>两倍：{doubled}</p>

编译后，点击按钮只会更新按钮文字、段落文字和标题，不会重新执行整个组件。

深层状态与快照

svelte
<script>
  let todos = $state([{ text: '学习 Runes', done: false }]);

  function toggle(i) {
    todos[i].done = !todos[i].done; // 直接修改就会更新
  }

  function save() {
    localStorage.setItem('todos', JSON.stringify($state.snapshot(todos)));
  }
</script>
  • $state 返回的是 Proxy；交给第三方库或 structuredClone 时，用 $state.snapshot() 取得普通对象。
  • 大型且不需要深层追踪的数据用 $state.raw，只能通过整体替换来更新。

副作用与清理

svelte
<script>
  let query = $state('');
  let results = $state([]);

  $effect(() => {
    const q = query.trim();
    if (!q) {
      results = [];
      return;
    }
    const controller = new AbortController();
    fetch(`/api/search?q=${encodeURIComponent(q)}`, { signal: controller.signal })
      .then((r) => r.json())
      .then((data) => (results = data))
      .catch((err) => {
        if (err.name !== 'AbortError') console.error(err);
      });
    return () => controller.abort();
  });
</script>

query 变化时先执行返回的清理函数，取消上一次请求。

和 Svelte 4 的区别

Svelte 4Svelte 5
顶层 let 自动响应式$state
$: doubled = count * 2$derived
$: { ... } 副作用$effect
export let name$props()
on:clickonclick

Svelte 5 仍能运行旧语法的组件，但一个组件里不能混用两种模式。

常见追问

  • Svelte 真的没有运行时吗？有一个小型运行时，负责调度和响应式系统，只是比 React、Vue 的运行时小。
  • Svelte 和 SvelteKit 的关系？Svelte 是组件框架，SvelteKit 提供路由、数据加载、SSR 和部署，见《SvelteKit 的路由、load 和服务端边界怎样协作？》。
