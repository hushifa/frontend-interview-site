TypeScript 声明合并和模块扩展有哪些边界？

同名 interface 合并成员，namespace 可以与函数、类、枚举合并来添加静态成员，declare module 和 declare global 可以给已有模块或全局对象补充类型。这些扩展只改变类型，运行时实现必须另外提供并确保被加载。含运行时代码的 namespace 不是可擦除语法，在 erasableSyntaxOnly 和 Node.js 类型剥离下会报错。

参考答案

简答

  • 同名 interface 合并为一个，同名属性类型必须相同；同名方法合并为重载，后声明的重载排在前面。
  • namespace 能与同名函数、类、枚举合并，给它们添加静态成员；但它会生成运行时代码。
  • declare module './x' 给已有模块补充类型（模块增补），只能修改已有导出，不能新增顶层导出。
  • declare global { interface Window { ... } } 在模块文件中扩展全局类型。
  • 所有扩展都只是类型声明，运行时必须有对应的实现，并通过副作用导入确保它被执行。

接口合并

TypeScript
interface PanelOptions {
  title: string;
}
interface PanelOptions {
  width: number;
}
const panel: PanelOptions = { title: '阅读设置', width: 320 };

函数与 namespace 合并

TypeScript
function formatLabel(value: string): string {
  return value.trim();
}
namespace formatLabel {
  export const version = '1.0.0';
}

namespace 会编译成给函数对象赋值的 IIFE。开启 erasableSyntaxOnly（TS 5.8+）时报 TS1294，Node.js 直接运行也会失败。等价的可擦除写法：

TypeScript
export const formatLabel = Object.assign(
  (value: string) => value.trim(),
  { version: '1.0.0' },
);

只含类型的 namespace 和 declare namespace 是可擦除的，不受影响。

模块增补

TypeScript
// counter.ts
export class Counter {
  value = 0;
  increment(): void {
    this.value += 1;
  }
}
TypeScript
// counter-reset.ts
import { Counter } from './counter.js';

declare module './counter.js' {
  interface Counter {
    reset(): void;
  }
}

Counter.prototype.reset = function () {
  this.value = 0;
};
TypeScript
// main.ts
import { Counter } from './counter.js';
import './counter-reset.js';

const counter = new Counter();
counter.increment();
counter.reset();

去掉 main.ts 中的副作用导入后，类型检查仍然通过，运行时 reset 不存在。增补文件自身必须是模块（有 import 或 export），否则 declare module 会声明一个新的环境模块而不是增补。

全局扩展

TypeScript
// globals.d.ts
export {};
declare global {
  interface Window {
    appVersion?: string;
  }
}

这只告诉编译器 window.appVersion 可能存在，赋值要在别处完成。

常见场景与风险

  • 给 Vue 的 ComponentCustomProperties、Express 的 Request 增加字段，这是库预留的扩展点。
  • 不要用增补掩盖版本不兼容：库删除了某个方法，补上类型只会让错误推迟到运行时。
  • 全局扩展影响整个项目，容易和其他库冲突。

常见追问

  • type 能合并吗？不能，同名 type 报重复标识符错误，见《type 和 interface 有哪些区别？》。
  • 类和接口能合并吗？能，同名 interface 会给类实例补充成员，但不提供实现，同样需要另外赋值。
