AI 结构化输出为什么仍需要 Schema 校验？

区分模型声称返回 JSON 和应用真正得到可用数据，设计解析、校验、修复和错误展示流程。

参考答案

模型输出即使看起来像 JSON，也可能缺字段、类型错误、截断或混入额外文本。应用应先处理传输完整性，再解析 JSON，最后用运行时 Schema 校验字段、枚举、范围和业务约束。

Schema 校验失败时要明确区分重试、修复提示、人工确认和放弃；不能静默把缺失值填成看似合理的默认值。结构化输出也不等于事实正确，引用、权限和业务规则仍需独立检查。

流式结构化输出尤其要处理部分对象、增量解析和取消。前端展示可以使用中间状态，但保存或执行工具前必须等待完整且通过校验的数据。
