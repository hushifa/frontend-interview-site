模型返回 JSON，是否就能安全地当成业务数据使用？

参考答案

JSON 语法正确、结构符合 Schema、事实准确和业务允许，是四个不同层次。结构化输出可以约束字段和类型，但不能证明引用真实、金额合理、目标资源存在，或当前用户有权执行相应操作。

AI SDK 当前通过输出 Schema 配合生成与验证。使用流式结构化数据时，中间对象可能尚未完整，不能因为界面已收到某些字段就直接保存或执行操作。最终仍需处理生成失败、校验失败和模型拒绝等情况。

前端可用中间状态渐进展示草稿，在完整校验后再提供提交入口；服务端仍应执行权威校验。TypeScript 类型断言只影响静态检查，无法把模型文本变成可信运行时数据。自动生成表单、配置或工具参数时尤其要分清这些边界。
