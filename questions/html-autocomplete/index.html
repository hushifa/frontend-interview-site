HTML autocomplete 属性怎样帮助表单体验和隐私？

autocomplete 用标准令牌告诉浏览器和密码管理器字段的用途，例如 email、new-password、one-time-code；它是提示而不是强制，填入的数据仍要校验。

参考答案

简答

  • 正确的令牌让浏览器一键填好姓名、地址、电话，移动端能少打很多字。
  • 登录用 username 和 current-password，注册和改密码用 new-password，浏览器会据此建议生成强密码。
  • 短信验证码用 one-time-code，iOS 和 Android 可以直接从短信中提取。
  • autocomplete="off" 是提示，浏览器对登录框通常会忽略；不要为了“安全”关掉密码填充，这会让用户改用弱密码。
  • 令牌可以组合分组和类型，例如 shipping postal-code、billing street-address。

登录表单

HTML
<form>
  <label>
    邮箱
    <input type="email" name="email" autocomplete="username" required>
  </label>
  <label>
    密码
    <input type="password" name="password" autocomplete="current-password" required>
  </label>
  <button>登录</button>
</form>

用户名字段写 username，即使它是邮箱格式，密码管理器才能正确保存账号。

地址和支付

HTML
<input name="name" autocomplete="name">
<input name="tel" type="tel" autocomplete="tel">
<input name="address" autocomplete="shipping street-address">
<input name="postal" autocomplete="shipping postal-code">
<input name="cc" autocomplete="cc-number" inputmode="numeric">
<input name="exp" autocomplete="cc-exp">

同一页面既有收货地址又有账单地址时，用 shipping 和 billing 区分，否则浏览器会把两组都填成一样的值。

无障碍

WCAG 1.3.5（识别输入用途）要求收集用户个人信息的字段标明用途，autocomplete 是满足它的标准方式。WCAG 2.2 新增的 3.3.7（冗余输入）要求同一流程里已填过的信息不再让用户重复输入，自动填充也能帮助满足。

隐私

  • 自动填充可能把信息填进页面上看不见的字段，所以不要在表单里放隐藏的输入框收集额外信息。
  • 共享设备上，用户自己决定是否保存数据；网站能做的是不阻止正常填充，并提供退出登录。

常见追问

  • 为什么 autocomplete="off" 对密码框无效？浏览器认为阻止保存密码会降低安全性，所以主流浏览器对登录字段忽略这个值。
