Vue 生命周期中何时访问 DOM、发请求和清理资源？

setup 最先执行，用来创建状态和发起请求，此时还没有 DOM；onMounted 后可以访问 DOM；onUnmounted 时清理计时器和订阅。SSR 只执行 setup，不调用挂载钩子；被 KeepAlive 缓存的组件切换时触发 activated 和 deactivated。

参考答案

简答

  • 顺序：setup → onBeforeMount → onMounted →（数据变化）onBeforeUpdate → onUpdated → onBeforeUnmount → onUnmounted。
  • setup 中创建响应式状态、发起数据请求；这时 DOM 不存在，模板 ref 为 null。
  • onMounted 中组件的 DOM 已插入页面，可以聚焦、测量、初始化第三方库。
  • onUnmounted 中清理计时器、事件监听、观察器、WebSocket，否则组件销毁后它们仍在运行。
  • 服务端渲染时只运行 setup（以及 onServerPrefetch），挂载和更新钩子都不会执行，所以访问 window、document 的代码要放进 onMounted。

示例

vue
<script setup>
import { onMounted, onUnmounted, ref } from 'vue';

const props = defineProps({ id: Number });
const chartEl = ref(null);
const data = ref(null);
let chart;

// setup 阶段就开始请求，不必等到挂载
const controller = new AbortController();
fetch(`/api/stats/${props.id}`, { signal: controller.signal })
  .then((r) => r.json())
  .then((json) => {
    data.value = json;
    chart?.setData(json);
  })
  .catch((err) => {
    if (err.name !== 'AbortError') console.error(err);
  });

onMounted(() => {
  chart = createChart(chartEl.value); // 需要 DOM
  if (data.value) chart.setData(data.value);
});

onUnmounted(() => {
  controller.abort();
  chart?.destroy();
});
</script>

<template>
  <div ref="chartEl" />
</template>

请求和挂载哪个先完成不确定，所以两边都检查对方是否就绪。

父子组件的顺序

挂载时：父 setup → 子 setup → 子 onMounted → 父 onMounted。父组件的 onMounted 执行时，子组件都已挂载。卸载时同样是子组件的 onUnmounted 先于父组件。

钩子必须同步注册

JavaScript
// 错误：await 之后注册，钩子无法关联到当前组件
const user = await fetchUser();
onMounted(() => {});

生命周期钩子要在 setup 中同步调用。组合式函数里的钩子也遵循同一规则。

KeepAlive 中的组件

被缓存的组件切走时不会卸载，onUnmounted 不执行，改为触发 onDeactivated；切回时触发 onActivated。需要在离开时暂停的资源应写在这对钩子中，见《KeepAlive 与 Teleport 有哪些使用边界？》。
