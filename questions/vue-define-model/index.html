Vue 3 defineModel 的双向绑定边界是什么？

defineModel 是 Vue 3.4 起稳定的 script setup 宏，自动声明模型 prop 和更新事件，返回可读写的 ref。修改这个 ref 会 emit 更新事件；子组件的 default 值不会同步给父组件，修改对象模型的内部属性也不会触发事件。

参考答案

简答

  • const model = defineModel() 等价于声明 modelValue prop 和 update:modelValue 事件；给 model.value 赋值就会 emit。
  • defineModel('title') 声明命名模型，对应父组件的 v-model:title。
  • 修饰符通过解构读取：const [model, modifiers] = defineModel()，再在 set 选项里根据 modifiers 转换写入的值。
  • 父组件没有绑定值时，子组件用 default 显示，但这个默认值不会回传给父组件，两边可能不一致。
  • 模型是对象时，model.value.name = 'x' 直接修改了父组件的对象，不会 emit；需要通知父组件时整体赋新对象。

基本用法

vue
<!-- Rating.vue -->
<script setup>
const score = defineModel({ type: Number, required: true });
</script>

<template>
  <button v-for="n in 5" :key="n" :aria-pressed="n <= score" @click="score = n">★</button>
</template>

父组件写 <Rating v-model="rating" /> 即可。required: true 让父组件必须提供值，避免出现子组件用默认值、父组件却是 undefined 的情况。

自定义修饰符

vue
<!-- TitleInput.vue -->
<script setup>
const [title, modifiers] = defineModel('title', {
  set(value) {
    return modifiers.capitalize ? value.charAt(0).toUpperCase() + value.slice(1) : value;
  },
});
</script>

<template>
  <input v-model="title" />
</template>
vue
<TitleInput v-model:title.capitalize="pageTitle" />

set 只作用于子组件写入的值。父组件直接给 pageTitle 赋小写字符串，不会被转换。

多个模型

vue
<script setup>
const first = defineModel('first');
const last = defineModel('last');
</script>

父组件写 <NameEditor v-model:first="f" v-model:last="l" />。两个模型各自 emit，父组件分两次收到更新；需要两个字段必须同时生效时，改用单个对象模型并整体赋值。

编译结果

defineModel 只能在 <script setup> 中使用，不需要导入，由编译器处理。它展开后就是 prop、emit 和一个本地 ref：父组件传入的值变化时同步到 ref，ref 被赋值时 emit。原理见《组件 v-model 的本质是什么？》。

常见追问

  • 父组件没有用 v-model 时，子组件赋值会怎样？本地 ref 会更新并显示新值，但父组件不知道，像一个非受控组件。
  • 能在普通组合式函数里调用吗？不能，它是编译宏，只在 SFC 的 <script setup> 顶层有效。
