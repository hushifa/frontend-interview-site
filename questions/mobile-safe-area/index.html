移动端安全区域怎样避免内容被刘海和底部手势条遮挡？

安全区域适配要把背景铺满和内容可用范围分开，用 CSS 环境变量保护固定控件、滚动末尾和横屏边缘，同时处理动态工具栏和键盘的独立影响。

参考答案

简答

  • 页面要延伸到刘海和圆角区域，需要在 viewport meta 中设置 viewport-fit=cover。
  • 设置后用 env(safe-area-inset-top/right/bottom/left) 获取被遮挡的距离，给内容和固定控件加上对应的内边距。
  • 背景可以铺满整个屏幕，只有文字、按钮等可交互内容需要避开安全区域。
  • 底部固定栏、滚动列表末尾和横屏时的左右两侧最容易被遮挡。
  • 浏览器地址栏伸缩和虚拟键盘不属于安全区域，要用动态视口单位或 VisualViewport 单独处理。

开启全屏布局

HTML
<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover" />

不设置 viewport-fit=cover 时，浏览器会自动在页面周围留出安全区域，env() 的值为 0；设置后页面占满屏幕，避让工作交给开发者。

常见写法

CSS
.toolbar {
  position: fixed;
  inset-inline: 0;
  bottom: 0;
  padding-bottom: calc(12px + env(safe-area-inset-bottom, 0px));
  padding-inline: max(16px, env(safe-area-inset-left, 0px)) max(16px, env(safe-area-inset-right, 0px));
  background: #fff;
}

.list {
  padding-bottom: calc(64px + env(safe-area-inset-bottom, 0px));
}

.header {
  padding-top: env(safe-area-inset-top, 0px);
}
  • 底部工具栏的背景铺到屏幕底边，按钮通过内边距避开手势条。
  • 列表末尾留出工具栏高度加安全区域的空间，最后一项不会被挡住。
  • 横屏时刘海在左侧或右侧，用 max() 保证至少有正常的内边距。
  • env() 第二个参数是回退值，不支持的浏览器使用它。

动态工具栏和键盘

  • 移动浏览器的地址栏会随滚动收起和展开，100vh 按工具栏收起时的高度计算，可能被遮挡。用 100dvh（随工具栏变化）或 100svh（按工具栏展开时计算）代替。
  • 虚拟键盘弹出时安全区域不会变化，底部固定栏可能被键盘遮挡，处理方式见《移动端虚拟键盘出现时怎样避免布局被遮挡？》。

测试

  • iOS 模拟器选择带刘海和灵动岛的机型，分别测试竖屏和横屏。
  • Android 设备上开启全面屏手势测试底部区域。
  • Chrome DevTools 的设备模拟不能准确模拟安全区域，要以真机或模拟器为准。

常见追问

  • constant() 还需要写吗？这是 iOS 11.0 的旧语法，iOS 11.2 起已改为 env()，现在不需要再写。
  • WebView 中安全区域无效怎么办？需要原生侧允许 WebView 内容延伸到安全区域之外，否则原生已经留了空间，env() 的值为 0。
