数据表格怎样设计才方便键盘和读屏用户理解？

数据表用原生 table，caption 给出表名，th 加 scope 标明是行表头还是列表头；读屏在单元格间移动时会读出对应表头。不要用 div 拼表格，也不要用 table 做布局。

参考答案

简答

  • <caption> 是表格的名称，读屏进入表格时读出。
  • 列表头 <th scope="col">，行表头 <th scope="row">；读屏在单元格之间移动时会读出“列名，行名，值”。
  • 多级表头用 scope="colgroup" 和 colspan；关系太复杂时用 headers 属性逐个关联，或者考虑拆成多个简单表格。
  • 排序列在表头里放一个按钮，并给 th 设置 aria-sort="ascending" 或 descending。
  • 窄屏下表格可以放进可横向滚动的容器，容器加 tabindex="0"、role="region" 和名称，键盘用户才能滚动。

基本结构

HTML
<div role="region" aria-labelledby="sales-caption" tabindex="0" class="table-scroll">
  <table>
    <caption id="sales-caption">2026 年季度销售额（万元）</caption>
    <thead>
      <tr>
        <th scope="col">地区</th>
        <th scope="col">
          <button>第一季度</button>
        </th>
        <th scope="col" aria-sort="descending">
          <button>第二季度</button>
        </th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <th scope="row">华东</th>
        <td>120</td>
        <td>150</td>
      </tr>
    </tbody>
  </table>
</div>

多级表头

HTML
<thead>
  <tr>
    <td></td>
    <th scope="colgroup" colspan="2">上半年</th>
  </tr>
  <tr>
    <th scope="col">地区</th>
    <th scope="col">Q1</th>
    <th scope="col">Q2</th>
  </tr>
</thead>

常见错误

  • 用 CSS Grid 加 div 显示表格数据：读屏无法按行列导航。确实需要 div 结构时，要完整补上 role="table"、row、columnheader、cell。
  • 给布局用的表格加了 th：读屏会把它当成数据表。布局用 CSS，不要用 table。
  • 表格里每个单元格都可聚焦：Tab 要经过几百次。普通数据表只让单元格里的链接和按钮可聚焦。

可交互的网格

可编辑的表格（像电子表格那样用方向键移动）是 role="grid"，需要实现漫游焦点、方向键、Enter 编辑等键盘行为，复杂度高得多，参考 APG 的 Grid 模式。

常见追问

  • 窄屏下把表格改成卡片可以吗？可以，但每张卡片要把表头文字一起显示，例如“第二季度：150”，读屏用户才不会丢掉列的含义。
