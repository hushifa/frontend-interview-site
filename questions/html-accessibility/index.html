触发操作为什么应优先使用 button，而不是可点击的 div？

原生 button 自带很多东西：读屏能认出是按钮、Tab 能聚焦、Enter 和空格能触发、有禁用状态和表单提交。用 div 模拟就得自己一样样补，很容易漏。跳转页面则用带 href 的 a。

参考答案

简答

<button> 免费带了一整套行为：读屏软件会读出“按钮”，按 Tab 能聚焦到它，按 Enter 或空格都会触发 click，还有禁用状态。

一个 div 加 onclick 只有鼠标能用。要补上 role="button"、tabindex="0"、键盘事件和禁用逻辑，才勉强接近原生按钮，而且很容易漏。

选元素的规则很简单：改变页面地址用 <a href>，执行一个动作用 <button>。链接支持在新标签页打开、复制地址，按钮不支持。

用 <button> 也有两点要注意。在表单里它默认是 type="submit"，不需要提交的按钮要写 type="button"。只有图标的按钮要有可访问名称，用 aria-label 或者视觉上隐藏的文字。

用 div 模拟，要补多少东西

HTML
<div role="button" tabindex="0" aria-disabled="false">保存</div>
JavaScript
el.addEventListener('keydown', (event) => {
  if (event.key === 'Enter') el.click();
  if (event.key === ' ') event.preventDefault();
});
el.addEventListener('keyup', (event) => {
  if (event.key === ' ') el.click();
});

role="button" 让读屏认出它是按钮，tabindex="0" 让它能被 Tab 聚焦。可是键盘行为还得手写。

为什么 Enter 和空格要分开处理？因为原生按钮就是这样：Enter 在按下时触发，空格在松开时触发。而且空格默认会让页面往下滚，按下时要阻止。

这还没完，禁用时不响应、焦点样式、表单提交，都要自己处理。这些 <button> 全部自带。

想要自定义样式怎么办

不想要按钮的默认外观，不用换成 div，把样式清掉就行：

CSS
.icon-button {
  all: unset;
  display: inline-grid;
  place-items: center;
  cursor: pointer;
}

.icon-button:focus-visible {
  outline: 2px solid currentColor;
  outline-offset: 2px;
}

要注意 all: unset 会把默认的焦点轮廓也清掉。键盘用户就看不到焦点在哪里了，所以一定要用 :focus-visible 补回来。

按钮的状态怎么告诉读屏

切换型的按钮，比如“静音”，用 aria-pressed="true" 表示当前是按下的。

展开收起的控件用 aria-expanded，再用 aria-controls 指向被控制的区域。

禁用要多想一步。disabled 的按钮不能聚焦，读屏用户用 Tab 可能根本找不到它，也就不知道为什么不能提交。需要让用户知道原因时，可以改用 aria-disabled="true"，按钮保留焦点，在点击处理里把操作拦下来。

常见追问

整张卡片都要能点，怎么做？

不要把整张卡片包成一个链接，也不要嵌套交互元素。卡片标题用一个真正的链接，再用伪元素把这个链接的点击区域扩大到整张卡片。卡片里的其他按钮提高层级，让它们盖在伪元素上面，还能单独点击。
