触发操作为什么应优先使用 button，而不是可点击的 div？

原生 button 自带按钮角色、可聚焦、Enter 和空格激活、禁用状态和表单提交行为；用 div 模拟要自己补齐这些，很容易漏。跳转页面用带 href 的 a。

参考答案

简答

  • <button> 会被读屏识别为“按钮”，能被 Tab 聚焦，按 Enter 或空格都会触发 click。
  • div 加 onclick 只有鼠标能用；要补 role="button"、tabindex="0"、键盘事件和禁用逻辑，才接近原生按钮。
  • 在表单里，<button> 默认 type="submit"，不需要提交的按钮要写 type="button"。
  • 改变页面地址用 <a href>，执行动作用 <button>。链接支持新标签打开和复制地址，按钮不支持。
  • 按钮要有可访问名称；只有图标时用 aria-label 或视觉隐藏的文字。

div 模拟需要补什么

HTML
<div role="button" tabindex="0" aria-disabled="false">保存</div>
JavaScript
el.addEventListener('keydown', (event) => {
  if (event.key === 'Enter') el.click();
  if (event.key === ' ') event.preventDefault();
});
el.addEventListener('keyup', (event) => {
  if (event.key === ' ') el.click();
});

原生按钮在空格键松开时激活，Enter 按下时激活，空格还要阻止页面滚动。还要处理禁用时不响应、焦点样式、表单提交。这些 <button> 全部自带。

样式

CSS
.icon-button {
  all: unset;
  display: inline-grid;
  place-items: center;
  cursor: pointer;
}

.icon-button:focus-visible {
  outline: 2px solid currentColor;
  outline-offset: 2px;
}

all: unset 会清除默认的焦点轮廓，一定要用 :focus-visible 补回来。

状态

  • 切换按钮用 aria-pressed="true"，例如“静音”。
  • 展开控件用 aria-expanded，并用 aria-controls 指向被控制的区域。
  • disabled 的按钮不能聚焦，读屏用户可能找不到它；需要让用户知道为什么不可用时，可以用 aria-disabled="true" 保留焦点，并在点击处理里拦截。

常见追问

  • 整张卡片都要能点怎么办？卡片标题用一个真正的链接，再用伪元素把链接的点击区域扩展到整张卡片，卡片里的其他按钮提高层级，避免嵌套交互元素。
