Intl.ListFormat 怎样生成自然的列表文案？

Intl.ListFormat 按语言生成"A、B 和 C""A, B, or C"这样的列表文案，type 区分"和""或"。输入要先格式化成字符串；每项需要单独渲染（如链接）时用 formatToParts。

参考答案

简答

  • names.join(', ') 处理不了各语言的连接词和标点：英文是 "Alice, Bob, and Carol"，中文是"张三、李四和王五"。
  • type: 'conjunction' 表示"和"，'disjunction' 表示"或"，'unit' 用于"5 小时 30 分"这类单位列表。
  • 只接受字符串。对象要先取显示名，数字要先用 NumberFormat 格式化。
  • 空数组返回空字符串，显示"暂无参与者"还是隐藏整行由业务决定；去重和排序也要事先完成。
  • 需要给每一项加链接时用 formatToParts()，它把输入项和连接词分开返回。

基本用法（Node 22 实测）

JavaScript
const names = ['Alice', 'Bob', 'Carol'];
new Intl.ListFormat('en', { type: 'conjunction' }).format(names); // 'Alice, Bob, and Carol'
new Intl.ListFormat('en', { type: 'disjunction' }).format(names); // 'Alice, Bob, or Carol'
new Intl.ListFormat('zh-CN').format(['张三', '李四', '王五']); // '张三、李四和王五'
new Intl.ListFormat('en').format([]); // ''
new Intl.ListFormat('en').format(['Alice']); // 'Alice'

style 有 long、short、narrow，影响连接词的写法，不是长度截断。

每项渲染成链接

JSX
function UserList({ users, locale }) {
  const parts = new Intl.ListFormat(locale).formatToParts(users.map((u) => u.name));
  let index = 0;
  return parts.map((part, i) =>
    part.type === 'element' ? (
      <a key={i} href={`/users/${users[index++].id}`}>
        {part.value}
      </a>
    ) : (
      <span key={i}>{part.value}</span>
    ),
  );
}

element 按输入顺序出现，用顺序映射回用户 ID，不要用名字当键，因为可能重名。不要把拼好的整句按逗号拆开，名字里也可能有逗号。

ListFormat 不做 HTML 转义，结果按普通文本渲染。

列表很长时

"Alice、Bob 和其他 3 人"要单独设计一条带复数的翻译消息，不要拼一个英文的 "3 more" 塞进列表。几十个成员更适合用真正的列表元素、分页或折叠展示。

常见追问

  • 测试时能直接比对输出字符串吗？ 固定运行时版本时可以；跨环境时 CLDR 数据可能调整标点和空格，更稳妥的是检查各项都在、顺序正确、formatToParts 拼起来等于 format 的结果。
  • 和 Array.prototype.toLocaleString() 有什么区别？ 后者只用逗号连接各项的本地化字符串，没有"和""或"之类的连接词。
