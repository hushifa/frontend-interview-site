前端路由除切换组件外还需要管理什么？

路由让 URL 成为界面状态的来源：路径和查询参数决定显示什么，刷新、分享、前进后退都能恢复。hash 模式不需要服务器配置；history 模式地址更干净，但服务器要把未知路径回退到入口页。导航时还要处理参数校验、数据加载、错误页、标题、焦点和滚动位置。

参考答案

简答

  • 应该放进 URL 的状态：页面身份（/questions/42）、可分享的筛选、排序和页码（?tag=react&page=2）；临时状态（弹窗里未提交的输入、悬停）不需要。
  • hash 模式（/#/questions/42）：hash 变化不会请求服务器，监听 hashchange，无需服务器配置；hash 部分不会发送给服务器。
  • history 模式：用 history.pushState 改变地址、监听 popstate 响应前进后退；刷新时服务器收到完整路径，需要回退到 index.html。
  • 查询参数是外部输入，要解析和校验：页码可能是负数或非数字，标签可能不存在。
  • 导航后要更新 document.title、把焦点移到新内容、处理滚动位置，否则屏幕阅读器用户不知道页面已经变化。

原理

JavaScript
// history 模式的最小实现
function navigate(path) {
  history.pushState(null, '', path);
  render(path);
}

window.addEventListener('popstate', () => render(location.pathname));

document.addEventListener('click', (e) => {
  const a = e.target.closest('a[href^="/"]');
  if (!a || e.metaKey || e.ctrlKey || e.shiftKey || e.altKey || e.button !== 0) return; // 保留新标签页、新窗口和下载
  if (a.target && a.target !== '_self') return;
  if (a.hasAttribute('download')) return;
  e.preventDefault();
  navigate(a.getAttribute('href'));
});

pushState 不会触发 popstate，只有浏览器前进后退才会触发，所以 navigate 中要自己调用 render。

解析并规范化查询参数

JavaScript
function parseQuery(search, knownTags) {
  const params = new URLSearchParams(search);
  const page = Number(params.get('page'));
  const tag = params.get('tag');
  return {
    page: Number.isInteger(page) && page > 0 ? page : 1,
    tag: knownTags.includes(tag) ? tag : null,
  };
}

参数非法时使用默认值，必要时用 history.replaceState 把地址改成规范形式，避免同一内容有多种 URL。

导航时的其他工作

  • 数据加载：进入路由时开始请求，快速切换时取消旧请求，见《路由并发导航和权限变化应该怎样处理？》。
  • 错误与 404：参数指向的数据不存在时显示 404 页面；SSR 或静态托管时还要返回真实的 404 状态码，见《前端渲染方式怎样影响 SEO 和部署？》。
  • 标题与焦点：更新 document.title，把焦点移到新页面的 <h1>（加 tabindex="-1"），或用 aria-live 区域播报。
  • 滚动：新页面滚动到顶部，后退时恢复原来的位置。Vue Router 用 scrollBehavior，React Router 用 <ScrollRestoration>。

路由守卫

前端路由守卫（如未登录跳转到登录页）只改善体验。用户可以直接调用接口，权限必须由服务端在每个请求中校验。

常见追问

  • pushState 和 replaceState 的区别？前者新增一条历史记录，后者替换当前记录，适合修正参数、筛选条件实时变化等不希望堆积历史的场景。
  • Navigation API 是什么？浏览器提供的新路由 API，用一个 navigate 事件统一拦截链接点击、表单提交和前进后退，可以替代手动拦截点击和监听 popstate。
