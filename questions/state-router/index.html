前端路由除切换组件外还需要管理什么？

参考答案

路由把 URL 与页面状态对应起来，还涉及嵌套路由、参数、数据加载、错误边界和导航中的等待状态。URL 中可分享的筛选条件，应与仅在当前交互中存在的临时状态区分。

React Router 提供不同使用模式，数据加载与框架能力随模式而异。不能把某个旧版本示例的 API 直接套到所有模式；应先明确项目所用版本与模式，再设计 loader、action 或组件内请求。

部署还要处理深层地址直接访问和刷新。History 路由通常需要服务器回退规则，静态托管可选择适合的路由或预生成策略。导航成功后还应关注标题、焦点与滚动恢复，而不只是组件是否出现。
