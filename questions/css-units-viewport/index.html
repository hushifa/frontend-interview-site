px、rem、em、百分比和动态视口单位怎么选？

px 是固定的 CSS 像素；rem 相对根元素字号，适合字号和间距；em 相对当前元素字号，适合随组件字号缩放的局部尺寸；百分比的参照由属性决定；svh、lvh、dvh 区分移动端浏览器工具栏伸缩时的视口高度。

参考答案

简答

  • 字号和主要间距用 rem，用户在浏览器设置里调大默认字号时页面会一起放大；用 px 写死字号会忽略这一设置。
  • em 相对当前元素的字号，按钮内边距用 em，按钮变大时内边距一起变大；嵌套使用时会逐层叠加。
  • 百分比的参照因属性而异：width 参照包含块宽度，padding 和 margin 也参照包含块宽度（包括上下方向），transform: translate 参照元素自身。
  • 移动端 100vh 等于工具栏收起时的大视口，页面初次加载时底部会被遮住；100svh 是工具栏展开时的小视口，100dvh 随工具栏实时变化。
  • 边框、阴影等不需要随字号缩放的细节用 px。

示例

CSS
html {
  font-size: 100%;
}

body {
  font-size: 1rem;
}

.button {
  font-size: 1.125rem;
  padding: 0.5em 1em;
  border: 1px solid;
}

.hero {
  min-block-size: 100svh;
}

把根字号设成 62.5% 让 1rem 等于 10px 的写法会改变用户的默认字号基准，现在一般不推荐。

视口单位怎么选

单位含义适合
svh工具栏全部展开时的高度首屏必须完整可见
lvh工具栏全部收起时的高度背景、装饰
dvh当前实际高度，会变化全屏应用外壳

dvh 在滚动时会随工具栏变化，元素高度跟着跳动，所以不要在长页面的普通区块上使用。

其他常用单位

  • ch：当前字体中“0”的宽度，max-inline-size: 65ch 常用于控制正文行宽。
  • lh：当前行高，适合按行数设置高度。
  • cqi：容器查询单位，相对查询容器的行内尺寸。
  • vw 包含滚动条宽度，width: 100vw 在有滚动条的桌面上会出现横向滚动。

常见追问

  • 字号要不要随屏幕缩放？可以用 clamp(1rem, 0.9rem + 0.5vw, 1.25rem)，但必须包含 rem 部分，否则用户放大页面时字号不会变。
