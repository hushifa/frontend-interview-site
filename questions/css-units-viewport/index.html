px、rem、em、百分比和动态视口单位怎么选？

字号和间距用 rem，用户调大浏览器字号时会跟着变；跟着组件字号走的局部尺寸用 em；细边框用 px。百分比参照什么要看属性。移动端整屏高度用 svh、lvh、dvh 区分工具栏展开和收起。

参考答案

简答

字号和主要的间距用 rem，它相对根元素的字号。用户在浏览器设置里调大默认字号，整个页面会一起放大。用 px 写死字号，就把用户的这个设置忽略了。

em 相对当前元素的字号，适合跟着组件一起缩放的尺寸，比如按钮内边距写成 em，按钮字号变大，内边距也跟着变大。要注意 em 嵌套使用时会一层层叠加。边框、阴影这类不需要跟着字号变的细节，用 px。

百分比参照什么，要看是哪个属性。width 参照包含块的宽度；padding 和 margin 也参照包含块的宽度，上下方向也是；transform: translate 参照元素自己。

移动端整屏高度最容易出问题。100vh 等于工具栏收起时的大视口，页面刚打开时工具栏是展开的，底部就被遮住了。100svh 是工具栏展开时的小视口，100dvh 跟着工具栏实时变化。

一个常见的组合

CSS
html {
  font-size: 100%;
}

body {
  font-size: 1rem;
}

.button {
  font-size: 1.125rem;
  padding: 0.5em 1em;
  border: 1px solid;
}

.hero {
  min-block-size: 100svh;
}

根字号保持 100%，也就是用户设置的默认字号。按钮的内边距用 em，是按按钮自己的 1.125rem 来算的。边框用 1px，不管字号多大都是一条细线。首屏区块用 100svh，保证工具栏展开时也能完整看到。

以前流行把根字号设成 62.5%，让 1rem 等于 10px，方便换算。可是这改变了用户默认字号的基准，现在一般不推荐。

三种视口高度怎么选

手机浏览器的地址栏和工具栏会随着滚动收起和展开，所以视口高度不是一个固定值。

svh 是工具栏全部展开时的高度，也就是最小的视口。首屏内容必须完整可见时用它。

lvh 是工具栏全部收起时的高度，也就是最大的视口。背景、装饰这类被挡住一点也无所谓的，可以用它。

dvh 是当前实际的高度，会变。适合全屏应用的外壳。可是在长页面里，用户一滚动工具栏就变，dvh 的元素高度也跟着跳，所以不要用在普通区块上。

其他常用单位

ch 是当前字体里“0”这个字符的宽度，max-inline-size: 65ch 常用来控制正文一行的长度。

lh 是当前的行高，适合按行数设置高度。

cqi 是容器查询单位，相对于查询容器的行内尺寸。

vw 包含滚动条的宽度。所以桌面上有竖向滚动条时，width: 100vw 比页面可用宽度更宽，会多出横向滚动条。

常见追问

字号要不要跟着屏幕宽度缩放？

可以用 clamp(1rem, 0.9rem + 0.5vw, 1.25rem) 这种写法。但中间那部分一定要包含 rem。只写 vw 的话，用户放大页面时视口宽度不变，字号也就不会变大。
