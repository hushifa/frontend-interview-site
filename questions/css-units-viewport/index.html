vw、vh、svh、lvh、dvh 有什么区别？移动端整屏高度怎么写？

视口单位按视口尺寸的百分比计算，1vw 是视口宽度的 1%。手机浏览器的工具栏会展开收起，所以视口高度分成三种：svh 按工具栏展开时的小视口算，lvh 按收起时的大视口算，dvh 跟着当前状态变化，目前的 vh 等同于 lvh。首屏整屏用 svh，全屏应用外壳用 dvh；100vw 不扣除滚动条，相对父元素要用百分比或容器查询单位。

参考答案

简答

视口单位是按浏览器可视区域的大小来算的，1vw 是视口宽度的 1%，1vh 是视口高度的 1%。它们和字号、父元素都没有关系。

麻烦出在手机上。手机浏览器的地址栏和工具栏会随滚动收起、展开，视口高度一直在变。所以规范把视口分成三种：svh 按工具栏全部展开时的小视口算，lvh 按全部收起时的大视口算，dvh 跟着工具栏当前的状态实时变化。MDN 写明，目前浏览器里的 vh 都等同于 lvh。

这就解释了老问题：页面刚打开时工具栏是展开的，height: 100vh 却按收起时的高度算，底部就被遮住了。首屏内容必须完整可见时用 100svh；全屏应用的外壳用 100dvh；普通长页面里不要用 dvh，用户一滚动它就变，元素高度跟着跳。

宽度方向也有坑。100vw 按“没有滚动条”来算，桌面上有竖向滚动条时它比页面可用宽度更宽，会多出横向滚动条。要相对父元素就用百分比，要相对组件容器就用 cqi 这类容器查询单位。

三种视口高度分别是多少

手机浏览器的工具栏会随着滚动收起和展开，所以“视口有多高”有三种答案。CSS Values 4 规范的定义是：

单位按什么算会不会变
svh工具栏全部展开时的视口，也就是最小的只有视口本身改变尺寸时才变
lvh工具栏全部收起时的视口，也就是最大的只有视口本身改变尺寸时才变
dvh按工具栏当前的状态动态计算滚动时工具栏一动就变

vh 呢？规范允许浏览器自己决定它按哪种算，MDN 写明目前所有浏览器的 vh、vw 等默认视口单位都等同于 lv* 那一套。宽度方向同理，也有 svw、lvw、dvw，只是手机上工具栏一般只影响高度。

整屏高度该写哪个

CSS
.hero {
  min-block-size: 100vh;   /* 不支持新单位的浏览器用这一行 */
  min-block-size: 100svh;
}

.app-shell {
  block-size: 100dvh;
}

首屏区块写 100svh，因为它按工具栏展开时算，用户刚打开页面时就能完整看到。前面那行 100vh 是回退，不认识 svh 的浏览器会丢掉第二条声明，继续用第一条。

dvh 适合聊天窗口、地图这种整屏固定、内部自己滚动的应用外壳，工具栏收起时它跟着变高，不会留空白。可是 MDN 也提醒，基于动态视口的单位会让内容在用户滚动时改变尺寸，影响体验，还可能带来性能开销。所以长页面里的普通区块不要用 dvh。

lvh 用得少，适合被遮住一点也无所谓的背景、装饰。

为什么 100vw 会多出横向滚动条

规范规定，除非根元素的 overflow 设成了 scroll 这类一定出现滚动条的值，视口单位都按“滚动条不存在”来计算。普通页面是 overflow: auto，内容一长出现竖向滚动条，100vw 却还按没有滚动条的宽度算，比页面实际可用的宽度多出一条滚动条宽，于是又多出一个横向滚动条。

所以撑满宽度一般写 width: 100%，而不是 100vw。

视口单位、百分比和容器查询单位怎么分

视口单位只看视口。一个 width: 50vw 的元素放进 300px 宽的侧栏里，宽度仍然是视口的一半，会把侧栏撑破。

百分比参照什么，要看是哪个属性。width 参照包含块的宽度；padding 和 margin 也参照包含块的宽度，上下方向也一样；transform: translate() 的百分比参照元素自己的尺寸。

组件要根据自己所在的容器调整尺寸时，用容器查询单位。1cqi 是查询容器行内尺寸的 1%。MDN 说明，找不到合适的查询容器时，它退回到对应方向的小视口单位。

常见追问

字号能不能用 vw，让文字跟着屏幕宽度缩放？

不要只写 vw。用户在浏览器里放大页面时视口宽度不变，纯 vw 的字号就不会变大。一般写成 clamp(1rem, 0.9rem + 0.5vw, 1.25rem)，让中间那部分也包含 rem。rem、em 的区别和换算见《rem 和 em 有什么区别？各自怎么换算？》。

设计稿上的 px 怎么换成 vw？

用 px ÷ 设计稿宽度 × 100。比如 375px 宽的设计稿上 75px 的按钮，写成 75 / 375 × 100 = 20vw。整页按 vw 等比缩放的完整方案见《移动端怎样做屏幕适配？1px 边框为什么看起来变粗了？》。
