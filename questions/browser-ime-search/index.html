中文输入法期间怎样触发搜索？composition 与请求竞态如何一起处理？

输入法组字期间 input 事件的 isComposing 为 true，此时不应发请求；在 compositionend 后再触发防抖搜索，并用 AbortController 或请求序号丢弃过期结果。

参考答案

简答

  • 用拼音输入"前端"时，组字过程中会产生 q、qian、qian d 等中间值，并触发 input 事件。
  • 组字期间 event.isComposing 为 true，compositionstart 和 compositionend 标出组字的开始和结束。
  • 组字期间跳过搜索，在 compositionend 后按最终值触发一次防抖搜索。
  • 每次发新请求前取消上一个请求，只渲染最后一次请求的结果。

示例

JavaScript
function bindSearch(input, search) {
  let composing = false;
  let timer;
  let controller;

  const run = () => {
    clearTimeout(timer);
    timer = setTimeout(async () => {
      controller?.abort();
      controller = new AbortController();
      const { signal } = controller;
      try {
        const results = await search(input.value.trim(), signal);
        if (!signal.aborted) render(results);
      } catch (error) {
        if (error.name !== 'AbortError') renderError(error);
      }
    }, 250);
  };

  input.addEventListener('compositionstart', () => {
    composing = true;
  });
  input.addEventListener('compositionend', () => {
    composing = false;
    run();
  });
  input.addEventListener('input', (event) => {
    if (composing || event.isComposing) return;
    run();
  });
}
  • 同时检查自己维护的 composing 和 event.isComposing，兼容事件顺序不同的浏览器。
  • 有的浏览器在 compositionend 之后还会触发一次 input，防抖会把两次合并成一次请求。
  • search 内部要把 signal 传给 fetch。

回车键

组字时按回车是确认候选词，不应提交表单：

JavaScript
input.addEventListener('keydown', (event) => {
  if (event.key === 'Enter' && !event.isComposing) submit();
});

Safari 中确认候选词的回车，keydown 的 isComposing 可能为 false，可以再检查 event.keyCode === 229 作为兜底。

常见追问

  • 为什么不用节流：搜索关心的是用户停下来后的最终输入，防抖更合适。
  • 只用请求序号可以吗：可以丢弃过期结果，但旧请求仍在占用网络；abort() 能真正取消请求。
