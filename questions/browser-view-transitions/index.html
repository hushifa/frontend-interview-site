View Transitions API 如何实现页面和视图切换动画？

同文档切换用 document.startViewTransition() 包住 DOM 更新，浏览器截取前后快照并用 CSS 动画过渡；跨文档切换用 @view-transition 规则开启。同文档已是 Baseline，跨文档目前 Firefox 不支持。

参考答案

简答

  • document.startViewTransition(update)：浏览器先截取旧画面，执行 update 修改 DOM，再截取新画面，默认用淡入淡出过渡。
  • 给元素设置 view-transition-name，浏览器会单独为它做位置和尺寸的过渡，实现"共享元素"动画。
  • 动画用 ::view-transition-old()、::view-transition-new() 等伪元素和普通 CSS 定制。
  • 跨文档（MPA）切换：两个同源页面都声明 @view-transition { navigation: auto; }。
  • 不支持的浏览器直接执行更新，没有动画；需要尊重 prefers-reduced-motion。

同文档示例

JavaScript
function navigate(render) {
  if (!document.startViewTransition) {
    render();
    return;
  }
  const transition = document.startViewTransition(() => render());
  return transition.finished;
}
CSS
.product-image {
  view-transition-name: product-hero;
}

::view-transition-old(root),
::view-transition-new(root) {
  animation-duration: 200ms;
}

@media (prefers-reduced-motion: reduce) {
  ::view-transition-group(*),
  ::view-transition-old(*),
  ::view-transition-new(*) {
    animation: none;
  }
}

同一时刻页面上每个 view-transition-name 必须唯一，否则过渡会被跳过。列表项可以只在被点击的那一项上临时设置名称。

render 可以返回 Promise，浏览器等它完成后才截取新画面，这段时间页面不响应交互，所以数据应先加载好再开始过渡。

返回对象

  • updateCallbackDone：DOM 更新完成。
  • ready：伪元素已创建，动画即将开始，可以在这里用 Web Animations API 自定义动画。
  • finished：动画结束。
  • skipTransition()：跳过动画，DOM 更新照常执行。

跨文档切换

CSS
@view-transition {
  navigation: auto;
}

两个页面都写这条规则，同源导航时就会有过渡。离开页面时触发 pageswap，新页面在首次渲染前触发 pagereveal，可以在其中根据来源页面设置不同的动画。

兼容性

同文档切换已是 Baseline；跨文档切换 Chromium 和 Safari 支持，Firefox 尚未支持。两者都可以作为渐进增强，不支持时页面照常切换。
