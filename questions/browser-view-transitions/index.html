View Transitions API 如何实现页面和视图切换动画？

把 DOM 更新包进 document.startViewTransition()，浏览器会截下前后两张画面，用 CSS 动画过渡。跨页面切换用 @view-transition 规则开启。同文档已是 Baseline，跨文档 Firefox 还不支持。

参考答案

简答

以前做页面切换动画，得同时保留新旧两份 DOM，自己算位置、写动画，很麻烦。View Transitions API 把这件事交给了浏览器：调用 document.startViewTransition(update)，浏览器先截下旧画面，执行 update 改 DOM，再截下新画面，默认用淡入淡出从旧画面过渡到新画面。

想让某个元素单独“飞”过去，比如列表里的缩略图变成详情页的大图，就给它设 view-transition-name。浏览器会为它单独做位置和尺寸的过渡，这叫共享元素动画。动画用 ::view-transition-old()、::view-transition-new() 这些伪元素加普通 CSS 来定制。

多页应用也能用。两个同源页面都声明 @view-transition { navigation: auto; }，页面跳转时就有过渡。

要注意，不支持的浏览器直接执行更新，没有动画，所以可以放心当渐进增强。另外要尊重 prefers-reduced-motion，用户设置了减少动画就关掉。

先看同文档切换怎么写

JavaScript
function navigate(render) {
  if (!document.startViewTransition) {
    render();
    return;
  }
  const transition = document.startViewTransition(() => render());
  return transition.finished;
}

不支持就直接 render()，支持就把 render 包进 startViewTransition。

样式这边，给商品图起个名字，调一下动画时长，再照顾减少动画的用户：

CSS
.product-image {
  view-transition-name: product-hero;
}

::view-transition-old(root),
::view-transition-new(root) {
  animation-duration: 200ms;
}

@media (prefers-reduced-motion: reduce) {
  ::view-transition-group(*),
  ::view-transition-old(*),
  ::view-transition-new(*) {
    animation: none;
  }
}

为什么设了名字动画却没了

同一时刻，页面上每个 view-transition-name 必须唯一。如果列表里每一项都设了同一个名字，过渡会被直接跳过。

改法是只在被点击的那一项上临时设置名字，其他项不设。

为什么切换时页面没反应

render 可以返回 Promise，浏览器会等它完成才截新画面。可是这段等待期间，页面不响应交互。如果在 render 里去请求数据，网络一慢，用户就会觉得页面卡住了。所以数据应该先加载好，再开始过渡。

startViewTransition 返回了什么

返回的对象上有三个 Promise 和一个方法。updateCallbackDone 在 DOM 更新完成时兑现。ready 在伪元素创建好、动画即将开始时兑现，可以在这里用 Web Animations API 写自定义动画。finished 在动画结束时兑现。skipTransition() 跳过动画，但 DOM 更新照常执行。

跨文档切换怎么开

CSS
@view-transition {
  navigation: auto;
}

两个页面都写这条规则，同源导航时就会有过渡。离开页面时会触发 pageswap，新页面在首次渲染前会触发 pagereveal，可以在里面根据是从哪个页面来的，设置不同的动画。

兼容性上，同文档切换已经是 Baseline；跨文档切换 Chromium 和 Safari 支持，Firefox 还不支持。两者都可以作为渐进增强，不支持时页面照常切换。

常见追问

列表项都设了 view-transition-name，为什么没有动画？

因为同一时刻每个名字必须唯一，重名时过渡会被跳过。只在被点击的那一项上临时设置名字就行。

不支持 View Transitions 的浏览器会怎样？

直接执行 DOM 更新，只是没有动画，功能不受影响。所以它很适合当渐进增强来用。
