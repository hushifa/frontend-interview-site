MediaDevices.getUserMedia 的权限和资源生命周期怎样处理？

getUserMedia 在 HTTPS 页面里申请摄像头或麦克风，返回一个 MediaStream。要分清权限被拒、没有设备、设备被占用等错误；不用时对每条轨道调用 stop()，摄像头指示灯才会灭。

参考答案

简答

做视频通话或扫码时，用 navigator.mediaDevices.getUserMedia({ video, audio }) 打开摄像头和麦克风。它只在安全上下文里可用，第一次调用会弹出授权框，成功后返回一个 MediaStream。

失败时要看错误名区分原因：NotAllowedError 是用户或策略拒绝了，NotFoundError 是没有对应的设备，NotReadableError 是设备被别的程序占着，OverconstrainedError 是要求的参数满足不了。

最常被忽略的是释放。不用时要调用 stream.getTracks().forEach((t) => t.stop())，只把 video.srcObject 设成 null 是不会释放摄像头的，指示灯会一直亮。

另外，enumerateDevices() 能列出设备，但授权之前设备的 label 是空字符串；设备插拔时会触发 devicechange 事件。

打开摄像头并返回关闭函数

下面打开摄像头显示在 <video> 里，返回一个关闭函数，同时把错误翻译成提示文字。

JavaScript
async function startCamera(video, deviceId) {
  const stream = await navigator.mediaDevices.getUserMedia({
    video: deviceId ? { deviceId: { exact: deviceId } } : { width: { ideal: 1280 }, facingMode: 'user' },
    audio: false,
  });
  video.srcObject = stream;
  await video.play();
  return () => {
    stream.getTracks().forEach((track) => track.stop());
    video.srcObject = null;
  };
}

function describeError(error) {
  switch (error.name) {
    case 'NotAllowedError':
      return '摄像头权限被拒绝，请在浏览器设置中允许';
    case 'NotFoundError':
      return '没有找到摄像头';
    case 'NotReadableError':
      return '摄像头正在被其他程序使用';
    case 'OverconstrainedError':
      return `摄像头不支持要求的参数：${error.constraint}`;
    default:
      return '无法打开摄像头';
  }
}

为什么关闭时要对每条轨道调用 stop()？因为真正占着设备的是轨道，不是 <video>。把 srcObject 设成 null，只是 <video> 不再显示了，轨道还开着，摄像头就一直被占用。

约束里的 ideal 和 exact 区别很大。ideal 是期望值，满足不了时浏览器会选最接近的；exact 是必须满足，满足不了就抛 OverconstrainedError。所以指定某个设备用 exact，分辨率这种“尽量就行”的用 ideal。

在 iOS 上，预览本地画面的 <video> 要加 playsinline 和 muted，才不会被强制全屏，也才允许自动播放。

轨道在哪些时候会自己变化

页面切到后台时，手机系统可能暂停摄像头，轨道会触发 mute 事件，回到前台后触发 unmute。

轨道被系统或用户停掉时，会触发 ended 事件。界面应该更新状态，并允许用户重新打开。

在单页应用里切换路由时，一定要调用上面的关闭函数。否则页面换了，摄像头指示灯还亮着。

常见追问

为什么 enumerateDevices() 拿到的设备名是空的？

出于隐私，用户授权之前，设备的 label 是空字符串。一般先调用一次 getUserMedia 拿到授权，再列设备，就能看到名字了。

屏幕共享也用 getUserMedia 吗？

不是，用 navigator.mediaDevices.getDisplayMedia()。它必须由用户手势触发，每次都会显示选择界面，浏览器不会记住授权。
