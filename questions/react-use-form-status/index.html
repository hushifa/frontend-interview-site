React useFormStatus 适合管理什么表单状态？

useFormStatus 让表单里面的子组件知道外层表单是不是正在提交、提交了什么，适合做通用的提交按钮。它只能在表单的子组件里用，拿不到提交结果和错误信息。

参考答案

简答

很多表单都要一个“提交中就禁用”的按钮。以前得把 isPending 从表单组件一层层传给按钮。useFormStatus 让按钮自己去问：“我所在的那个表单，现在是不是在提交？”

它从 react-dom 导入，返回 { pending, data, method, action }，描述的是最近一个父级 <form> 的当前提交。pending 表示是否在提交，data 是这次提交的 FormData。

它最适合做可复用的提交按钮和提交提示，放进哪个表单就自动跟哪个表单走，不用传任何 props。

要注意，它必须在 <form> 里面渲染的组件中调用，在渲染 <form> 的那个组件里调用读不到。它只对用 action 属性提交的表单生效。它也只告诉你“是不是在提交、提交了什么”，提交结果和校验错误要用 useActionState 管理。

写一个通用提交按钮

按钮自己读表单状态，提交期间禁用并换文字：

JSX
import { useFormStatus } from 'react-dom';

export function SubmitButton({ children, pendingText = '提交中…' }) {
  const { pending } = useFormStatus();
  return (
    <button type="submit" disabled={pending} aria-busy={pending}>
      {pending ? pendingText : children}
    </button>
  );
}

用的时候直接放进表单就行：

JSX
function CommentForm() {
  async function addComment(formData) {
    await postComment(formData.get('text'));
  }

  return (
    <form action={addComment}>
      <textarea name="text" required />
      <SubmitButton>发表评论</SubmitButton>
    </form>
  );
}

CommentForm 没给 SubmitButton 传任何状态。用户提交时，addComment 还没执行完，按钮读到 pending 为 true，就显示“提交中…”并禁用。换一个表单用它，它读的就是新表单的状态。

为什么在表单组件里调用永远是 false

很多人第一次会这样写：

JSX
function CommentForm() {
  const { pending } = useFormStatus(); // 永远是 false
  return <form action={addComment}>...</form>;
}

useFormStatus 是往上找父级的 <form>。可这里的 <form> 是 CommentForm 自己渲染出来的，在它下面，不在它上面，所以它什么也找不到。

所以要么把读状态的部分拆成子组件放进表单里，要么在同一层改用 useActionState 返回的 isPending。

显示正在提交的内容

data 就是这次提交的 FormData，可以拿来做更具体的提示：

JSX
function SavingHint() {
  const { pending, data } = useFormStatus();
  if (!pending) return null;
  return <p role="status">正在保存《{data.get('title')}》…</p>;
}

和 useActionState 怎么分工

useFormStatus 在表单的子组件里调用，提供“是否在提交”和“提交了什么数据”，适合通用按钮和提示组件。useActionState 在渲染表单的组件里调用，提供 Action 返回的状态和 isPending，适合显示提交结果和错误。

两者经常一起用：外层用 useActionState 显示结果，里面的按钮用 useFormStatus 控制禁用。详见《useActionState 如何把异步 Action 的结果变成组件状态？》。

常见追问

普通的 onSubmit 提交也能用吗？

不能。它只追踪通过 action 属性发起的提交。

页面上有好几个表单，会不会串？

不会。每个子组件只读它自己所在的那个表单，互不影响。
