React useFormStatus 适合管理什么表单状态？

useFormStatus 让 form 内部的子组件读取父级 form 的提交状态（pending、data、method、action），适合做通用的提交按钮和提交提示。它只能在 form 的子组件中调用，不提供提交结果和错误信息。

参考答案

简答

  • 从 react-dom 导入，返回 { pending, data, method, action }，描述最近一个父级 <form> 的当前提交。
  • 必须在 <form> 内部渲染的组件中调用；在渲染 <form> 的同一个组件里调用，读不到这个表单的状态。
  • 只对使用 action 属性提交的表单生效，即 <form action={fn}>。
  • 只告诉你"是否正在提交、提交了什么"；提交结果、校验错误要用 useActionState 管理。
  • 典型用途：可复用的提交按钮，自动在提交期间禁用并显示加载文字。

通用提交按钮

JSX
import { useFormStatus } from 'react-dom';

export function SubmitButton({ children, pendingText = '提交中…' }) {
  const { pending } = useFormStatus();
  return (
    <button type="submit" disabled={pending} aria-busy={pending}>
      {pending ? pendingText : children}
    </button>
  );
}
JSX
function CommentForm() {
  async function addComment(formData) {
    await postComment(formData.get('text'));
  }

  return (
    <form action={addComment}>
      <textarea name="text" required />
      <SubmitButton>发表评论</SubmitButton>
    </form>
  );
}

SubmitButton 不需要任何 props 就知道表单状态，可以放进任意表单。

常见错误：在表单组件自身调用

JSX
function CommentForm() {
  const { pending } = useFormStatus(); // 永远是 false
  return <form action={addComment}>...</form>;
}

useFormStatus 只查找父级的 <form>，这里的 <form> 是当前组件渲染出来的子元素。需要在同一层读取，改用 useActionState 返回的 isPending。

读取正在提交的数据

data 是本次提交的 FormData，可以用来显示"正在保存《标题》…"：

JSX
function SavingHint() {
  const { pending, data } = useFormStatus();
  if (!pending) return null;
  return <p role="status">正在保存《{data.get('title')}》…</p>;
}

和 useActionState 的分工

useFormStatususeActionState
调用位置form 的子组件渲染 form 的组件
提供提交中、提交的数据Action 返回的状态、isPending
适合通用按钮、提示组件显示结果和错误

两者经常一起使用，见《useActionState 如何把异步 Action 的结果变成组件状态？》。

常见追问

  • 支持普通 onSubmit 吗？不支持，只追踪通过 action 发起的提交。
  • 页面上有多个表单怎么办？每个子组件只读取自己所在的那个表单，互不影响。
