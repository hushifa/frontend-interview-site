怎样实现只在停止调用后执行的防抖函数？

防抖将短时间内密集发生的调用合并。下面实现的是尾沿执行版本：距离最后一次调用经过 wait 后才执行，保留最后的参数与 this，并支持取消。它不包含首沿执行、最大等待时间或返回 Promise 等扩展语义。

参考答案

防抖将短时间内密集发生的调用合并。下面实现的是尾沿执行版本：距离最后一次调用经过 wait 后才执行，保留最后的参数与 this，并支持取消。它不包含首沿执行、最大等待时间或返回 Promise 等扩展语义。

JavaScript
function debounce(fn, wait) {
  let timer;
  function wrapped(...args) {
    clearTimeout(timer);
    timer = setTimeout(() => {
      timer = undefined;
      fn.apply(this, args);
    }, wait);
  }
  wrapped.cancel = () => {
    clearTimeout(timer);
    timer = undefined;
  };
  return wrapped;
}

适合搜索建议等允许等待输入停顿的场景。持续输入可能一直不触发；组件卸载时应取消未执行任务。计时器延迟是调度条件，不是精确执行时刻。异步请求本身的取消和返回顺序还需要另外处理。

手写题先明确输入约束、输出契约、重复值、空输入和异常行为，再选择数据结构。实现之后用边界样例验证，不要只运行一个正常输入；异步题还要验证顺序、取消和并发上限。

复杂度应同时说明时间、空间和额外资源。教学实现适合解释原理，生产代码还需要考虑可读性、监控、错误处理和已有标准库能力。

实际使用手写实现前，先确认数据量、调用频率和取消要求。小数据的清晰实现可能比复杂优化更合适；数据规模上来后，再根据测量结果决定是否使用标准库、缓存或专门的数据结构。
