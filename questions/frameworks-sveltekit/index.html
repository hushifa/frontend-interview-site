SvelteKit 的路由、load 和服务端边界怎样协作？

SvelteKit 用目录结构定义路由。+page.js 中的 load 在服务端和浏览器都可能运行，+page.server.js 中的 load 和表单 actions 只在服务端运行，可以访问数据库和密钥。load 返回的数据会发送到浏览器，部署能力由 adapter 决定。

参考答案

简答

  • src/routes/blog/[slug]/+page.svelte 对应 /blog/:slug；+layout.svelte 是共享布局。
  • 通用 load（+page.js）首次访问时在服务端运行，之后的客户端导航在浏览器运行，不能使用密钥。
  • 服务端 load（+page.server.js）只在服务端运行，可以查数据库；返回值会序列化后发给浏览器，所以只返回页面需要的字段。
  • +page.server.js 中的 actions 处理表单 POST，配合 use:enhance 实现无刷新提交，不开启 JavaScript 时也能用普通表单提交。
  • +server.js 定义 API 端点；adapter（node、static、vercel 等）决定构建产物在哪里运行，adapter-static 下服务端代码无法在运行时执行。

服务端 load

JavaScript
// src/routes/account/+page.server.js
import { error } from '@sveltejs/kit';

export async function load({ locals }) {
  if (!locals.user) error(401, '请先登录');
  return {
    user: { id: locals.user.id, displayName: locals.user.displayName },
  };
}

locals.user 由 hooks.server.js 根据会话 cookie 设置。返回值里不要包含密码哈希、令牌或完整数据库记录。

表单 action

JavaScript
// src/routes/todos/+page.server.js
import { fail } from '@sveltejs/kit';

export const actions = {
  create: async ({ request, locals }) => {
    if (!locals.user) return fail(401, { message: '请先登录' });
    const data = await request.formData();
    const text = String(data.get('text') ?? '').trim();
    if (!text) return fail(400, { text, message: '内容不能为空' });
    await db.todo.create({ text, userId: locals.user.id });
  },
};
svelte
<!-- +page.svelte -->
<script>
  import { enhance } from '$app/forms';
  let { form } = $props();
</script>

<form method="POST" action="?/create" use:enhance>
  <input name="text" value={form?.text ?? ''} />
  {#if form?.message}<p role="alert">{form.message}</p>{/if}
  <button>添加</button>
</form>

fail 返回的数据通过 form prop 传回页面，用于显示错误和回填输入。action 成功后，SvelteKit 会重新运行页面的 load。

load 什么时候重新运行

  • 路由参数、url 变化，且 load 读取了它们。
  • 调用 invalidate(url) 或 invalidateAll()。
  • action 提交之后。

父布局的 load 不一定在每次子页面导航时重新执行，所以权限检查不能只放在布局里，每个服务端 load、action 和端点都要自己检查。

注意点

  • 不要在服务端模块的顶层变量里存当前用户数据，同一个进程会被多个请求共享。
  • 在 load 里用 SvelteKit 提供的 fetch，它会转发 cookie，并在 SSR 时把响应内联到页面，避免客户端重复请求。
  • 多个互不依赖的请求用 Promise.all 并行，await parent() 会让当前 load 等待父级，应放在需要时才调用。

常见追问

  • 和 Next.js App Router 的区别？SvelteKit 用 load 函数显式加载数据，没有 Server Components；Next.js 在 Server Component 中直接 await 数据。
  • 预渲染怎么开启？在页面或布局中导出 export const prerender = true，构建时生成静态 HTML。
