React use API 可以读取哪些值？

use 在渲染中读取 Promise 或 Context。读取未完成的 Promise 时组件会挂起，由最近的 Suspense 显示 fallback，失败交给 Error Boundary。它可以在条件语句中调用，但 Promise 必须缓存，不能在渲染时新建。

参考答案

简答

  • use(context)：等同于 useContext，但可以写在 if 和循环里。
  • use(promise)：Promise 未完成时组件挂起，显示最近 Suspense 的 fallback；成功时返回结果；失败时交给最近的 Error Boundary。
  • use 不是 Hook，可以条件调用，但仍然只能在组件或 Hook 中调用，也不能包在 try/catch 里。
  • 传入的 Promise 必须在多次渲染间保持同一个实例，通常来自 Server Component 的 props、数据请求库或缓存；在渲染中写 use(fetch(url)) 会不断重新请求。
  • Server Components 中直接用 await；use(context) 不能在 Server Components 中使用。

服务端创建 Promise，客户端读取

JSX
// app/page.jsx（Server Component）
import { Suspense } from 'react';
import { Comments } from './comments';

export default async function Page({ params }) {
  const { id } = await params; // Next.js 15 起 params 是 Promise
  const commentsPromise = getComments(id); // 不 await，立即开始请求
  return (
    <Suspense fallback={<p>评论加载中…</p>}>
      <Comments commentsPromise={commentsPromise} />
    </Suspense>
  );
}
JSX
// app/comments.jsx
'use client';

import { use } from 'react';

export function Comments({ commentsPromise }) {
  const comments = use(commentsPromise);
  return <ul>{comments.map((c) => <li key={c.id}>{c.text}</li>)}</ul>;
}

页面其余部分先显示，评论数据到达后再填充。Promise 的结果必须可序列化。

条件读取 Context

JSX
function Heading({ children }) {
  if (children == null) return null;
  const theme = use(ThemeContext); // 提前 return 之后调用，useContext 做不到
  return <h1 style={{ color: theme.color }}>{children}</h1>;
}

为什么 Promise 要缓存

JSX
// 错误：每次渲染都创建新 Promise，组件反复挂起
function Profile({ id }) {
  const user = use(fetch(`/api/users/${id}`).then((r) => r.json()));
}

挂起后重新渲染时又会创建一个新 Promise，永远等不到结果，React 会警告 "A component was suspended by an uncached promise"。客户端组件中需要发起请求时，在事件处理器或路由 loader 中创建 Promise，存入 state，或者使用支持 Suspense 的数据请求库。

错误处理

JSX
<ErrorBoundary fallback={<p>加载失败</p>}>
  <Suspense fallback={<p>加载中…</p>}>
    <Comments commentsPromise={commentsPromise} />
  </Suspense>
</ErrorBoundary>

不想显示错误界面时，可以在创建 Promise 的地方 .catch(() => []) 提供兜底值。

常见追问

  • 和 await 的区别？await 只能在 async 函数中使用，客户端组件不能是 async 函数；use 在普通组件函数中实现等待。
  • 刷新数据怎么办？在 startTransition 中创建新的 Promise 并存入 state，组件读取新 Promise，期间保留旧内容。
