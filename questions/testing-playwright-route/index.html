Playwright route 拦截适合怎样的接口测试？

使用 route.fulfill、continue 和 abort 构造稳定的成功、失败和慢响应场景，避免测试依赖真实后端偶然状态。

参考答案

Playwright route 可以拦截匹配请求，继续发送、修改请求、返回固定响应或主动失败。它适合测试 UI 对加载、空结果、权限错误、超时和重试的处理。

模拟应尽量贴近真实接口契约，包含状态码、响应头、错误结构和延迟。只返回最小成功 JSON 会让测试忽略解析失败、缓存头和错误分支。

拦截范围要限定到具体测试上下文，测试结束时清理；不要把所有请求全局 mock 成成功，否则端到端测试失去发现集成问题的能力。关键流程还应保留少量真实后端测试。
