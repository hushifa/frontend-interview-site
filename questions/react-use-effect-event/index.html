React useEffectEvent 适合解决什么依赖问题？

useEffectEvent 把 Effect 里"只想读最新值、不想因为它重跑"的那部分逻辑拎出来。比如房间变了要重连，主题变了不要重连。它只能在 Effect 内部调用，不能当 useCallback 用。

参考答案

简答

写 Effect 时常碰到一种两难：某个值 Effect 里要用，写进依赖它一变 Effect 就重跑；不写进依赖，又读到旧值。useEffectEvent 就是为这种情况准备的，它在 React 19.2 中成为稳定 API。

它返回一个函数，这个函数每次被调用时，读到的都是最新一次渲染的 props 和 state，所以不会有过期闭包。而且它不能也不需要写进依赖数组，Effect 只依赖真正决定“要不要重新同步”的值。

典型例子是聊天室：房间变了要重连，主题变了只需要下次通知时用新颜色，不该断线重连。

要注意，它只能在同一个组件或 Hook 里、从 Effect 内部调用，不能传给子组件，不能在渲染时或事件处理器里调用。也别拿它藏真正的依赖，某个值变了外部连接必须重建，它就该留在依赖数组里。配套的 lint 规则需要升级到最新的 eslint-plugin-react-hooks。

先看聊天室的例子

连接成功时要弹一个通知，通知的样式跟着主题走：

JSX
import { useEffect, useEffectEvent } from 'react';

function ChatRoom({ roomId, theme }) {
  const onConnected = useEffectEvent(() => {
    showNotification('已连接', theme);
  });

  useEffect(() => {
    const connection = createConnection(roomId);
    connection.on('connected', onConnected);
    connection.connect();
    return () => connection.disconnect();
  }, [roomId]);

  return <h1>{roomId}</h1>;
}

切换 roomId 时，依赖变了，Effect 重新执行，断开旧房间、连上新房间。切换 theme 时，Effect 不执行，连接不会断；等下次连接成功，onConnected 读到的是最新的 theme。

没有 useEffectEvent 之前只能二选一：要么把 theme 写进依赖，换个主题就断线重连；要么关掉 lint 规则不写，结果通知一直用旧主题。

为什么它能读到最新值又不用当依赖

依赖数组的意思是“这些值变了要重新同步”。theme 变了不需要重连，所以它本来就不该是这个 Effect 的依赖，只是 Effect 里恰好要读它。

useEffectEvent 把“读 theme”这部分逻辑分离出去，变成一个事件。事件是被调用时才去读值的，所以总能拿到最新的。Effect 本身就只剩下跟 roomId 有关的同步逻辑。

记录访问日志

另一个常见场景是 URL 变了要记日志，日志里顺便带上购物车数量，但购物车数量变了不该再记一次：

JSX
function Page({ url, cartCount }) {
  const onVisit = useEffectEvent((visitedUrl) => {
    logVisit(visitedUrl, cartCount);
  });

  useEffect(() => {
    onVisit(url);
  }, [url]);
}

为什么把 url 当参数传进去，而不是在 onVisit 里直接读？因为这样读代码的人一眼就能看出：这个 Effect 是因为 url 变化才执行的，url 是触发原因，cartCount 只是顺带读一下。

和 useCallback 有什么区别

两者都返回函数，但用途不同。useCallback 返回的函数在依赖不变时引用稳定，读到的是创建时的依赖值，可以在任何地方调用、传给子组件。useEffectEvent 返回的函数不保证引用稳定，你也不该依赖它的引用；它读到的是调用时的最新值；只能在 Effect 内部调用。

常见追问

能在 setInterval 回调里用吗？

可以，因为回调是在 Effect 里注册的，调用也发生在 Effect 建立的定时器里。例子见《React 中的过期闭包为什么会读到旧状态？》。

为什么不能传给子组件？

它的设计目的就是给 Effect 读最新值。如果当成普通回调到处传，lint 就没法判断依赖关系，规则也就失去了意义。
