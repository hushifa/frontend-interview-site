表单的 name、value、label 与提交行为如何协作？

label 告诉用户和读屏这个控件是什么，name 是提交时的字段名，value 是提交的值。没有 name、被 disabled、没勾选的控件都不会提交，FormData 也按这套规则收集。

参考答案

简答

三者各管一件事。label 是给人看的名字，用 <label for="id"> 关联，或者用 label 把控件包起来，读屏会读出这个名字，点文字也能聚焦或勾选控件。name 是提交时的字段名，value 是提交的值。

哪些控件会提交，规则要记清楚。只有带 name 的才提交；disabled 的不提交，readonly 的会提交。没勾选的复选框和单选框什么都不提交；勾选了但没写 value，提交的是字符串 "on"。

同名的多个控件，比如一组多选框，会提交多条记录，用 formData.getAll(name) 读出来。

还有一个实用的细节：被点击的提交按钮如果有 name，它的值也会提交，可以用来区分用户点的是“保存”还是“发布”。

看一个表单到底提交了什么

HTML
<form id="post">
  <label for="title">标题</label>
  <input id="title" name="title" required>

  <fieldset>
    <legend>标签</legend>
    <label><input type="checkbox" name="tag" value="css"> CSS</label>
    <label><input type="checkbox" name="tag" value="html"> HTML</label>
  </fieldset>

  <input name="author" value="hu" readonly>
  <input name="draftId" value="42" disabled>

  <button name="action" value="save">保存</button>
  <button name="action" value="publish">发布</button>
</form>
JavaScript
form.addEventListener('submit', (event) => {
  event.preventDefault();
  const data = new FormData(form, event.submitter);
  data.getAll('tag');   // 例如 ['css', 'html']
  data.get('author');   // 'hu'
  data.get('draftId');  // null，disabled 不提交
  data.get('action');   // 'save' 或 'publish'
});

author 和 draftId 都不能编辑，为什么一个拿得到、一个是 null？因为 readonly 只是不让改，值照样提交；disabled 表示这个控件不参与表单，值不提交。

tag 两个都勾选时，get('tag') 只会拿到第一个，要用 getAll 才能拿到全部。

action 的值来自点击的那个按钮。注意 new FormData(form, event.submitter) 的第二个参数，它把被点击的按钮加进去。只传 form 的话，按钮的值是不包含在里面的。

表单有哪几种提交方式

method="get" 把字段拼到网址的查询参数里，适合搜索。

method="post" 默认编码成 application/x-www-form-urlencoded。要上传文件，得加 enctype="multipart/form-data"。

用代码提交时，form.requestSubmit() 会先校验，再触发 submit 事件，跟用户点按钮一样。form.submit() 跳过校验和事件，直接提交。

控件的名字要怎么给

placeholder 不能当名字用。用户一输入它就消失了，也不是所有读屏都能可靠地读出来。

一组单选框或复选框，用 fieldset 包起来，再用 legend 说明这一组问的是什么，比如上面的“标签”。

补充说明用 aria-describedby 关联，读屏会在读完名字以后接着读出来。

常见追问

不想让用户改，又要提交这个值，用 readonly 还是 disabled？

用 readonly。它能聚焦，也会提交；disabled 两样都没有。不过复选框和下拉框不支持 readonly，这时可以用一个隐藏的 input 来提交值。
