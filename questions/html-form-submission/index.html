表单的 name、value、label 与提交行为如何协作？

label 给控件提供名称并扩大点击区域，name 是提交时的字段名，value 是提交的值；没有 name、被 disabled 或未选中的控件不会提交，FormData 按同样规则收集。

参考答案

简答

  • <label for="id"> 或用 label 包住控件，读屏会读出名称，点击文字也能聚焦或勾选控件。
  • 只有带 name 的控件才会提交；disabled 的控件不提交，readonly 的控件会提交。
  • 未勾选的复选框和单选框不提交任何值；勾选但没写 value 时提交字符串 "on"。
  • 同名的多个控件（如多选复选框）提交多条记录，用 formData.getAll(name) 读取。
  • 点击的提交按钮如果有 name，它的值也会提交，可以用来区分“保存”和“发布”。

示例

HTML
<form id="post">
  <label for="title">标题</label>
  <input id="title" name="title" required>

  <fieldset>
    <legend>标签</legend>
    <label><input type="checkbox" name="tag" value="css"> CSS</label>
    <label><input type="checkbox" name="tag" value="html"> HTML</label>
  </fieldset>

  <input name="author" value="hu" readonly>
  <input name="draftId" value="42" disabled>

  <button name="action" value="save">保存</button>
  <button name="action" value="publish">发布</button>
</form>
JavaScript
form.addEventListener('submit', (event) => {
  event.preventDefault();
  const data = new FormData(form, event.submitter);
  data.getAll('tag');   // 例如 ['css', 'html']
  data.get('author');   // 'hu'
  data.get('draftId');  // null，disabled 不提交
  data.get('action');   // 'save' 或 'publish'
});

new FormData(form, submitter) 的第二个参数把点击的按钮加进去；只传 form 时不包含按钮的值。

提交方式

  • method="get" 把字段拼到 URL 查询参数里，适合搜索。
  • method="post" 默认编码为 application/x-www-form-urlencoded，上传文件需要 enctype="multipart/form-data"。
  • form.requestSubmit() 会先执行校验并触发 submit 事件；form.submit() 跳过校验和事件，直接提交。

名称

  • placeholder 不是名称，输入后就消失了，也不被所有读屏可靠读出。
  • 一组单选或复选框用 fieldset 和 legend 说明整组的问题。
  • 补充说明用 aria-describedby 关联，读屏会在名称之后读出。

常见追问

  • 不想让用户修改又想提交，用 readonly 还是 disabled？用 readonly。它保留焦点和提交，disabled 两者都没有。复选框和下拉框不支持 readonly，可以用隐藏的 input 提交值。
