Map、Set、WeakMap 与普通对象各有什么用途？

字段固定的记录用普通对象，键会动态增减、键不是字符串时用 Map，存不重复的值用 Set。WeakMap 的键必须是对象，不会阻止对象被回收，适合给对象挂额外数据。

参考答案

简答

普通对象的键只能是字符串或 Symbol，适合字段固定的记录，比如一个用户的信息。Map 的键可以是任意值，包括对象，有 size 属性，按插入顺序遍历，适合键会动态增减的字典。

Set 存的是不重复的值。ES2025 给它加了集合运算，比如并集 union、交集 intersection、差集 difference、对称差 symmetricDifference，还有判断子集的 isSubsetOf 等。Map 和 Set 判断两个键是否相同时，用的是 SameValueZero 规则：NaN 等于自己，对象看是不是同一个。

WeakMap 和 WeakSet 的键必须是对象，或者没有注册过的 Symbol。它们不会阻止键被回收，所以适合给对象附加私有数据或者做缓存，对象没了，对应的条目自动消失。

也正因为键随时可能被回收，它们没有 size，也不能遍历。

为什么对象作键要用 Map

JavaScript
const key = {};
const values = new Map([[key, 1]]);
console.log(values.get(key)); // 1
console.log(values.get({}));  // undefined

用 key 能取到 1，可用另一个看起来一样的 {} 去取，得到的是 undefined。因为 Map 比较对象键时只看是不是同一个对象，两个 {} 是不同的对象。

如果用普通对象存，问题更大。普通对象的键只能是字符串或 Symbol，用对象作键时会被转成字符串 '[object Object]'，于是所有对象键都变成了同一个键，互相覆盖。

Map 和普通对象怎么选

普通对象Map
键类型字符串、Symbol任意值
大小Object.keys(o).lengthmap.size
原型上的键可能冲突（如 'constructor'）无
JSON直接序列化需先 Object.fromEntries
频繁增删一般针对此优化

“原型上的键可能冲突”是指普通对象会继承 Object.prototype 上的属性，用户输入的键正好叫 constructor 时，读到的可能是继承来的东西。想要一个没有原型的纯字典，也可以用 Object.create(null) 创建。

Set 怎样做并集和交集

JavaScript
const a = new Set([1, 2, 3]);
const b = new Set([2, 3, 4]);

console.log([...a.union(b)]);        // [1, 2, 3, 4]
console.log([...a.intersection(b)]); // [2, 3]
console.log([...a.difference(b)]);   // [1]
console.log(a.isSubsetOf(new Set([1, 2, 3, 4]))); // true

这些方法都返回新的 Set，不会修改原来的集合。参数也不一定要是 Set，只要是“类 Set”对象就行，也就是有 size、has、keys 的对象，所以也可以直接传一个 Map。

WeakMap 适合做什么

JavaScript
const cache = new WeakMap();

function getLayout(element) {
  if (!cache.has(element)) cache.set(element, element.getBoundingClientRect());
  return cache.get(element);
}

这里用元素作键，缓存它的布局信息。等元素从 DOM 移除、也没有别的地方引用它时，这条缓存会跟着可以被回收。

如果换成 Map，Map 会一直牢牢引用着这个元素作键，元素从页面上删了也释放不掉，缓存越积越多。

那为什么 WeakMap 不能遍历、没有 size？因为对象什么时候被回收由引擎决定，代码观察不到。如果能遍历，结果就会随回收时机随机变化。需要在对象被回收后执行回调，可以用 FinalizationRegistry，但回调什么时候执行不确定，不能用于必须完成的清理。

常见追问

数组怎样去重？

写 [...new Set(arr)]。要注意对象元素是按身份去重的，两个内容相同的不同对象会都保留下来。

WeakRef 是什么？

它持有对象的弱引用，不阻止对象被回收。用 deref() 取对象，可能拿到 undefined，说明对象已经被回收了，所以只适合做丢了也没关系的缓存。
