Map、Set、WeakMap 与普通对象各有什么用途？

普通对象适合结构固定的记录；Map 适合键动态、键可以是任意值、需要频繁增删和按插入顺序遍历的集合；Set 存唯一值，ES2025 起有并集、交集等方法；WeakMap 和 WeakSet 的键必须是对象（或未注册的 Symbol），不阻止键被回收，也不能遍历。

参考答案

简答

  • 普通对象的键只能是字符串或 Symbol，适合固定字段的记录；Map 的键可以是任意值，有 size，按插入顺序迭代，适合动态字典。
  • Map、Set 用 SameValueZero 比较键：NaN 等于自身，对象按身份。
  • Set 存唯一值；ES2025 新增 union、intersection、difference、symmetricDifference、isSubsetOf 等方法。
  • WeakMap、WeakSet 的键必须是对象或未注册的 Symbol，不阻止键被回收，因此没有 size，也不能遍历。
  • WeakMap 适合给对象附加私有数据或缓存，对象被回收后对应条目自动消失。

对象作键

JavaScript
const key = {};
const values = new Map([[key, 1]]);
console.log(values.get(key)); // 1
console.log(values.get({}));  // undefined

用普通对象存同样的数据，key 会被转成字符串 '[object Object]'，所有对象键都会冲突。

Map 与普通对象

普通对象Map
键类型字符串、Symbol任意值
大小Object.keys(o).lengthmap.size
原型上的键可能冲突（如 'constructor'）无
JSON直接序列化需先 Object.fromEntries
频繁增删一般针对此优化

需要无原型的字典时也可以用 Object.create(null)。

Set 集合运算（ES2025）

JavaScript
const a = new Set([1, 2, 3]);
const b = new Set([2, 3, 4]);

console.log([...a.union(b)]);        // [1, 2, 3, 4]
console.log([...a.intersection(b)]); // [2, 3]
console.log([...a.difference(b)]);   // [1]
console.log(a.isSubsetOf(new Set([1, 2, 3, 4]))); // true

这些方法返回新 Set，不修改原集合。参数只需是"类 Set"对象（有 size、has、keys），也可以传 Map。

WeakMap 的用途

JavaScript
const cache = new WeakMap();

function getLayout(element) {
  if (!cache.has(element)) cache.set(element, element.getBoundingClientRect());
  return cache.get(element);
}

元素从 DOM 移除且没有其他引用后，缓存条目随之可回收。用 Map 做同样的事，缓存会一直持有元素。

回收时机由引擎决定，不能观测，所以 WeakMap 不提供遍历和计数。需要在回收后执行回调时用 FinalizationRegistry，但回调时间不确定，不能用于必须执行的清理。

常见追问

  • 数组去重？[...new Set(arr)]，对象元素按身份去重。
  • WeakRef 是什么？持有对象的弱引用，deref() 可能返回 undefined，用于可丢弃的缓存。
