数组常用方法怎样选择，哪些会修改原数组？

按意图选方法：转换用 map，筛选用 filter，查找用 find/some，汇总用 reduce。sort、reverse、splice 等会修改原数组，ES2023 的 toSorted、toReversed、toSpliced、with 返回副本。返回新数组只是新容器，元素对象仍共享。

参考答案

简答

  • 会修改原数组：push、pop、shift、unshift、splice、sort、reverse、fill、copyWithin。
  • 返回新数组：map、filter、slice、concat、flat，以及 ES2023 的 toSorted、toReversed、toSpliced、with。
  • 新数组是浅复制，里面的对象仍是同一个引用。
  • sort 默认按字符串比较，数字排序要传 (a, b) => a - b。
  • forEach 不能 break，也不会等待 async 回调；需要等待时用 for...of 加 await 或 Promise.all。

sort 与 toSorted

JavaScript
const values = [10, 2, 1];
const numeric = values.toSorted((a, b) => a - b);

console.log(values.join(','));  // 10,2,1
console.log(numeric.join(',')); // 1,2,10
console.log(values.sort() === values); // true
console.log(values.join(',')); // 1,10,2

sort() 不传比较函数时把元素转成字符串比较，所以 10 排在 2 前面。sort 原地排序并返回原数组；toSorted 返回排好序的副本。规范要求排序稳定。

splice 返回被删除的元素数组，不是修改后的数组；slice 不修改原数组。

新数组不等于深拷贝

JavaScript
const source = [{ id: 1, score: 10 }];
const selected = source.filter(() => true);
selected[0].score = 20;
console.log(source[0].score); // 20

const updated = source.map(row =>
  row.id === 1 ? { ...row, score: 30 } : row,
);
console.log(source[0].score);  // 20
console.log(updated[0].score); // 30

不可变更新的做法是：只为被修改的那一项创建新对象，其余项复用原引用。

边界

  • [].some(fn) 为 false，[].every(fn) 为 true。
  • 空数组调用 reduce 不传初始值会抛 TypeError，求和时写 reduce((s, x) => s + x, 0)。
  • 稀疏数组 [, 2] 的空位会被 map、forEach、filter 跳过，但展开和 for...of 会把空位读成 undefined。不要用 delete arr[i] 删元素。

async 回调

JavaScript
async function double(value) {
  return value * 2;
}

async function calculate() {
  const values = [1, 2, 3];
  const results = await Promise.all(values.map(double));
  console.log(results.join(',')); // 2,4,6
}

calculate();

forEach(async ...) 只是发起了几个 Promise，forEach 本身立即返回 undefined。要并行就 Promise.all(arr.map(...))，要串行就 for (const x of arr) await task(x)。

分组与异步收集

Object.groupBy（ES2024）按回调返回的键分组，结果是原型为 null 的对象，要用 Object.hasOwn 判断键；键不是字符串时用 Map.groupBy。Array.fromAsync（ES2026）把异步可迭代对象逐个等待后收集成数组。

JavaScript
const items = [
  { name: 'a', type: 'js' },
  { name: 'b', type: 'css' },
  { name: 'c', type: 'js' },
];
const groups = Object.groupBy(items, (item) => item.type);
console.log(groups.js.map((item) => item.name)); // ['a', 'c']

常见追问

  • map 回调里修改元素算不算修改原数组？map 本身不改容器，但回调可以改元素对象，语言不会阻止。
  • for...in 能遍历数组吗？能，但会遍历到继承的可枚举属性，键是字符串，不推荐。
