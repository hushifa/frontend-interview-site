React Native 与浏览器里的 React 有哪些共同点和差异？

参考答案

React Native 复用 React 的组件与状态思路，但渲染目标是平台原生能力和组件，常见基础组件是 View、Text、Image 等，并不是把 div 和 CSS 原样搬进手机应用。

平台布局、文本、手势、导航和权限存在差异，浏览器 DOM API 也不能直接使用。跨端共享通常更适合业务模型、校验和部分状态逻辑；界面与平台能力需要明确适配边界。

选型时评估原生依赖、升级成本、调试工具和团队能力，而不只比较代码复用率。具体渲染架构会随版本演进，不能长期沿用“所有交互都通过旧式桥接”的过时概括。
