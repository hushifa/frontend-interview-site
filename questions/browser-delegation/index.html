事件委托是什么？target 和 currentTarget 有何区别？

事件委托把监听器挂在祖先元素上，利用冒泡统一处理子元素事件；target 是实际触发事件的元素，currentTarget 是当前执行监听器的元素。

参考答案

简答

  • 事件委托是在共同的祖先上注册一个监听器，事件从子元素冒泡上来时统一处理。
  • event.target 是最初触发事件的元素，event.currentTarget 是当前正在执行监听器的元素。
  • 用 target.closest(selector) 找到真正关心的元素，并确认它在委托容器内。
  • 不冒泡的事件（如 focus、mouseenter）不能直接委托，可改用 focusin、pointerover 或捕获阶段。

为什么用委托

  • 列表有成百上千项时，只注册一个监听器，内存和注册成本更低。
  • 动态新增的子元素不需要再单独绑定。
  • 移除子元素时不用逐个解绑。

示例

JavaScript
const list = document.querySelector('#todo-list');

list.addEventListener('click', (event) => {
  const button = event.target.closest('button[data-action]');
  if (!button || !list.contains(button)) return;

  const item = button.closest('li');
  if (button.dataset.action === 'remove') item.remove();
});

点击按钮里的图标时，target 是图标元素，所以要用 closest() 向上找按钮。list.contains(button) 防止匹配到容器外层的同名元素。

target 和 currentTarget

HTML
<ul id="list"><li><span>文字</span></li></ul>

点击 span，监听器挂在 ul 上：

  • event.target 是 span。
  • event.currentTarget 是 ul，与监听器里的 this（普通函数）相同。

currentTarget 只在事件分发期间有值，异步回调里读取会得到 null，需要的话先保存到变量里。

注意事项

  • 在中间层调用 stopPropagation() 会让委托监听器收不到事件。
  • 委托到 document 上会让每次点击都经过判断逻辑，范围应尽量小。
  • 键盘可操作性来自真实的 button 或 a 元素，委托只负责处理逻辑。
