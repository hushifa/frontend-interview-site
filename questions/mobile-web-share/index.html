Web Share API 使用时要处理哪些降级？

了解 navigator.share 的用户激活、权限和平台支持边界，为分享按钮设计复制链接等降级方案。

参考答案

Web Share API 允许页面调用系统分享面板，但通常要求安全上下文和用户激活，且不同浏览器支持的 url、text、files 能力不同。调用可能被用户取消，也可能因数据格式或权限失败。

分享按钮应先检测 navigator.share 和必要能力，再提供复制链接、生成二维码或展示可复制文本的降级。不要在页面加载时自动触发分享，也不要把未确认的敏感 URL 放进分享内容。

分享完成不代表对方收到内容；它只是把数据交给系统或目标应用。业务仍应处理取消、重复点击和移动端返回行为。
