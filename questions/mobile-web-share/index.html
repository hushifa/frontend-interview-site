Web Share API 使用时要处理哪些降级？

了解 navigator.share 的用户激活、安全上下文和平台支持边界，区分用户取消与真正失败，为分享按钮设计复制链接等降级方案。

参考答案

简答

  • navigator.share() 打开系统分享面板，只能在安全上下文中、由用户点击等手势触发调用。
  • 移动端浏览器和部分桌面浏览器支持，桌面版 Firefox 等不支持，要先检测 navigator.share 是否存在。
  • 分享文件前用 navigator.canShare({ files }) 检查，部分平台只支持分享链接和文本。
  • 用户关闭分享面板时 Promise 以 AbortError 拒绝，这不是错误，不应提示失败。
  • 不支持时降级为复制链接（navigator.clipboard.writeText），复制也失败时显示可选中的链接文本。

完整的分享按钮

JavaScript
async function share({ title, url }) {
  if (navigator.share) {
    try {
      await navigator.share({ title, url });
      return 'shared';
    } catch (error) {
      if (error.name === 'AbortError') return 'cancelled';
      // 其他错误继续走降级
    }
  }

  try {
    await navigator.clipboard.writeText(url);
    showToast('链接已复制');
    return 'copied';
  } catch {
    showLinkDialog(url); // 让用户手动复制
    return 'manual';
  }
}

shareButton.addEventListener('click', () => {
  share({ title: document.title, url: location.href });
});
  • 调用必须直接发生在点击处理中。先 await 一个网络请求再调用 share()，用户激活可能已经失效，会抛 NotAllowedError。
  • 同一时间只能有一个分享面板，重复点击会抛 InvalidStateError，可以在分享期间禁用按钮。

分享文件

JavaScript
const file = new File([blob], 'poster.png', { type: 'image/png' });

if (navigator.canShare?.({ files: [file] })) {
  await navigator.share({ files: [file], title: '活动海报' });
} else {
  downloadFile(file);
}

允许分享的文件类型由浏览器决定，常见图片、PDF、文本一般支持。

安全与隐私

  • 分享内容会交给用户选择的其他应用，不要在 URL 中带上会话令牌或个人信息。
  • 在 iframe 中调用需要父页面通过 allow="web-share" 授权。

常见追问

  • 怎样让分享出去的链接显示标题和图片？这由目标应用抓取页面的 Open Graph 元信息决定，与 Web Share API 无关。
  • 可以接收别的应用分享过来的内容吗？安装后的 PWA 可以在 Manifest 中声明 share_target，目前主要在 Chromium 中支持。
