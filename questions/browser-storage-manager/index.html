StorageManager 能告诉我们浏览器存储的哪些信息？

navigator.storage 提供 estimate() 估算已用空间和配额、persist() 申请持久存储、persisted() 查询状态，以及 getDirectory() 访问 OPFS；返回值是估算值，配额由浏览器决定。

参考答案

简答

  • navigator.storage.estimate() 返回 { usage, quota }，是本源 IndexedDB、Cache Storage、OPFS 等的估算用量和可用配额。
  • 默认存储是"尽力而为"的，存储压力大时浏览器可能清除；persist() 申请持久存储，persisted() 查询是否已获得。
  • getDirectory() 返回源私有文件系统（OPFS）的根目录，适合存大文件和数据库文件。
  • 这些数值是估算值，不同浏览器的配额策略不同，不能作为精确容量使用。

示例

JavaScript
async function checkStorage() {
  const { usage = 0, quota = 0 } = await navigator.storage.estimate();
  const persisted = await navigator.storage.persisted();
  return {
    usedMB: Math.round(usage / 1024 / 1024),
    quotaMB: Math.round(quota / 1024 / 1024),
    persisted,
  };
}

async function requestPersistence() {
  if (!navigator.storage?.persist) return false;
  if (await navigator.storage.persisted()) return true;
  return navigator.storage.persist();
}

使用建议

  • 下载大量离线数据前先检查剩余空间（quota - usage），不足时提示用户。
  • 写入时仍要处理 QuotaExceededError，估算值和实际可写入的空间可能不一致。
  • Chrome 会根据用户与网站的互动程度自动决定是否授予持久存储，Firefox 会弹出提示询问用户。
  • 获得持久存储后，用户仍可在浏览器设置里手动清除数据，重要数据要有服务端备份。
  • 为防止网站探测用户的磁盘大小，浏览器返回的 quota 不等于真实剩余磁盘空间。

常见追问

  • 无痕模式下配额会怎样：通常会小很多，窗口关闭后数据被清除。
  • 存储按什么划分：按源划分，并且在第三方 iframe 中按顶层站点分区。
