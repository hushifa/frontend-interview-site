Vue 自定义指令适合什么场景？

自定义指令用于复用对普通 DOM 元素的底层操作，例如自动聚焦、点击外部关闭、懒加载图片。它通过 mounted、updated、unmounted 等钩子访问元素，必须在卸载时清理资源；需要渲染结构或管理状态时应该用组件或组合式函数。

参考答案

简答

  • 指令对象可以定义 created、beforeMount、mounted、beforeUpdate、updated、beforeUnmount、unmounted 钩子，参数是 (el, binding, vnode, prevVnode)。
  • binding 包含 value（绑定值）、oldValue、arg（v-x:arg）、modifiers（v-x.foo）。
  • 在 <script setup> 中，以 v 开头的驼峰变量（如 vFocus）可以直接作为指令 v-focus 使用。
  • 在 mounted 中注册的监听器、观察器，必须在 unmounted 中移除。
  • 用在组件上时，指令作用于组件的根元素；多根组件会被忽略并警告，所以不推荐在组件上使用。

自动聚焦

vue
<script setup>
const vFocus = { mounted: (el) => el.focus() };
</script>

<template>
  <input v-focus />
</template>

点击外部关闭

JavaScript
// directives/clickOutside.js
export const clickOutside = {
  mounted(el, binding) {
    el._onClickOutside = (event) => {
      if (!el.contains(event.target)) binding.value(event);
    };
    document.addEventListener('pointerdown', el._onClickOutside);
  },
  unmounted(el) {
    document.removeEventListener('pointerdown', el._onClickOutside);
    delete el._onClickOutside;
  },
};
vue
<div v-if="open" v-click-outside="() => (open = false)">菜单内容</div>

处理函数保存在元素上，卸载时能拿到同一个引用来移除。

绑定值变化

JavaScript
export const lazySrc = {
  mounted(el, { value }) {
    el._observer = new IntersectionObserver(([entry]) => {
      if (entry.isIntersecting) {
        el.src = el.dataset.src;
        el._observer.disconnect();
      }
    });
    el.dataset.src = value;
    el._observer.observe(el);
  },
  updated(el, { value, oldValue }) {
    if (value !== oldValue) {
      el.dataset.src = value;
      if (el.src) el.src = value; // 已加载过的图片直接换地址
    }
  },
  unmounted(el) {
    el._observer?.disconnect();
  },
};

只写 mounted 的指令，绑定值后续变化时不会生效。（实际项目中，<img loading="lazy"> 已能满足大部分懒加载需求。）

全局注册

JavaScript
app.directive('click-outside', clickOutside);

什么时候不用指令

  • 需要渲染额外的 DOM 结构（例如 tooltip 的浮层）：用组件。
  • 需要管理状态或复用业务逻辑：用组合式函数。
  • 权限控制隐藏按钮：用 v-if 加权限判断函数更清楚，指令删除 DOM 节点不会卸载对应组件实例。

常见追问

  • 函数简写是什么意思？app.directive('color', (el, binding) => {...}) 等同于同时定义 mounted 和 updated。
  • SSR 中指令会执行吗？DOM 钩子不在服务端执行，需要输出到 HTML 的属性要用 getSSRProps 钩子提供。
