absolute、fixed 和 sticky 的定位参照是什么？

absolute 相对最近的定位祖先；fixed 通常相对视口，但祖先有 transform、filter 等属性时会改为相对该祖先；sticky 在最近的滚动容器里吸附，且不会超出自己的父元素。

参考答案

简答

  • absolute 的包含块是最近的 position 非 static 的祖先的内边距盒；找不到时是初始包含块。
  • fixed 默认相对视口，但祖先设置了 transform、perspective、filter、contain: paint 或对应的 will-change 时，会相对该祖先定位。
  • sticky 在最近的滚动祖先里按 top 等阈值吸附，吸附范围不超过自己的父元素。
  • 百分比的 top、width 也按包含块计算。
  • 浮层被裁剪或位置不对时，先在开发者工具里找到它的包含块。

absolute

CSS
.card {
  position: relative;
}

.card .badge {
  position: absolute;
  inset-block-start: 8px;
  inset-inline-end: 8px;
}

.card 设置 position: relative 只是为了成为包含块，本身不移动。

fixed 失效

CSS
.modal-wrapper {
  transform: translateZ(0);
}

.modal-wrapper .overlay {
  position: fixed;
  inset: 0;
}

.overlay 只盖住 .modal-wrapper，而不是整个视口。常见原因是动画库在祖先上加了 transform。解决办法是把浮层渲染到 body 下（React 的 Portal），或使用 <dialog> 和 popover，它们进入顶层，不受祖先影响。

sticky 不生效的原因

CSS
.table-head {
  position: sticky;
  top: 0;
}
  • 没有设置 top、bottom 等阈值。
  • 某个祖先设置了 overflow: hidden 或 auto，sticky 改为相对这个祖先吸附，而它可能并不滚动。
  • 父元素和 sticky 元素一样高，没有可吸附的距离。
  • 在 flex 或 grid 中被拉伸成和父元素一样高，可以加 align-self: start。

常见追问

  • overflow: clip 和 hidden 对 sticky 有区别吗？有。clip 不会创建滚动容器，sticky 仍然相对外层真正滚动的祖先吸附。
