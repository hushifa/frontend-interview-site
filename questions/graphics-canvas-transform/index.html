Canvas 的 transform 怎样影响坐标和绘制？

当前变换矩阵决定后续绘制坐标如何映射到位图，translate、scale、rotate 的调用顺序会改变结果。用 save/restore 限制局部状态，用 setTransform 处理高 DPI，用完整矩阵的逆变换把指针坐标换回绘图空间。

参考答案

简答

  • 变换只影响之后的绘制，已经画好的像素不会移动。要做动画就清空后按新状态重画。
  • 矩阵 (a, b, c, d, e, f) 把点 (x, y) 映射为 (a·x + c·y + e, b·x + d·y + f)。
  • 新变换乘在当前矩阵右侧，所以先 translate(100, 0) 再 scale(2, 2) 时，点 (10, 5) 变成 (120, 10)；顺序反过来变成 (220, 10)。
  • transform() 在当前矩阵上叠加，setTransform() 直接替换，resetTransform() 恢复单位矩阵。每帧调用 scale() 而不重置，缩放会不断累积。
  • 修改 canvas.width 或 height 会清空画布并重置所有状态，之后要重新设置变换。

顺序验证

JavaScript
const ctx = document.createElement('canvas').getContext('2d');
ctx.translate(100, 0);
ctx.scale(2, 2);
const p = new DOMPoint(10, 5).matrixTransform(ctx.getTransform());
console.log(p.x, p.y); // 120 10

点先被缩放成 (20, 10)，再平移 100。rotate() 使用弧度，绕当前原点旋转；要绕图形中心旋转，先把原点平移到中心，再按局部坐标绘制：

JavaScript
ctx.save();
ctx.translate(cx, cy);
ctx.rotate(Math.PI / 4);
ctx.fillRect(-20, -10, 40, 20); // 以中心为原点
ctx.restore();

save 和 restore

save() 把矩阵、填充和描边样式、线宽、裁剪区域等状态压栈，restore() 弹出。它不是像素撤销，也不会清空当前路径，新图形仍要 beginPath()。

高 DPI

CSS 尺寸 300×150、设备像素比为 2 时，把位图设为 600×300，再设置 ctx.setTransform(2, 0, 0, 2, 0, 0)，绘图代码就可以继续使用 CSS 像素坐标。场景的平移和缩放叠加在这个矩阵之上。

指针坐标转回绘图空间

JavaScript
// worldToBitmap：绘制场景时使用的完整矩阵，已包含 DPR
function clientToWorld(canvas, clientX, clientY, worldToBitmap) {
  const rect = canvas.getBoundingClientRect();
  if (rect.width === 0 || rect.height === 0) return null;
  const x = ((clientX - rect.left) * canvas.width) / rect.width;
  const y = ((clientY - rect.top) * canvas.height) / rect.height;
  const p = new DOMPoint(x, y).matrixTransform(worldToBitmap.inverse());
  return Number.isFinite(p.x) && Number.isFinite(p.y) ? { x: p.x, y: p.y } : null;
}
  • 先换算到位图坐标，再乘逆矩阵。DPR 已经包含在矩阵里，不要再除一次。
  • 保存绘制时实际使用的矩阵，不要在 restore() 之后随手读取 getTransform()。
  • 缩放为 0 时矩阵不可逆，结果是非有限数，函数返回 null。
  • canvas 有边框、内边距或 CSS 旋转时，这个换算不成立，需要额外处理。

清空画布

clearRect() 也受当前变换影响。清空整个位图时：

JavaScript
ctx.save();
ctx.resetTransform();
ctx.clearRect(0, 0, canvas.width, canvas.height);
ctx.restore();

裁剪区域仍会限制清除范围，重置矩阵不会取消 clip()。
