组件 v-model 的本质是什么？

组件上的 v-model 是一个 prop 加一个更新事件的语法糖，默认是 modelValue 和 update:modelValue。状态始终属于父组件，子组件只是发出"想改成这个值"的事件。Vue 3.4 起可以用 defineModel 简化子组件的写法。

参考答案

简答

  • <Child v-model="name" /> 展开为 <Child :modelValue="name" @update:modelValue="v => name = v" />。
  • v-model:title="t" 使用 title prop 和 update:title 事件，一个组件可以有多个 v-model。
  • 数据始终归父组件所有，子组件不能直接修改 prop，只能 emit 新值，由父组件决定是否更新。
  • 子组件手写实现时，常用可写 computed 把 prop 读取和 emit 包装成一个可以绑定的值。
  • Vue 3.4 起用 defineModel() 宏自动完成上述声明，见《Vue 3 defineModel 的双向绑定边界是什么？》。

手写实现

vue
<!-- TextField.vue -->
<script setup>
import { computed } from 'vue';

const props = defineProps({ modelValue: { type: String, default: '' } });
const emit = defineEmits(['update:modelValue']);

const value = computed({
  get: () => props.modelValue,
  set: (next) => emit('update:modelValue', next),
});
</script>

<template>
  <label>姓名 <input v-model="value" /></label>
</template>
vue
<!-- Parent.vue -->
<script setup>
import { ref } from 'vue';
import TextField from './TextField.vue';

const name = ref('Lin');
</script>

<template>
  <TextField v-model="name" />
  <p>{{ name }}</p>
</template>

用户输入时：内部 input 写入 value → setter 发出 update:modelValue → 父组件更新 name → 新值作为 prop 传回子组件 → getter 返回新值。可写 computed 不保存数据，只是读写的转接。

父组件可以拒绝或改写更新

因为更新是一个事件，父组件可以不用 v-model 简写，自己处理：

vue
<TextField :modelValue="name" @update:modelValue="(v) => (name = v.slice(0, 20))" />

这里父组件把名字截断为 20 个字符。子组件即使 emit 了更长的值，显示的也是父组件最终给出的 prop。

原生元素上的 v-model

在 input、textarea、select 上，v-model 由编译器按元素类型展开：文本框绑定 value 和 input 事件，复选框绑定 checked 和 change 事件。文本输入时还会处理输入法组合，拼音输入完成前不会更新。内置修饰符 .lazy（改用 change 事件）、.number、.trim 只对原生元素有效，组件需要自己实现修饰符。

常见追问

  • Vue 2 有什么不同？Vue 2 默认使用 value prop 和 input 事件，用 .sync 实现其他属性的双向绑定；Vue 3 统一为 v-model:xxx，移除了 .sync。
  • 绑定对象后在子组件里修改它的属性会怎样？会直接改到父组件的对象，但不经过 emit，数据流向不清晰，应 emit 一个新对象。
