浅拷贝、深拷贝和 structuredClone 如何选择？

展开语法、Object.assign、slice 都是浅拷贝，嵌套对象仍共享。structuredClone 能深拷贝 Date、Map、Set、ArrayBuffer 和循环引用，但遇到函数、DOM 节点会抛错，并丢失原型、getter 和不可枚举属性。状态更新通常只复制被修改的路径。

参考答案

简答

  • 浅拷贝（{...obj}、Object.assign、arr.slice()、Array.from）只复制一层，嵌套对象仍是同一个引用。
  • structuredClone 深拷贝普通对象、数组、Date、RegExp、Map、Set、ArrayBuffer、Error 等，并正确处理循环引用。
  • structuredClone 遇到函数、DOM 节点、Symbol 值会抛 DataCloneError；类实例会变成普通对象，getter 会被求值成普通值，不可枚举属性和 Symbol 键会丢失。
  • JSON.parse(JSON.stringify(x)) 会丢 undefined 和函数，把 Date 变成字符串，遇到循环引用和 BigInt 会抛错。
  • 不可变状态更新只复制修改路径上的对象，其余部分共享引用。

浅拷贝

JavaScript
const source = { child: { count: 1 } };
const shallow = { ...source };
const deep = structuredClone(source);

shallow.child.count = 2;
console.log(source.child.count); // 2
console.log(deep.child.count);   // 1

structuredClone 的能力与限制

JavaScript
const original = { when: new Date(0), tags: new Set(['a']) };
original.self = original;

const copy = structuredClone(original);
console.log(copy.when instanceof Date); // true
console.log(copy.self === copy); // true
值结果
Date、Map、Set、RegExp、TypedArray保留类型
循环引用保留结构
类实例变成普通对象，丢失原型方法
函数、DOM 节点、Symbol 值抛 DataCloneError
getter复制求值结果

第二个参数 { transfer: [buffer] } 会把 ArrayBuffer 转移给副本，原 buffer 变为长度 0。postMessage 用的是同一个算法。

状态更新：按路径复制

JavaScript
const next = {
  ...state,
  user: { ...state.user, name: '新名字' },
};

只有 next、next.user 是新对象，state.settings 等未改动的部分仍共享。React 依赖引用变化判断更新，整棵树深拷贝既浪费又会让所有子组件认为数据变了。嵌套很深时可以用 Immer。

常见追问

  • 手写深拷贝要处理什么？基本类型直接返回；用 WeakMap 记录已复制对象处理循环引用；区分数组、Date、Map、Set；决定是否保留原型和 Symbol 键。
  • structuredClone 在哪里可用？浏览器和 Node.js 17 起都是全局函数。
