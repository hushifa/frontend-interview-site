浅拷贝、深拷贝和 structuredClone 如何选择？

展开语法、Object.assign 只复制一层，里面的对象还是共用的。structuredClone 能完整深拷贝常见数据，但复制不了函数和 DOM 节点，也会丢掉类的原型。更新状态时通常只复制改动的那条路径。

参考答案

简答

浅拷贝只复制最外面一层。{...obj}、Object.assign、arr.slice()、Array.from 都是浅拷贝，复制出来的新对象里，嵌套的对象还是和原来共用同一个。

要完整复制一份，可以用 structuredClone。它能深拷贝普通对象、数组、Date、RegExp、Map、Set、ArrayBuffer、Error 等，循环引用也能正确处理。

但它有限制。遇到函数、DOM 节点、Symbol 值会抛 DataCloneError；类的实例会变成普通对象，丢掉原型上的方法；getter 会被求值成普通值；不可枚举属性和 Symbol 键会丢掉。老办法 JSON.parse(JSON.stringify(x)) 问题更多，会丢掉 undefined 和函数，把 Date 变成字符串，碰到循环引用和 BigInt 直接报错。

实际更新状态时，一般不做整体深拷贝，而是只复制被修改的那条路径，其他部分继续共用。

浅拷贝和深拷贝差在哪

JavaScript
const source = { child: { count: 1 } };
const shallow = { ...source };
const deep = structuredClone(source);

shallow.child.count = 2;
console.log(source.child.count); // 2
console.log(deep.child.count);   // 1

改的是 shallow.child.count，可 source.child.count 也变成了 2。

因为展开语法只复制了 source 这一层，shallow.child 和 source.child 指向同一个对象，从哪边改都是改它。structuredClone 会把里面的对象也重新创建一份，所以 deep.child 是独立的，还是 1。

structuredClone 能复制什么，不能复制什么

JavaScript
const original = { when: new Date(0), tags: new Set(['a']) };
original.self = original;

const copy = structuredClone(original);
console.log(copy.when instanceof Date); // true
console.log(copy.self === copy); // true

original.self 指向自己，这叫循环引用，手写递归拷贝很容易在这里陷入死循环。structuredClone 会记住已经复制过的对象，所以副本的 self 正确地指向副本自己。Date 复制出来也还是 Date。

各种值的处理结果如下：

值结果
Date、Map、Set、RegExp、TypedArray保留类型
循环引用保留结构
类实例变成普通对象，丢失原型方法
函数、DOM 节点、Symbol 值抛 DataCloneError
getter复制求值结果

它还有第二个参数。传 { transfer: [buffer] } 时，ArrayBuffer 不是被复制，而是被转移给副本，原来的 buffer 长度变成 0。postMessage 给 Worker 发数据时用的也是这同一套复制规则。

更新状态时为什么不整个深拷贝

JavaScript
const next = {
  ...state,
  user: { ...state.user, name: '新名字' },
};

这里只创建了两个新对象：next 和 next.user。state.settings 这类没改动的部分，还是原来的引用。

React 靠引用有没有变来判断数据有没有更新。如果把整棵状态树都深拷贝一遍，不光浪费，而且每个部分的引用都变了，所有子组件都会以为自己的数据变了，跟着重新渲染。只复制修改路径，没改的部分引用不变，就能跳过。嵌套很深、手写展开太繁琐时，可以用 Immer 这类库。

常见追问

手写深拷贝要处理什么？

基本类型直接返回。用 WeakMap 记下已经复制过的对象，碰到循环引用时直接返回之前的副本。数组、Date、Map、Set 要分别处理。还要想清楚要不要保留原型、要不要复制 Symbol 键。

structuredClone 在哪里能用？

现代浏览器里都能直接用，Node.js 从 17 版开始也是全局函数。
