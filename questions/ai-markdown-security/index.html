AI 生成的 Markdown 应该怎样安全地渲染？

参考答案

模型输出应按不可信内容处理。不要直接把生成文本作为 HTML 交给 dangerouslySetInnerHTML，也不要把生成的 JSX、MDX 或脚本直接编译执行。展示代码与执行代码是不同的权限边界。

react-markdown 默认提供安全基础，但其官方文档提醒：修改 URL 转换、添加插件或自定义组件可能引入风险。若确实支持原始 HTML，应使用合适的解析与净化流程，并为标签、属性和协议制定明确规则，而不是认为“用了 Markdown 库就都安全”。

外链和远程图片也需要产品策略：即使不执行脚本，加载图片仍可能向第三方发送请求，伪装链接也可能误导用户。流式内容尚不完整时，应允许暂时以纯文本展示，不要为了修补标签而绕过净化。公式、图表和代码沙盒属于额外能力，需要单独评估。
