AI 生成的 Markdown 应该怎样安全地渲染？

模型输出要当成用户输入一样不信任。默认不渲染原始 HTML，链接只放行 http 和 https，外部图片谨慎加载；确实要 HTML 时，在插件链的最后做净化。流式输出要合并更新，未闭合的块先按纯文本显示。

参考答案

简答

模型的输出要当成用户输入来对待。它可能复述网页里的恶意内容，也可能在提示词注入下生成钓鱼链接或 HTML。

所以默认关闭原始 HTML，链接只允许 http: 和 https:，外部图片默认不加载。图片看起来无害，可是图片地址里可以带上对话内容，浏览器一加载，数据就发到攻击者的服务器上了。

确实需要 HTML 时，用维护中的净化库处理最终要进入页面的结构，净化之后的插件不能再插入没净化过的内容。

代码块只展示不执行。MDX、Mermaid、代码沙盒这些能力，要单独评估它们需要什么权限。

一个受限的渲染组件

下面用 react-markdown 渲染模型输出。注意看两处：a 链接经过了 safeHref 检查，img 被换成了一段文字。

JSX
import Markdown from 'react-markdown';

function safeHref(href) {
  if (!href) return null;
  try {
    // 基地址由应用指定，不使用模型提供的值
    const url = new URL(href, 'https://app.example.com/');
    return ['http:', 'https:'].includes(url.protocol) ? url.href : null;
  } catch {
    return null;
  }
}

export function Answer({ text }) {
  return (
    <Markdown
      skipHtml
      components={{
        a: ({ href, children }) => {
          const url = safeHref(href);
          return url ? (
            <a href={url} target="_blank" rel="noopener noreferrer">
              {children}
            </a>
          ) : (
            <span>{children}</span>
          );
        },
        img: ({ alt }) => <span>[图片：{alt || '未命名'}]</span>,
      }}
    >
      {text}
    </Markdown>
  );
}

react-markdown 本来就不渲染原始 HTML，也会过滤 javascript: 这类危险协议。那为什么还要自己写 safeHref？因为这些默认行为很容易被改掉。自定义了 urlTransform，或者启用了 rehype-raw，默认的保护就变了。自己在组件里再检查一遍，规则写在明处，不怕后来有人改配置。

还要知道，只允许 http 和 https，只是排除了危险协议，不代表链接本身可信，钓鱼网站也是 https。可以在链接旁边显示域名，或者跳转前提示一下。

图片被换成了文字，是因为前面说的数据外带问题。如果确实要显示图片，可以改成“点击加载”，或者只允许经过自己代理的、在白名单里的域名。

确实需要 HTML 怎么办

先列清楚允许哪些标签、哪些属性、哪些 URL 协议，再用 rehype-sanitize、DOMPurify 这类维护中的工具做净化。

顺序很关键。Markdown 渲染一般要经过好几个插件，如果净化之后，后面的插件又加了 HTML 或者属性，前面的净化就白做了。所以净化要放在最后，处理的是最终进入页面的东西。

SVG、iframe、内联样式各有各的攻击方式。不要为了一个样式需求，就把整个 HTML 都放开。

流式输出时怎么渲染

模型是一点点输出的，中间会出现半个链接、没闭合的代码块、只有一半的表格。每来一个 token 就重新解析一遍，页面会不停跳动，也有大量重复计算。可以按动画帧把更新合并起来。

没闭合的块，先按纯文本显示，等它结束了再完整渲染。另外要限制总长度、代码块数量和嵌套深度，防止一段超长输出把页面拖垮。

常见追问

在提示词里要求“不要输出 HTML”不就够了吗？

不够。提示词只是让模型尽量遵守，攻击者可以通过注入让它改主意。真正的边界是浏览器端渲染时的限制，那是模型改变不了的。

用户想运行模型生成的代码怎么办？

放进隔离的沙盒里运行，比如跨源的 iframe 或者 Worker，限制它能访问的网络和资源，并且要等用户明确点击以后才运行。
