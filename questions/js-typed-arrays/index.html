ArrayBuffer、TypedArray 和普通数组有什么区别？

ArrayBuffer 是一段原始字节，本身不能读写；TypedArray 按固定数值类型（如 Uint8、Float32）查看缓冲区，长度固定、元素会被强制转换。subarray 共享缓冲区，slice 复制。普通数组可以存任意值并自由伸缩。

参考答案

简答

  • ArrayBuffer 只是一块字节存储，要通过 TypedArray 或 DataView 视图读写。
  • TypedArray 每个元素是固定类型的数值，写入时会被转换：Uint8Array 写 256 得到 0，Uint8ClampedArray 写 256 得到 255。
  • subarray 返回共享同一缓冲区的新视图，slice 复制出独立数据。
  • 多个视图可以指向同一个缓冲区；Array.isArray(typedArray) 为 false。
  • 普通 ArrayBuffer 创建后长度固定；ES2024 起可以用 new ArrayBuffer(len, { maxByteLength }) 创建可调整大小的缓冲区。

共享与复制

JavaScript
const bytes = new Uint8Array([1, 2, 3]);
const shared = bytes.subarray(1);
const copied = bytes.slice(1);
shared[0] = 9;

console.log(bytes[1]); // 9
console.log(copied[0]); // 2
console.log(Array.isArray(bytes)); // false

元素转换

JavaScript
const u8 = new Uint8Array(1);
u8[0] = 256;
console.log(u8[0]); // 0，按 2^8 取模

const clamped = new Uint8ClampedArray(1);
clamped[0] = 256;
console.log(clamped[0]); // 255，钳制到范围内

const i8 = new Int8Array([200]);
console.log(i8[0]); // -56

Uint8ClampedArray 用于 Canvas 的 ImageData。

与普通数组对比

普通数组TypedArray
元素任意值固定数值类型
长度可变固定
push / pop有没有
越界写入扩展数组被忽略
用途通用文件、网络、WebGL、音视频、WASM

视图的偏移

JavaScript
const buffer = new ArrayBuffer(8);
const all = new Uint8Array(buffer);
const tail = new Uint16Array(buffer, 4, 2); // 从第 4 字节开始，2 个元素
tail[0] = 0xffff;
console.log(all[4], all[5]); // 255 255

byteOffset 必须是元素大小的整数倍，否则抛 RangeError。多字节类型按平台字节序读写（几乎都是小端），需要指定字节序时用 DataView。

可调整大小与转移

  • new ArrayBuffer(8, { maxByteLength: 64 }) 后可调用 resize()；不传长度创建的 TypedArray 会随缓冲区长度变化。
  • buffer.transfer()（ES2024）把内容移到新缓冲区，原缓冲区变为已分离，长度为 0。
  • postMessage(data, [buffer]) 把缓冲区转移给 Worker，避免复制。

常见追问

  • 怎样把 TypedArray 转成普通数组？Array.from(view) 或 [...view]。
  • SharedArrayBuffer 有什么前提？页面需要跨源隔离（COOP + COEP），并配合 Atomics 同步访问。
