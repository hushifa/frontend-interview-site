Object.keys、for...in 和 Reflect.ownKeys 会返回哪些属性？

Object.keys 返回对象自身、可枚举的字符串属性键；for...in 还会遍历继承链上的可枚举字符串键；Reflect.ownKeys 包含自身的字符串键与 Symbol 键，不限于可枚举属性。

参考答案

Object.keys 返回对象自身、可枚举的字符串属性键；for...in 还会遍历继承链上的可枚举字符串键；Reflect.ownKeys 包含自身的字符串键与 Symbol 键，不限于可枚举属性。

可以把过程拆成表达式求值、函数调用、任务排队和副作用清理四步。先写一个只包含关键变量的最小例子，再逐步加入闭包、异常或异步操作，能更容易看出结果是在哪一步产生的。

JavaScript
const key = Symbol('内部标记');
const object = Object.create({ inherited: 1 });
object.visible = 2;
Object.defineProperty(object, 'hidden', { value: 3 });
object[key] = 4;
console.log(Object.keys(object).join(',')); // 输出：visible
console.log(Reflect.ownKeys(object).length); // 输出：3
console.log(Object.hasOwn(object, 'inherited')); // 输出：false

遍历输入对象前应先明确需要的是记录字段还是包含继承的属性集合，避免把原型属性误当作用户数据。属性描述符、Symbol 和属性顺序都有规则，序列化或复制操作不能被当作完整保留对象语义的通用方案。

如果几个写法都能得到同样输出，还要比较可读性、执行时机、内存占用和取消方式。涉及 Promise、事件或资源时，完成结果和清理结果要分别验证。

在实际项目中，搜索框、定时器、事件监听和请求经常同时存在。先写出每一步的触发顺序，再决定在哪里更新状态、在哪里清理资源，能避免“结果看起来对，但偶尔重复、过期或无法取消”的问题。
