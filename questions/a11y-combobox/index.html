可访问的 Combobox 需要哪些键盘和 ARIA 行为？

可编辑 Combobox 就是能边打字边从候选里选的输入框，由带 role="combobox" 的输入框加一个 listbox 弹层组成；焦点始终留在输入框，用 aria-activedescendant 指示当前候选，方向键浏览、Enter 确认、Esc 关闭。能用原生 select 或 datalist 时优先用原生。

参考答案

简答

Combobox 就是城市选择框那种控件：可以打字过滤，也可以从弹出的候选里选。如果只是从固定选项里挑一个，用原生 <select> 就够了，不用自己写。

自己写时，输入框要设置 role="combobox"、aria-expanded、aria-controls（指向列表）和 aria-autocomplete="list"；列表是 role="listbox"，每一项是 role="option"。焦点一直留在输入框里，用 aria-activedescendant 指向当前高亮的选项 ID，这样用户能一边浏览候选一边继续打字。

键盘上，↓ 打开列表，↑ 和 ↓ 在候选之间移动，Enter 确认，Esc 关闭，再按一次可以清空。Tab 直接离开，不要把每个选项都放进 Tab 顺序。

最容易写错的是状态。输入的文字、高亮的候选、最终提交的值是三个不同的状态；异步结果返回时，还要丢掉过期的请求。

结构怎么写

下面是一个列表展开、当前高亮“北京”的城市选择框。

HTML
<label for="city">城市</label>
<input
  id="city"
  role="combobox"
  aria-expanded="true"
  aria-controls="city-list"
  aria-autocomplete="list"
  aria-activedescendant="city-bj"
  autocomplete="off"
>
<ul id="city-list" role="listbox" aria-label="城市">
  <li id="city-bj" role="option" aria-selected="true">北京</li>
  <li id="city-sh" role="option" aria-selected="false">上海</li>
</ul>
<p role="status" class="visually-hidden">2 个结果</p>

焦点明明在输入框上，读屏怎么知道当前高亮的是北京？靠的就是 aria-activedescendant。它像一根指针，告诉辅助技术“现在活动的是 city-bj 这一项”，读屏就会读出“北京”，而键盘焦点不用离开输入框。

autocomplete="off" 关掉浏览器自带的历史提示，免得和自己的列表打架。最后那个 role="status" 用来播报结果数量。

列表关闭时要真正隐藏（hidden），并移除 aria-activedescendant。高亮的那一项被过滤掉以后，也要清掉它，不能指向一个不存在的节点。

为什么要分三种状态

假设用户之前选了“上海”，现在输入“北”，再按 ↓ 高亮了“北京”。这时有三个值：输入文本是“北”，用来过滤；活动候选是北京，只是正在浏览；已选值仍然是上海，要等用户按 Enter 或点击，才变成北京。

如果只用一个字符串存这些，问题就来了。按方向键时会把用户输入的“北”覆盖掉；按 Esc 想撤销，也恢复不回去；慢请求返回的旧候选，还可能被当成用户的选择。

容易出错的细节

中文输入法在组合拼音时，按 Enter 是确认拼音，不是选候选。所以要判断 event.isComposing，组合过程中不要提交候选。

左右键、Home、End 不要拦截，它们在输入框里是用来移动光标的。

输入框一失焦就关闭列表，会出一个问题：用户用鼠标点选项时，输入框先失焦，列表先关了，选项的 click 来不及触发。可以在选项上监听 pointerdown 并调用 preventDefault()，让焦点留在输入框里。

结果数量变化时，用 role="status" 的区域简短播报。“加载中”“无结果”只是提示，不要做成可以选的 option。候选文字用 textContent 插入，接口返回的内容不要当 HTML 处理。

和 datalist 有什么区别

<datalist> 也能提供原生的建议列表，但样式没法定制，不同浏览器的过滤方式和读屏表现也不一致。只有需要高亮匹配、分组、异步加载时，才值得自己实现，或者用经过测试的组件库。

常见追问

列表很长、要虚拟滚动怎么办？

aria-activedescendant 指向的节点必须在 DOM 里，所以滚动时不能把当前活动项卸载掉。另外给选项加上 aria-setsize 和 aria-posinset，告诉读屏一共有多少项、当前是第几项。
