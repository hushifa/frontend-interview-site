React Server Components 和 SSR 是同一件事吗？

不是。SSR 把组件树渲染成 HTML，客户端组件也参与 SSR，之后还要 hydration。Server Components 只在服务端或构建时运行，可以直接访问数据库，代码不会发到浏览器，输出的是序列化的组件结果。两者可以配合使用。

参考答案

简答

  • SSR 解决"首屏 HTML 怎样在服务端生成"：组件在服务端执行一次生成 HTML，客户端下载同样的组件代码再 hydration。
  • Server Components 解决"哪些组件只在服务端运行"：它们可以是 async 函数、直接查询数据库，代码和依赖不进入客户端包，也不会 hydration。
  • 'use client' 标记客户端边界：该文件及其导入的模块进入客户端包，可以使用 state、Effect 和浏览器 API。
  • Server Component 可以渲染 Client Component，传给它的 props 必须可序列化；Client Component 不能导入 Server Component，但可以通过 children 接收已经渲染好的 Server Component。
  • 'use server' 标记的是 Server Function（客户端可调用的服务端函数），不是 Server Component；Server Component 不需要任何指令。

示例

JSX
// app/article/[id]/page.jsx —— Server Component
import { db } from '@/lib/db';
import { marked } from 'marked'; // 只在服务端使用，不进入客户端包
import BookmarkButton from './BookmarkButton';

export default async function ArticlePage({ params }) {
  const { id } = await params;
  const article = await db.article.findUnique({ where: { id } });
  return (
    <article>
      <h1>{article.title}</h1>
      <div dangerouslySetInnerHTML={{ __html: marked(article.body) }} />
      <BookmarkButton articleId={article.id} />
    </article>
  );
}
JSX
// BookmarkButton.jsx —— Client Component
'use client';

import { useState } from 'react';

export default function BookmarkButton({ articleId }) {
  const [saved, setSaved] = useState(false);
  return <button onClick={() => setSaved(!saved)}>{saved ? '已收藏' : '收藏'}</button>;
}

浏览器只下载 BookmarkButton 的代码；marked 和数据库客户端都留在服务端。（示例中正文若来自用户输入，渲染为 HTML 前必须先做清洗。）

一次请求中发生了什么

  1. 服务端运行 Server Components，生成 RSC payload：一种描述组件树的序列化格式，其中 Client Component 的位置只是一个引用和它的 props。
  2. 框架再用 SSR 把这棵树（含 Client Components）渲染成 HTML，与 RSC payload 一起发送。
  3. 浏览器显示 HTML，下载 Client Component 代码并 hydration。
  4. 之后的客户端导航只请求新的 RSC payload，不需要整页 HTML。

组合方式

JSX
// Client Component 通过 children 接收服务端内容
'use client';
export function Tabs({ children }) {
  const [tab, setTab] = useState(0);
  return <div>{/* 切换逻辑 */}{children}</div>;
}
JSX
// Server Component 中
<Tabs>
  <ServerRenderedList />
</Tabs>

ServerRenderedList 在服务端渲染好后作为 props 传入，Tabs 不需要知道它的实现。

注意点

  • 传给 Client Component 的 props 会发送到浏览器，不要直接传整个数据库记录，只传需要的字段。
  • 只能在服务端使用的模块，可以导入 server-only 包，被客户端误导入时构建会报错。
  • Server Components 需要框架支持打包和路由，例如 Next.js App Router，单独使用 React 无法直接启用。

常见追问

  • Server Components 能用 Hook 吗？不能用 useState、useEffect 这类有状态或副作用的 Hook。
  • 和 Server Functions 的区别，见《React Server Functions/Actions 的边界是什么？》。
