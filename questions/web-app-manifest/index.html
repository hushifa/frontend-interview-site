Web App Manifest 主要描述哪些 PWA 信息？

Web App Manifest 是一个 JSON 文件，声明应用名称、图标、启动地址、显示模式和主题色，浏览器据此提供安装和启动体验；离线能力由 Service Worker 提供，manifest 本身不负责。

参考答案

简答

  • 通过 <link rel="manifest" href="/manifest.webmanifest"> 引用，内容是 JSON。
  • 常用字段：name、short_name、icons、start_url、scope、display、theme_color、background_color、id。
  • display: standalone 让安装后的应用在独立窗口中运行，没有浏览器地址栏。
  • 图标至少提供 192×192 和 512×512 两种尺寸，purpose: "maskable" 的图标会被系统裁成各种形状。
  • manifest 只描述安装和启动方式，离线访问、推送等能力需要 Service Worker。

示例

json
{
  "id": "/",
  "name": "前端面试题库",
  "short_name": "题库",
  "start_url": "/?source=pwa",
  "scope": "/",
  "display": "standalone",
  "theme_color": "#1f6feb",
  "background_color": "#ffffff",
  "icons": [
    { "src": "/icons/192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "/icons/512.png", "sizes": "512x512", "type": "image/png" },
    { "src": "/icons/maskable-512.png", "sizes": "512x512", "type": "image/png", "purpose": "maskable" }
  ]
}

字段说明

  • id：应用的唯一标识。不设置时浏览器用 start_url 计算，以后修改 start_url 会被当成另一个应用，所以建议显式设置并保持不变。
  • scope：应用的导航范围，范围外的链接会在浏览器中打开。
  • start_url：可以带参数用于统计从桌面图标启动的次数。
  • display：fullscreen、standalone、minimal-ui、browser；display_override 可以按优先级列出更多模式。
  • shortcuts：长按图标出现的快捷入口。

各平台差异

  • Chromium 浏览器满足安装条件后会显示安装入口，并触发 beforeinstallprompt 事件，页面可以自定义安装按钮。
  • iOS Safari 不支持 beforeinstallprompt，用户只能通过分享菜单中的"添加到主屏幕"安装。
  • iOS 还会读取 <meta name="apple-mobile-web-app-title"> 等专用标签和 apple-touch-icon 图标。

常见追问

  • 修改 manifest 后已安装的应用会更新吗：浏览器会定期检查，更新的时机和范围由浏览器决定，名称和图标的更新可能需要用户确认。
