Web App Manifest 主要描述哪些 PWA 信息？

了解 manifest 的名称、图标、启动方式和显示模式，区分安装元数据与离线能力。

参考答案

Web App Manifest 用 JSON 描述应用名称、短名称、图标、主题色、启动 URL、显示模式和方向等安装相关信息。它不会自动让网站变成离线应用，也不会替代 Service Worker。

图标要提供适合不同尺寸和掩模的资源，启动 URL 和作用域要与部署路径一致。仓库子路径、CNAME、自定义域名和相对资源路径变化时，manifest 也要一起检查。

安装提示和可安装性由浏览器、平台和当前站点条件共同决定。应保证普通浏览器仍能使用完整网页，不把安装状态当成业务权限。

使用边界

使用 Web API 前要确认安全上下文、权限、用户手势、浏览器支持和可用的降级路径。请求、监听器、流、对象 URL 或设备句柄都应有明确的结束和清理逻辑，不能把“调用成功”当成整个任务已经完成。

接口返回的异常、取消和用户拒绝应分别处理。浏览器端的取消只代表客户端停止等待，涉及写入、上传或设备操作时还要查询实际状态。
