标准盒模型和 border-box 有什么区别？

明确 width、padding 和 border 如何参与最终尺寸计算。

参考答案

content-box 下，声明的 width 指内容区宽度，边框盒宽度还要加上左右 padding 与 border。border-box 下，声明的宽度包含内容、padding 和 border。margin 不属于这两种宽度。

CSS
*, *::before, *::after {
  box-sizing: border-box;
}

实际布局还会受到 min-width、max-width、Flex 收缩和内容最小尺寸等约束。排查“宽度不对”时，应检查最终计算样式，而不只看 width。

复习提示

回答时先区分 HTML 语义、CSS 规则和浏览器默认行为，再说明结构、样式与交互之间的影响。涉及兼容性时给出目标浏览器范围，不把某个浏览器的现象当成规范结论。可先用一个最小示例验证“盒模型、box-sizing”，再补充空值、异常和兼容性边界。
