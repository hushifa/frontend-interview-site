Proxy 与 Reflect 能实现什么，存在哪些限制？

Proxy 用 get、set、has、deleteProperty 等陷阱拦截对象的基本操作；Reflect 提供每个陷阱对应的默认行为，转发时传入 receiver 才能让 getter 中的 this 指向代理。Proxy 必须遵守不变式，拦截不了私有字段，Map、Date 等依赖内部槽的对象直接经代理调用方法会抛错。

参考答案

简答

  • new Proxy(target, handler) 返回一个新对象，对它的属性读写、in、delete、枚举、调用都会进入 handler 中对应的陷阱。
  • Reflect.get、Reflect.set 等与陷阱一一对应，陷阱中用它们转发默认行为，并传入 receiver。
  • 陷阱结果必须满足不变式，例如不可配置且不可写的属性，get 必须返回真实值，否则抛 TypeError。
  • 代理和目标是不同对象，proxy !== target；直接修改目标不会经过陷阱。
  • 私有字段 #x 和内部槽（Map、Set、Date）不经过陷阱，需要把方法绑定到原对象。

记录读取与校验写入

JavaScript
const reads = [];
const target = {
  price: 10,
  get total() {
    return this.price * 2;
  },
};

const product = new Proxy(target, {
  get(object, key, receiver) {
    reads.push(String(key));
    return Reflect.get(object, key, receiver);
  },
  set(object, key, value, receiver) {
    if (key === 'price' && (!Number.isFinite(value) || value < 0)) {
      throw new RangeError('价格必须是非负有限数值');
    }
    return Reflect.set(object, key, value, receiver);
  },
});

console.log(product.total); // 20
console.log(reads.join(',')); // total,price
product.price = 12;
console.log(target.price); // 12
console.log(product === target); // false

Reflect.get(object, key, receiver) 让 total 的 getter 以代理为 this 执行，所以内部读取 this.price 也被记录。写成 return object[key] 时 getter 的 this 是原对象，price 的读取不会被追踪。Vue 3 的响应式依赖这一点。

不变式

JavaScript
const locked = {};
Object.defineProperty(locked, 'id', { value: 7, writable: false, configurable: false });

const proxy = new Proxy(locked, { get: () => 8 });
try {
  console.log(proxy.id);
} catch (error) {
  console.log(error.name); // TypeError
}

类似规则：ownKeys 必须包含所有不可配置的键；目标不可扩展时，ownKeys 必须恰好是目标的键。

内部槽

JavaScript
const map = new Map();
const values = new Proxy(map, {
  get(target, key) {
    const value = Reflect.get(target, key);
    return typeof value === 'function' ? value.bind(target) : value;
  },
});
values.set('a', 1); // 不绑定时抛 TypeError

Map.prototype.set 要求 this 有 Map 的内部槽，代理没有。Vue 对集合类型使用专门的处理器。

实现响应式还需要什么

  • 嵌套对象在 get 时惰性包装，并用 WeakMap 缓存原对象到代理的映射，保证同一对象始终得到同一个代理。
  • 数组的 push 会触发 length 的读写，需要避免重复触发。
  • 依赖收集、批量调度、清理旧依赖都是代理之外的工作。

常见追问

  • Object.defineProperty 实现的响应式有什么不足？只能劫持已存在的属性，新增属性、删除属性和数组索引需要额外 API，Vue 2 因此提供了 Vue.set。
  • Proxy.revocable 做什么？返回 { proxy, revoke }，撤销后对代理的任何操作都抛 TypeError，用于收回授予第三方的访问权。
