Playwright 视觉回归测试怎样减少无意义差异？

通过稳定环境、截图范围和差异阈值捕获视觉回归，同时避免把字体和动画波动当成真实缺陷。

参考答案

视觉回归测试的核心不是“每个像素都不能变”，而是捕获用户能感知的布局、颜色、间距和状态变化。它把当前截图和基线截图比较，所以第一步不是调阈值，而是固定浏览器版本、视口、字体、时区、动画、数据和资源加载时机。

测试对象要足够小，失败时才容易判断原因。比如一个日期选择器可以分别覆盖关闭、打开、选中和错误状态，而不是只截整页；动态时间、随机 ID、广告和网络图片要替换成稳定内容，必要时使用 mask 排除不可控区域。

Playwright 的截图比较可以设置差异阈值，但阈值不是越大越好。抗锯齿和字体渲染带来的少量差异可以容忍，按钮位置错一行、文字被截断或弹层跑出视口则不应该被阈值掩盖。失败截图、基线和运行环境应作为代码审查的一部分保存。

基线更新不能在 CI 失败时全部点击批准。先确认变更来自预期的 UI 修改，再更新对应基线；如果同一页面经常因为环境变化产生噪声，应先稳定测试环境或缩小截图范围。视觉测试发现的是表现差异，交互和业务逻辑仍需要其他测试覆盖。
