如何合并时间区间？相邻区间算不算重叠？

以视频已观看片段为例，按左闭右开区间合并重叠片段：先按起点排序，再依次与结果中最后一个区间比较。首尾相接的区间是否合并取决于业务语义，统计覆盖范围时应合并，判断预约冲突时不算冲突。

参考答案

简答

  • 先按起点升序排序，然后遍历：当前区间的起点不超过结果中最后一个区间的终点，就延长最后一个区间，否则追加为新区间。
  • 采用左闭右开区间 [start, end)：[0, 10) 与 [10, 20) 首尾相接但没有公共点。下面的实现默认合并相接区间（start <= last[1]），可以通过选项改为只合并真正重叠的区间（start < last[1]）。
  • 延长时取 Math.max(last[1], end)，处理 [0, 30) 包含 [5, 10) 这类嵌套区间。
  • 时间复杂度 O(n log n)，主要来自排序；先复制再排序，不修改调用方传入的数组。
  • 判断两个预约是否冲突时用严格的 <，首尾相接的预约不算冲突。

实现

JavaScript
function mergeIntervals(intervals, { mergeTouching = true } = {}) {
  const sorted = intervals
    .map(([start, end]) => {
      if (!Number.isFinite(start) || !Number.isFinite(end) || start > end) {
        throw new RangeError(`非法区间：[${start}, ${end})`);
      }
      return [start, end];
    })
    // 空区间不覆盖任何时间，直接丢弃。
    .filter(([start, end]) => start < end)
    .sort((a, b) => a[0] - b[0]);

  const result = [];
  for (const [start, end] of sorted) {
    const last = result.at(-1);
    const overlaps = last && (mergeTouching ? start <= last[1] : start < last[1]);
    if (overlaps) last[1] = Math.max(last[1], end);
    else result.push([start, end]);
  }
  return result;
}

console.log(mergeIntervals([[20, 25], [0, 10], [8, 15]])); // [[0, 15], [20, 25]]
console.log(mergeIntervals([[0, 10], [10, 20]])); // [[0, 20]]
console.log(mergeIntervals([[0, 10], [10, 20]], { mergeTouching: false })); // [[0, 10], [10, 20]]
console.log(mergeIntervals([[0, 30], [5, 10]])); // [[0, 30]]

map 先复制每个区间，后续修改 last[1] 不会影响输入数组。实测用 2000 组随机区间对比"合并前后覆盖的时间点集合相同"以及"结果区间互不相接"，均通过。

两种语义

场景相接区间 [0,10) 和 [10,20)
统计观看进度应合并为 [0, 20)，用户连续看完了 20 秒
会议室预约不冲突，前一场结束时下一场开始

预约冲突判断不需要合并，排序后检查相邻两项即可：

JavaScript
function hasConflict(bookings) {
  const sorted = [...bookings].sort((a, b) => a[0] - b[0]);
  for (let i = 1; i < sorted.length; i++) {
    if (sorted[i][0] < sorted[i - 1][1]) return true;
  }
  return false;
}

hasConflict([[9, 10], [10, 11]]); // false
hasConflict([[9, 11], [10, 12]]); // true

常见追问

  • 区间是秒级浮点数怎么办？ 浮点误差会让本应相接的区间出现 10.000000001 这样的缝隙。可以先换算成整数毫秒再合并。
  • 新增一个区间时要整体重算吗？ 结果已经有序，可以用二分查找定位插入位置，只合并受影响的相邻区间，见《二分查找怎样定位时间轴边界？为什么重复值和空数组容易写错？》。
  • 观看进度怎么算百分比？ 合并后累加每个区间的长度，再除以视频总时长。
