Canvas 和 SVG 怎样选择？

SVG 画出来的每个图形都是 DOM 元素，可以用 CSS 和事件直接操作；Canvas 2D 画完只剩像素，图形对象和命中检测由应用管理。对象数量、更新频率、交互、清晰度和无障碍共同决定选型。

参考答案

简答

SVG 画的每个圆、每条路径都是一个 DOM 元素，可以改属性、加 CSS、绑事件，浏览器会负责重绘和判断点中了谁。这种“图形一直保留着”的方式叫保留模式。

Canvas 2D 正好相反，画完就只剩像素，这叫即时模式。想拖动某个图形，应用得自己记住坐标、自己算点中了没有、自己重画。

所以图标、流程图、几百到几千个元素的交互图表适合 SVG；上万个点、粒子动画、绘图板、像素处理适合 Canvas。

有两点要注意。Canvas 要按 devicePixelRatio 设置内部尺寸才清晰，宽高各翻一倍，像素数就是四倍，内存也跟着涨。另外两者都不会自动无障碍：SVG 要加标题和角色，Canvas 要另外提供文字或 HTML 替代。

同一个圆，两种画法

先用 SVG 画：

HTML
<svg viewBox="0 0 200 100" role="img" aria-labelledby="t">
  <title id="t">蓝色圆形</title>
  <circle cx="50" cy="50" r="20" fill="royalblue" />
</svg>

再用 Canvas 画：

JavaScript
const ctx = document.querySelector('canvas').getContext('2d');
ctx.fillStyle = 'royalblue';
ctx.beginPath();
ctx.arc(50, 50, 20, 0, Math.PI * 2);
ctx.fill();
// 页面里只有一个 canvas 元素，querySelector 找不到这个圆

看起来画出来一样。可是 SVG 版里有个真实的 <circle> 元素，你可以给它加 click 监听，或者用 CSS 改它的颜色。Canvas 版画完，页面里只有一个 canvas，那个圆已经变成了像素，没有任何东西可以选中。

两者具体差在哪里

SVGCanvas 2D
图形对象DOM 元素应用自己维护
交互直接绑定事件自己做命中检测
缩放矢量，任意放大都清晰位图，需要按缩放重绘
大量对象DOM 和样式成本高只受绘制成本影响
像素访问不支持getImageData
导出序列化 XMLtoBlob、toDataURL

为什么对象多了 SVG 会慢？因为每个图形都是 DOM 元素，浏览器要为它们算样式、维护节点。Canvas 不管画了多少东西，都只有一个元素，成本只在绘制本身。

不过两者之间没有固定的数量分界线，要用真实数据在目标设备上测。

为什么 Canvas 在高清屏上会模糊

高清屏上，一个 CSS 像素对应好几个物理像素，这个比例就是 devicePixelRatio。canvas 的位图如果只按 CSS 尺寸设置，就会被拉伸显示，看起来发虚。所以要把位图尺寸乘上这个比例：

JavaScript
function setupCanvas(canvas, cssWidth, cssHeight) {
  const dpr = window.devicePixelRatio || 1;
  canvas.style.width = `${cssWidth}px`;
  canvas.style.height = `${cssHeight}px`;
  canvas.width = Math.round(cssWidth * dpr);
  canvas.height = Math.round(cssHeight * dpr);
  const ctx = canvas.getContext('2d');
  ctx.scale(dpr, dpr); // 之后按 CSS 像素坐标绘制
  return ctx;
}

style 上的宽高决定它在页面上占多大，canvas.width、canvas.height 决定位图有多少像素。最后 scale(dpr, dpr)，之后的绘图代码就还能按 CSS 像素来写。

能不能混着用

可以，而且很常见。复杂编辑器常用 Canvas 画画布内容，用 HTML 做工具栏、输入框和属性面板，用 SVG 画选择框和控制点。

图表也可以用 Canvas 画大量数据点，再提供一个 HTML 数据表作为无障碍替代，见《前端图表如何同时满足无障碍和高性能？》。

安全上要注意什么

用户上传的 SVG 里可以带脚本和外部引用。所以不要直接把它内联插进页面，用 <img> 引用，或者先净化。

Canvas 画了没有 CORS 授权的跨源图片以后，会被“污染”。之后调用 getImageData 和 toBlob 会抛 SecurityError。

常见追问

Canvas 卡了怎么办？

可以分层，静态背景画一层，动态内容画另一层；只重画变化的区域；或者把绘制移到 Worker 里的 OffscreenCanvas，不占主线程。

WebGL 也是画在 canvas 上，它算哪一边？

它是 canvas 的另一种上下文，绘制模型和 Canvas 2D 完全不同，适合更大规模的绘制，见《什么场景值得用 WebGL？GPU 加速有哪些成本？》。
