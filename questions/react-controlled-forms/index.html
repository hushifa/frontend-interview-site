受控组件与非受控组件应该如何选择？

受控组件的值存在 React state 里，每敲一个字都经过 onChange；非受控组件的值留在浏览器的输入框里，提交时再读。要边输边校验或联动就用受控，只在提交时要值就用非受控。

参考答案

简答

区别在于输入框的值由谁保管。受控组件是 React 保管：你传 value 和 onChange，输入框显示的永远是 state。非受控组件是浏览器保管：你只用 defaultValue 给个初值，之后通过 ref 或提交时的 FormData 去读。

受控的好处是每次输入都经过你的代码，可以实时格式化、校验，或者让别的按钮跟着变。非受控的好处是简单，不用给每个字段建 state，React 19 的 <form action> 直接把 FormData 交给你。

所以要实时校验、联动就选受控；只在提交时要值、或者表单很大，就选非受控。

有几个坑：传了 value 却不写 onChange，输入框会变成只读；同一个输入框不要在受控和非受控之间切换，初值要用 '' 而不是 undefined；<input type="file"> 只能是非受控的，因为出于安全原因脚本不能设置它的值。

受控：边输入边处理

下面是一个手机号输入框，输入时过滤掉非数字，按钮在凑够 11 位数字时才可点。

JSX
function PhoneInput() {
  const [phone, setPhone] = useState('');
  const digits = phone.replace(/\D/g, '');

  return (
    <>
      <input
        value={phone}
        inputMode="numeric"
        onChange={(e) => setPhone(e.target.value.replace(/[^\d ]/g, ''))}
      />
      <button disabled={digits.length !== 11}>发送验证码</button>
    </>
  );
}

用户敲的每个字都先经过 onChange，过滤后写进 phone，输入框再显示 phone。按钮的状态也是从同一个 phone 算出来的，所以输入框和按钮永远一致，不会出现“框里已经 11 位了按钮还是灰的”。

为什么只写 value 输入框就打不了字

受控的意思是“输入框显示什么，完全由 value 决定”。你传了 value 却没有 onChange，用户敲字时 state 不会变，React 就继续显示原来的值，看起来就是只读的。React 会在控制台给出警告。

切换问题也是同样的道理。value 是 undefined 时 React 认为它是非受控的，后来变成字符串又成了受控的，React 会警告。所以初值写 ''，从一开始就是受控的。

非受控：提交时一次读出来

只在提交时需要值的表单，没必要给每个字段建 state：

JSX
function FeedbackForm() {
  async function submit(formData) {
    await fetch('/api/feedback', { method: 'POST', body: formData });
  }

  return (
    <form action={submit}>
      <input name="title" defaultValue="" required />
      <textarea name="content" />
      <button>提交</button>
    </form>
  );
}

React 19 的 <form action> 会把整个表单的 FormData 直接传给函数，按 name 取值即可。Action 成功后，React 还会自动重置这些非受控字段。

怎么选

一般看你什么时候需要这个值。输入时就要用来校验、格式化或联动别的字段，选受控。只在提交时需要，选非受控加 FormData。字段很多、对性能敏感的大表单，以非受控为主，或者用 React Hook Form 这类库。要接入只操作 DOM 的第三方输入组件，用非受控加 ref。

中文输入法会出什么问题

用拼音打字时，字还没选定，输入框里是拼音字母，这个阶段叫组合输入。受控输入在组合过程中也会触发 onChange。

如果你在 onChange 里做“去掉非数字”“截断长度”这类改写，就可能把还没打完的拼音改掉，打断输入。需要时可以监听 compositionstart 和 compositionend，等组合结束再处理。

常见追问

怎么重置非受控表单？

调用表单 DOM 的 form.reset()，或者给表单换一个 key，让 React 把它卸载后重新挂载。

改了 defaultValue，输入框为什么没变？

defaultValue 只在第一次挂载时生效，之后值就由浏览器的输入框自己保管了。想让它变，要么改成受控，要么换 key 让它重新挂载。
