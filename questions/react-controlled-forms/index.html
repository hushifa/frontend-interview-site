受控组件与非受控组件应该如何选择？

受控组件的值由 React state 提供，每次输入都经过 onChange 更新；非受控组件的值保存在 DOM 中，用 defaultValue 设置初值，在提交时读取。需要实时校验或联动时用受控，简单表单或配合 form action 时用非受控。

参考答案

简答

  • 受控：传 value（或 checked）和 onChange，React state 是唯一数据源，输入框显示的永远是 state。
  • 非受控：传 defaultValue（或 defaultChecked），浏览器维护当前值，通过 ref 或提交时的 FormData 读取。
  • 传了 value 却没有 onChange，输入框会变成只读，React 会给出警告。
  • 同一个输入框不要在受控和非受控之间切换，例如 value 从 undefined 变成字符串；初值用 '' 而不是 undefined。
  • <input type="file"> 只能是非受控的，因为出于安全原因脚本不能设置它的值。

受控：实时格式化与联动

JSX
function PhoneInput() {
  const [phone, setPhone] = useState('');
  const digits = phone.replace(/\D/g, '');

  return (
    <>
      <input
        value={phone}
        inputMode="numeric"
        onChange={(e) => setPhone(e.target.value.replace(/[^\d ]/g, ''))}
      />
      <button disabled={digits.length !== 11}>发送验证码</button>
    </>
  );
}

每次输入都经过 onChange 过滤，按钮状态由同一个 state 推导，不会和输入框不一致。

非受控：提交时一次读取

JSX
function FeedbackForm() {
  async function submit(formData) {
    await fetch('/api/feedback', { method: 'POST', body: formData });
  }

  return (
    <form action={submit}>
      <input name="title" defaultValue="" required />
      <textarea name="content" />
      <button>提交</button>
    </form>
  );
}

React 19 的 <form action> 直接把 FormData 交给函数，字段不需要各自的 state；Action 成功后 React 会重置非受控字段。

选择依据

需求推荐
输入时实时校验、格式化、联动其他字段受控
只在提交时需要值非受控 + FormData
大型表单、性能敏感非受控为主，或 React Hook Form 这类库
接入只操作 DOM 的第三方输入组件非受控 + ref

中文输入法

受控输入在拼音组合过程中也会触发 onChange。如果在 onChange 里做"去掉非数字""截断长度"这类改写，可能打断组合输入。需要时监听 compositionstart / compositionend，组合结束后再处理。

常见追问

  • 怎么重置非受控表单？调用 form.reset()，或者给表单换 key 让它重新挂载。
  • defaultValue 改了为什么输入框不变？它只在首次挂载时生效，之后的值由 DOM 维护。
