异步 Clipboard API 为什么会出现权限或用户激活错误？

异步剪贴板 API 需要安全上下文，读取和写入还可能受到权限、用户激活和浏览器策略限制。不同浏览器的具体要求并不完全一致，不能用某个浏览器的一次成功推断所有环境。

参考答案

异步剪贴板 API 需要安全上下文，读取和写入还可能受到权限、用户激活和浏览器策略限制。不同浏览器的具体要求并不完全一致，不能用某个浏览器的一次成功推断所有环境。

写纯文本可使用 writeText，复杂内容则使用 ClipboardItem 等机制。复制按钮应由明确用户操作触发，并等待 Promise 结果后再提示成功，避免接口拒绝时仍显示“已复制”。

剪贴板可能包含来自其他应用的敏感内容，不应在无明确需求时后台读取。粘贴的 HTML 也不能直接视为可信内容。兼容策略应区分权限失败、不支持 API 和格式不支持，而不是统一依赖已弃用的 execCommand。

复习提示

回答时说明 API 的输入、生命周期、取消或错误路径，并给出资源清理方式。涉及权限、设备或用户手势时，要把安全上下文、授权结果和降级方案一起说明。建议用一个最小示例验证“Clipboard、安全上下文、用户激活”，再比较正常路径、失败路径和目标运行环境的差异。
