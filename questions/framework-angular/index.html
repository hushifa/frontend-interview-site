Angular Signals 的依赖追踪与 computed 有什么特点？

参考答案

Signal 包装一个值，通过读取函数让框架追踪消费者；可写 signal 提供更新能力，computed 根据其他信号推导只读值。依赖可以随实际执行分支变化，而不是简单固定为所有可能读取的来源。

派生状态优先使用 computed，外部副作用才考虑相应 effect 机制。把派生值反复复制到另一个可写状态，容易产生同步和循环更新问题。

Signal 不是任意对象的自动深度不可变保护。项目仍需明确数据更新方式、组件边界与生命周期。Angular 具体版本的调度、注入上下文和 effect 约束应按官方文档使用，不能直接套用另一个框架的同名概念。
