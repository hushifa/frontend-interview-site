一个可访问的模态对话框需要具备哪些行为？

模态对话框要有名称和 dialog 角色，打开时焦点移入、背景不可操作，Tab 只在对话框内循环，Esc 可关闭，关闭后焦点回到触发元素；原生 dialog 的 showModal() 已提供大部分行为。

参考答案

简答

  • 名称：用 aria-labelledby 指向对话框标题，读屏打开时会读出。
  • 打开时焦点移到对话框内：通常是第一个可操作元素；内容很长时可以是标题或对话框本身（加 tabindex="-1"）；破坏性确认框可以先聚焦“取消”。
  • 背景不可交互、不可被读屏浏览，Tab 不会跑到背景里。
  • Esc 关闭，关闭后焦点回到打开它的按钮；触发按钮已被删除时，移到合理的位置。
  • <dialog> 的 showModal() 自动处理顶层显示、背景惰性、Esc 关闭和焦点恢复，优先使用它。

原生实现

HTML
<button id="open">编辑资料</button>

<dialog id="edit" aria-labelledby="edit-title">
  <h2 id="edit-title">编辑资料</h2>
  <form method="dialog">
    <label>昵称 <input name="nickname" autofocus></label>
    <button value="cancel" formnovalidate>取消</button>
    <button value="save">保存</button>
  </form>
</dialog>
JavaScript
document.querySelector('#open').addEventListener('click', () => {
  document.querySelector('#edit').showModal();
});

autofocus 指定打开时的初始焦点。showModal() 会让对话框以外的内容变为惰性，相当于给背景加了 inert。

自己实现时要补什么

不能使用原生 dialog 时（例如旧组件库），需要：

  • 容器 role="dialog"、aria-modal="true"、aria-labelledby。
  • 打开时给背景容器加 inert，关闭时移除。
  • 监听 Esc 关闭。
  • 记录打开前的 document.activeElement，关闭后调用它的 focus()。
  • 把对话框渲染到 body 下，避免被祖先的 overflow 或层叠上下文影响。

只加 aria-modal="true" 不会阻止背景交互，它只是告诉辅助技术背景不可用，键盘仍能 Tab 到背景，必须配合 inert。

其他细节

  • 点击遮罩关闭可以用 closedby="any"，表单有未保存内容时应先确认。closedby 目前不是 Baseline，要先检测 'closedBy' in HTMLDialogElement.prototype，不支持时监听 click，在 event.target === dialog 时调用 close()。
  • 打开对话框时阻止背景滚动，可以用 html:has(dialog[open]) { overflow: hidden; }。
  • 对话框里有错误提示或异步结果时，用 live region 播报。
  • 不需要阻断背景的提示用 popover 或非模态对话框，不要滥用模态。
