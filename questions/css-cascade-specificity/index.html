层叠、优先级、继承和 !important 谁先决定样式？

层叠按顺序比较来源与重要性、层叠层、优先级、作用域远近和源码顺序；继承只在元素没有任何声明时提供值，不携带父元素选择器的优先级。

参考答案

简答

  • 比较顺序：来源和重要性 → 层叠层 → 优先级 → 作用域远近（@scope）→ 源码顺序。前一步分出胜负就不再往后比。
  • 优先级按 (ID, 类/属性/伪类, 元素/伪元素) 三列逐列比较，十个类也赢不了一个 ID。
  • !important 会反转来源和层的顺序：普通声明里后声明的层胜出，重要声明里先声明的层胜出。
  • 继承只在元素自身没有匹配声明时生效，任何直接命中的声明都比继承值优先。
  • :where() 的优先级为 0，:is()、:not()、:has() 取参数中最高的优先级。

优先级

CSS
#nav a { }        /* 1-0-1 */
.menu .item a { } /* 0-2-1 */
a:hover { }       /* 0-1-1 */
:where(.menu) a { } /* 0-0-1 */

内联 style 属性比任何选择器都优先。通配符 * 和组合符不计入优先级。

层叠层

CSS
@layer reset, components, utilities;

@layer components {
  .button { padding: 8px 16px; }
}

@layer utilities {
  .p-0 { padding: 0; }
}

后声明的 utilities 胜出，与选择器优先级无关。未放进任何层的样式优先于所有层里的普通样式。这让组件库样式可以放在低层，业务覆盖不必提高优先级。

!important 的顺序

普通声明：用户代理 < 用户 < 作者。重要声明：作者 < 用户 < 用户代理。层也一样反转：

CSS
@layer base, theme;

@layer base {
  a { color: red !important; }
}

@layer theme {
  a { color: blue !important; }
}

链接是红色，因为对重要声明来说先声明的 base 层更优先。正在过渡中的属性值优先级最高，动画值高于所有普通声明。

继承

CSS
.card { color: gray; }
p { color: black; }

.card 里的 <p> 是黑色。p 选择器直接命中元素，父元素的 .card 即使优先级更高，传下来的也只是继承值。color、font 等文本属性默认继承，margin、border 等不继承，可以用 inherit 强制继承。

排查方法

在开发者工具的 Styles 面板查看被划掉的声明，以及它是被哪条规则覆盖的。Computed 面板会显示最终值来自哪里。

常见追问

  • 怎样避免优先级越写越高？用层叠层分配顺序，用 :where() 写低优先级的基础样式，避免 ID 选择器和 !important。
