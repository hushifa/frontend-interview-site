层叠、优先级、继承和 !important 谁先决定样式？

最终样式来自一套层叠排序：先考虑来源、重要性与层叠层等，再比较选择器特异性，必要时比较作用域接近程度和出现顺序。仅比较 id、class 和标签数量不足以解释所有结果。

参考答案

最终样式来自一套层叠排序：先考虑来源、重要性与层叠层等，再比较选择器特异性，必要时比较作用域接近程度和出现顺序。仅比较 id、class 和标签数量不足以解释所有结果。

继承发生在属性没有通过层叠获得指定值等情况下，并不是父元素选择器优先级传递给子元素。:where 的特异性为零；:is、:not、:has 的特异性与参数相关，不能统一视为普通伪类权重。

!important 应作为受控例外而不是常规布局工具。排查样式时使用 DevTools 查看被覆盖声明、来源层与继承链，再调整结构，避免不断增加选择器长度导致维护成本上升。

实现检查

实际排查时先看语义结构和布局上下文，再查看计算后的样式、盒模型、层叠来源和绘制结果。把视觉问题拆成结构、尺寸、定位和绘制几步，通常比反复修改一个 CSS 属性更容易定位原因。

交付前还要检查键盘操作、响应式断点、文本放大、打印和减少动画偏好。兼容性结论应以目标浏览器和特性检测为前提，不要把某个浏览器的偶发现象当成通用规则。
