memo、useMemo、useCallback 各自优化什么？

结合测量判断缓存的收益、依赖和维护成本。

参考答案
  • memo 尝试在 props 未变化时跳过父组件引起的重复渲染；组件自己的状态和所订阅的 context 仍可触发更新。
  • useMemo 缓存计算结果。
  • useCallback 缓存函数引用，常用于配合 memo 子组件或稳定依赖。

它们属于性能优化，不能成为业务正确性的前提。每次新建的对象或函数会破坏基于引用相等的比较。先通过 React DevTools Profiler 定位瓶颈，再判断缓存是否值得。

启用 React Compiler 的项目可能由编译器自动处理许多记忆化场景，但仍应按项目实际配置和测量结果判断。
