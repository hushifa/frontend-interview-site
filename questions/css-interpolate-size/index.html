interpolate-size 和 calc-size() 怎样实现 auto 高度动画？

interpolate-size: allow-keywords 允许在长度与 auto、max-content 等固有尺寸之间过渡；它仍是实验特性，不支持的浏览器应直接切换状态。

参考答案

简答

  • 默认值 numeric-only 下，height: 0 到 height: auto 不会过渡；在 :root 设置 interpolate-size: allow-keywords 后可以过渡。
  • 两端必须有一端是长度或百分比，两个固有尺寸之间（如 auto 到 max-content）仍然不能插值。
  • 该属性可继承，所以通常在 :root 或组件容器上设置一次。
  • calc-size() 也能实现，适合需要在固有尺寸上再做计算的场景；只做动画时 MDN 推荐用 interpolate-size。
  • 截至目前它是实验特性，属于有限可用，不支持时展开和收起应照常工作，只是没有动画。

折叠面板

CSS
:root {
  interpolate-size: allow-keywords;
}

.panel {
  height: 0;
  overflow: hidden;
  transition: height 200ms ease;
}

.panel.open {
  height: auto;
}

@media (prefers-reduced-motion: reduce) {
  .panel {
    transition: none;
  }
}

展开和收起的状态写在 @supports 之外，不支持的浏览器里 .open 仍会把高度设为 auto，功能完整。overflow: hidden 在动画期间和收起后都保持，避免过渡中途出现滚动条。

details 元素

<details> 的内容由 ::details-content 伪元素承载。只对它做过渡，<summary> 不会被裁掉：

CSS
details::details-content {
  height: 0;
  overflow: hidden;
  transition:
    height 200ms ease,
    content-visibility 200ms allow-discrete;
}

details[open]::details-content {
  height: auto;
}

收起时浏览器会把内容切到 content-visibility: hidden，加上 allow-discrete 才能等高度动画结束后再隐藏。::details-content 的支持范围比 interpolate-size 更窄，要单独检查。

calc-size()

CSS
.panel.open {
  height: calc-size(auto, size + 16px);
}

size 代表 auto 计算出的高度。需要“内容高度再加一点”这类计算时才用它。

以前的做法

  • 过渡 max-height 到一个足够大的值：时间曲线会失真，内容越短动画越像有延迟。
  • 用 JavaScript 读取 scrollHeight 写成像素值，结束后再改回 auto：可靠但要处理内容变化和中途反向。
  • 用 grid-template-rows: 0fr 到 1fr：Grid 轨道可以插值，兼容性好，至今仍是常用的回退方案。

常见追问

  • 为什么不默认允许？现有样式表假设固有尺寸不能动画，默认开启会改变已有页面的行为。
