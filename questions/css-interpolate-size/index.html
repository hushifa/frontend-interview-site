interpolate-size 和 calc-size() 怎样实现 auto 高度动画？

以前 height 从 0 过渡到 auto 是没有动画的，直接跳。设置 interpolate-size: allow-keywords 后就能过渡了。它还是实验特性，不支持的浏览器照样能展开收起，只是没动画。

参考答案

简答

做折叠面板时，height: 0 切到 height: auto，加了 transition 也不会有动画，直接跳过去。因为 interpolate-size 的默认值是 numeric-only，只允许在数字之间算中间值。在 :root 上写 interpolate-size: allow-keywords，auto 这类关键字就能参与过渡了。

它有个限制：两端至少有一端是长度或百分比。auto 到 max-content 这种两端都是关键字的，还是不能过渡。这个属性会继承，一般在 :root 或组件容器上写一次就行。

另一个办法是 calc-size()，适合要在内容高度上再做计算的场景。只做动画的话，MDN 推荐用 interpolate-size。

要注意它目前还是实验特性，支持有限。所以写法上要保证不支持时展开和收起照样能用，只是没有动画。

折叠面板

CSS
@supports (interpolate-size: allow-keywords) {
  :root {
    interpolate-size: allow-keywords;
  }
}

.panel {
  height: 0;
  overflow: hidden;
  transition: height 200ms ease;
}

.panel.open {
  height: auto;
}

@media (prefers-reduced-motion: reduce) {
  .panel {
    transition: none;
  }
}

注意展开和收起的样式写在 @supports 外面。所以不支持的浏览器里，.open 照样把高度设成 auto，功能完整，只是没有动画。

overflow: hidden 在动画过程中和收起以后都保留着。不然高度变到一半时，内容比盒子高，会冒出滚动条。

details 元素怎么做

<details> 里展开的内容由一个伪元素 ::details-content 承载。只对它做过渡，<summary> 那一行就不会被裁掉：

CSS
details::details-content {
  height: 0;
  overflow: hidden;
  transition:
    height 200ms ease,
    content-visibility 200ms allow-discrete;
}

details[open]::details-content {
  height: auto;
}

为什么要多写一个 content-visibility 的过渡？因为收起时，浏览器会把内容切成 content-visibility: hidden，内容一下子就没了，高度动画根本看不到。content-visibility 是离散属性，只能直接切换，没有中间值。加上 allow-discrete，它会等高度动画结束再切过去。

::details-content 已经是 Baseline 2025，比 interpolate-size 支持得广。没有高度动画的浏览器里，面板照样能展开收起。

calc-size() 什么时候用

CSS
.panel.open {
  height: calc-size(auto, size + 16px);
}

size 代表 auto 算出来的高度。需要“内容高度再加一点”这种计算时才用它，普通的展开动画用 interpolate-size 就够了。

以前是怎么做的

最常见的是过渡 max-height 到一个足够大的值。问题是动画按这个大值走，内容越短，前面越多时间花在“看不见的高度”上，看起来像有延迟。

另一种是用 JavaScript 读 scrollHeight，把高度写成具体像素，动画结束后再改回 auto。这样可靠，但要处理内容变化、动画中途反向这些情况。

还有一种是用 Grid，让 grid-template-rows 从 0fr 过渡到 1fr。Grid 轨道本来就能插值，兼容性好，到现在仍是常用的回退方案。

常见追问

为什么浏览器不默认允许 auto 动画？

因为现有的样式表都默认固有尺寸是不能动画的。如果默认打开，很多已有页面的行为会突然变化，所以要开发者自己选择开启。
