前端工程师编写 Node 服务时需要守住哪些安全边界？

参考答案

服务端代码能够访问网络、文件系统和环境配置，权限边界比浏览器页面更广。输入校验、认证与授权、请求大小限制、超时和依赖安全都需要明确处理，不能把客户端已经验证当成可信依据。

CPU 密集型处理、无限制请求体或过长连接都可能导致资源耗尽。需要为上游调用设置超时与并发上限，避免错误重试放大流量。对文件路径和命令参数尤其不能直接拼接不可信输入。

作为前端适配层的 Node 服务应保持清晰职责，避免重复实现核心权限与业务规则。错误日志要能诊断问题，同时过滤令牌等敏感信息；上线后还需要监控与可回滚的发布流程。
