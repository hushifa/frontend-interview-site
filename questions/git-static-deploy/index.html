静态托管发布时为什么要检查资源路径和缓存？

参考答案

静态托管提供 HTML、CSS、JavaScript 等文件，不会自动运行应用的 Node 服务端。构建后的站点必须使用部署环境能够提供的路径；仓库子路径与域名根路径的区别常导致脚本或图片 404。

页面路由的直接访问也需要设计。查询参数或哈希通常仍命中同一静态文件，而 History 路由的深层路径可能需要托管支持的回退或预生成页面。

发布时应保证 HTML 引用的带哈希资源已经可访问。过早删除旧文件可能影响尚未刷新的页面或缓存中的 HTML。部署成功后实际打开页面、刷新深层入口并查看资源加载，比只看到构建绿灯更可靠。
