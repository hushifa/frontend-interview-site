可访问的树控件需要怎样处理键盘和层级状态？

树控件就是文件管理器那种可以层层展开的列表。它用 role="tree" 和 treeitem，展开状态用 aria-expanded，子节点放在 role="group" 里；整棵树只占一个 Tab 位置，用方向键移动和展开。能用嵌套列表加 details 表达的结构，不必做成 tree。

参考答案

简答

树控件就是编辑器侧栏里那种文件树，文件夹可以层层展开。结构上，role="tree" 包着若干 role="treeitem"；有子节点的项加 aria-expanded 表示展开还是折叠，子节点包在 role="group" 里。

整棵树只占一个 Tab 位置。只有当前项是 tabindex="0"，其余都是 -1，用户 Tab 一次进去，再 Tab 一次就出来。在树里面用键盘走：↓ 和 ↑ 移到下一个或上一个可见节点，→ 展开或进入第一个子节点，← 折叠或回到父节点，Home 和 End 跳到首尾，Enter 激活。要支持多选，就在 tree 上加 aria-multiselectable="true"，节点用 aria-selected 表示选中。

不过不是所有层级结构都该做成 tree。文件导航、侧栏目录这类只需要展开和跳转的场景，用嵌套的 ul 加链接，或者 <details>，更简单，读屏体验也更稳定。

结构怎么写

下面是一棵小文件树，src 展开着，components 折叠着。

HTML
<ul role="tree" aria-label="项目文件">
  <li role="treeitem" aria-expanded="true" tabindex="0">
    src
    <ul role="group">
      <li role="treeitem" tabindex="-1">main.ts</li>
      <li role="treeitem" aria-expanded="false" tabindex="-1">
        components
        <ul role="group" hidden>
          <li role="treeitem" tabindex="-1">Button.tsx</li>
        </ul>
      </li>
    </ul>
  </li>
</ul>

注意 main.ts 没有 aria-expanded。它是叶子节点，没有可以展开的东西；如果也写上，读屏会把它读成“已折叠”，用户会以为里面还有内容。

components 下面的 group 加了 hidden。折叠的子组一定要真正隐藏，否则读屏用户仍然能浏览到里面的节点，和视觉上看到的不一致。

方向键怎样只走可见节点

按 ↓ 时，焦点应该跳过折叠起来的节点。下面先找出所有可见节点，再按偏移量移动。

JavaScript
function visibleItems(tree) {
  return [...tree.querySelectorAll('[role="treeitem"]')].filter(
    (item) => !item.closest('[role="group"][hidden]'),
  );
}

function moveFocus(tree, current, offset) {
  const items = visibleItems(tree);
  const next = items[items.indexOf(current) + offset];
  if (!next) return;
  current.tabIndex = -1;
  next.tabIndex = 0;
  next.focus();
}

“可见节点”指的是所有祖先都已经展开的节点。判断方法很直接：如果一个节点被某个隐藏的 group 包着，它就看不见。

移动时把旧节点的 tabIndex 改成 -1，新节点改成 0。这样用户 Tab 出去再回来，焦点还停在上次的位置，这就是漫游 tabindex。

树很大时怎么办

节点很多时，通常只渲染展开的部分。可这样一来，读屏就数不出层级和位置了。所以要给每个节点设置 aria-level、aria-setsize、aria-posinset，读屏才能读出类似“第 2 级，共 5 项中的第 3 项”。

子节点是异步加载的，就在加载期间设置 aria-busy="true"，加载完再移除。APG 还推荐一个可选行为：输入首字母，跳到匹配的节点。

常见追问

侧栏导航要不要用 role="tree"？

一般不要。tree 角色会让读屏进入应用模式，用户必须用方向键操作，不能用平时浏览链接的方式。普通导航用嵌套列表加链接就够了。
