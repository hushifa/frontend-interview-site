多数元素怎样找？摩尔投票为什么是对的？

多数元素是出现次数超过 ⌊n/2⌋ 的元素。用 Map 计数是 O(n) 时间 O(n) 空间，排序后取中间位置是 O(n log n)。摩尔投票只用一个候选值和一个计数：计数为 0 时换候选，相同加 1，不同减 1，最后剩下的就是答案，O(n) 时间 O(1) 空间。它依赖“多数元素一定存在”，不保证存在时要再数一遍验证。

参考答案

简答

LeetCode 169 给一个长度为 n 的数组，找出出现次数超过 ⌊n/2⌋ 的元素，并保证它一定存在。比如 [2,2,1,1,1,2,2] 的答案是 2。

最直接的做法是用 Map 数每个数出现几次，O(n) 时间但要 O(n) 空间。也可以排序，多数元素超过一半，排好后一定会占据中间位置，取 nums[Math.floor(n / 2)] 就行，复杂度是排序的 O(n log n)。题目的进阶要求是 O(n) 时间、O(1) 空间，这就要用摩尔投票。

摩尔投票只维护一个候选值和一个计数。遍历时，计数为 0 就把当前数设为候选；当前数和候选相同，计数加 1，不同就减 1。可以理解成每次拿两个不同的数互相抵消，多数元素的个数比其他所有数加起来还多，所以抵消到最后剩下的一定是它。

要注意，摩尔投票只在多数元素一定存在时直接成立。如果题目不保证存在，比如 [1,2,3]，它也会留下一个候选，这时必须再遍历一遍，数一下候选是否真的超过一半。

摩尔投票

JavaScript
function majorityElement(nums) {
  let candidate = null;
  let count = 0;
  for (const num of nums) {
    if (count === 0) candidate = num;
    count += num === candidate ? 1 : -1;
  }
  return candidate;
}

console.log(majorityElement([3, 2, 3])); // 3
console.log(majorityElement([2, 2, 1, 1, 1, 2, 2])); // 2
console.log(majorityElement([1, 2, 3])); // 3

前两组是 LeetCode 169 的示例。第三组没有多数元素，函数照样返回了 3，它只是最后剩下的候选，所以不保证存在时不能直接用这个结果。

拿 [2,2,1,1,1,2,2] 走一遍：前两个 2 让计数到 2，接着三个 1 把计数减到 0 后又让 1 当上候选，计数是 1；后面两个 2 先把计数减到 0，再让 2 重新当上候选。最后候选是 2。

为什么中途换了候选也不会出错？计数归零时，前面那一段里候选和非候选正好一样多，等于两两抵消掉了。多数元素在这一段里最多占一半，所以在剩下的部分里它仍然超过一半。对剩下的部分继续投票，结论不变。

不保证存在时怎样验证

JavaScript
function findMajority(nums) {
  let candidate = null;
  let count = 0;
  for (const num of nums) {
    if (count === 0) candidate = num;
    count += num === candidate ? 1 : -1;
  }
  // 第二遍数一下，确认候选真的超过一半
  const times = nums.filter((num) => num === candidate).length;
  return times > Math.floor(nums.length / 2) ? candidate : 'none';
}

console.log(findMajority([1, 2, 3])); // none
console.log(findMajority([1, 1, 2])); // 1
console.log(findMajority([1, 2, 1, 2])); // none

[1,2,1,2] 里 1 和 2 各出现 2 次，都没有超过 ⌊4/2⌋ = 2，所以没有多数元素。“超过一半”是严格大于，正好一半不算。验证多遍历了一次，时间仍然是 O(n)，空间仍是 O(1)。

常见追问

找出所有出现次数超过 ⌊n/3⌋ 的元素怎么做？

这是 LeetCode 229。超过三分之一的元素最多只有两个，所以同时维护两个候选和两个计数：和某个候选相同就给它加 1；某个计数为 0 就让当前数当候选；都不是就两个计数同时减 1，相当于三个不同的数一起抵消。最后必须再数一遍，确认两个候选是否真的超过 ⌊n/3⌋。

排序取中间为什么一定对？

多数元素超过一半，排好序后它是一段连续的区间，长度超过 n/2。不管这段从哪里开始，都会盖住下标 Math.floor(n / 2) 这个位置。注意 JavaScript 的 sort 默认按字符串比较，数字要传 (a, b) => a - b。
