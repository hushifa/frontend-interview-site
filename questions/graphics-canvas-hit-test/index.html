Canvas 图形命中测试应该怎样实现？

Canvas 只有一个 DOM 元素，点中了哪个图形要应用自己判断。用 Path2D 让绘制和命中共用同一份几何，统一坐标系后用 isPointInPath 检测，重叠时从最上层往下找，对象多时先用包围盒或空间索引粗筛。

参考答案

简答

  • 浏览器不会把点击分发给 Canvas 里的某个圆，要根据保存的几何信息自己判断。
  • 用 Path2D 定义形状，同一个对象既用于 fill() 也用于 isPointInPath()，绘制和命中不会不一致。
  • isPointInPath(path, x, y) 中的 x、y 是位图坐标，不受当前变换影响；path 则按当前变换参与检测。
  • 图形重叠时按绘制的逆序检测，第一个命中的可交互对象胜出。
  • 对象很多时先用包围盒、网格或四叉树缩小候选，再做精确检测。

基本用法

JavaScript
const canvas = document.querySelector('canvas');
const ctx = canvas.getContext('2d');

const circle = new Path2D();
circle.arc(50, 50, 20, 0, Math.PI * 2);
ctx.fill(circle);

ctx.isPointInPath(circle, 50, 50); // true
ctx.isPointInPath(circle, 80, 50); // false

isPointInPath 检查的是路径的填充区域，与像素颜色无关。只描边的线条用 isPointInStroke，结果受 lineWidth 影响；触摸操作可以临时加大线宽来放大命中范围。带孔洞的路径要传入和绘制时相同的填充规则（'nonzero' 或 'evenodd'）。

坐标转换

指针事件给的是 client 坐标，要先换算成位图坐标：

JavaScript
function toBitmap(canvas, event) {
  const rect = canvas.getBoundingClientRect();
  return {
    x: ((event.clientX - rect.left) * canvas.width) / rect.width,
    y: ((event.clientY - rect.top) * canvas.height) / rect.height,
  };
}

这里假设 canvas 没有边框和内边距，也没有 CSS 旋转。

绘制时如果设置了变换，检测时要用同一个变换：

JavaScript
ctx.setTransform(2, 0, 0, 2, 100, 0);
ctx.isPointInPath(circle, 200, 100); // true，圆心 (50,50) 映射到位图 (200,100)

另一种做法是把指针坐标用变换的逆矩阵转回局部坐标，再在单位矩阵下检测，见《Canvas 的 transform 怎样影响坐标和绘制？》。两种做法只能选一种，混用会补偿两次。

重叠与粗筛

JavaScript
// x、y 和 shape.bounds 都是画布位图坐标；shape.path 是局部坐标，配合 shape.matrix 使用
function hitTest(ctx, shapes, x, y) {
  const saved = ctx.getTransform();
  try {
    for (let i = shapes.length - 1; i >= 0; i--) {
      const shape = shapes[i];
      if (!shape.selectable) continue;
      const { left, top, right, bottom } = shape.bounds;
      if (x < left || x > right || y < top || y > bottom) continue; // 包围盒粗筛
      ctx.setTransform(shape.matrix);
      if (ctx.isPointInPath(shape.path, x, y)) return shape;
    }
    return null;
  } finally {
    ctx.setTransform(saved); // 检测完恢复原矩阵，不影响后续绘制
  }
}
  • shapes 按绘制顺序存放，逆序遍历就是从上往下。
  • 锁定、不可选、允许穿透的对象由业务模型标记。
  • 空间索引要在对象移动、缩放、删除时同步更新。

其他方案

颜色拾取：在离屏画布上用唯一颜色绘制每个对象，读取点击处像素的颜色得到对象 ID。它适合形状复杂、数量巨大的场景，但要关掉抗锯齿，getImageData 有读回开销，而且画布被跨源图片污染后无法读取。

常见追问

  • 命中检测之外还要做什么？ 拖动要配合 setPointerCapture；重要操作要提供键盘或普通控件入口。
  • 能用 isPointInPath 判断像素是否透明吗？ 不能，它只看几何。需要按透明度判断时用颜色拾取或读取像素。
