逻辑属性为什么比固定写 left、right 更适合国际化？

逻辑属性按行内方向（inline）和块方向（block）描述边距、尺寸和定位，会随 direction 和 writing-mode 自动映射到实际方向，同一套样式可以用于从左到右、从右到左和竖排。

参考答案

简答

  • inline 方向是文字排列的方向，block 方向是行堆叠的方向；start 和 end 分别指起点和终点。
  • 横排中文和英文里，margin-inline-start 等于 margin-left；阿拉伯语（dir="rtl"）里等于 margin-right。
  • 竖排（writing-mode: vertical-rl）时，inline 变为上下方向，inline-size 对应高度。
  • 常用对照：width → inline-size，padding-left → padding-inline-start，top → inset-block-start，text-align: left → text-align: start。
  • 方向由 HTML 的 dir 属性设置，样式里不需要再为 RTL 写一套覆盖规则。

示例

CSS
.message {
  padding-inline: 16px;
  margin-block-end: 8px;
  border-inline-start: 4px solid steelblue;
  text-align: start;
}
HTML
<p class="message" dir="ltr">Saved</p>
<p class="message" dir="rtl">تم الحفظ</p>

两条消息的色条分别出现在左侧和右侧，不需要额外样式。

简写

  • margin-inline: 0 auto 依次是 start 和 end。
  • inset-inline: 0 同时设置左右两侧（横排时）。
  • padding-block: 8px 同时设置上下。

注意 margin: 1px 2px 3px 4px 这类四值简写仍然是物理方向。

不需要转换的地方

  • 和书写方向无关的视觉效果，例如阴影偏移、背景位置、以屏幕为基准的固定悬浮按钮，可以继续用物理属性。
  • 图标是否需要镜像要看含义：箭头、返回按钮通常镜像，时钟、播放按钮不镜像。用 :dir(rtl) 处理图标翻转。
  • transform: translateX() 没有逻辑版本，RTL 下需要单独处理方向。

常见追问

  • flex 和 grid 需要改吗？不需要。flex-direction: row、justify-content: flex-start 本身就跟随书写方向，RTL 下自动从右往左排。
