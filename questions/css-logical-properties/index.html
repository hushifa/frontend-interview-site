逻辑属性为什么比固定写 left、right 更适合国际化？

逻辑属性不写左右上下，而是写"文字开始的一侧""文字结束的一侧"。页面换成从右往左的阿拉伯语或竖排时，同一套样式会自动对应到正确的方向。

参考答案

简答

margin-left 永远是左边。可是阿拉伯语是从右往左写的，同样的设计，间距应该在右边。逻辑属性不说左右，说的是“开始”和“结束”：margin-inline-start 在中文、英文里等于 margin-left，在 dir="rtl" 的阿拉伯语里等于 margin-right。

这里有两个方向。inline 方向是文字排列的方向，block 方向是一行行往下堆的方向。竖排（writing-mode: vertical-rl）时，inline 变成上下方向，inline-size 对应的就是高度。

常用的对照是：width 对应 inline-size，padding-left 对应 padding-inline-start，top 对应 inset-block-start，text-align: left 对应 text-align: start。

好处是方向只由 HTML 的 dir 属性决定，样式里不用再为 RTL 写一套覆盖规则。要注意，和书写方向无关的东西，比如阴影、固定在屏幕角落的按钮，继续用物理属性。

同一套样式，左右自动翻转

CSS
.message {
  padding-inline: 16px;
  margin-block-end: 8px;
  border-inline-start: 4px solid steelblue;
  text-align: start;
}
HTML
<p class="message" dir="ltr">Saved</p>
<p class="message" dir="rtl">تم الحفظ</p>

两条消息用的是同一个类。英文那条，色条在左边；阿拉伯语那条，色条自动跑到右边，文字也右对齐。

如果写的是 border-left 和 text-align: left，阿拉伯语那条的色条还在左边，在从右往左读的人看来就是在“结尾”，要另外写一套 [dir="rtl"] 的覆盖样式。

简写怎么读

margin-inline: 0 auto 两个值依次是开始和结束。inset-inline: 0 同时设置行内方向的两侧，横排时就是左右。padding-block: 8px 同时设置块方向的两侧，横排时就是上下。

容易误会的是 margin: 1px 2px 3px 4px 这种四个值的简写，它仍然是物理方向，上右下左，不会跟着书写方向变。

哪些地方不用改

和书写方向无关的视觉效果，可以继续用物理属性。比如阴影的偏移、背景图的位置、固定在屏幕右下角的悬浮按钮。

图标要不要镜像，看它的含义。箭头、返回按钮表示方向，通常要镜像；时钟、播放按钮不表示阅读方向，不镜像。需要翻转图标时用 :dir(rtl) 来写。

transform: translateX() 没有逻辑版本，RTL 下要单独处理方向。

常见追问

flex 和 grid 布局要不要改成逻辑写法？

不用。flex-direction: row、justify-content: flex-start 本来就跟着书写方向走，RTL 下会自动从右往左排。
