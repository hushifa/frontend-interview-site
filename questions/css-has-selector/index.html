:has() 怎样根据后代或相邻元素设置样式？

:has() 判断一个元素里面或后面有没有某样东西，有的话选中的还是这个元素本身。这样父元素和前面的兄弟元素终于能根据后面的内容改样式了。

参考答案

简答

以前 CSS 只能从父元素往下选，没法说“包含图片的卡片”。:has() 补上了这个能力，.card:has(img) 选中的是里面有图片的 .card，样式加在卡片上，不是加在图片上。

括号里写的是相对于当前元素的选择器。:has(> img) 只看直接子元素，:has(+ .error) 看紧挨在后面的兄弟元素。所以它不光能选父元素，还能选前面的兄弟。

以前这类需求要用 JavaScript 给父元素加类名，比如整组表单字段在输入无效时变红，现在一条选择器就够了。

要注意几点：它的优先级取括号里最高的那个，写 :has(#id) 就会带上 ID 级优先级；:has() 不能嵌套，伪元素也不能放进参数。主流浏览器都已经支持，可以直接用。

常见用法

下面几条都是以前必须靠 JavaScript 加类名才能做到的：

CSS
/* 含图片的卡片改为左右布局 */
.card:has(> img) {
  display: grid;
  grid-template-columns: 120px 1fr;
}

/* 字段无效时高亮整组 */
.field:has(input:user-invalid) {
  border-color: crimson;
}

/* 后面紧跟说明文字的标题减小间距 */
h2:has(+ .subtitle) {
  margin-block-end: 4px;
}

/* 打开对话框时禁止页面滚动 */
html:has(dialog[open]) {
  overflow: hidden;
}

第三条值得多看一眼。h2:has(+ .subtitle) 选中的是 h2，条件是它后面紧跟着 .subtitle。以前的 + 选择器只能选后面那个，现在可以反过来选前面那个。

多个条件怎么组合

CSS
/* 同时包含两者 */
.item:has(.badge):has(.price) { }

/* 包含任意一个 */
.item:has(.badge, .price) { }

/* 不包含 */
.item:not(:has(img)) { }

连写两个 :has() 是“并且”，括号里用逗号分开是“或者”，外面套 :not() 是“不包含”。

会不会很慢

浏览器为 :has() 专门做了优化，常见写法没有明显的性能问题。

要小心的是范围太大的写法，比如 body:has(.x) 或 :has(*)。页面上任何地方的 DOM 变化，都可能让浏览器重新检查一大片元素。所以前面的元素尽量写具体，比如 .field:has(...)，而不是 body:has(...)。

常见追问

:has() 和 :focus-within 有什么区别？

:focus-within 只能判断后代里有没有元素获得焦点。:has(:focus-visible) 能判断更具体的状态，比如只在键盘聚焦时生效，而且 :has() 还能用在兄弟关系上。
