函数重载、联合参数与泛型怎样选择？函数类型何时可赋值？

多种输入走同一逻辑、返回同一类型时用联合参数；返回类型由输入类型决定时用泛型；几种离散调用形式各自返回不同类型时用重载，实现签名对调用方不可见。函数赋值时参数按逆变检查（strictFunctionTypes），返回值按协变检查；方法简写语法的参数仍按双变检查。

参考答案

简答

  • 联合参数：(value: string | unknown[]) => number，输入不同但返回契约相同。
  • 泛型：<T>(value: T) => { value: T }，返回类型跟随输入类型。
  • 重载：几条公开签名加一个实现签名，调用方只能看到公开签名，传入 string | number 这样的联合不会匹配任何一条。
  • 函数类型赋值：参数位置要求"能接受更宽的输入"（逆变），返回值要求"产出更窄的结果"（协变）。
  • strictFunctionTypes 对所有函数类型（包括函数类型属性 handle: (v: T) => void）生效，方法简写 handle(v: T): void 仍是双变的，以兼容数组等内置类型。

联合参数

TypeScript
function lengthOf(value: string | readonly unknown[]): number {
  return value.length;
}

泛型

TypeScript
function wrap<T>(value: T): { value: T } {
  return { value };
}
wrap(12).value.toFixed(0);

重载

TypeScript
function convert(value: string): number;
function convert(value: number): string;
function convert(value: string | number): string | number {
  return typeof value === 'string' ? value.length : String(value);
}

convert('HTML').toFixed(0);
convert(12).toUpperCase();

function forward(value: string | number) {
  // @ts-expect-error 两条公开签名都不接受 string | number
  return convert(value);
}

需要接受联合时再加一条 function convert(value: string | number): string | number;。重载按书写顺序匹配，具体的签名要写在前面。很多场景用条件类型返回值也能表达，但实现内部常需要断言。

参数逆变

TypeScript
type Animal = { name: string };
type Dog = Animal & { bark(): void };
type Handler<T> = (value: T) => void;

const handleAnimal: Handler<Animal> = (animal) => console.log(animal.name);
const handleDog: Handler<Dog> = (dog) => dog.bark();

const forDog: Handler<Dog> = handleAnimal; // 能处理任意 Animal，当然能处理 Dog
// @ts-expect-error 只会处理 Dog，不能承诺处理任意 Animal
const forAnimal: Handler<Animal> = handleDog;

方法语法的双变

TypeScript
type MethodHandler<T> = { handle(value: T): void };
const dogMethods: MethodHandler<Dog> = { handle: handleDog };
const widerMethods: MethodHandler<Animal> = dogMethods; // 允许，但不安全

设计回调类型时写成属性形式 handle: (value: T) => void，才能得到严格检查。

其他赋值规则

  • 参数少的函数可以赋给参数多的类型：[1, 2].map((x) => x * 2)。
  • 返回 void 的函数类型可以接受有返回值的函数，返回值被忽略。
  • 回调中由调用方保证传入的参数，类型应声明为必需而不是可选。

常见追问

  • TypeScript 4.7 的 in/out 方差注解有什么用？interface Box<out T> 显式声明方差，可以加快复杂泛型的检查，并在实现与声明不符时报错。
  • 箭头函数能写重载吗？不能直接写，可以把函数类型声明为带多个调用签名的接口或类型字面量。
