HTTP 103 Early Hints 适合怎样的加载优化？

解释 103 响应如何在最终响应前提示关键资源，理解它与 preload、服务端和代理支持的关系。

参考答案

103 Early Hints 是最终响应之前的临时响应，服务端可以在主文档还没准备好时发送 Link: rel=preload 等提示，让浏览器提前开始获取关键资源。

它需要服务器、代理、CDN 和浏览器链路配合。若资源提示错误、过多或最终响应不需要这些资源，就会浪费连接和带宽。它也不能替代最终响应中的正确资源声明和缓存策略。

使用前应验证代理是否会转发 103、是否会重复 preload，以及真实 LCP 和带宽是否改善。对于已经能从 HTML 很快发现的资源，额外提示未必有收益。
