MutationObserver 和 ResizeObserver 分别观察什么？

MutationObserver 观察 DOM 节点的增删、属性和文本变化，回调在微任务中批量执行；ResizeObserver 观察元素渲染尺寸的变化。尺寸变化不一定伴随 DOM 变化，两者不能互相替代。

参考答案

简答

  • MutationObserver 观察 DOM 结构变化：子节点增删（childList）、属性（attributes）、文本（characterData），subtree: true 时包括所有后代。
  • 回调在微任务中执行，一次收到这段时间内的所有变化记录。
  • ResizeObserver 观察元素尺寸变化，窗口缩放、字体加载、父容器变宽都会触发，这些情况下 DOM 并没有变化。
  • 回调里修改被观察的 DOM，会产生新的记录并再次触发回调，容易形成循环。

MutationObserver 示例

JavaScript
const observer = new MutationObserver((records) => {
  for (const record of records) {
    for (const node of record.addedNodes) {
      if (node instanceof Element && node.matches('img[data-src]')) lazyLoad(node);
    }
  }
});

observer.observe(container, { childList: true, subtree: true });
  • attributeFilter: ['class'] 只观察指定属性，减少回调次数。
  • attributeOldValue: true 在记录中保留旧值。
  • observer.takeRecords() 取出还没交给回调的记录，disconnect() 停止观察。

选哪一个

需求用
第三方脚本插入了节点MutationObserver
富文本编辑器的内容变化MutationObserver
容器宽度变化后重新布局图表ResizeObserver
元素进入视口IntersectionObserver

注意事项

  • 观察 document.body 的整个子树，每次 DOM 变化都要产生记录，在频繁更新的页面上开销明显，范围应尽量小。
  • 自己框架渲染的组件，通常在组件内部就知道何时更新，不需要用 MutationObserver 观察。
  • ResizeObserver 的具体用法见《ResizeObserver 为什么可能出现循环通知错误？》。
