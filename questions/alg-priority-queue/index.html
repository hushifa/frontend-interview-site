前端任务怎样按优先级排队？二叉堆为什么不需要每次完整排序？

以资源加载队列为例，用最小堆实现优先队列：插入时上浮，取出时把末尾元素放到堆顶再下沉，两者都是 O(log n)，比每次插入后整体排序的 O(n log n) 更省。同优先级按提交顺序取出，需要额外的序号。优先队列只决定先后，不负责限制并发和取消任务。

参考答案

简答

  • 二叉堆是用数组存储的完全二叉树，下标 i 的父节点是 (i - 1) >> 1，子节点是 2i + 1 和 2i + 2；最小堆中每个父节点都不大于子节点。
  • 插入：放到数组末尾，与父节点比较并上浮；取出：取走堆顶，把末尾元素移到堆顶，与较小的子节点比较并下沉。两者都是 O(log n)，查看堆顶是 O(1)。
  • 堆只保证堆顶最小，不维护整体有序，所以不需要每次排序。
  • 堆不是稳定结构，同优先级的任务要按提交顺序取出时，给每个任务加递增序号作为第二比较键。
  • 优先队列只决定下一个执行谁，并发数量和任务取消要由调度器另外处理。

实现

JavaScript
class PriorityQueue {
  #heap = [];
  #sequence = 0;

  get size() {
    return this.#heap.length;
  }

  // 数字越小优先级越高；优先级相同时先提交的排在前面。
  #before(a, b) {
    return a.priority < b.priority || (a.priority === b.priority && a.sequence < b.sequence);
  }

  #swap(i, j) {
    [this.#heap[i], this.#heap[j]] = [this.#heap[j], this.#heap[i]];
  }

  push(value, priority) {
    if (!Number.isFinite(priority)) throw new TypeError('优先级必须为有限数值');
    const heap = this.#heap;
    heap.push({ value, priority, sequence: this.#sequence++ });
    let index = heap.length - 1;
    while (index > 0) {
      const parent = (index - 1) >> 1;
      if (!this.#before(heap[index], heap[parent])) break;
      this.#swap(index, parent);
      index = parent;
    }
  }

  peek() {
    return this.#heap[0]?.value;
  }

  pop() {
    const heap = this.#heap;
    if (heap.length === 0) return undefined;
    const top = heap[0];
    const last = heap.pop();
    if (heap.length > 0) {
      heap[0] = last;
      let index = 0;
      while (true) {
        const left = index * 2 + 1;
        const right = left + 1;
        let best = index;
        if (left < heap.length && this.#before(heap[left], heap[best])) best = left;
        if (right < heap.length && this.#before(heap[right], heap[best])) best = right;
        if (best === index) break;
        this.#swap(index, best);
        index = best;
      }
    }
    return top.value;
  }
}

const queue = new PriorityQueue();
queue.push('下一页图片', 5);
queue.push('视口图片 A', 1);
queue.push('视口图片 B', 1);
console.log(queue.pop()); // 视口图片 A
console.log(queue.pop()); // 视口图片 B
console.log(queue.pop()); // 下一页图片
console.log(queue.pop()); // undefined

实测用 500 组随机插入和取出序列，与"按优先级、再按序号排序后取第一个"的朴素做法对比，结果一致。>> 1 只在堆长度小于 2³¹ 时正确，这对前端任务队列不构成限制。

和排序数组比较

操作每次插入后排序有序数组二分插入二叉堆
插入O(n log n)查找 O(log n)，移动元素 O(n)O(log n)
取最小O(1)（从末尾取）O(1)O(log n)

任务不断加入又不断被取走时，堆的总成本最低。

放进调度器

JavaScript
async function runQueue(queue, limit) {
  let active = 0;
  return new Promise((resolve) => {
    const next = () => {
      if (queue.size === 0 && active === 0) return resolve();
      while (active < limit && queue.size > 0) {
        const task = queue.pop();
        active++;
        // 同步抛错也转成拒绝；失败只记录，不中断队列，也不产生未处理拒绝。
        Promise.resolve()
          .then(task)
          .catch((error) => console.error('任务失败', error))
          .finally(() => {
            active--;
            next();
          });
      }
    };
    next();
  });
}

优先队列决定顺序，limit 控制同时运行的数量。单个任务失败只记录错误，队列继续执行，全部结束后 runQueue 兑现；需要汇总失败时，可以在 catch 里收集错误再一并返回。用户滚动后某张图片不再需要时，要在任务里检查取消标记或用 AbortController 中止请求，堆本身不支持删除任意元素。

常见追问

  • 怎样支持修改优先级？ 维护"值 → 堆下标"的映射，修改后按新优先级上浮或下沉；更简单的做法是插入一个新条目，旧条目出队时发现已失效就跳过。
  • 浏览器原生有优先级调度吗？ scheduler.postTask 提供 user-blocking、user-visible、background 三个优先级；fetch 的 priority 选项可以提示网络请求的优先级。两者都只在部分浏览器中支持，使用前需要特性检测。
