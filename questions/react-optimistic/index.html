useOptimistic 的临时状态怎样与真实结果收敛？

useOptimistic 在 Action 或 Transition 进行期间，把临时更新叠加到传入的真实状态上显示；Action 结束后，临时状态自动丢弃，界面回到真实状态。成功时要更新真实状态，失败时只需提示错误。

参考答案

简答

  • 签名：const [optimisticState, addOptimistic] = useOptimistic(state, updateFn)，updateFn(currentState, optimisticValue) 计算临时状态。
  • addOptimistic 必须在 Action 或 startTransition 里调用，临时状态只在这次 Action 进行期间存在。
  • Action 结束后 React 丢弃临时状态，显示传入的 state。所以成功时必须把真实结果写进 state，否则界面会回退。
  • 失败时不需要手动回滚，临时状态自动消失；只需提示错误。
  • 适合点赞、发送消息这类成功率高、失败可以撤回的操作；涉及支付、库存等操作仍应等服务端确认。

发送消息

JSX
import { useOptimistic, useState, startTransition } from 'react';

export default function Chat({ initialMessages }) {
  const [messages, setMessages] = useState(initialMessages);
  const [error, setError] = useState('');
  const [optimisticMessages, addOptimistic] = useOptimistic(
    messages,
    (current, text) => [...current, { id: `temp-${Date.now()}`, text, sending: true }],
  );

  function send(formData) {
    const text = String(formData.get('text'));
    setError('');
    startTransition(async () => {
      addOptimistic(text);
      try {
        const saved = await postMessage(text); // 返回 { id, text }
        startTransition(() => setMessages((list) => [...list, saved]));
      } catch {
        setError('发送失败，请重试');
      }
    });
  }

  return (
    <>
      <ul>
        {optimisticMessages.map((m) => (
          <li key={m.id} style={{ opacity: m.sending ? 0.5 : 1 }}>{m.text}</li>
        ))}
      </ul>
      {error && <p role="alert">{error}</p>}
      <form action={send}>
        <input name="text" required />
        <button>发送</button>
      </form>
    </>
  );
}
  • 点击发送后，消息立即以半透明显示。
  • 成功：setMessages 写入服务端返回的消息，Action 结束后临时消息被替换为真实消息。
  • 失败：Action 结束，临时消息自动消失，显示错误提示。
  • await 之后的 setMessages 需要再包一层 startTransition，这是目前 Action 中 await 之后更新状态的要求。

注意点

  • 临时条目的 id 和真实 id 不同，用作 key 时，成功后该行会重新挂载。需要保留行内状态时，可以由客户端生成 ID 一起提交给服务端。
  • 多个请求并发时，每个 addOptimistic 都叠加在最新的真实状态上。
  • 乐观更新只是显示策略，服务端仍要做校验、幂等和冲突处理。

常见追问

  • 和手动 setState 再回滚相比有什么好处？不需要自己记录旧值和写回滚逻辑，也不会出现回滚覆盖了期间其他更新的问题。
  • 能在表单之外使用吗？可以，只要在 startTransition 中调用。
