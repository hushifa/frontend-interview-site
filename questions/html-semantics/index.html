HTML 语义化对阅读、搜索与无障碍有什么价值？

参考答案

语义化是用元素表达内容的角色，例如标题、导航、主内容、文章和表单，而不是只选择看起来合适的默认样式。辅助技术、搜索引擎和浏览器都能利用这些结构信息。

页面应有清晰的标题层级，nav 表示主要导航，main 表示主要内容，article 适合可独立理解的内容单元。section 通常需要有可识别的主题，不能把它当作任意布局容器替代 div。

语义正确不等于自动获得好体验，还需要合理焦点顺序、可访问名称和内容质量。不要因为默认样式不喜欢就用 span 模拟标题或按钮，应通过 CSS 调整原生元素的视觉表现。
