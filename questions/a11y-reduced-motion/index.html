如何让动画尊重用户的减少动态效果设置？

有些用户看到大幅动画会头晕，系统里因此有“减少动态效果”设置。用 prefers-reduced-motion 媒体查询读取它，关闭或替换大幅移动、缩放、视差和自动播放的动画；保留淡入淡出等不会引起不适的反馈，状态变化本身不能丢。

参考答案

简答

有一类用户前庭功能有障碍，看到大面积的移动、缩放、视差，可能会头晕、恶心。系统设置里的“减少动态效果”就是为他们准备的，网页可以读到这个设置：CSS 用 @media (prefers-reduced-motion: reduce)，JavaScript 用 matchMedia('(prefers-reduced-motion: reduce)')。

减少不等于全部删掉。把位移和缩放换成淡入淡出，或者直接切换；加载指示、焦点变化这些反馈仍然要有，状态变化本身不能丢。

WCAG 里有两条相关要求。自动播放、持续超过 5 秒的动画要能暂停（2.2.2）；由交互触发的动画要能关闭（2.3.3，AAA 级）。

还要注意，用户可能在页面开着的时候改设置，所以长时间运行的动画要监听 change 事件。

CSS 怎么写

下面是一个卡片入场动画，默认从下往上滑入并淡入。

CSS
.card {
  transition: transform 300ms, opacity 300ms;
}

.card.enter {
  transform: translateY(24px);
  opacity: 0;
}

@media (prefers-reduced-motion: reduce) {
  .card {
    transition: opacity 150ms;
  }

  .card.enter {
    transform: none;
  }
}

开启减少模式后，位移被去掉了，只保留透明度变化。用户还是能看出卡片“出现了”，只是不会看到它在动。

也可以反过来写：默认没有动画，只在用户没要求减少时才启用。

CSS
@media (prefers-reduced-motion: no-preference) {
  .hero {
    animation: float 6s ease-in-out infinite;
  }
}

这种写法的好处是，不支持这个媒体查询的环境默认就是安静的。

JavaScript 怎么写

用脚本播放动画时，先查一下偏好。

JavaScript
const query = matchMedia('(prefers-reduced-motion: reduce)');

function playIntro(element) {
  if (query.matches) {
    element.style.opacity = '1';
    return;
  }
  element.animate(
    [{ opacity: 0, transform: 'scale(0.9)' }, { opacity: 1, transform: 'none' }],
    { duration: 400, easing: 'ease-out' },
  );
}

query.addEventListener('change', () => {
  // 偏好变化时停止正在运行的循环动画
});

要求减少时，直接把元素设成最终状态，跳过缩放动画。change 监听用来处理用户中途改了设置的情况。

你可能注意到这里没写 fill: 'forwards'。这是故意的：动画结束后元素回到自身的样式，之后再通过 CSS 或脚本设置 transform 时，不会被动画的结果盖住。

哪些动画需要处理

视差滚动、整页缩放过渡、背景视频、无限循环的装饰动画，都属于要处理的范围。Canvas、WebGL 场景里的镜头移动也一样。

容易漏掉的是平滑滚动。点锚点时的 scroll-behavior: smooth 也是一种大幅移动，减少模式下应该改成 auto。

常见追问

用户没开系统选项，但觉得动画太多怎么办？

可以在网站自己的设置里提供一个“减少动画”开关，和系统偏好一起生效，任何一边要求减少就减少。
