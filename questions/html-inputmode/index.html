inputmode 怎样改善移动端输入体验？

inputmode 只决定手机上弹出哪种键盘，比如数字键盘、电话键盘、邮箱键盘。它不改变值的类型，也不限制能输入什么，校验还是要靠 pattern 或代码。

参考答案

简答

手机上填验证码，弹出来的是全键盘，还得切到数字，很麻烦。inputmode 就是告诉手机该弹哪种虚拟键盘，可选值有 none、text、decimal、numeric、tel、search、email、url。

验证码、银行卡号这种“全是数字但不是数值”的字段，用 type="text" 加 inputmode="numeric"，不要用 type="number"。因为 type="number" 会显示上下步进按钮，鼠标滚轮会改掉值，还会把开头的 0 丢掉。

金额要输小数点，用 decimal。电话号码直接用 type="tel"，它本身就会弹电话键盘。

要注意，inputmode 只管键盘长什么样。用户照样能粘贴，或者用外接键盘输入任何字符，所以还是要配合 pattern 和服务端校验。

几种常见字段

HTML
<label>
  验证码
  <input
    name="code"
    inputmode="numeric"
    autocomplete="one-time-code"
    pattern="[0-9]{6}"
    maxlength="6"
  >
</label>

<label>
  金额
  <input name="amount" inputmode="decimal">
</label>

<label>
  搜索
  <input type="search" name="q" enterkeyhint="search">
</label>

验证码这个字段几个属性各司其职：inputmode 弹数字键盘，autocomplete 让系统能从短信里填验证码，pattern 校验是不是 6 位数字，maxlength 限制长度。

搜索框上的 enterkeyhint 改的是键盘上回车键显示的文字，可选 enter、done、go、next、previous、search、send。写 search，回车键就会显示成“搜索”。

type 和 inputmode 怎么分工

type 决定这是什么控件，带有内置校验和值的格式。inputmode 只影响虚拟键盘。autocomplete 说明字段用途，用于自动填充。pattern 是校验规则。

所以 type="email" 已经会弹出邮箱键盘、也会校验格式，不用再写 inputmode="email"。inputmode 主要用在 type="text" 或者 contenteditable 的元素上，这些地方 type 帮不上忙。

常见追问

inputmode="none" 有什么用？

页面自己做了一个输入面板时用，比如自定义的数字键盘。写上 none，系统键盘就不会弹出来挡住页面自己的键盘。
