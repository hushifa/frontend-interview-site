inputmode 怎样改善移动端输入体验？

inputmode 只决定虚拟键盘的类型，例如 numeric、decimal、tel、email；它不改变值的类型，也不限制输入字符，校验仍要靠 pattern 或代码。

参考答案

简答

  • 可选值：none、text、decimal、numeric、tel、search、email、url。
  • 验证码、银行卡号这类“由数字组成但不是数值”的字段，用 type="text" 加 inputmode="numeric"，而不是 type="number"。
  • type="number" 会显示步进按钮、滚轮会改值、会丢掉前导 0，不适合编号。
  • 需要小数点的金额用 decimal，电话号码用 type="tel"，它本身就会弹出电话键盘。
  • 用户仍可以粘贴或用外接键盘输入任何字符，所以要配合 pattern 和服务端校验。

示例

HTML
<label>
  验证码
  <input
    name="code"
    inputmode="numeric"
    autocomplete="one-time-code"
    pattern="[0-9]{6}"
    maxlength="6"
  >
</label>

<label>
  金额
  <input name="amount" inputmode="decimal">
</label>

<label>
  搜索
  <input type="search" name="q" enterkeyhint="search">
</label>

enterkeyhint 改变键盘回车键的文字，可选 enter、done、go、next、previous、search、send。

type 和 inputmode 的分工

属性作用
type控件类型、内置校验、值的格式
inputmode只影响虚拟键盘
autocomplete字段用途和自动填充
pattern校验规则

type="email" 已经会弹出邮箱键盘并校验格式，不需要再写 inputmode="email"。inputmode 主要用于 type="text" 或 contenteditable 元素。

常见追问

  • inputmode="none" 有什么用？用于页面自己提供输入面板的场景，例如自定义数字键盘，避免系统键盘弹出遮挡。
