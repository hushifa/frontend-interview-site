Intl.RelativeTimeFormat 怎样正确显示相对时间？

Intl.RelativeTimeFormat 只负责把"数值 + 单位"格式化成"5 分钟前""明天"这样的文字，时间差和单位选择要应用自己计算。numeric auto 输出"昨天"等自然说法；排序和刷新要基于时间戳，SSR 要固定基准时间。

参考答案

简答

  • format(value, unit) 只做格式化：format(-5, 'minute') 在中文下输出"5分钟前"。它不会计算两个时间相差多少。
  • 应用先算出时间差，再选单位（秒、分、小时、天……）并决定取整方式。
  • numeric: 'auto' 会把 -1 天、0 天、1 天说成"昨天""今天""明天"；默认的 'always' 一律用数字。
  • 列表排序、刷新判断都基于原始时间戳，不要用显示出来的字符串。
  • SSR 时服务端和客户端的"现在"不同，相对时间会对不上，常见做法是服务端输出绝对时间，客户端水合后再替换。

输出示例（Node 22 实测）

JavaScript
const zh = new Intl.RelativeTimeFormat('zh-CN');
zh.format(-5, 'minute'); // '5分钟前'
zh.format(-3, 'hour'); // '3小时前'

const zhAuto = new Intl.RelativeTimeFormat('zh-CN', { numeric: 'auto' });
zhAuto.format(-1, 'day'); // '昨天'
zhAuto.format(0, 'day'); // '今天'

const en = new Intl.RelativeTimeFormat('en');
en.format(-1, 'day'); // '1 day ago'
new Intl.RelativeTimeFormat('en', { numeric: 'auto' }).format(2, 'day'); // 'in 2 days'
new Intl.RelativeTimeFormat('en', { style: 'short' }).format(-3, 'month'); // '3 mo. ago'

计算时间差并选单位

JavaScript
const UNITS = [
  ['year', 365 * 24 * 3600],
  ['month', 30 * 24 * 3600],
  ['day', 24 * 3600],
  ['hour', 3600],
  ['minute', 60],
  ['second', 1],
];

function formatRelative(timestamp, now, locale) {
  const seconds = Math.round((timestamp - now) / 1000);
  const rtf = new Intl.RelativeTimeFormat(locale, { numeric: 'auto' });
  for (const [unit, size] of UNITS) {
    if (Math.abs(seconds) >= size || unit === 'second') {
      return rtf.format(Math.round(seconds / size), unit);
    }
  }
}

这里的"月""年"用固定秒数近似，适合"大约多久以前"的展示。"昨天"如果要严格按日历日计算（比如昨晚 23 点到今早 1 点只差 2 小时，也应显示"昨天"），要先按用户时区比较日期，再算天数差。

显示与刷新

  • 在相对时间旁边提供绝对时间，例如 <time datetime="2026-10-28T09:00:00Z" title="2026年10月28日 17:00">。
  • 按时间差决定刷新频率：一分钟内每 10 秒刷新，一小时内每分钟刷新，更早的不必自动刷新。
  • 读屏器不需要每次刷新都播报，不要把相对时间放进 live region。
  • 列表排序、是否需要刷新都用原始时间戳判断，不要解析显示出来的字符串。
  • SSR 时服务端渲染的"现在"和客户端水合时不同，"3分钟前"可能变成"4分钟前"，造成水合不一致。常见做法是服务端只输出绝对时间，客户端水合后再替换成相对时间。

与 Temporal 的关系

Temporal 已进入 TC39 第 4 阶段，预计收入 ES2027。它提供带时区和日历的日期计算（例如按日历日相减），计算结果仍然交给 Intl.RelativeTimeFormat 显示。Node 22 还没有 Temporal，使用前要做能力检测或引入 polyfill。

常见追问

  • 要按词高亮数字部分怎么办？ 用 formatToParts()，返回结果里数字部分的 type 是 'integer'。
  • 为什么不用 moment 的 fromNow()？ 可以用现成库，但 Intl 内置在运行时里，不增加包体积，语言数据也由运行时维护。
