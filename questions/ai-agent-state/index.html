Agent 前端界面怎样展示计划、工具调用和人工确认？

建模 Agent 的消息、步骤、工具状态和审批状态，避免只显示一段不可解释的最终文本。

参考答案

Agent 界面通常需要区分用户消息、模型计划、工具调用、工具结果、人工审批、重试、取消和最终回答。每一步都应有稳定 ID、时间和状态，才能支持流式更新、刷新恢复和错误定位。

工具调用不能只展示“正在执行”。用户要知道工具名称、输入范围、可能产生的副作用和是否需要确认；确认前不要执行不可逆操作，结果也要标明来源和权限。

前端状态不是 Agent 的唯一事实来源。服务端需要记录会话和执行状态，客户端刷新或断线后重新同步；不可信工具结果和检索文档不能直接升级为系统指令。
