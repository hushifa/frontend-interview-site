Web 排版中的行高、行宽和断行怎样处理？

正文行高用无单位数值，行宽控制在约 60–75 个字符或 30–40 个汉字，用 overflow-wrap 和 word-break 处理长单词与中日韩断行，可变字体用 font-weight 等高层属性控制轴。

参考答案

简答

  • line-height 写无单位数值（如 1.6），子元素按自己的字号重新计算；写 px 或 em 会把父元素算好的固定值继承下去。
  • 正文行宽用 max-inline-size: 65ch 一类的限制，过长的行会让读者找不到下一行的开头。
  • 长 URL 撑破布局时用 overflow-wrap: anywhere；word-break: break-all 会在任意字母间断开，会影响英文可读性。
  • word-break: keep-all 让中日韩文字按词或标点断行，line-break: strict 控制标点避头尾。
  • 可变字体优先用 font-weight、font-stretch、font-style 控制；font-variation-settings 是低层属性，会覆盖这些高层属性，而且多次声明时整体替换，不会按轴合并。

行高

CSS
body {
  font-size: 1rem;
  line-height: 1.6;
}

h1 {
  font-size: 2.5rem;
  line-height: 1.2;
}

如果 body 写 line-height: 24px，h1 的 40px 字号也只有 24px 行高，多行标题会重叠。

断行

CSS
.content {
  overflow-wrap: anywhere;
}

.cjk-title {
  word-break: keep-all;
}

.code {
  white-space: pre;
  overflow-x: auto;
}

overflow-wrap: break-word 和 anywhere 都只在没有其他断点时才断开单词，区别在于 anywhere 断开后的软换行机会会参与最小内容尺寸计算，flex 和 grid 项目里更不容易撑开容器。

hyphens: auto 能为英文加连字符，需要正确的 lang 属性，浏览器才知道用哪种语言的断词规则。

字体栈

CSS
body {
  font-family: system-ui, -apple-system, 'Segoe UI', 'PingFang SC',
    'Microsoft YaHei', sans-serif;
}

先写西文字体再写中文字体，英文和数字使用西文字形，汉字落到中文字体。中文 Web 字体体积大，正文通常直接用系统字体。字体加载策略见《font-display 怎样影响字体加载期间的文字显示？》。

可变字体

CSS
@font-face {
  font-family: 'Inter';
  src: url('/inter.woff2') format('woff2');
  font-weight: 100 900;
}

strong {
  font-weight: 650;
}

@font-face 里声明 font-weight 的范围后，任意数值都能用。只有自定义轴（如 GRAD）才需要 font-variation-settings。

常见追问

  • 为什么文字底部和容器有空隙？行高是在字形上下平均分配的，加上字体自身的上下留白，视觉上不居中。text-box: trim-both cap alphabetic 可以裁掉多余的空白，支持情况要查兼容表。
