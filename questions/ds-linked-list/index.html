怎样反转链表？怎样用反转判断回文链表？

反转链表用三个指针，一边遍历一边把每个节点的 next 指回前一个节点，走完后 prev 就是新的头。判断回文链表可以用快慢指针找到中点，把后半段反转，再和前半段逐个比较。两种做法都是 O(n) 时间、O(1) 额外空间。

参考答案

简答

链表是一串节点，每个节点存一个值和一个指向下一个节点的 next。它和数组不同，不能按下标直接访问第几个，只能从头一个个往后走；可是在已知节点后面插入或删除，只要改指针，不用像数组那样挪动后面的元素。

反转链表就是让每个节点的 next 改为指向它前面的节点。遍历时用三个变量：prev 是已经反转好的部分的头，current 是当前节点，next 先把下一个节点记下来，免得改了指针以后找不到后面的节点。每一步把 current.next 指向 prev，然后三个指针一起往后挪。走完以后 prev 就是新的头。

反转常被拿来组合出别的题。LeetCode 234 回文链表：判断链表正着读和倒着读是否一样。先用快慢指针找到中点，慢的每次走一步、快的每次走两步，快的走到末尾时慢的正好在中间；再把后半段反转，和前半段逐个比较值。

要注意，把值抄进数组再比较也能做，写法更直观，但要 O(n) 的额外空间。LeetCode 234 的进阶要求是 O(1) 空间，答案就是“找中点加反转后半段”。

代码实现

先用数组构造一个链表，再反转，然后用反转后半段的办法判断回文：

JavaScript
function fromArray(values) {
  let head = null;
  for (let i = values.length - 1; i >= 0; i--) {
    head = { value: values[i], next: head };
  }
  return head;
}

function toArray(head) {
  const values = [];
  for (let node = head; node; node = node.next) values.push(node.value);
  return values;
}

function reverse(head) {
  let prev = null;
  let current = head;
  while (current) {
    const next = current.next;
    current.next = prev;
    prev = current;
    current = next;
  }
  return prev;
}

function isPalindrome(head) {
  let slow = head;
  let fast = head;
  while (fast && fast.next) {
    slow = slow.next;
    fast = fast.next.next;
  }
  // 节点数为奇数时 slow 停在正中间，它和自己比较也不影响结果。
  let right = reverse(slow);
  let left = head;
  while (right) {
    if (left.value !== right.value) return false;
    left = left.next;
    right = right.next;
  }
  return true;
}

const list = fromArray([1, 2, 3, 4]);
console.log(toArray(reverse(list)).join()); // 4,3,2,1

console.log(isPalindrome(fromArray([1, 2, 2, 1]))); // true
console.log(isPalindrome(fromArray([1, 2]))); // false
console.log(reverse(null)); // null

reverse 里为什么要先存 next？因为下一行 current.next = prev 会把指向后面的指针改掉，如果没提前存起来，就再也找不到后面的节点，链表就断了。

isPalindrome 里为什么只比较到 right 走完？后半段反转以后，前半段最后一个节点的 next 仍指着中间那个节点，而中间节点已经变成反转后半段的尾巴，next 是 null。所以 right 走完时，前后两半正好都比较过了。循环条件 fast && fast.next 保证快指针走两步时不会读 null 的属性。

常见追问

怎样判断链表有没有环、找到入环点？

同样用快慢指针，相遇就说明有环，见《环形链表怎样找到入环点？为什么相遇后从头再走就能找到？》。

判断回文以后链表被改了，怎么办？

后半段已经被反转，如果调用方还要用这条链表，比较完再把后半段反转回来接上。面试时主动提这一点，说明考虑到了函数的副作用。

递归能反转链表吗？

能。先递归反转 head.next 之后的部分，再让 head.next.next = head、head.next = null。写法短，但链表很长时递归层数太多可能栈溢出，循环写法更稳妥。
