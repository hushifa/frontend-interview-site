网页打印样式应该怎样单独设计？

用 @media print 单独写一套打印样式：藏掉导航和按钮，把滚动区域展开，换成适合纸张的字号和颜色；用 @page 设页边距，用 break-* 控制在哪里分页。

参考答案

简答

网页打印出来，导航、按钮、广告在纸上都没用。所以用 @media print 写一套打印专用的样式，先把这些东西藏掉。

有固定高度和滚动条的区域要特别处理，改成 height: auto; overflow: visible。不然纸上只会印出能看到的那一截，滚动条下面的内容全丢了。

页面版式用 @page 设置，比如 @page { margin: 2cm; } 设页边距，size 设纸张方向，不过用户的打印设置可能会覆盖这些值。分页用 break-* 控制，break-inside: avoid 防止表格行、图片被切到两页，break-before: page 强制换页。

要注意，浏览器默认不打印背景色。重要信息不能只靠背景色来表达，确实要打印背景时用 print-color-adjust: exact。

一套基本的打印样式

CSS
@media print {
  nav,
  .toolbar,
  .ad {
    display: none;
  }

  body {
    font-size: 11pt;
    color: black;
  }

  .scroll-area {
    height: auto;
    overflow: visible;
  }

  a[href^='http']::after {
    content: ' (' attr(href) ')';
  }

  h2 {
    break-after: avoid;
  }

  tr,
  img {
    break-inside: avoid;
  }

  thead {
    display: table-header-group;
  }
}

@page {
  margin: 2cm;
}

链接那条规则是在链接后面把网址打出来。纸上没法点链接，印出网址读者才知道来源在哪里。

h2 的 break-after: avoid 是为了避免标题印在这一页最底下，正文却跑到下一页。

thead 那条要解释一下。thead 默认就是 table-header-group，长表格分页时，浏览器通常会在每一页重复表头。只有当你的样式把它改成了别的 display 时，才需要像这里一样明确改回来。

打印时常遇到的问题

position: fixed 的元素会在每一页都重复出现，比如固定的顶栏。打印时一般改成 static 或者直接藏掉。

懒加载的图片如果从来没进入过视口，打印时可能是空白的。可以在 beforeprint 事件里触发这些图片加载。

flex 和 grid 容器里的分页控制支持得比较弱。需要分页的长内容，尽量用普通的块布局。

怎么测试

开发者工具的 Rendering 面板可以模拟 print 媒体类型，方便调样式。但最终效果要用浏览器的打印预览确认，并且 A4 和 Letter 两种纸张都要看一下。

常见追问

要不要单独生成 PDF？

发票、合同这种格式必须固定的，用服务端生成 PDF 更可控。普通文章用打印样式就够了。
