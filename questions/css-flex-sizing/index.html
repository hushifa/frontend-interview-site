flex-basis、flex-grow、flex-shrink 如何分配空间？

每个项目先按 flex-basis 占一个初始大小；空间有多就按 flex-grow 的比例分，空间不够就按 flex-shrink 乘 flex-basis 的比例缩。min-width 这类限制最后才起作用。

参考答案

简答

浏览器先给每个项目一个初始大小，就是 flex-basis。容器的尺寸减去这些初始大小的总和，就是剩余空间。

剩余空间是正的，说明有多，按 flex-grow 的比例分给各项目。是负的，说明不够，要缩，按 flex-shrink × flex-basis 的比例分摊，大的多缩，小的少缩。

常用简写要记住：flex: 1 等于 1 1 0%，忽略内容大小，平分全部空间；flex: auto 等于 1 1 auto，先按内容占位再分剩下的；flex: none 等于 0 0 auto，保持内容尺寸，不伸也不缩。

最常踩的坑是 flex 项目默认 min-width: auto，不会缩得比最长的单词或图片还窄，内容就会溢出。想让它能缩，要写 min-width: 0。

空间有多时怎么分

容器宽 600px，两个项目的 flex-basis 都是 100px，flex-grow 分别是 1 和 2。

两个项目先占掉 200px，剩余 600 − 200 = 400px。这 400px 按 1:2 分，第一个分到三分之一，第二个分到三分之二。所以第一个是 100 + 400 × 1/3 ≈ 233px，第二个是 100 + 400 × 2/3 ≈ 367px。

要注意，flex-grow 分的是剩余空间，不是总宽度。所以最后两个项目的宽度并不是 1:2。

空间不够时怎么缩

容器宽 300px，两个项目的 flex-basis 分别是 200px 和 400px，flex-shrink 都是 1。

两个加起来 600px，要缩掉 600 − 300 = 300px。收缩权重是 flex-shrink 乘以 flex-basis，第一个是 200 × 1 = 200，第二个是 400 × 1 = 400，比例 1:2。所以第一个缩 300 × 200/600 = 100px，剩 100px；第二个缩 200px，剩 200px。

为什么收缩要乘以 basis，不直接按 flex-shrink 平分？如果平分，两个项目各缩 150px，第一个只剩 50px，小的项目会先被压得没法看。乘上 basis 以后，大项目多缩、小项目少缩，缩完比例还是 1:2。

内容为什么溢出了容器

CSS
.main {
  flex: 1;
  min-width: 0;
}

.main 里放了很长的代码行或者宽表格。不写 min-width: 0 时，你会发现它怎么都缩不下去，整行撑出了容器。

原因是 flex 项目的 min-width 默认是 auto，意思是最小不能比内容的最小宽度还窄。长代码行没法断开，它的最小宽度就是整行那么长。

写上 min-width: 0，项目就能缩到比内容窄，内容自己去滚动或者换行。另外，某个项目被最小宽度卡住缩不下去时，浏览器会把还需要缩的量重新分给其他项目。

几种常见写法

flex: 1 让项目平分空间，不管内容多宽。flex: auto 让内容多的项目分得更多。flex: none 把项目固定为内容尺寸。flex: 0 0 240px 常用来做固定 240px 宽的侧栏，不伸也不缩。

常见追问

flex-basis 和 width 都写了，听谁的？

flex-basis 不是 auto 时，听 flex-basis 的。只有 flex-basis: auto 时，才用 width 作为初始大小。
