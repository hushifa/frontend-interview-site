flex-basis、flex-grow、flex-shrink 如何分配空间？

flex-basis 给出项目的初始尺寸；有剩余空间时按 flex-grow 比例分配，空间不足时按 flex-shrink 乘以 flex-basis 的比例收缩；min-width 等约束最后生效。

参考答案

简答

  • 先算每个项目的 flex-basis，再用容器尺寸减去它们的总和，得到剩余空间。
  • 剩余空间为正时，按 flex-grow 的比例分给各项目；为负时，按 flex-shrink × flex-basis 的比例分摊收缩量。
  • flex 项目默认 min-width: auto，不会缩到比最长单词或图片更窄；需要能缩时设 min-width: 0。
  • flex: 1 等于 1 1 0%，各项目平分全部空间；flex: auto 等于 1 1 auto，先按内容占位再分剩余。
  • flex: none 等于 0 0 auto，项目保持内容尺寸，不伸也不缩。

放大

容器 600px，两个项目 flex-basis 都是 100px，flex-grow 分别为 1 和 2：

  • 剩余空间：600 − 200 = 400px。
  • 第一个：100 + 400 × 1/3 ≈ 233px；第二个：100 + 400 × 2/3 ≈ 367px。

收缩

容器 300px，两个项目 flex-basis 分别是 200px 和 400px，flex-shrink 都是 1：

  • 需要收缩：600 − 300 = 300px。
  • 收缩权重：200 × 1 = 200，400 × 1 = 400。
  • 第一个缩 300 × 200/600 = 100px，得 100px；第二个缩 200px，得 200px。

收缩乘以 basis，是为了让大项目多缩、小项目少缩，避免小项目先被压没。

min-width: auto 的影响

CSS
.main {
  flex: 1;
  min-width: 0;
}

.main 里有很长的代码行或表格时，不加 min-width: 0 它不会缩到小于内容宽度，整行会溢出容器。项目被约束卡住后，浏览器会把剩下的空间重新分给其他项目。

常见写法

写法含义
flex: 1平分空间，忽略内容宽度
flex: auto内容大的项目分得更多
flex: none固定为内容尺寸
flex: 0 0 240px固定 240px 的侧栏

常见追问

  • flex-basis 和 width 哪个优先？两者都设置时 flex-basis（非 auto）优先，flex-basis: auto 时才使用 width。
