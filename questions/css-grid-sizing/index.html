Grid 的 fr、minmax、auto-fit 和 auto-fill 如何使用？

fr 按比例分剩下的空间，minmax 给列宽定上下限，repeat 加 auto-fill 或 auto-fit 能按容器宽度自动决定放几列。两者的区别是空出来的列留着还是收起来。

参考答案

简答

fr 是“份”的意思，分的是去掉固定宽度的列和间距以后剩下的空间，1fr 2fr 就是按 1:2 分。

要注意 1fr 的最小值是 auto，内容很宽时这一列会被撑开。想严格等分，要写 minmax(0, 1fr)。

想让列数跟着容器宽度变，用 repeat(auto-fill, minmax(200px, 1fr))，它会尽量多放列。auto-fit 规则一样，区别在于项目少、放不满一行时，auto-fill 把空列留着，auto-fit 把空列收成 0，让已有的项目拉宽铺满。

项目多到能填满一行时，两者的结果完全一样。

auto-fill 和 auto-fit 差在哪里

CSS
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  gap: 16px;
}

容器宽 1000px，间距 16px，每列至少 200px，算下来可以放 4 列。现在只有 2 个项目，会怎样？

用 auto-fill，浏览器还是生成 4 列，2 个项目各占一列，右边空着两列。用 auto-fit，空着的 2 列被收成 0 宽，2 个项目各自拉宽到约 492px，铺满整行。

所以商品列表这种希望每张卡片大小一致的，用 auto-fill；希望项目少时也铺满一行的，用 auto-fit。

为什么写了 1fr，页面还是出现横向滚动条

CSS
.layout {
  grid-template-columns: 240px minmax(0, 1fr);
}

侧栏固定 240px，主区占剩下的空间。如果第二列只写 1fr，主区里放一张很宽的表格或一段很长的代码，整个页面就会出现横向滚动条。

原因是 1fr 其实等于 minmax(auto, 1fr)，最小值是 auto，也就是内容的最小宽度，内容多宽这一列就至少多宽。写成 minmax(0, 1fr)，允许这一列比内容窄，内容自己在里面滚动。

项目超出了定义的行怎么办

项目比你定义的行还多时，浏览器会自动加行，这些自动加出来的行叫隐式轨道，高度由 grid-auto-rows 决定：

CSS
.grid {
  grid-auto-rows: minmax(120px, auto);
}

每行至少 120px，内容多时自动变高。

常见追问

容器比 200px 还窄时，minmax(200px, 1fr) 会怎样？

列不会小于 200px，所以会溢出容器。可以改成 minmax(min(200px, 100%), 1fr)，容器很窄时，最小值变成容器宽度，退成一列。
