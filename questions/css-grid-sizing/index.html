Grid 的 fr、minmax、auto-fit 和 auto-fill 如何使用？

fr 按比例分配网格剩余空间，minmax 约束轨道尺寸范围，auto-fill 与 auto-fit 自动决定重复列数；两者的关键差别是是否折叠没有项目占用的重复轨道。

参考答案

做一个商品列表时，通常要解决三件事：一行能放几列，每列如何瓜分空间，以及商品只有一两个时要不要把它们拉得很宽。fr、minmax() 和自动重复分别处理这些问题，不是几个可以随意互换的写法。

fr 分的是剩余空间

CSS
.layout {
  display: grid;
  width: 900px;
  gap: 20px;
  grid-template-columns: 200px minmax(0, 1fr) minmax(0, 2fr);
}

假设没有额外的尺寸约束，先扣掉第一列的 200px 和两个 20px 间隙，还剩 660px。后两列按 1:2 分配，分别得到 220px、440px。

所以 1fr 2fr 不是各占容器总宽度的三分之一和三分之二，它们还要考虑固定轨道、间隙以及轨道自身的尺寸限制。相较直接写百分比，fr 在分配空间时会计入 gap，避免“列宽已经占满 100%，再加间隙就溢出”的常见问题。

为什么常写 minmax(0, 1fr)

单独的 1fr 轨道隐含了自动最小值，通常可以理解成 minmax(auto, 1fr)。自动最小值可能受网格项目的内容贡献影响，因此一段很长、不能换行的内容有机会把轨道撑大。

minmax(0, 1fr) 把轨道最小值明确设为 0，让这一列可以小于内容原本要求的最小宽度。但允许列缩小，不等于内容已经能正确展示：

CSS
.article-layout {
  display: grid;
  grid-template-columns: 15rem minmax(0, 1fr);
  gap: 1rem;
}

.article-layout > main {
  min-width: 0;
  overflow-wrap: anywhere;
}

.article-layout pre {
  max-width: 100%;
  overflow: auto;
}

这里正文可以换行，代码块在自身范围内横向滚动。把所有内容直接设成 overflow: hidden 虽然也能遮住溢出，却可能让用户看不到完整代码，不能混为一种修复。

minmax() 的两个参数是轨道最小值与最大值，例如 minmax(12rem, 1fr) 表示至少 12rem，有余地时参与弹性分配。它不是“先按 1fr 算，再保证一定不溢出”，当容器小于 12rem 时，这个固定下限本身仍可能造成溢出。

自动列数和窄屏下限一起处理

HTML
<div class="cards">
  <article>课程一</article>
  <article>课程二</article>
  <article>课程三</article>
</div>
CSS
.cards {
  display: grid;
  gap: 1rem;
  grid-template-columns: repeat(auto-fit, minmax(min(100%, 16rem), 1fr));
}

.cards > article {
  min-width: 0;
  overflow-wrap: anywhere;
}

repeat() 重复的是轨道定义。这里浏览器会按当前容器宽度和间隙，计算能容纳多少列，而不是我们手动枚举手机两列、平板三列等断点。

min(100%, 16rem) 在空间足够时提供 16rem 的下限，容器比这个值更窄时则允许下限降为容器宽度。否则直接写 minmax(16rem, 1fr)，在非常窄的侧栏里即使只排一列，也可能超出容器。

这类规则适合容器宽度已由页面布局明确分配的普通卡片列表。如果容器自身宽度完全依靠内容推导，自动重复和百分比尺寸的解析还会涉及内在尺寸规则，不能拿固定宽度下的计算直接套用。

auto-fill 和 auto-fit 到底差在哪

把例子简化为宽 700px 的容器、20px 间隙、最小列宽 200px。一行最多能容纳三列，因为 3 × 200 + 2 × 20 = 640px，而四列放不下。

如果只有两个项目：

  • repeat(auto-fill, minmax(200px, 1fr)) 保留三条轨道，三列各分得 220px。第三列虽然没有项目，仍然占位。
  • repeat(auto-fit, minmax(200px, 1fr)) 先按相同方式计算轨道数，再折叠空轨道及相应间隙。两个项目所在的列各分得 340px。

如果三列都被占用，两种方式往往看起来没有区别。auto-fit 折叠的是整条没有流内项目放入或跨越的重复轨道，不是逐行删除每一行末尾的空格子。因此有四个项目时，第一行占满三列、第二行只有一个项目，第二行这个项目不会自动独占整行。

希望商品卡片在数量少时仍保持类似的列槽位，可以选 auto-fill；希望少量内容主动铺满一行，可以选 auto-fit。如果需要最后一行的每项单独伸展，可能更适合按行分配空间的 Flex，或者另行设计布局规则。
