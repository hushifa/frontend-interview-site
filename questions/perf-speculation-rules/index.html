Speculation Rules API 的预取和预渲染有什么区别？

用 <script type="speculationrules"> 声明哪些链接可以提前处理。prefetch 只下载目标页面的 HTML，不下载子资源；prerender 在隐藏标签页里完整加载并执行页面，切换时几乎瞬间显示。eagerness 控制触发时机。它不是 Baseline，不支持的浏览器会忽略规则。

参考答案

简答

  • prefetch：只取目标文档的响应正文，不取子资源，成本低，可以较广泛使用。
  • prerender：取文档、加载所有子资源、执行 JavaScript，资源消耗接近渲染一个 iframe，只用于高概率访问的页面。
  • eagerness：immediate 立即执行，eager 在 Chromium 中目前与 immediate 行为相同，moderate 在桌面端悬停约 200ms 或按下指针时，conservative 在按下指针或触摸时。列表规则默认 immediate，文档规则默认 conservative。
  • 预渲染默认只限同源；同站跨源需要目标页面返回 Supports-Loading-Mode: credentialed-prerender，跨站不支持。
  • 预渲染的页面会执行代码，统计、广告曝光等副作用要等页面真正被用户看到再执行。

规则示例

HTML
<script type="speculationrules">
  {
    "prerender": [
      {
        "where": {
          "and": [
            { "href_matches": "/questions/*" },
            { "not": { "selector_matches": ".no-prerender" } }
          ]
        },
        "eagerness": "moderate"
      }
    ],
    "prefetch": [{ "urls": ["/questions/"], "eagerness": "immediate" }]
  }
</script>
  • 退出登录、加入购物车这类会改变状态的链接必须排除。
  • 使用 CSP 时，内联规则需要 'inline-speculation-rules'、nonce 或 hash。
  • 也可以通过响应头 Speculation-Rules: "/rules.json" 下发，文件类型为 application/speculationrules+json。

处理预渲染的副作用

JavaScript
function whenVisible(callback) {
  if (document.prerendering) {
    document.addEventListener('prerenderingchange', callback, { once: true });
  } else {
    callback();
  }
}

whenVisible(() => sendPageView());
  • 预渲染期间，地理位置、通知、getUserMedia 等 API 会延迟到激活后执行。
  • 服务器可以通过 Sec-Purpose: prefetch 或 Sec-Purpose: prefetch;prerender 请求头识别推测请求。
  • 判断页面是否经过预渲染：performance.getEntriesByType('navigation')[0].activationStart > 0。

兼容性

MDN 标注其为实验性、有限可用。检测支持：

JavaScript
if (HTMLScriptElement.supports?.('speculationrules')) {
  // 动态插入规则
}

不支持的浏览器会忽略规则，页面照常工作，可以用 <link rel="prefetch"> 作为下一页资源的降级方案。浏览器也可能因为省电、省流量模式或内存不足不执行推测。

验证

  • DevTools 的 Application 面板有 Speculative loads 视图，可以看到规则和每个 URL 的状态。
  • 用真实用户数据对比被预渲染导航和普通导航的 LCP。
  • 返回 2xx 以外的状态码时预取或预渲染不会生效，204 和 205 还会阻止预渲染。

常见追问

  • 和 <link rel="prefetch"> 有什么区别？后者预取任意资源并放入 HTTP 缓存；Speculation Rules 针对整页导航，结果存在按文档隔离的内存缓存里。
  • 会不会浪费流量？prerender 会，要配合 moderate 或 conservative，并限制匹配范围。
