TypeScript 怎样通过控制流缩小类型？

TypeScript 根据 typeof、instanceof、in、相等比较、真值判断和提前返回，在每条执行路径上缩小变量的类型。自定义类型守卫和断言函数可以把运行时检查的结论告诉编译器，as 断言则不做任何检查。对象属性的收窄在回调中会失效，let 变量在最后一次赋值之后创建的闭包里可以保留收窄（5.4+）。

参考答案

简答

  • typeof、instanceof、in、===、Array.isArray、真值判断、return/throw 提前退出都会让后续代码中的类型变窄。
  • typeof x === 'object' 仍包含 null；真值判断会同时排除 0、''、false。
  • 自定义类型守卫 (v): v is T 在返回 true 时把参数收窄为 T；断言函数 asserts v is T 在正常返回后收窄。两者的正确性都由实现者负责。
  • as T 只改变编译器看待值的方式，不生成任何检查。
  • 收窄在回调中可能失效：const 变量的收窄会保留；对象属性在回调里会退回原类型；let 变量和参数在最后一次赋值之后创建的闭包里可以保留收窄（TS 5.4+）。需要时先存入局部 const。

提前返回

TypeScript
function format(value: string | number | null): string {
  if (value === null) return '暂无';
  if (typeof value === 'number') return value.toFixed(2);
  return value.trim();
}

每次 return 都从后续路径上排除一种类型，最后只剩 string。

in 与属性类型

TypeScript
function readTitle(value: unknown): string | undefined {
  if (typeof value !== 'object' || value === null) return undefined;
  if ('title' in value && typeof value.title === 'string') {
    return value.title;
  }
  return undefined;
}

'title' in value 只证明属性存在（含原型链），类型是 unknown，还需要再判断类型。

类型守卫与断言函数

TypeScript
type User = { name: string; age: number };

function isUser(value: unknown): value is User {
  return typeof value === 'object' && value !== null &&
    'name' in value && typeof value.name === 'string' &&
    'age' in value && typeof value.age === 'number';
}

function assertUser(value: unknown): asserts value is User {
  if (!isUser(value)) throw new TypeError('不是有效的 User');
}

const input: unknown = JSON.parse('{"name":"Lin","age":24}');
assertUser(input);
console.log(input.name.toUpperCase());

守卫写错（例如总是返回 true），编译器不会发现。TypeScript 5.5 起，filter(x => x !== undefined) 这类简单箭头函数会被自动推断为类型守卫，结果类型去掉 undefined。

回调中的收窄

TypeScript
function printLater(box: { label?: string }) {
  if (typeof box.label === 'string') {
    setTimeout(() => {
      // box.label 在这里是 string | undefined，外部可能已修改
    }, 0);
    const label = box.label;
    setTimeout(() => console.log(label.toUpperCase()), 0);
  }
}

TypeScript 5.4 起，在最后一次赋值之后创建的闭包中，let 变量和参数的收窄可以保留；对象属性的收窄在回调中仍会失效。
