Angular 中 Observable 和 Signals 怎样协作？

Observable 适合描述随时间到达的事件和异步流，可以组合、取消；Signal 适合表示可以随时同步读取的当前状态。用 toSignal 把 Observable 转为 Signal 给模板使用，用 toObservable 把 Signal 变化接入 RxJS 管道。

参考答案

简答

  • Signal 总有当前值，读取是同步的；Observable 是推送的事件流，可能还没有值，也可能已经完成或出错。
  • toSignal(obs$) 订阅 Observable，把最新值作为 Signal 返回，组件销毁时自动取消订阅；在第一个值到达前，Signal 的值是 undefined，可以用 initialValue 指定。
  • toObservable(sig) 在 Signal 变化后发出新值，适合接入 debounceTime、switchMap 等操作符。
  • 需要防抖、取消上一次请求、合并多个事件流时，RxJS 更合适；表示界面状态和派生值时，Signal 更简单。
  • toSignal 遇到 Observable 出错时，读取该 Signal 会抛出错误，所以要在管道中用 catchError 处理。

搜索框：Signal 输入 → RxJS 处理 → Signal 输出

TypeScript
import { Component, inject, signal } from '@angular/core';
import { toObservable, toSignal } from '@angular/core/rxjs-interop';
import { HttpClient } from '@angular/common/http';
import { catchError, debounceTime, distinctUntilChanged, of, switchMap } from 'rxjs';

@Component({
  selector: 'app-search',
  template: `
    <input [value]="query()" (input)="query.set($any($event.target).value)" />
    @for (item of results(); track item.id) {
      <p>{{ item.title }}</p>
    }
  `,
})
export class SearchComponent {
  private http = inject(HttpClient);
  readonly query = signal('');

  readonly results = toSignal(
    toObservable(this.query).pipe(
      debounceTime(300),
      distinctUntilChanged(),
      switchMap((q) =>
        q
          ? this.http
              .get<{ id: number; title: string }[]>(`/api/search?q=${encodeURIComponent(q)}`)
              .pipe(catchError(() => of([])))
          : of([]),
      ),
    ),
    { initialValue: [] },
  );
}
  • switchMap 在新查询到来时取消上一次未完成的请求。
  • initialValue 让模板在第一次请求完成前也能直接遍历。
  • catchError 写在 switchMap 内部的请求上：如果放在外层管道，一次出错就会让整个流结束，之后的输入不再触发搜索。

订阅清理

  • toSignal 和 async 管道会自动取消订阅。

  • 手动订阅时用 takeUntilDestroyed()：

    TypeScript
    this.socket.messages$.pipe(takeUntilDestroyed()).subscribe((m) => this.messages.update((l) => [...l, m]));

    在构造期间调用无需参数，其他位置需要传入 DestroyRef。

也可以用 resource

只需要"根据参数请求一次数据"时，Angular 的 resource / rxResource 直接把参数 Signal 和异步加载结合起来，不必手动转换，见《Angular Signals 的依赖追踪与 computed 有什么特点？》。

常见追问

  • toSignal 能在组件外调用吗？必须在注入上下文中调用，否则要传入 injector 选项。
  • 同步发出值的 Observable（如 BehaviorSubject）能省略初始值吗？可以设置 requireSync: true，类型中就不会包含 undefined。
