迭代器、可迭代对象和 Generator 有什么关系？

可迭代对象实现 [Symbol.iterator]()，返回迭代器；迭代器的 next() 每次返回 { value, done }。for...of、展开、解构都按这个协议取值。Generator 函数用 yield 暂停执行，自动实现两个协议。ES2025 的 Iterator helpers 让迭代器可以直接链式调用 map、filter、take。

参考答案

简答

  • 可迭代对象：有 [Symbol.iterator]() 方法，每次调用返回一个新的迭代器。数组、字符串、Map、Set 都是可迭代对象，普通对象不是。
  • 迭代器：有 next() 方法，返回 { value, done }，记录本次遍历的位置。
  • Generator 函数调用后返回生成器对象，它既是迭代器又是可迭代对象（[Symbol.iterator]() 返回自身），所以只能遍历一次。
  • 生成器惰性执行：第一次 next() 才开始运行函数体，每次运行到 yield 暂停。
  • ES2025 的 Iterator helpers 在迭代器上提供 map、filter、take、drop、flatMap、reduce、toArray 等惰性方法。

手写可迭代对象

JavaScript
function range(start, end) {
  if (!Number.isSafeInteger(start) || !Number.isSafeInteger(end)) {
    throw new TypeError('区间端点必须是安全整数');
  }
  return {
    [Symbol.iterator]() {
      let current = start;
      return {
        next() {
          if (current >= end) return { done: true, value: undefined };
          return { done: false, value: current++ };
        },
      };
    },
  };
}

const numbers = range(2, 5);
console.log([...numbers].join(',')); // 2,3,4
console.log([...numbers].join(',')); // 2,3,4
const iterator = numbers[Symbol.iterator]();
const first = iterator.next();
console.log(first.value); // 2
console.log(first.done); // false

每次展开都会调用 [Symbol.iterator]() 得到新的游标，所以能重复遍历。

Generator 的执行过程

JavaScript
function* sequence() {
  console.log('开始执行');
  const reply = yield 1;
  console.log(reply);
  return 9;
}

const it = sequence();
console.log('已创建');
console.log(it.next().value);     // 开始执行 → 1
console.log(it.next('收到').value); // 收到 → 9
console.log(it.next().done);      // true
  • next(x) 的参数成为上一个 yield 表达式的值；第一次 next 的参数没有对应的 yield，会被忽略。
  • return 的值伴随 done: true，for...of 和展开不会包含它。
  • yield* iterable 把遍历委托给另一个可迭代对象。
  • 生成器不是线程，next() 之后的同步代码仍占用主线程，直到下一个 yield。

Iterator helpers（ES2025）

JavaScript
function* naturals() {
  let n = 1;
  while (true) yield n++;
}

const result = naturals()
  .filter((n) => n % 2 === 0)
  .map((n) => n * n)
  .take(3)
  .toArray();
console.log(result); // [4, 16, 36]

除 map、filter、take 外，惰性方法还有 drop（跳过前 n 项）和 flatMap（展开每项返回的迭代器）。每个方法返回新的迭代器，只有 toArray、reduce、forEach、some、every、find 会真正消费。对无限序列也只计算需要的项。数组要先调用 values() 才能使用这些方法；Iterator.from(obj) 把只有 next() 的对象包装成支持 helpers 的迭代器。

用途

  • 惰性序列：分页、树遍历、无限 ID 生成。
  • 让自定义数据结构支持 for...of 和展开。
  • 状态机：用暂停点代替手写的状态变量。

[...iterator] 会一次性取出全部值，对无限序列会永不结束。提前退出时的清理见《JavaScript 迭代器关闭和 return 方法有什么作用？》，异步数据源见《异步迭代器和 for await...of 适合处理什么数据？》。

常见追问

  • 怎样让普通对象可以 for...of？给它加 *[Symbol.iterator]() { yield* Object.entries(this); }。
  • 生成器的 throw() 做什么？在暂停的 yield 处抛出错误，可以被生成器内部的 try/catch 捕获。
