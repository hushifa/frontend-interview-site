subgrid 如何让嵌套组件对齐父网格？

普通的嵌套网格自己算自己的行列，跟外面的网格没关系；写成 subgrid 后，子网格直接用父网格的行列，所以不同卡片里的标题、按钮能对齐成一排。

参考答案

简答

一排卡片，每张都有标题、正文、按钮。有的标题一行，有的两行，结果各张卡片的按钮高低不齐。原因是每张卡片自己是一个网格，自己算自己的行高，互相不知道。

subgrid 让子网格不自己定义行列，直接借用父网格的。条件是子网格本身是父网格的一个项目，并且跨了若干行或列，借用的就是它跨的那几条。

行和列可以分开设置。只写 grid-template-rows: subgrid 时，列还可以自己定义。子网格默认继承父网格的 gap，也可以自己改。

典型用途就是卡片列表对齐和表单的标签对齐。subgrid 主流浏览器都已经支持了。

让卡片里的内容对齐

CSS
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(220px, 1fr));
  gap: 16px;
}

.card {
  display: grid;
  grid-row: span 3;
  grid-template-rows: subgrid;
}
HTML
<div class="cards">
  <article class="card">
    <h3>标题</h3>
    <p>正文长短不一</p>
    <a href="/a">查看</a>
  </article>
</div>

每张卡片在父网格里跨 3 行，subgrid 让它直接用这 3 行，标题、正文、链接分别放进去。

现在这 3 行是父网格的行，同一排所有卡片共用。某张卡片的标题换成两行，这一行变高，同一排所有卡片的标题区一起变高，下面的按钮还是对齐的。

不用 subgrid 时，常见的办法是给标题固定高度，或者用 flex 把按钮推到底部。后一种只能让最后一项对齐，标题和正文的分界线还是参差不齐。

表单标签对齐

CSS
.form {
  display: grid;
  grid-template-columns: max-content 1fr;
}

.field {
  display: grid;
  grid-column: span 2;
  grid-template-columns: subgrid;
}

每个 .field 里包着一个 label 和一个 input，HTML 结构保持完整。因为用的是父网格的两列，所有 label 这一列的宽度，由最长的那个 label 决定，输入框就能左边对齐。

常见追问

subgrid 和 display: contents 有什么区别？

display: contents 是让元素自己的盒子消失，子元素直接变成父网格的项目。代价是元素自己的背景、边框没了，有的浏览器里语义也会丢。subgrid 保留了元素的盒子，背景、边框、语义都在。
