subgrid 如何让嵌套组件对齐父网格？

普通嵌套 Grid 自己计算轨道，和父网格互不相关；子网格写 grid-template-rows 或 columns 为 subgrid 后，直接使用父网格中自己所跨的轨道，跨组件对齐由此变得简单。

参考答案

简答

  • 子网格必须本身是父网格的项目，并跨越若干轨道，subgrid 使用的就是这几条轨道。
  • 行和列可以分别设置：只写 grid-template-rows: subgrid 时，列仍可自己定义。
  • 典型用途是卡片列表：每张卡片的标题、正文、按钮分别对齐成一行，而不受其他卡片内容长短影响。
  • 子网格继承父网格的 gap，也可以自己覆盖。
  • subgrid 已被主流浏览器支持。

卡片对齐

CSS
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(220px, 1fr));
  gap: 16px;
}

.card {
  display: grid;
  grid-row: span 3;
  grid-template-rows: subgrid;
}
HTML
<div class="cards">
  <article class="card">
    <h3>标题</h3>
    <p>正文长短不一</p>
    <a href="/a">查看</a>
  </article>
</div>

每张卡片占父网格的 3 行，标题、正文、链接分别落在这 3 行里。某张卡片的标题换成两行时，同一行所有卡片的标题区一起变高，按钮依然对齐在底部。

不用 subgrid 时，常见做法是给标题固定高度或用 flex 把按钮推到底部，只能对齐最后一项。

表单对齐

CSS
.form {
  display: grid;
  grid-template-columns: max-content 1fr;
}

.field {
  display: grid;
  grid-column: span 2;
  grid-template-columns: subgrid;
}

每个 .field 包着 label 和 input，保留语义结构，而所有 label 列宽由最长的那个决定。

常见追问

  • 和 display: contents 有什么区别？contents 让元素的盒子消失，子元素直接参与父网格，但元素自身的背景、边框和部分浏览器中的语义会丢失。subgrid 保留了元素的盒子。
