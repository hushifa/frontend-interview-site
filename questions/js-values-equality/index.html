JavaScript 的值类型与相等比较应该怎样理解？

JavaScript 有 7 种原始类型和对象。原始值按值比较，对象按身份比较。===、Object.is 和 SameValueZero 都不做类型转换，区别只在 NaN 和正负零；== 会按规则转换类型。没有哪个运算符做深度比较。

参考答案

简答

  • 原始类型有 7 种：undefined、null、boolean、number、bigint、string、symbol，其余都是对象。
  • 原始值按值比较；对象按身份比较，两个属性相同的对象也不相等。
  • === 不转换类型，但 NaN !== NaN，+0 === -0。
  • Object.is 认为 NaN 等于自身，并区分 +0 和 -0。
  • Map、Set、includes 用 SameValueZero：NaN 等于自身，+0 等于 -0。

JavaScript
console.log(NaN === NaN); // false
console.log(Object.is(NaN, NaN)); // true
console.log(Object.is(+0, -0)); // false
console.log(new Set([NaN, NaN, +0, -0]).size); // 2

判断 NaN 用 Number.isNaN。全局 isNaN 会先转数字，isNaN('abc') 也是 true。

对象比较身份

JavaScript
const first = { count: 1 };
const second = { count: 1 };
const alias = first;

console.log(first === second); // false
console.log(first === alias);  // true
alias.count = 2;
console.log(first.count);      // 2

所以 new Set([{ id: 1 }, { id: 1 }]) 有两项。按业务 ID 去重时应提取 ID 作为键。

函数参数是按值传递的，只是对象的"值"是引用。函数内修改参数对象的属性，调用方能看到；函数内给参数重新赋值，调用方的变量不变。

宽松相等

JavaScript
console.log(0 == '');       // true
console.log(false == '0');  // true
console.log([] == false);  // true
console.log([] == []);     // false

== 把布尔值转成数字，字符串和数字比较时把字符串转成数字，对象和原始值比较时先把对象转成原始值。[] == false 是 '' == 0，结果为 true，但 Boolean([]) 是 true。两个对象比较时只看身份。

日常用 ===。value == null 同时匹配 null 和 undefined，是唯一常见的有意使用。

typeof 的特例

  • typeof null === 'object' 是历史遗留。
  • 函数返回 'function'，数组返回 'object'，判断数组用 Array.isArray。
  • new Boolean(false) 是对象，在条件判断中为真。

深度相等

语言没有内置深度比较。实现时要决定：数组顺序是否重要、Date 比时间值、Map 和 Set 如何比、循环引用、原型是否参与。JSON.stringify 比较会受属性顺序影响，并丢失 undefined、函数等值。有稳定 ID 的业务数据直接比 ID。

常见追问

  • "原始值在栈上、对象在堆上"对吗？这是引擎实现细节，语言规范只规定可观察的语义。
  • 原始值不可变是什么意思？str[0] = 'x' 不会改变字符串；给变量赋新字符串是换绑定的值。
