DataView 怎样读取指定字节序的二进制数据？

DataView 在 ArrayBuffer 上按任意字节偏移读写不同数值类型，每次调用可指定字节序，默认大端。网络协议和文件格式常用大端，TypedArray 则按平台字节序（通常是小端）。解析前要校验长度，越界读取会抛 RangeError。

参考答案

简答

  • DataView 用 getUint16(offset, littleEndian) 这类方法在任意字节偏移读写，不要求对齐。
  • 第二个参数省略或为 false 时按大端，true 时按小端。
  • TypedArray 使用平台字节序，主流平台都是小端，所以解析大端协议要用 DataView。
  • 读取越过视图末尾时抛 RangeError，解析前先检查 byteLength。
  • ES2025 新增 Float16Array、getFloat16/setFloat16 和 Math.f16round，MDN 标注为 Baseline 2025。

大端与小端

JavaScript
const buffer = new ArrayBuffer(2);
const view = new DataView(buffer);
view.setUint16(0, 0x1234); // 未传 littleEndian，按大端写入

console.log(new Uint8Array(buffer).join(',')); // 18,52
console.log(view.getUint16(0)); // 4660，也就是 0x1234
console.log(view.getUint16(0, true)); // 13330，也就是 0x3412

大端把高位字节放在低地址：0x12 在前、0x34 在后。按小端重新读取同样两个字节就得到 0x3412。

解析一个协议头

假设协议头为：1 字节版本、1 字节类型、4 字节大端无符号长度。

JavaScript
function parseHeader(buffer) {
  const view = new DataView(buffer);
  if (view.byteLength < 6) throw new RangeError('协议头不完整');

  const header = {
    version: view.getUint8(0),
    type: view.getUint8(1),
    length: view.getUint32(2),
  };
  if (view.byteLength < 6 + header.length) throw new RangeError('消息体不完整');
  return header;
}

注意事项：

  • getInt* 与 getUint* 对同样字节的解释不同，0xff 用 getInt8 读是 -1。
  • 64 位整数用 getBigUint64/getBigInt64，返回 BigInt。
  • 从 Uint8Array 创建视图时要带上偏移：new DataView(u8.buffer, u8.byteOffset, u8.byteLength)，否则会读到整个底层缓冲区。

Float16

JavaScript
if (typeof Float16Array === 'function') {
  const half = new Float16Array([1.1]);
  console.log(half[0]); // 1.099609375，半精度只有约 3 位有效数字
}

半精度用于 WebGPU、机器学习模型权重等节省带宽的场景。Node.js 22 还没有 Float16Array，使用前做能力检测。

常见追问

  • 怎样判断当前平台字节序？new Uint8Array(new Uint16Array([1]).buffer)[0] === 1 为小端。
  • 文本怎么读？用 new TextDecoder('utf-8').decode(new Uint8Array(buffer, offset, length))。
