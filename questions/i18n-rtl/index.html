前端页面如何支持从右到左的语言？

阿拉伯语、希伯来语页面用 dir="rtl" 声明方向、lang 声明语言，布局使用 CSS 逻辑属性，混合方向的文本用 bdi 或 dir="auto" 隔离；图标按语义决定是否镜像，并检查键盘顺序和挂到 body 的浮层。

参考答案

简答

  • 在 <html> 上同时写 lang="ar" 和 dir="rtl"。lang 说明语言，dir 说明基础方向，写了其中一个不会自动推出另一个。
  • 布局用逻辑属性：margin-inline-start、padding-inline、inset-inline-end、text-align: start，切换方向时无需另写一套样式。
  • 用户名、产品名、数字等方向不确定的内容用 <bdi> 或 dir="auto" 隔离，不要手动反转字符串。代码块保持 dir="ltr"。
  • 表示前进、返回的箭头要镜像；品牌标志、播放按钮、数字不镜像。按语义逐个判断，不要整体 scaleX(-1)。
  • Flex 和 Grid 会随 direction 自动调整顺序，再加 row-reverse 会把顺序又反回去。

声明方向

HTML
<html lang="ar" dir="rtl">

用户切换语言时同步更新这两个属性。通过 portal 挂到 body 的弹窗和提示框，要确认它们继承了正确的方向。

逻辑属性

CSS
.card {
  padding-inline: 1rem;
  border-inline-start: 3px solid currentColor;
  text-align: start;
}

.card__action {
  margin-inline-start: auto; /* LTR 下推到右边，RTL 下推到左边 */
}

.close-button {
  position: absolute;
  inset-inline-end: 0.75rem;
  inset-block-start: 0.75rem;
}

在水平书写模式下，inline-start 在 LTR 中是左边、在 RTL 中是右边。确实要固定在物理位置的装饰，仍可以用 left、right。

混合方向的文本

HTML
<p>
  المستخدم <bdi>Alice_42</bdi> علّق
</p>
<pre dir="ltr"><code>const total = price * count;</code></pre>

<bdi> 让里面的文本独立判断方向，用户名里的数字和标点不会把周围的阿拉伯文排乱。

双向控制字符（如 U+202E）可以让文本显示顺序和实际顺序不同，被用来伪装文件名或代码。显示用户提供的标识符时，检测并过滤这些字符，<bdi> 只解决排版，不解决这个安全问题。

交互检查

  • 视觉上从右到左排列后，Tab 顺序也应从右到左。用 order 或 row-reverse 调整的位置不会改变 Tab 顺序，优先保持 DOM 顺序合理。
  • 滑块、标签页、菜单的左右方向键在 RTL 下语义相反，按组件模式处理。
  • 用真实的阿拉伯文和希伯来文测试，加上数字、英文混排和长文本。

常见追问

  • direction: rtl 和 dir="rtl" 有什么区别？ dir 是 HTML 语义，会影响双向文本算法和可访问性；CSS direction 只是样式。优先使用 dir。
  • 怎样根据语言自动得到方向？ 用 Intl.Locale 的 getTextInfo()，见《Intl.Locale 解决什么问题？语言标签应该怎样建模？》。
