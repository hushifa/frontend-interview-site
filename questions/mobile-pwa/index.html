PWA 由哪些能力组成，是否所有浏览器体验都一致？

参考答案

PWA 使用 Web 技术提供接近应用的体验，常见能力包括可安装元信息、离线或弱网支持，以及与平台能力的渐进集成。Web App Manifest 描述名称、图标和启动方式等，Service Worker 可用于缓存与网络控制。

安装条件和平台能力因浏览器与操作系统而异，不能把某个平台的安装提示或后台行为当成统一保证。即使没有安装，基础网站也应该可正常访问。

离线支持需要设计资源缓存、数据同步和失败提示，而不只是注册一个 worker。更新策略也很重要：用户可能长时间停留在旧版本，发布时应避免旧 HTML 与新资源互不匹配。
