动态规划怎么入门？爬楼梯和最小路径和怎样做？

动态规划把大问题拆成重叠的小问题，用数组记住小问题的答案，避免重复计算。写的时候先定义状态 dp[i] 表示什么，再找转移方程和初始值。爬楼梯 dp[i] = dp[i-1] + dp[i-2]；最小路径和 dp[i][j] = grid[i][j] + min(上方, 左方)，第一行和第一列只有一条来路，可以压成一维数组。

参考答案

简答

爬楼梯：每次能上 1 级或 2 级，上到第 n 级有几种走法？到第 n 级的最后一步，要么从第 n-1 级跨 1 级上来，要么从第 n-2 级跨 2 级上来，所以走法数等于这两者之和。大问题的答案由更小问题的答案组成，这就是动态规划能用的前提。

直接写递归 f(n) = f(n-1) + f(n-2) 会很慢，因为 f(n-2) 在算 f(n-1) 时又会被算一遍，越往下重复越多，是指数级。动态规划的做法是把算过的结果存起来，从小到大依次算，每个只算一次，变成 O(n)。

解题分三步：先定义状态，dp[i] 代表什么；再找转移方程，dp[i] 怎样由前面的值算出来；最后定初始值，最小的几个答案是多少。想清楚 dp[i] 的含义是最关键的一步。

状态也可以是二维的。LeetCode 64 最小路径和：在一个非负整数网格里，从左上角走到右下角，每次只能向右或向下，求路径上数字之和的最小值。dp[i][j] 表示走到格子 (i, j) 的最小和，它只能从上方或左方过来，所以等于 grid[i][j] 加上这两者的较小值。时间 O(mn)，空间可以压到一行。

爬楼梯和最小路径和

JavaScript
function climbStairs(n) {
  if (n <= 2) return n;
  let prev = 1; // dp[i-2]
  let current = 2; // dp[i-1]
  for (let i = 3; i <= n; i++) {
    [prev, current] = [current, prev + current];
  }
  return current;
}

function minPathSum(grid) {
  const cols = grid[0].length;
  const dp = new Array(cols).fill(Infinity);
  dp[0] = 0;
  for (const row of grid) {
    dp[0] += row[0];
    for (let j = 1; j < cols; j++) {
      dp[j] = row[j] + Math.min(dp[j], dp[j - 1]);
    }
  }
  return dp[cols - 1];
}

console.log(climbStairs(5)); // 8
console.log(minPathSum([[1, 3, 1], [1, 5, 1], [4, 2, 1]])); // 7
console.log(minPathSum([[1, 2, 3], [4, 5, 6]])); // 12
console.log(minPathSum([[0]])); // 0

climbStairs 为什么只用两个变量，没有开数组？因为 dp[i] 只依赖前两项，更早的值算完就用不到了。只保留需要的两项，空间从 O(n) 降到 O(1)，这是动态规划常见的空间优化。

minPathSum 用的是同一个思路，只是压掉的是一维。二维的 dp[i][j] 只依赖上一行的 dp[i-1][j] 和这一行的 dp[i][j-1]，所以一行数组就够了：更新 dp[j] 之前，它里面存的还是上一行的值，也就是“上方”；dp[j - 1] 刚被更新过，是“左方”。

初始值怎么定？第一列的格子只能从上方下来，所以 dp[0] 一路累加 row[0]。第一行的格子只能从左边过来，把 dp 初始化成 Infinity，第一行计算时“上方”取不到，Math.min 自然选左方。第一个例子里，最优路径是 1 → 3 → 1 → 1 → 1，和为 7。

最长递增子序列也是常考的动态规划题，它的 O(n²) 写法和二分优化见《最长递增子序列怎样用贪心加二分做到 O(n log n)？Vue 3 的 diff 为什么用它？》。

怎样判断能不能用动态规划

题目问“最多”“最少”“有几种”，而且大问题可以由规模更小的同类问题推出来，就可以考虑动态规划。比如零钱兑换问最少几枚硬币、编辑距离问最少改几次、背包问题问最大价值。

如果每一步的选择只需看眼前、不会影响以后，比如找零时硬币面额是 1、5、10 这样的倍数关系，贪心就够了；面额不规则时贪心会出错，比如面额是 1、3、4，凑 6 时贪心先拿 4，再拿两个 1，一共 3 枚，而最优是两个 3，这时就得用动态规划。

常见追问

记忆化递归和动态规划有什么区别？

本质一样，都是把子问题的答案存起来。记忆化递归从大问题往下拆，用到哪个子问题才算哪个，写法接近原始思路；动态规划从小问题往上推，用循环填表，没有递归栈溢出的风险。

最小路径和能不能用贪心，每步走较小的那一格？

不能。每步只看眼前会被后面的大数坑到，比如 [[1, 2, 5], [3, 9, 9], [1, 1, 1]]，第一步贪心选 2，最后走到 9 附近只能付出更大代价；向下走 1 → 3 → 1 → 1 → 1 和为 7，比贪心路线 1 → 2 → 5 → 9 → 1 的 18 小得多。动态规划把每个格子的所有来路都比较过，才能保证最小。
