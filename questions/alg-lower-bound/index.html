二分查找怎样定位时间轴边界？为什么重复值和空数组容易写错？

以视频章节定位为例，用左闭右开区间实现 lowerBound 和 upperBound：lowerBound 返回第一个大于等于目标的位置，upperBound 返回第一个大于目标的位置。两者组合可以找出当前所在章节、统计重复值个数，并天然处理空数组和未命中。

参考答案

简答

  • lowerBound 返回第一个 >= target 的下标，upperBound 返回第一个 > target 的下标；目标比所有元素都大时返回数组长度，空数组返回 0。
  • 搜索区间写成左闭右开 [left, right)，循环条件是 left < right，right 初始为 values.length，这样不用单独处理空数组和末尾位置。
  • 有重复值时，lowerBound 落在第一个重复值上，upperBound - lowerBound 就是重复的个数。
  • 视频章节按开始时间排序，当前播放时间 t 所在的章节是 upperBound(starts, t) - 1，结果为 -1 表示还没进入第一章。
  • 中点写成 left + Math.floor((right - left) / 2)。(left + right) >> 1 在 left + right 超过 2³¹ − 1 时会因 32 位转换出错。

lowerBound

JavaScript
function lowerBound(values, target) {
  let left = 0;
  let right = values.length;
  while (left < right) {
    const middle = left + Math.floor((right - left) / 2);
    if (values[middle] < target) left = middle + 1;
    else right = middle;
  }
  return left;
}

console.log(lowerBound([10, 20, 20, 40], 20)); // 1
console.log(lowerBound([10, 20, 20, 40], 25)); // 3
console.log(lowerBound([10, 20, 20, 40], 50)); // 4
console.log(lowerBound([], 20)); // 0

循环不变量：left 左边的元素都 < target，right 及右边的元素都 >= target。每轮至少缩小一个位置，left === right 时就是分界点。

upperBound 与章节定位

JavaScript
function upperBound(values, target) {
  let left = 0;
  let right = values.length;
  while (left < right) {
    const middle = left + Math.floor((right - left) / 2);
    if (values[middle] <= target) left = middle + 1;
    else right = middle;
  }
  return left;
}

const starts = [0, 10, 20, 40]; // 各章节开始的秒数
console.log(upperBound(starts, 25) - 1); // 2，第 20 秒开始的章节
console.log(upperBound(starts, 20) - 1); // 2，正好在章节开头
const values = [10, 20, 20, 40];
console.log(upperBound(values, 20) - lowerBound(values, 20)); // 2

两个函数只差一个比较符号：< 和 <=。实测用 2000 组随机有序数组与线性查找对比，结果一致。

容易写错的地方

写法问题
right = values.length - 1 配合 left < right永远不会返回 values.length，目标比所有元素都大时结果错误
找到相等元素就直接返回有重复值时返回的位置不确定
left = middle（左闭右开写法里）区间可能不再缩小，陷入死循环
对未排序的数组使用结果没有意义，二分的前提是有序

常见追问

  • 时间复杂度？ O(log n)。百万个元素最多约 20 次比较。
  • 元素是对象怎么办？ 传入比较函数，例如 (item) => item.start < target。
  • 数组会频繁插入怎么办？ 每次插入要移动元素，代价是 O(n)；插入很频繁时考虑平衡树或跳表。区间合并中的应用见《如何合并时间区间？相邻区间算不算重叠？》。
