field-sizing: content 会怎样改变表单控件尺寸？

field-sizing: content 让 input、textarea、select 按内容自动调整尺寸，取代用 JavaScript 读 scrollHeight 的做法；要配合 min/max 约束防止布局失控。

参考答案

简答

  • 默认值 fixed 下，表单控件有固定的默认尺寸；content 让控件按当前内容或占位文字伸缩。
  • textarea 会随输入变高，单行 input 会随输入变宽，select 按选中项宽度调整。
  • 一定要配 min-* 和 max-*：空内容时控件可能缩得很小，长内容会无限撑开。
  • 自 2026 年 6 月起进入 Baseline，旧浏览器保持固定尺寸，功能不受影响。
  • 在 field-sizing: content 下 rows、cols、size 不再起作用；要固定某个方向，就设置显式的宽或高。

自动增高的 textarea

CSS
textarea {
  field-sizing: content;
  min-block-size: 3lh;
  max-block-size: 12lh;
}

lh 是当前行高。内容少时至少显示 3 行，超过 12 行出现滚动条。以前要监听 input 事件，把高度设为 auto 再读 scrollHeight，现在不需要 JavaScript。

按内容伸缩的输入框

CSS
.tag-input {
  field-sizing: content;
  min-inline-size: 8ch;
  max-inline-size: 100%;
}

适合标签输入、行内编辑。注意布局稳定性：输入框变宽会推动同一行的其他元素，放在 flex 容器里时要确认换行行为。

无障碍和体验

  • 占位文字也参与尺寸计算，空输入框会按 placeholder 的宽度显示，所以占位文字不要太长。
  • 自动伸缩不改变 <label> 的关联，名称和错误提示仍按常规方式提供。
  • 用户放大页面后，最大尺寸要能容纳内容，避免文字被截断。

常见追问

  • 不支持时要不要写 JavaScript 回退？多数场景不需要，固定尺寸的 textarea 加上滚动条仍然可用。确实需要时，用 CSS.supports('field-sizing', 'content') 判断后再加载回退逻辑。
