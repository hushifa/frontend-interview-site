表单关联自定义元素怎样参与原生提交和校验？

自定义元素声明 static formAssociated = true 并调用 attachInternals()，就能通过 ElementInternals 设置提交值、校验状态和无障碍属性，像原生控件一样参与 form 的提交、重置和禁用。

参考答案

简答

  • 在类上声明 static formAssociated = true，构造函数里调用 this.attachInternals() 拿到 ElementInternals。
  • internals.setFormValue(value) 设置随表单提交的值，internals.setValidity(flags, message, anchor) 设置校验状态。
  • 元素连接到页面后就要同步一次校验状态，否则用户不操作直接提交时，表单会认为它有效。
  • 浏览器会调用 formResetCallback、formDisabledCallback、formStateRestoreCallback 等生命周期方法。
  • 无障碍属性用 internals.role、internals.ariaDisabled 等设置，不需要写在宿主元素的属性上。

示例：必填的评分组件

JavaScript
class StarRating extends HTMLElement {
  static formAssociated = true;
  static observedAttributes = ['required'];
  #internals = this.attachInternals();
  #value = '';

  connectedCallback() {
    this.#internals.role = 'radiogroup';
    this.#sync();
  }

  attributeChangedCallback() {
    this.#sync();
  }

  set value(next) {
    this.#value = String(next);
    this.#sync();
  }

  get value() {
    return this.#value;
  }

  formResetCallback() {
    this.value = '';
  }

  formDisabledCallback(disabled) {
    this.#internals.ariaDisabled = String(disabled);
  }

  #sync() {
    this.#internals.setFormValue(this.#value);
    if (this.hasAttribute('required') && this.#value === '') {
      this.#internals.setValidity({ valueMissing: true }, '请选择评分');
    } else {
      this.#internals.setValidity({});
    }
  }
}

customElements.define('star-rating', StarRating);
HTML
<form>
  <star-rating name="score" required></star-rating>
  <button>提交</button>
</form>
  • 提交时浏览器检查到 valueMissing，阻止提交并显示"请选择评分"。
  • 提交成功时，FormData 里有 score 字段。
  • 去掉 required 属性后，attributeChangedCallback 重新同步，空值也能提交。

校验消息显示位置

浏览器原生气泡会锚定到 setValidity 的第三个参数，通常传入 Shadow DOM 里可聚焦的元素。如果要自己显示错误文本，在 invalid 事件中读取 this.#internals.validationMessage 写入错误区域，并调用 event.preventDefault() 关闭原生气泡。

能获得的原生能力

  • form.elements、new FormData(form) 能拿到它。
  • <fieldset disabled> 会通过 formDisabledCallback 通知它。
  • 表单的 checkValidity()、reportValidity() 和元素的 :invalid 伪类会使用它的校验状态。如果希望元素自己也有 checkValidity() 方法，在类上定义并转调 internals.checkValidity()。
  • 浏览器的前进后退和自动填充通过 formStateRestoreCallback 恢复值。
