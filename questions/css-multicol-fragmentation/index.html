CSS 多栏布局和 Grid 有什么区别？怎样避免内容被跨栏切开？

多栏布局让一段连续内容依次流入多个栏，适合长文本；Grid 把独立项目放进行列格子。多栏中用 break-inside 防止卡片被切开，用 column-span 让标题横跨所有栏。

参考答案

简答

  • 多栏布局里内容是一条流：填满第一栏后进入第二栏，就像报纸排版。
  • column-width: 18rem 设定理想栏宽，浏览器按容器宽度决定栏数；column-count 设定最大栏数。
  • 卡片或图片放进多栏时可能被切成两半，加 break-inside: avoid 让它整体移到下一栏。
  • column-span: all 让元素横跨所有栏，常用于章节标题。
  • 多栏的阅读顺序是竖向的，项目需要横向浏览或对齐时用 Grid。

示例

CSS
.article {
  column-width: 18rem;
  column-gap: 2rem;
  column-rule: 1px solid #ddd;
}

.article h2 {
  column-span: all;
}

.article figure {
  break-inside: avoid;
}

窄屏下只有一栏，宽屏自动变成两到三栏，不需要媒体查询。

和 Grid 对比

多栏Grid
内容模型一段连续内容独立项目
顺序先竖后横先横后竖（默认）
栏高自动平衡由轨道决定
适合长文、术语表、链接列表卡片、页面布局

注意事项

  • 屏幕上的多栏长文需要读者上下来回滚动，内容超过一屏高时体验会变差，可以给容器限定高度或只在宽屏使用。
  • break-inside: avoid 是建议，元素比一栏还高时仍会被切开。
  • 同样的 break-* 属性也用于打印分页，见《网页打印样式应该怎样单独设计？》。

常见追问
