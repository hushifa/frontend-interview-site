CSS 多栏布局和 Grid 有什么区别？怎样避免内容被跨栏切开？

多栏布局像报纸，一段内容填满第一栏再流到第二栏，适合长文本；Grid 是把一个个独立项目放进格子。多栏里用 break-inside 防止卡片被切成两半，用 column-span 让标题横跨所有栏。

参考答案

简答

多栏布局就像报纸排版，内容是连续的一条流，填满第一栏就流进第二栏。Grid 不一样，它是把一个个独立的项目放进行列格子里。

用 column-width: 18rem 设一个理想栏宽，浏览器按容器宽度决定分几栏；column-count 设的是最多几栏。

多栏里最常见的问题是卡片或图片被切成两半，上半截在这一栏底部，下半截在下一栏顶部。加上 break-inside: avoid，它会整个挪到下一栏。章节标题想横跨所有栏，用 column-span: all。

要注意，多栏的阅读顺序是先竖后横。项目需要横着浏览或者行列对齐时，用 Grid。

一段文章分栏

CSS
.article {
  column-width: 18rem;
  column-gap: 2rem;
  column-rule: 1px solid #ddd;
}

.article h2 {
  column-span: all;
}

.article figure {
  break-inside: avoid;
}

窄屏上装不下两个 18rem，就只有一栏；屏幕变宽，自动变成两栏、三栏，不用写媒体查询。column-rule 是栏之间的分隔线。

和 Grid 到底差在哪里

多栏处理的是一段连续内容，顺序是先往下排满一栏，再到下一栏，各栏的高度会自动平衡。所以它适合长文章、术语表、一长串链接。

Grid 处理的是独立的项目，默认先横着排满一行，再到下一行，行高由轨道决定。所以卡片、页面布局用 Grid。

要注意什么

屏幕上看多栏长文，读完第一栏要滚回顶部看第二栏。内容超过一屏高时，读者就得上下来回滚，体验很差。所以可以给容器限定高度，或者只在宽屏上分栏。

break-inside: avoid 只是建议，不是保证。元素比一整栏还高时，放到哪一栏都放不下，还是会被切开。

同样的 break-* 属性也用来控制打印分页，见《网页打印样式应该怎样单独设计？》。

常见追问

多栏能拿来做瀑布流吗？

能做出差不多的样子，但顺序是先竖后横，而且新加项目时，所有栏都会重新分配。详见《CSS Masonry 和传统瀑布流方案应该怎样选择？》。
