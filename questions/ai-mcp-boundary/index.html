MCP、模型工具调用和聊天界面是什么关系？

MCP 定义 AI 应用与外部能力交换上下文的协议。宿主应用管理客户端，客户端连接服务器；服务器可暴露工具、资源和提示模板。它不规定模型怎样思考，也不自动替应用完成 Agent 编排。

参考答案

MCP 定义 AI 应用与外部能力交换上下文的协议。宿主应用管理客户端，客户端连接服务器；服务器可暴露工具、资源和提示模板。它不规定模型怎样思考，也不自动替应用完成 Agent 编排。

AI 界面至少要区分用户消息、模型流、工具调用、工具结果、审批、取消、重试和最终状态。每一步都应有稳定 ID 和可恢复的状态，不能把网络片段直接拼成可信业务对象。

模型工具调用是生成某个操作及参数的机制；MCP 是接入外部能力的协议；前端负责把能力、输入、过程和结果呈现给用户。这几层可以组合，但不是安装一个 MCP 客户端就自动获得安全可靠的智能体。

普通网页不能直接像本机进程一样启动 stdio 服务器。远程接入需考虑受支持的传输、认证、浏览器跨源限制及部署方式。工具描述与结果仍是不可信外部数据，不能凭服务器宣称“已授权”就扩大权限。具体协议版本和 SDK 必须配套核对。

补充参考：OWASP · 提示词注入防护。

模型输出、检索内容和工具结果都属于不可信输入。密钥、权限和不可逆操作必须留在受控边界，前端负责展示确认和错误恢复，服务端负责最终授权、校验和执行记录。

实际 AI 界面要把每次生成当成一个可追踪任务，而不是一段字符串。用户刷新、断网、取消或重新发送后，仍要能判断哪些内容已经保存、哪些工具已经执行、哪些结果只能作为候选信息展示。
