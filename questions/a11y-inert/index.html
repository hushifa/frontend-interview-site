inert、aria-hidden、disabled 和 pointer-events 有什么区别？

这四种写法都能让东西“用不了”，但范围不同。inert 让整个区域不能聚焦、点击、查找，也从无障碍树中移除；aria-hidden 只对辅助技术隐藏，键盘仍能聚焦；disabled 用于单个表单控件；pointer-events: none 只屏蔽指针，键盘照样可用。

参考答案

简答

这四种写法都能让东西“用不了”，区别在于对谁用不了。inert 最彻底：区域里的元素不能聚焦、不触发点击、不能选择和编辑文字，浏览器的页内查找也找不到，还会从无障碍树里移除。它已经是 Baseline 广泛可用。

aria-hidden="true" 只对读屏隐藏，元素照样能被 Tab 聚焦，结果就是焦点落在读屏看不见的地方。所以不要把它放在可聚焦元素或它的祖先上。

disabled 只给 button、input 这类表单控件用，控件不能聚焦、也不会提交，读屏会读出“不可用”。pointer-events: none 只挡住鼠标和触摸，键盘和读屏完全不受影响。

选的时候看范围：一整块区域暂时不能用，比如弹窗背后的页面、加载中的面板，用 inert；单个控件用 disabled。

四种写法对比

能 Tab 聚焦能点击读屏可见页内查找
inert否否否否
aria-hidden是是否是
disabled否否是（不可用）是
pointer-events: none是否是是

看这张表最容易发现问题的是后两行。用 pointer-events: none 做“禁用”，鼠标点不了，可键盘用户按 Tab 过去再按 Enter，照样能触发。

打开侧边面板时怎样屏蔽背景

下面打开一个筛选面板，同时让页面其余部分变成惰性。

HTML
<div id="page">…页面内容…</div>
<aside id="panel" hidden aria-labelledby="panel-title">
  <h2 id="panel-title">筛选</h2>
  …
  <button id="close">关闭</button>
</aside>
JavaScript
const page = document.querySelector('#page');
const panel = document.querySelector('#panel');
let opener = null;

function openPanel() {
  opener = document.activeElement;
  panel.hidden = false;
  page.inert = true;
  panel.querySelector('h2').tabIndex = -1;
  panel.querySelector('h2').focus();
}

function closePanel() {
  panel.hidden = true;
  page.inert = false;
  opener?.focus();
}

打开时先记下触发元素，再给页面加 inert，把焦点移到面板标题上。标题本来不能聚焦，所以先设 tabIndex = -1。关闭时移除 inert，把焦点还给触发元素。

如果面板是模态的，更简单的做法是直接用 <dialog> 的 showModal()，它会自动让其他内容变成惰性。

提交中的按钮怎么处理

保存期间要防止重复提交，通常把按钮设成 disabled。

JavaScript
async function saveAndClose(button, save) {
  button.disabled = true;
  try {
    await save();
    closePanel();
  } catch {
    showError('保存失败，请重试');
  } finally {
    button.disabled = false;
  }
}

保存失败时，按钮在 finally 里恢复可用，用户可以重试；保存成功时关闭面板，焦点回到触发元素。

可是 disabled 有个副作用。按钮正处于焦点时被禁用，就变得不能聚焦，焦点可能丢掉。提交期间改用 aria-disabled="true"，按钮仍然能聚焦，读屏也知道它暂时不可用，只是点击逻辑要自己拦住。

还要注意什么

inert 本身没有任何视觉效果，要另外用样式提示区域不可用，比如降低不透明度。另外，用 showModal() 打开的 dialog 不受祖先 inert 的影响。

常见追问

为什么不能直接在 body 上加 aria-hidden？

弹窗一般也在 body 里面，会被一起隐藏。以前的做法是给弹窗以外的兄弟节点逐个加 aria-hidden，现在用 inert 或原生 dialog 更可靠。
