srcset、sizes 和 picture 怎样减少图片浪费？

srcset 列出同一张图的多种尺寸，sizes 告诉浏览器图片在页面上显示多宽，浏览器据此挑最小够用的文件；picture 用于换格式或在不同屏幕显示不同裁切。

参考答案

简答

  • srcset="a-480.jpg 480w, a-960.jpg 960w" 用 w 描述每个文件的实际宽度。
  • sizes="(width > 800px) 50vw, 100vw" 描述图片的显示宽度；浏览器在 CSS 加载前就要选图，所以需要这个提示。
  • 浏览器用显示宽度乘以设备像素比，选出足够清晰的最小文件。
  • 固定显示尺寸的图片（如头像）用 1x、2x 描述符即可，不需要 sizes。
  • <picture> 的 <source type="image/avif"> 提供新格式，media 条件用于在不同屏幕显示不同裁切；最后的 <img> 是回退，必须保留。

宽度描述符

HTML
<img
  src="/hero-960.jpg"
  srcset="/hero-480.jpg 480w, /hero-960.jpg 960w, /hero-1920.jpg 1920w"
  sizes="(width > 1024px) 50vw, 100vw"
  width="1920"
  height="1080"
  alt="团队在办公室讨论"
>

手机宽 390px、像素比 3 时，需要约 1170px，浏览器选 1920w。桌面 1440px 宽、像素比 1，图片显示 720px，选 960w。没有 sizes 时默认按 100vw 计算，桌面上会下载过大的图片。

width 和 height 让浏览器提前算出宽高比，图片到达前就占好位置，避免布局偏移。

picture

HTML
<picture>
  <source media="(width < 600px)" type="image/avif" srcset="/hero-square.avif">
  <source media="(width < 600px)" srcset="/hero-square.jpg">
  <source type="image/avif" srcset="/hero.avif">
  <source type="image/webp" srcset="/hero.webp">
  <img src="/hero.jpg" alt="团队在办公室讨论" width="1920" height="1080">
</picture>

浏览器按顺序使用第一个匹配的 <source>，所以带 media 的裁切版本要排在通用格式之前，否则支持 AVIF 的浏览器会直接选中大图。alt、loading 等属性只写在 <img> 上。

加载优先级

  • 首屏的大图（通常是 LCP 元素）不要加 loading="lazy"，可以加 fetchpriority="high"。
  • 首屏以下的图片加 loading="lazy"，进入视口附近才下载。
  • decoding="async" 允许浏览器异步解码，减少对主线程的阻塞。

常见追问

  • CSS 背景图怎么做响应式？用 image-set()，例如 background-image: image-set('a.avif' type('image/avif'), 'a.jpg' type('image/jpeg'))。
