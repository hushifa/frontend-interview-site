容器样式查询怎样根据父级配置改变组件样式？

@container style() 看祖先元素上某个自定义属性的值，父级写一个配置，里面的组件就能整段切换样式。目前浏览器只支持查询自定义属性。

参考答案

简答

容器样式查询让组件根据父级的配置换样式。比如侧栏写上 --density: compact，里面的列表项用 @container style(--density: compact) 判断，条件成立就变紧凑。

它和尺寸查询不一样，不需要写 container-type，所有元素默认都可以当样式容器。查询的是祖先，元素不能查自己。规范里还允许查普通属性，比如 style(font-weight: bold)，但目前浏览器只支持自定义属性。

它适合“父级声明一个配置，多个子组件各自响应”的场景，比给每个子组件都加一个修饰类更集中。

要注意，它的支持范围比尺寸查询窄，用之前要查兼容表。不支持的浏览器会忽略整段规则，所以组件的默认样式本身要能用。

先看一个例子

CSS
.sidebar {
  --density: compact;
}

@container style(--density: compact) {
  .item {
    padding-block: 4px;
    font-size: 0.875rem;
  }
}

侧栏里的 .item 会自动变紧凑，主内容区里的 .item 保持默认，HTML 一个字都不用改。

自定义属性会继承，侧栏设置的 --density 里面所有元素都能读到。查询条件的意思是“最近的祖先上，这个属性的值是不是 compact”。

除了判断等于某个值，还可以只判断有没有设置，或者把多个条件组合起来：

CSS
/* 只要设置了 --theme 就生效 */
@container style(--theme) {
  .card {
    border-width: 2px;
  }
}

@container style(--theme: dark) or style(--theme: dim) {
  .card {
    background: #222;
  }
}

直接用 var() 不也能做到吗

自定义属性本来就能继承，写 padding: var(--item-padding)，再让侧栏改 --item-padding，也能实现密度切换。

区别在于要改多少东西。只传一个值时，直接用变量更简单。一个配置要同时改好几个不相关的属性，或者要切换一整段规则，比如改变布局方向、隐藏某个子元素，用变量就得为每个属性各准备一个，这时样式查询更合适。

写对了却不生效，可能是哪里的问题

查询比较的是计算值，写法要完全一致。compact 和 "compact" 是两个不同的值，一个带引号一个不带，就匹配不上。

用 @property 注册过类型的属性，可以按类型比较；没注册的属性按字符串比较。

不支持样式查询的浏览器会把整段 @container style() 规则忽略掉。所以把它当成增强，写在默认样式后面。

常见追问

尺寸条件和样式条件能写在一起吗？

可以，比如 @container card (inline-size > 400px) and style(--layout: row)。不过尺寸部分要求名叫 card 的容器设置了 container-type，样式部分则不需要。
