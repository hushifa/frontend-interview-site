AudioContext 与音频节点图怎样组织音频处理？

Web Audio 用 AudioContext 管理一张音频节点图，音源节点经过增益、滤波、分析等处理节点连到 destination 输出；AudioContext 受自动播放策略限制，需要用户手势后 resume。

参考答案

简答

  • AudioContext 是音频处理的环境，所有节点都由它创建，最后连到 context.destination（扬声器）。
  • 音源节点：AudioBufferSourceNode（解码后的音频）、MediaElementAudioSourceNode（<audio> 元素）、MediaStreamAudioSourceNode（麦克风）、OscillatorNode（振荡器）。
  • 处理节点：GainNode 调音量、BiquadFilterNode 滤波、AnalyserNode 获取频谱、PannerNode 空间定位。
  • 浏览器的自动播放策略会让未经用户手势创建的 context 处于 suspended 状态，要在点击后调用 context.resume()。
  • 参数变化用 AudioParam 的调度方法（如 linearRampToValueAtTime），在音频线程上精确执行，避免爆音。

示例：播放音效并淡出

JavaScript
const context = new AudioContext();
let buffer;

async function load() {
  const data = await fetch('/click.mp3').then((r) => r.arrayBuffer());
  buffer = await context.decodeAudioData(data);
}

async function play() {
  if (context.state === 'suspended') await context.resume();

  const source = new AudioBufferSourceNode(context, { buffer });
  const gain = new GainNode(context, { gain: 1 });
  source.connect(gain).connect(context.destination);

  const now = context.currentTime;
  gain.gain.setValueAtTime(1, now);
  gain.gain.linearRampToValueAtTime(0, now + 0.5);
  source.start(now);
  source.stop(now + 0.5);
}

button.addEventListener('click', play);
  • AudioBufferSourceNode 只能 start() 一次，每次播放都新建一个；节点很轻量，buffer 可以复用。
  • context.currentTime 是音频时钟，按它调度比用 setTimeout 精确。

音频可视化

JavaScript
// source 是任意音频节点，例如上面 play() 里创建的 AudioBufferSourceNode
function visualize(source) {
  const analyser = new AnalyserNode(context, { fftSize: 256 });
  source.connect(analyser);
  const bins = new Uint8Array(analyser.frequencyBinCount);

  function draw() {
    analyser.getByteFrequencyData(bins);
    renderBars(bins);
    requestAnimationFrame(draw);
  }
  draw();
}

注意事项

  • 一个页面通常只创建一个 AudioContext，不用时调用 suspend() 或 close() 释放音频硬件。
  • 自定义的采样级处理用 AudioWorklet，代码运行在音频线程，旧的 ScriptProcessorNode 已废弃。
  • 跨源音频要服务端返回 CORS 头，否则 MediaElementAudioSourceNode 只输出静音。
