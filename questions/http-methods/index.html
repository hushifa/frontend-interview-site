HTTP 方法的安全性和幂等性是什么意思？

安全性描述请求是否要求改变目标资源状态，幂等性描述重复相同请求的预期效果是否与一次相同。它们不是网络安全或必定成功的保证，响应不同也不必然破坏幂等，服务端仍需正确实现契约。

参考答案

HTTP 中的 safe 不是“没有安全漏洞”，idempotent 也不是“请求只会执行一次”。它们描述的是方法的预期语义，客户端、缓存和中间系统会根据这些语义决定如何处理请求。

安全方法不要求改变目标资源状态；幂等方法则要求重复相同请求的预期服务端效果，与只执行一次相同。两者相关，但不是同一个条件。

常见方法的语义分类

方法标准意义上安全标准意义上幂等常见用途
GET是是获取资源表示
HEAD是是获取相应响应头，不返回正文
OPTIONS是是了解支持的通信选项等
PUT否是按目标 URI 创建或替换资源表示
DELETE否是删除目标资源的相应关联
POST否不保证提交处理、创建下属资源等
PATCH否不保证按补丁语义修改部分状态

安全方法也可能产生日志、统计或缓存填充等附带效果。关键是调用方没有要求通过这次读取去执行删除、扣款等业务变更，不是服务器内部绝对一行状态都不能写。

若把“删除订单”设计成 GET 参数，服务器就违反了使用者可以依赖的安全语义，预取、爬虫、缓存或重复访问都可能产生意外后果。

幂等不要求每次响应完全一样

假设 PUT 把 /drafts/42 的标题设置为同一个值。第一次请求可能创建资源，返回 201；之后相同请求可能返回 200 或 204。最终目标仍是那份表示，不是每次追加一个新草稿。

DELETE 第一次可以返回 204，第二次发现已经不存在而返回 404，最终仍然是资源不存在。这些响应差异本身不否定幂等性。

相反，如果某个声称是 PUT 的接口，每调用一次就无条件创建一份新记录，那么仅仅写了 PUT 这个方法名，也不会使真实业务效果自动变得幂等。

POST 与 PATCH 可以通过接口设计获得幂等效果

POST 不提供普遍的幂等保证，但某个业务接口可以定义去重协议。创建订单时，客户端可能提供一次操作的唯一键，服务端保存这个键与请求内容、执行结果的关系，重复请求返回相同操作的结果。

PATCH 的具体效果取决于补丁操作。把一个字段设置为固定值，重复后可能效果相同；某个接口把载荷解释为“数量再加一”，重复则会继续累加。不能只看方法名，就知道所有 PATCH 都安全重试。

JSON Patch、JSON Merge Patch 或自定义补丁格式还有各自的含义。客户端与服务端必须约定内容类型与操作规则，不能把任何 JSON 对象都当成同一种“部分更新”。

超时之后，服务器可能已经执行成功

请求超时或连接中断，只说明客户端没有得到预期完成结果。它可能发生在请求还没到达服务器之前，也可能发生在服务器已经写入数据、但响应丢失之后。

因此创建、付款等变更不能简单地一失败就重新发一遍。界面禁用按钮只能减少一条交互入口，无法覆盖代理重试、客户端重连、多个标签页或用户再次打开页面。

幂等方法更适合相应的自动重试场景，但也应考虑权限、资源版本、其他参与者的修改与重试时效。幂等不等于重复操作在任何并发环境中都不会影响别人。

幂等键需要服务端真正参与

一些接口通过 Idempotency-Key 等约定请求头传递操作标识。关键不是头的名字，而是服务端怎样处理同一个键：是否限制到当前用户与操作范围，是否校验请求内容一致，怎样处理进行中状态，结果保留多久。

只在前端设置一个随机头，服务端没有实现相应存储与去重，不会产生幂等保证。每次重试都生成新键，也通常失去了识别同一次操作的意义。

如果同一键带着不同业务载荷再次到来，应按协议拒绝或明确处理，不能把另一个操作的成功结果悄悄返回给当前请求。

条件请求可以进一步保护资源版本

编辑一个资源时，可以结合 ETag 与 If-Match 等前置条件，要求“只有资源仍是我编辑时的版本才应用变更”。条件不成立时返回相应失败，让客户端处理冲突。

这与缓存验证中常见的 If-None-Match 用途不同，也不是仅靠方法幂等性就能替代的保护。幂等解决相同请求的重复效果，版本条件帮助发现基于旧数据进行的覆盖。

方法语义与缓存、浏览器限制也不同

GET 并不保证一定命中缓存，响应策略与请求条件仍然重要；某些其他方法的响应在明确条件下也可能具有缓存语义，但具体缓存实现不一定支持相同范围。

浏览器 Fetch 对 GET、HEAD 的请求体有明确限制，接口不应依赖在这些请求里随意塞 body 来表达查询。查询参数、请求头与身份信息也要有清楚协议，不能把方法名称当成唯一输入来源。

设计和调试时应分别问：这次操作要求改变什么，重复会怎样，结果不确定时怎样确认，以及谁负责重试和去重。把这些问题说清楚，才算真正理解安全性与幂等性。
