FormatJS

提供 ICU 消息、复数、日期数字格式化和多语言工具链的开源 JavaScript/TypeScript 方案。

官方入口GitHub

适合把消息目录、变量、复数和本地化格式化纳入统一工作流，React 项目可以使用 React Intl，其他框架也可以复用核心格式化能力。引入前要明确消息提取、语言包加载、回退和构建体积策略。

消息模板仍需经过运行时数据校验，用户输入不能因为进入消息变量就被当作 HTML 执行。语言目录、占位符和复数分支应在 CI 中检查，真实页面还要测试长文案、RTL、缺失翻译和服务端/客户端 locale 一致性。

本条只收录 FormatJS 开源代码和公开文档，不包含翻译平台托管、商业服务或第三方 API 费用。

本次具体核对了官方 npm 发布包 intl-messageformat 12.1.4 的 package.json 与 LICENSE.md，许可为 BSD-3-Clause，可免费用于商业项目；分发时需保留许可要求的声明，不得擅用原作者名称背书。FormatJS 是多个包组成的工具链，接入 React Intl、消息提取工具或 polyfill 时，还应分别核对所选包和版本，不把一个包的核验范围当作整个生态的保证。
