ECMAScript 规范

JavaScript 语言及内建对象的正式规范，用于核对语义和算法细节。

官方入口GitHub

ECMAScript 语言规范（ECMA-262）的在线版本，用来查类型转换、属性访问、Promise、迭代器等行为的正式定义。

规范用抽象操作和算法步骤描述语义，适合已有基础后追查边界行为。DOM、fetch 等浏览器 API 不在这里定义，Node.js 的文件系统也不在。提案进度看 tc39/proposals 仓库。

许可：按 Ecma 版权政策免费阅读，规范文本可在保留版权声明的前提下复制。
