Apache ECharts

通过配置构建常见数据图表与可视化。

官方入口GitHub

适合仪表盘、统计报表和业务数据展示，支持折线、柱状、饼图、地图、关系图等配置式图表。组件通常通过 option 描述数据、坐标轴、系列和交互，适合需要快速组合多种图表的团队。

使用时要处理容器尺寸变化、实例销毁、数据更新策略和大数据量降采样；隐藏容器初始化可能得到错误尺寸。复杂图表还要考虑色彩对比、键盘替代、触摸交互和数据表格，不能把 Canvas/SVG 图形当作完整无障碍内容。

本条收录 Apache ECharts 开源代码本体和官方文档，不包含商业图表服务、托管分析或付费模板。发布前请核对目标版本和许可证要求。

使用建议

当前条目归入「图表与交互」，标注生态为框架无关，资源类型为第三方库。先明确是图表、二维绘制、三维场景还是拖拽交互，再按数据量、设备能力和无障碍要求选型。应测试缩放、重绘、资源释放和移动端表现，不能只依据示例页面的视觉效果。

接入前建议从官网当前版本开始，先完成一个最小用例，再记录版本、浏览器或运行时支持范围、产物体积和失败处理方式。将依赖版本写入锁文件，先验证关键 API 和失败路径，再评估升级与替换成本。
