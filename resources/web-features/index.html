Web Features 数据集

Web 平台特性及 Baseline 状态的开源数据集，适合在选型、兼容性评审和文档中判断一项能力是否达到目标浏览器范围。

官方入口GitHub

Web Platform DX 社区维护的特性数据集，把 Web 能力按特性归类，并给出 Baseline 状态（新近可用、广泛可用）。MDN 和 Can I use 都在使用这份数据。

Baseline 基于主流浏览器的发布时间计算，和项目的实际用户分布无关。达到 Baseline 的特性也可能受安全上下文或权限影响。批量使用时通过 npm 包 web-features 读取并锁定版本。

许可：Apache-2.0。
