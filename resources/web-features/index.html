Web Features 数据集

Web 平台特性及 Baseline 状态的开源数据集，适合在选型、兼容性评审和文档中判断一项能力是否达到目标浏览器范围。

官方入口GitHub

Web Features 是 Web Platform DX 社区维护的开源数据集，把 Web 平台能力按特性组织起来，并关联规范、MDN 和浏览器支持信息。它适合在技术选型、设计评审和项目文档中回答“这项能力现在是否适合作为默认方案”，也适合被构建工具和文档站点读取。

Baseline 是一个面向 Web 开发者的兼容性视角，用规定的浏览器集合和时间线概括支持状态。它不是按你的网站访问统计计算的覆盖率，也不是某个特性在所有环境中可用的保证。项目官方明确将外部辅助技术支持和 Node.js 等非 Web 运行环境排除在目标范围之外。因此浏览器支持某个 HTML/ARIA 能力，不等于所有读屏器都能正确使用；Node.js 中同名 API 的可用性也不能直接由 Baseline 推导。

使用时应先明确项目支持的浏览器、操作系统和 WebView 版本，再查看特性的 Baseline 状态和备注。某项能力即使达到 Baseline，也可能受安全上下文、权限、用户设置、输入设备或服务器配置影响；“可用”不等于每个参数、性能特征和业务场景都一致。

这个仓库提供数据文件、模式说明和维护流程，适合需要批量分析或生成内部文档的团队。应锁定依赖版本并记录查询日期，避免远程数据更新后让构建或文档结果悄悄变化。面向使用者的快速查询可以直接阅读项目网站或 MDN 页面，不必在应用运行时请求该仓库。

该项目的数据和代码按仓库公开许可使用，不包含商业浏览器实验室、付费兼容性修复或技术支持。正式发布前仍应在目标设备上验证关键交互，并为未达到目标范围的能力准备渐进增强、特性检测或降级实现。
