alova

在 axios、fetch 等请求库之上提供分页、表单、上传等现成请求策略的请求层。

官方入口GitHub

建立在现有请求库之上的请求策略层，可以继续使用 axios 或 fetch 发请求。提供 usePagination、useForm、useUploader、useSSE 等 20 多种请求策略，同一套 API 可用于 React、Vue、Svelte、Solid、小程序和服务端。

内置请求共享、响应缓存和多级缓存，缓存失效通过 hitSource 声明。服务端的限流与重试在 alova/server 中提供。选型时要和团队已用的 TanStack Query、SWR 等方案比较，避免同一项目里出现两套缓存。
