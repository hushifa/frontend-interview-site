SheetJS Community Edition

处理电子表格格式与工作表数据的开源库。

官方入口GitHub

读写 XLSX、XLS、CSV、ODS 等电子表格格式，支持浏览器和 Node。

npm 上的 xlsx 包停留在 0.18.5（2022 年发布），官方仓库 README 说明模块从 cdn.sheetjs.com 获取，源码仓库已迁到 git.sheetjs.com，GitHub 仓库不再是主仓库。安装时按官方文档使用 CDN 地址。

许可：Apache-2.0。收录范围是 Community Edition，SheetJS Pro 不在范围内。
