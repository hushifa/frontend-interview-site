LangChain.js（开源库）

在 JavaScript/TypeScript 中组合模型、工具和 Agent 流程的开源库。

官方入口GitHub

用于组装提示模板、模型调用、检索和工具链，适合快速搭建检索增强和多步骤调用的原型。

流程变复杂后，要自己定义状态、重试、取消和人工确认。链的输出来自模型，执行写操作前仍要校验。

许可：MIT。LangSmith 等托管平台不在收录范围。
