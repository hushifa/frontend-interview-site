MDN Browser Compat Data

MDN 维护的开源浏览器兼容性数据集，适合在设计和发布功能前查询 API、CSS、HTML 与 JavaScript 特性的支持情况。

官方入口GitHub

Browser Compat Data（BCD）是 MDN 使用的结构化兼容性数据，记录浏览器对 HTML、CSS、JavaScript、Web API 以及部分平台功能的支持版本、前缀、别名和备注。它适合在引入新能力、制定兼容目标或排查“某浏览器为什么没有这个 API”时查阅，也可以被工具读取，用于生成兼容性检查或文档页面。

它是公开的开源数据仓库，数据文件和维护规则可以直接查看。仓库中的版本号表示数据集版本，不等于某个浏览器版本；查询结果中的 version_added、version_removed、partial_implementation 和 notes 需要结合目标浏览器、运行环境和实际功能路径理解。

使用时要看完整的支持记录

“支持”不一定意味着所有参数和边界都可用。例如某个 API 可能在浏览器中存在，但只支持部分选项；某个 CSS 特性可能需要前缀；某个功能可能只在安全上下文、特定操作系统或特定权限下可用。发布前应同时查看 MDN 的 API 说明、规范和目标浏览器的实测结果。

BCD 不能代替真实设备测试，也不能证明框架封装、WebView 内核或企业内嵌浏览器已经支持。对于支付、编辑器、音视频、无障碍等关键流程，应把兼容性数据转化为项目自己的浏览器矩阵和回归用例，并为不支持的环境准备降级路径。

适合哪些工作

  • 评估是否可以使用新的 CSS、HTML 或 Web API。
  • 为 browserslist、渐进增强和 polyfill 方案提供事实依据。
  • 在代码评审中解释某个兼容性判断的来源。
  • 通过仓库数据构建内部兼容性报告或文档索引。

如果只想快速查看一个特性，直接阅读 MDN 页面上的兼容性表通常比手动解析仓库更方便；如果要批量分析或集成到工具链，再使用仓库中的 JSON 数据和数据结构说明。项目应锁定需要的 BCD 版本，避免构建结果随着未锁定的远程数据悄悄变化。

免费范围与限制

本次核对仓库 LICENSE 为 CC0 1.0 Universal，BCD 数据可以免费使用，包括商业项目中的复用。这个许可结论针对 BCD 仓库，不能自动套用到所有 MDN 文章、图片或第三方资料。

BCD 不提供商业浏览器支持、设备实验室、兼容性修复或 SLA；数据也可能随着浏览器发布和维护者修订而更新。使用时记录数据版本和查询日期，不能把“MDN 标记支持”写成对所有用户环境的绝对承诺。
