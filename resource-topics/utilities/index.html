常用工具资源

常用 JavaScript 工具库，涵盖 Lodash、Day.js、date-fns、DOMPurify、Dexie.js、i18n、二维码、模糊搜索和事件通信工具。共 21 项资源。

  • date-fns

    用独立函数处理日期格式化、比较和计算的开源库。

  • Day.js

    使用链式 API 与插件处理日期和时间的开源库。

  • Lodash

    提供集合、对象和函数处理工具的成熟开源库。

  • Luxon

    提供日期时间、时长和区间模型的开源库。

  • Dexie.js

    为 IndexedDB 提供更易使用的数据访问接口的开源库。

  • Papa Parse

    在 JavaScript 中解析和生成 CSV 数据的开源库。

  • react-i18next

    把 i18next 翻译能力集成到 React 应用的开源库。

  • Vue I18n

    为 Vue 提供消息翻译和本地化能力的开源库。

  • clsx

    根据条件组合 className 字符串的轻量工具。

  • Nano ID

    生成紧凑随机标识符的开源库。

  • DOMPurify

    对 HTML 等标记内容进行净化处理的开源库。

  • node-qrcode

    在 JavaScript 环境中生成二维码的开源库。

  • Fuse.js

    为本地数据集合提供可配置模糊搜索的开源库。

  • mitt

    提供轻量事件发布与订阅接口的开源库。

  • ts-pattern

    用于联合类型和嵌套数据分支处理的 TypeScript 模式匹配库。

  • Radash

    面向现代 JavaScript/TypeScript 的集合、函数和异步工具库。

  • FormatJS

    提供 ICU 消息、复数、日期数字格式化和多语言工具链的开源 JavaScript/TypeScript 方案。

  • p-limit

    为异步函数设置并发上限的小型开源库，适合限制批量请求或独立异步任务同时运行的数量。

  • Comlink

    封装 postMessage 通信的开源库，让主线程通过异步代理调用 Worker 暴露的接口，减少手写消息分派代码。

  • @js-temporal/polyfill

    提供 Temporal 日期时间类型的开源兼容实现，适合在目标环境尚不具备所需原生能力时使用明确的日期与时区模型。

  • decimal.js

    支持可配置精度与舍入的十进制运算库，适合避免直接使用二进制浮点数处理需要明确精度规则的计算。
