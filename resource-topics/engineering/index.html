工程化与测试资源

前端构建、代码规范与测试工具，涵盖 Vite、webpack、Rspack、Rollup、esbuild、ESLint、Prettier、Vitest、Playwright、Storybook 和 pnpm。共 23 项资源。

  • Vite

    提供前端开发服务器与生产构建流程。

  • webpack

    通过模块依赖组织打包，并使用 Loader 和插件扩展。

  • ESLint

    通过可配置规则检查 JavaScript 等代码问题。

  • Prettier

    自动统一代码与常见文本格式。

  • Vitest

    与 Vite 工程集成的 JavaScript / TypeScript 测试工具。

  • Playwright

    在真实浏览器中自动化验证网页行为。

  • Testing Library

    从用户可见行为和可访问语义出发测试界面的工具集合。

  • Storybook

    独立展示、开发和验证 UI 组件的工作台。

  • Mock Service Worker

    在网络层模拟 API 响应，用于开发和测试。

  • Rspack

    以 Rust 实现的 JavaScript 构建工具。

  • Rsbuild

    基于 Rspack 提供应用开发和构建配置。

  • Rollup

    根据模块依赖生成 JavaScript 分发产物的打包工具。

  • esbuild

    提供 JavaScript / TypeScript 转换、打包与压缩能力。

  • pnpm

    用于管理 JavaScript 依赖与工作区的包管理器。

  • Turborepo

    为多包仓库组织任务依赖与构建缓存。

  • Nx（开源工具）

    通过项目图、任务和插件组织工程工作区。

  • Husky

    在项目中配置 Git hooks 的工具。

  • lint-staged

    对 Git 暂存区匹配的文件执行检查任务。

  • Stylelint

    以可配置规则检查 CSS 及相关样式代码。

  • commitlint

    检查提交说明是否符合约定格式。

  • Biome

    集成格式化、Lint 和部分 JavaScript/TypeScript 工具链的快速开发工具。

  • OpenTelemetry JS

    为浏览器和 Node.js 应用提供 traces、metrics 与 context 等可观测性 API 和 SDK。

  • vite-plugin-pwa

    为 Vite 项目生成 Web App Manifest 和 Service Worker 配置，帮助接入 PWA 能力。
