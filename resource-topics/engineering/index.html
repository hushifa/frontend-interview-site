工程化与测试资源

前端构建、代码规范与测试工具，涵盖 Vite、webpack、Rspack、Rollup、esbuild、ESLint、Prettier、Vitest、Playwright、Storybook 和 pnpm。共 36 项资源。

  • Vite

    提供前端开发服务器与生产构建流程的工具。

  • webpack

    通过模块依赖组织打包、并用 Loader 和插件扩展的构建工具。

  • ESLint

    通过可配置规则检查 JavaScript 与相关代码问题的工具。

  • Prettier

    自动统一代码和常见文本格式的开源工具。

  • Vitest

    与 Vite 工程集成的 JavaScript/TypeScript 测试工具。

  • Playwright

    在真实浏览器中自动化验证网页行为的工具。

  • Testing Library

    从用户可见行为和可访问语义出发测试界面的工具集合。

  • Storybook

    独立开发、展示和验证 UI 组件的工作台。

  • Mock Service Worker

    在网络层模拟 API 响应的开源工具。

  • Rspack

    以 Rust 实现、兼容部分 webpack 生态的构建工具。

  • Rsbuild

    基于 Rspack 提供应用开发服务器和构建配置的工具。

  • Rollup

    根据模块依赖生成 JavaScript 分发产物的打包工具。

  • esbuild

    提供 JavaScript/TypeScript 转换、打包和压缩能力的快速工具。

  • pnpm

    管理 JavaScript 依赖和工作区的包管理器。

  • Turborepo

    为多包仓库组织任务依赖与构建缓存的工具。

  • Nx（开源工具）

    通过项目图、任务和插件组织工程工作区的开源工具。

  • Husky

    在项目中配置 Git hooks 的工具。

  • lint-staged

    对 Git 暂存区匹配的文件执行检查任务的工具。

  • Stylelint

    以可配置规则检查 CSS 和相关样式代码的工具。

  • commitlint

    检查 Git 提交说明是否符合约定格式的工具。

  • Biome

    集成格式化、Lint 和部分 JavaScript/TypeScript 工具链的快速开发工具。

  • OpenTelemetry JS

    为浏览器和 Node.js 应用提供 traces、metrics 与 context 能力的开源可观测性 API/SDK。

  • vite-plugin-pwa

    为 Vite 配置 Web App Manifest、Service Worker 和 Workbox 集成的开源插件。

  • unplugin

    为 Vite、webpack、Rollup、esbuild 等构建工具复用插件逻辑的开源抽象层。

  • Oxlint

    基于 Rust/Oxc 的快速 JavaScript 和 TypeScript Lint 工具。

  • fast-check

    通过生成数据寻找违反不变量的最小反例的属性测试库。

  • Lighthouse

    覆盖性能、无障碍、SEO 和最佳实践的网页审计工具。

  • web-vitals

    采集 Web Vitals 指标的开源库。

  • axe-core

    在浏览器 DOM 中执行自动化无障碍规则检查的开源 JavaScript 引擎。

  • Web Platform Tests

    跨浏览器验证 Web 标准和平台 API 行为的开源测试套件与协作项目。

  • tsd

    通过独立类型用例验证 TypeScript 类型声明和公共 API 推导的开源测试工具。

  • Nu Html Checker

    W3C 生态中的开源 HTML 校验器，适合在本地或 CI 中发现 HTML 语法、结构和标准一致性问题。

  • SLSA

    面向软件供应链的开源规范和实践框架，用于描述构建来源、产物完整性、可追溯性和发布流程的安全保证。

  • OpenSSF Scorecard

    OpenSSF 的免费开源工具和规则，用于检查开源项目的供应链安全实践，如分支保护、依赖更新、危险工作流和发布流程。

  • Stryker Mutator

    JavaScript 和 TypeScript 生态的开源变异测试工具，通过生成代码变异检查测试是否真正能发现行为错误。

  • Knip

    分析 JavaScript/TypeScript 项目中未使用文件、导出和依赖的开源工具，适合辅助清理长期演进项目。
