表格与文件资源

前端表格与文件处理库，涵盖 TanStack Table、AG Grid Community、Vxe Table、文件上传、PDF.js、ExcelJS、JSZip 和 SheetJS 社区版。共 11 项资源。

  • TanStack Table

    为表格提供列、排序、筛选和行模型等无样式逻辑。

  • AG Grid Community

    免费社区版数据网格，提供常见数据展示与交互能力。

  • Vxe Table

    Vue 生态的表格、网格和数据编辑组件。

  • Uppy

    通过插件组织文件选择、上传与相关界面。

  • FilePond

    提供文件选择、上传交互与插件扩展的文件上传库。

  • react-dropzone

    以 React Hook 提供文件拖放与选择交互。

  • PDF.js

    在网页中解析和渲染 PDF 的工具。

  • pdf-lib

    使用 JavaScript 创建和修改 PDF 文档。

  • ExcelJS

    读写电子表格文件并处理工作表数据和样式。

  • JSZip

    在 JavaScript 中读取和生成 ZIP 压缩包。

  • SheetJS Community Edition

    处理电子表格文件格式与工作表数据。
