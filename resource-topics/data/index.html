路由与数据资源

前端路由、状态管理与请求工具，涵盖 React Router、Vue Router、Pinia、Redux Toolkit、Zustand、TanStack Query、Axios、VueUse 和 ahooks。共 25 项资源。

  • TanStack Query

    管理服务端数据获取、缓存、失效和异步状态的库。

  • SWR

    以 Hooks 管理 React 数据获取、缓存和重新验证的库。

  • Vue Router

    Vue 官方路由方案，组织页面匹配与导航状态。

  • React Router

    为 React 应用提供路由与数据组织能力。

  • Redux Toolkit

    Redux 官方推荐的状态管理工具集。

  • Pinia

    Vue 生态的 Store 状态管理方案。

  • Zustand

    以较小 API 组织 React Store 和状态订阅的开源库。

  • Axios

    支持浏览器和 Node.js 的 Promise HTTP 客户端。

  • VueUse

    将常用浏览器与状态逻辑封装成 Vue 组合式函数的开源集合。

  • ahooks

    覆盖请求、状态和常见交互逻辑的 React Hooks 集合。

  • Jotai

    以原子状态组织 React 应用数据和派生关系的状态库。

  • Valtio

    使用代理对象维护状态，并通过快照连接 React 视图的状态库。

  • Immer

    用修改草稿的写法生成不可变状态更新结果。

  • RxJS

    用 Observable 和操作符组合异步数据流的开源库。

  • Ky

    在 Fetch 之上提供配置、钩子和错误处理的 HTTP 客户端。

  • ofetch

    对 Fetch 的解析、错误和请求配置提供封装。

  • Apollo Client

    管理 GraphQL 查询、缓存和客户端数据更新的开源客户端。

  • urql

    通过可组合机制组织 GraphQL 请求与缓存的客户端库。

  • Socket.IO Client

    连接 Socket.IO 服务端并处理实时事件通信的客户端库。

  • tRPC

    通过 TypeScript 类型推导连接客户端和服务端过程的 RPC 工具。

  • TanStack Router

    面向 TypeScript 应用的类型安全前端路由。

  • nuqs

    将 React URL 搜索参数映射为类型化状态的开源库。

  • Yjs

    用 CRDT 数据结构实现实时协同状态同步的开源 JavaScript 库。

  • eventsource-parser

    将分块到达的 SSE 文本解析成事件的轻量开源库，适合 fetch 流式响应和 AI 文本流的协议适配。

  • idb

    为 IndexedDB 提供接近原生结构的 Promise 包装，适合需要事务与版本升级但希望减少事件回调代码的浏览器应用。
