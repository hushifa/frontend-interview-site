跨端开发资源

前端跨端开发资源，收录 uni-app、Taro、Ionic、Capacitor、Electron、React Native、Expo SDK 开源部分和 Tauri，查找移动端与桌面应用方案。共 8 项资源。

  • uni-app

    使用 Vue 技术栈开发多端应用的框架。

  • Taro

    支持多种前端框架与多端目标的应用开发框架。

  • Ionic Framework

    面向应用界面的 Web Components 与框架集成。

  • Capacitor

    让 Web 应用运行在原生应用容器并接入平台能力。

  • Electron

    用 Web 技术构建桌面应用的框架。

  • React Native

    使用 React 构建原生应用界面的框架文档。

  • Expo SDK（开源部分）

    围绕 React Native 提供开源 SDK 与本地开发工具。

  • Tauri

    结合 Web 前端与原生能力构建应用的框架。
