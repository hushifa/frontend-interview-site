编辑器与内容资源

前端编辑器、Markdown 渲染与代码高亮库，收录 Monaco Editor、CodeMirror、Tiptap 开源核心、Lexical、react-markdown、markdown-it、highlight.js 和 Shiki。共 9 项资源。

  • Monaco Editor

    为网页嵌入代码编辑体验的编辑器。

  • Tiptap Editor（开源核心）

    基于 ProseMirror、通过扩展组织能力的富文本编辑器。

  • Lexical

    可扩展的文本编辑器框架，提供 React 集成。

  • CodeMirror

    通过扩展组合语言与交互能力的网页代码编辑器。

  • react-markdown

    把 Markdown 渲染成 React 元素，支持 remark 与 rehype 插件。

  • markdown-it

    可扩展的 Markdown 解析器。

  • highlight.js

    为代码块提供语法高亮与主题。

  • Shiki

    基于语法与主题资源生成代码高亮。

  • Marked

    将 Markdown 解析为 HTML 的 JavaScript 库，支持扩展 tokenizer 和 renderer。
