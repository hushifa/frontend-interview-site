AI 应用开发资源

AI 前端应用开发资源，收录 AI SDK、LangChain.js 开源库、Transformers.js、ONNX Runtime Web 和 MCP 文档，了解浏览器推理与大模型应用集成。共 7 项资源。

  • AI SDK（开源库）

    组织模型调用、流式输出和工具交互的开源 TypeScript SDK。

  • Transformers.js

    在 JavaScript 中加载预训练模型完成文本、图像和音频等任务的开源库。

  • ONNX Runtime Web

    使用 WebAssembly、WebGPU 等后端在浏览器运行 ONNX 模型的开源运行时。

  • LangChain.js（开源库）

    在 JavaScript/TypeScript 中组合模型、工具和 Agent 流程的开源库。

  • Model Context Protocol

    AI 应用接入工具、资源和上下文的开放协议文档。

  • Promptfoo

    用于比较、评测和安全测试 LLM 提示词与 AI 应用输出的开源工具。

  • LangGraph.js

    用图结构组织带状态、循环、暂停和恢复的 Agent 工作流。
