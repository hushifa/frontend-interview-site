AI 应用开发资源

    为 TypeScript 应用组织模型调用、流式输出与 AI 界面。

  • Transformers.js

    在 JavaScript 中使用预训练模型完成文本、图像等任务。

  • ONNX Runtime Web

    使用 WebAssembly、WebGPU 等方式运行 ONNX 模型。

  • LangChain.js（开源库）

    在 JavaScript / TypeScript 中组织模型、工具和 Agent 工作流。

    AI 应用接入工具、资源和上下文的协议文档。
