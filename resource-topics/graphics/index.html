图表与交互资源

前端图表与交互库，涵盖 ECharts、D3、Chart.js、Three.js、Motion 开源库、Swiper、拖拽排序、虚拟列表与流程图工具。共 13 项资源。

  • Apache ECharts

    通过配置构建常见数据图表与可视化。

  • D3

    提供数据转换、比例尺、布局与可视化基础模块。

  • Chart.js

    基于 Canvas 绘制常见图表。

  • Three.js

    组织浏览器中的三维场景、相机、材质与渲染。

  • Motion（开源库）

    用于网页动画和交互过渡的动画工具。

  • SortableJS

    为列表提供拖拽排序与跨列表移动。

  • TanStack Virtual

    为长列表提供可定制的虚拟滚动基础。

  • Swiper

    提供触摸滑动、轮播与相关模块的交互库。

  • Floating UI

    计算浮层相对于参考元素的位置。

  • dnd kit

    为多个框架提供可组合的拖拽交互能力。

  • React Flow

    构建基于节点与连线的 React 交互编辑器。

  • lottie-web

    在网页中播放兼容的 Lottie 动画数据。

  • PixiJS

    面向 2D 图形和交互内容的渲染引擎，支持 WebGL 与 WebGPU 后端。
