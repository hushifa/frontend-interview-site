图表与交互资源

前端图表与交互库，涵盖 ECharts、D3、Chart.js、Three.js、Motion 开源库、Swiper、拖拽排序、虚拟列表与流程图工具。共 35 项资源。

  • Apache ECharts

    通过配置构建图表、仪表盘和数据可视化的开源库。

  • D3

    提供数据转换、比例尺、布局和可视化基础模块的开源库。

  • Chart.js

    基于 Canvas 绘制常见统计图表的开源库。

  • Three.js

    组织浏览器三维场景、相机、材质和渲染的开源库。

  • Motion（开源库）

    用于网页动画、过渡和手势交互的开源库。

  • SortableJS

    为列表提供拖拽排序和跨列表移动的开源库。

  • TanStack Virtual

    为长列表、网格和表格提供虚拟滚动基础。

  • Swiper

    提供触摸滑动、轮播和模块化交互的开源库。

  • Floating UI

    计算浮层相对于参考元素位置的开源库。

  • dnd kit

    为多个前端框架提供可组合拖拽与排序能力的开源库。

  • React Flow

    构建节点、连线和流程编辑器的 React 开源库。

  • lottie-web

    在网页播放 Lottie 动画数据的开源库。

  • PixiJS

    面向 2D 图形和交互内容的开源渲染引擎。

  • react-window

    提供 React 虚拟化列表和网格组件。

  • Leaflet

    轻量的交互式二维瓦片地图库。

  • OpenLayers

    功能完整的 Web GIS 地图库，支持多种投影和 OGC 服务。

  • MapLibre GL JS

    基于 WebGL 渲染矢量瓦片的地图库，源自 Mapbox GL JS 开源版本。

  • Konva

    带场景图和事件系统的 2D Canvas 库，提供 React、Vue 绑定。

  • Fabric.js

    面向可编辑图形的 Canvas 库，支持对象选择、变换和 SVG 导入导出。

  • hls.js

    基于 Media Source Extensions 在浏览器中播放 HLS 流的库。

  • Video.js

    带皮肤和插件体系的开源 HTML5 视频播放器。

  • 西瓜播放器

    字节跳动开源的 Web 视频播放器，支持 HLS、FLV 和 MP4 分段加载。

  • AntV G2

    基于图形语法、声明式构建统计图表的可视化库。

  • AntV G6

    提供绘制、布局、分析与交互能力的图（关系网络）可视化引擎。

  • AntV X6

    基于 HTML 和 SVG、用于搭建流程图和 DAG 等图编辑应用的引擎。

  • CesiumJS

    基于 WebGL、在浏览器中渲染 3D 地球和 2D 地图的库。

  • Anime.js

    驱动 CSS 属性、SVG、DOM 属性和 JavaScript 对象的动画库。

  • ZRender

    为 Apache ECharts 提供 2D 绘制能力的轻量图形库。

  • VChart

    VisActor 可视化体系中支持桌面、H5 和小程序的图表组件库。

  • Babylon.js

    在浏览器中构建三维场景和交互应用的渲染引擎。

  • Pragmatic drag and drop

    基于浏览器原生拖放 API、与框架无关的底层拖拽工具集。

  • vue-draggable-plus

    基于 SortableJS 的 Vue 拖拽排序组件。

  • Lenis

    基于原生滚动的轻量平滑滚动库。

  • mpegts.js

    在浏览器中播放 MPEG-TS 和 HTTP-FLV 直播流。

  • Vue ECharts

    Apache ECharts 的 Vue 组件封装。
